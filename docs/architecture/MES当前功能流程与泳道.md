## 1. 文档用途

本文只描述当前代码已经具备的业务能力，不混入尚未交付的完整批次谱系、质量处置和设备事件。需要了解未来完整流程时，再查看《MES 业务泳道与角色参与矩阵》。

> `v0.1.354` 补充：生产实绩产出已接入内部批次、自动待检、整批放行/冻结和库存状态流水；这只是生产产出切片，不包含来料、投入和发货批次分配。

## 2. 当前业务链

### 2.1 销售与履约

客户资料 → 销售订单 → 创建或关联发货单 → 确认发货并扣减库存 → 退货审核与返库。

销售订单保存物料、数量、单价、交期和已发数量；发货可以独立登记，也可以关联销售订单及其明细。销售订单目前不会自动生成生产订单，两者由业务人员按实际需求衔接。

### 2.2 来料与成本

供应商资料 → 来料登记 → 接收或拒收 → 库位库存与成本层 → 整单红冲。

来料可以记录数量、单位换算、实测数据、价格、供应商批次号和库位。接收后形成库存、成本层和库存流水；拒收不入库；已接收业务使用反向流水红冲。

### 2.3 生产执行

生产订单 → BOM 快照 → 发布与派工 → 班后生产实绩 → 确认过账 → 产出内部批次与待检任务 → 整批合格放行/不合格冻结 → 进度与成本更新 → 必要时冲销。

生产实绩保存员工、投入物料、产出物料、实际数量和库位。确认时在服务端事务中完成投入出库、产出待检入库、内部批次、质量任务、成本结转、库存流水和订单进度重算。质检员随后整批放行到可用库存或冻结；待检/冻结不能被普通业务消耗。已确认实绩不能删除，只能在库存和成本允许时冲销；已放行批次在尚无批次消费分配的当前版本不能直接冲销。

### 2.4 库存与转移

库存与库位余额 → 流程或库位转移 → 统一库存流水 → 搜索和核对。

库存流水记录数量、核算数量、成本、来源单据、库位、操作人和前后值，并支持智能搜索、高级字段搜索、列表与卡片视图。

### 2.5 独立支撑能力

- 新主流程使用 `QualityInspection` 关联内部产出批次，保存待检数量、样本数、良品数、不良品数、结论、人员、时间和备注，并在一个事务内转换库存状态。旧 `QCRecord` 只保留历史兼容，不作为新生产实绩的质量事实。
- 设备与工作中心已经具备台账和基础配置，但没有运行、停机、故障、点检和保养事件闭环。
- 附件、业务单据打印、二维码、权限、审计和数据维护作为公共模块被业务页面复用。

## 3. 当前边界

1. 当前只支持生产产出整批合格或不合格，不支持部分放行、复检、让步、返工、报废和解冻。
2. 来料可以保存供应商批次号，但尚未形成内部批次；投入和发货也未分配批次，因此没有完整投入产出谱系和客户反向追溯。
3. 销售订单、来料、生产订单和发货可以独立运行，不存在复杂 ERP/MRP 跨域自动编排。
4. 当前生产记录偏班后实绩，不等同于设备实时采集、OEE 或 APS 排程。
