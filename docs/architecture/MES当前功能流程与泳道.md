## 1. 文档用途

本文只描述当前代码已经具备的业务能力，不混入尚未交付的序列号、通用检验模板、设备保养/维修工单或 OEE。需要了解未来目标流程时，再查看《MES 业务泳道与角色参与矩阵》。

> `v0.1.370` 补充：来料、生产投入/产出、客户发货和退货回流均已形成内部批次关系；质量任务支持完整处置，批次追溯可多跳展开。岗位任务、生产命令、数据范围和临时授权已落地，业务资源现为 50 项；设备事件与周期点检已贯通，异常点检可联动故障事件。

## 2. 当前业务链

### 2.1 销售与履约

客户资料 → 销售订单 → 创建或关联发货单 → 确认发货并按批次扣减库存 → 从原发货登记退货 → 收货进入独立待检批次 → 整批/部分判定 → 必要时复检、返工、报废或授权放行。

销售订单保存物料、数量、单价、交期和已发数量；发货可以独立登记，也可以关联销售订单及其明细。销售订单目前不会自动生成生产订单，两者由业务人员按实际需求衔接。

### 2.2 来料与成本

供应商资料 → 来料登记 → 接收或拒收 → 内部批次/供应商批号 → 库位库存与成本层 → 流程转移同步批次余额 → 安全条件下整单红冲。

来料可以记录数量、单位换算、实测数据、价格、供应商批次号和库位。接收后形成库存、成本层和库存流水；拒收不入库；已接收业务使用反向流水红冲。

### 2.3 生产执行

生产订单 → BOM 快照 → 发布与派工 → 班后生产实绩 → 投入批次 FIFO 分配 → 确认过账 → 产出内部批次与投入谱系 → 待检任务 → 整批/部分判定 → 复检、返工、报废或授权放行 → 进度与成本更新 → 满足安全条件时冲销并恢复投入批次余额。

生产实绩保存员工、投入物料、产出物料、实际数量和库位。确认时在服务端事务中完成投入出库、产出待检入库、内部批次、质量任务、成本结转、库存流水和订单进度重算。质检员可整批或部分判定，处置人员可申请复检、转返工或报废，质量主管可让步或解冻；待检、冻结和返工中库存不能被普通业务消耗。已确认实绩不能删除，只能在库存、成本、批次状态和下游分配均允许时冲销。

### 2.4 库存与转移

库存与库位余额 → 流程或库位转移 → 统一库存流水 → 搜索和核对。

库存流水记录数量、核算数量、成本、来源单据、库位、操作人和前后值，并支持智能搜索、高级字段搜索、列表与卡片视图。

### 2.5 独立支撑能力

- 新主流程使用 `QualityInspection` 保存每轮待检与判定，使用 `QualityDisposition` 保存每次判定、复检、返工、报废、让步和解冻事实，并在一个事务内更新批次、库存、成本层与流水。旧 `QCRecord` 只保留历史兼容，不作为新生产实绩的质量事实。
- 设备与工作中心已经具备台账和基础配置；运行状态只能通过开机、停机、故障、恢复事件改变。周期点检按设备建立不可覆盖的标准，到期后逐项保存实测、结果、人员和附件；异常可同事务进入故障时间线。保养、维修工单、自动采集和 OEE 尚未贯通。
- 附件、业务单据打印、二维码、权限、审计和数据维护作为公共模块被业务页面复用。

## 3. 当前边界

1. 质量处置已覆盖整批/部分判定、复检、返工、报废、让步和解冻；检验项目模板、抽样方案、质量附件和复杂审批流尚未建设。
2. 批次级供应商到客户及退货回流已经贯通，并已提供跨批次搜索全景；尚无逐件序列号和客户指定批次拣货。
3. 销售订单、来料、生产订单和发货可以独立运行，不存在复杂 ERP/MRP 跨域自动编排。
4. 当前生产记录偏班后实绩，不等同于设备实时采集、OEE 或 APS 排程。
