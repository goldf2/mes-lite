# MES-lite 混合系统功能边界矩阵

状态：`v0.1.386` 架构基线，后续功能立项、模块责任和外部系统边界必须遵循
日期：2026-08-15

## 1. 决策摘要

MES-lite 采用“**MES 为核心、MRP 与 ERP 有限支持**”的产品边界：

- **MES 核心**负责把生产任务变成可执行、可记录、可追溯的现场事实，是系统必须保持完整的主能力。
- **MRP-lite**负责从需求、BOM 和库存推导缺料及建议，不建设复杂 APS、全自动采购或多工厂全局优化。
- **ERP-lite**只补齐独立运行所需的客户、供应商、销售、来料计价、发货和退货，不扩展总账、应收应付、税务、发票、资金和薪资。
- **共享平台**统一提供账号权限、附件、搜索、审计、AI、显示设置和数据维护，不在各能力域重复开发。
- 有外部 ERP 时，由 ERP 负责商业主数据和财务口径，MES-lite 通过接口接收任务、回传生产实绩；没有外部 ERP 时，系统内的计划与经营辅助能力形成轻量闭环。

MES、MRP-lite、ERP-lite 是**能力责任边界**，不是用户需要切换的三个顶层系统，也不是三套前端、数据库或部署。产品采用一个统一 MES 工作台和模块化单体：左上角可显示 MES-lite 主按钮和不可点击的 MRP/ERP 预留按钮，按钮名称及预留按钮显隐可配置，但它们不切换菜单、权限或数据。菜单按现场任务和功能区组织，领域模块继续保持独立责任，避免重复物料、库存、附件、权限和页面框架。

## 2. 标记说明

### 2.1 责任标记

| 标记 | 含义 |
| --- | --- |
| **主** | 该工作域是能力的业务负责人和事实来源 |
| **用** | 使用该能力或向负责人提供输入，不拥有最终口径 |
| **接** | 主要通过接口同步，不在本系统重复建设 |
| — | 不属于该工作域 |

### 2.2 当前状态

| 状态 | 含义 |
| --- | --- |
| **已有** | 已有可用页面或业务流程 |
| **部分** | 已有基础数据或操作，但尚未形成完整业务闭环 |
| **规划** | 属于目标边界，尚待实现 |
| **不建设** | 明确排除在 MES-lite 产品范围外，交由外部系统 |

## 5. 边界页面的字段级规则

一个页面同时服务多个能力域时，仍只保留一套页面和数据模型，通过字段分区、权限及部署模式控制，不复制页面。

| 共享对象 / 页面 | MES 负责字段 | MRP 使用字段 | ERP 负责字段 |
| --- | --- | --- | --- |
| 物料 | 编码、名称、规格、生产单位、BOM、路线、质量和追溯属性 | 计划策略、损耗、提前期、安全库存 | 销售/采购单位、税务分类、商业价格 |
| 物料变体 | 变体维度、规格组合、可生产 SKU、工艺差异 | 变体级需求和库存可用量 | 变体级销售/采购编码和价格 |
| 来料单 | 实收数量、单位、批次、实测、检验、库位、附件 | 在途到货和可用日期 | 供应商、采购单、单价、税率、结算口径 |
| 库存 | 实物数量、库位、批次、质量状态、预留、流水 | 可用量、在途、需求占用 | 计价方法、成本层、财务库存价值 |
| 销售订单 | 可生产性反馈、生产关联、实际交付 | 独立需求、需求日期、优先级 | 客户、价格、金额、商业状态和交付承诺 |
| 生产订单 | 状态、工序、投料、产量、损耗、人工、机时 | 建议来源、需求追溯、计划日期 | 外部订单号、成本结转和完工回传标识 |
| 工作台 | 产量、在制、质量、设备和异常 | 缺料、齐套和建议 | 销售、采购和金额；按当前账号权限显示 |

## 6. 两种部署模式的数据所有权

| 数据对象 | 独立运行模式 | 对接 ERP 模式 |
| --- | --- | --- |
| 物料、单位和 BOM | MES-lite 主控 | 按企业约定：物料商业字段由 ERP 主控，工程字段由 MES-lite 主控 |
| 客户、供应商 | ERP-lite 主控 | 外部 ERP 主控，MES-lite 只读引用 |
| 销售订单 | ERP-lite 主控 | 外部 ERP 主控，MES-lite 接收已确认需求 |
| MRP 计算与建议 | MRP-lite 主控 | 可关闭；或仅做现场缺料校验，不回写正式采购单 |
| 生产订单、派工和报工 | MES-lite 主控 | MES-lite 主控，接收外部来源并回传状态与实际 |
| 实物库存和批次 | MES-lite 主控 | MES-lite/WMS 主控，向 ERP 回传事务或余额 |
| 库存财务价值 | 基础参考口径 | 外部 ERP 主控，MES-lite 不反向覆盖 |
| 发货和退货 | ERP-lite 发起并完成库存事务 | ERP 发起；MES-lite/WMS 执行并回传实绩 |
| 附件和生产文档 | MES-lite 主控 | MES-lite 主控，外部系统通过资源标识引用或同步 |

## 7. 统一工作台与功能分区

### 7.1 当前导航合同

| 功能区 | 包含能力 | 用户入口 |
| --- | --- | --- |
| **工作台** | 岗位待办、生产/库存概况、全部功能、帮助中心 | 统一首页 |
| **生产与质量** | 生产订单、派工、流程转移、质量任务 | 同一导航按权限展示 |
| **物料与工程** | 物料、BOM、BOM 用量、工艺、路线和作业文档 | 同一导航按权限展示 |
| **仓储与物流** | 来料、库存、批次全景、库位和库存流水 | 同一导航按权限展示 |
| **销售履约** | 客户、销售订单、发货和退货 | 同一导航按权限展示 |
| **设备** | 设备台账、运行事件、点检、维保和备件领用 | 同一导航按权限展示 |
| **配置与系统** | 主数据配置、显示、导航、AI、数据工具和权限 | 同一导航按权限展示 |

应用壳不再使用 MES/MRP/ERP 选项卡切换工作区，只保留模块预留按钮。MES-lite 主按钮始终显示，MRP/ERP 可改名或隐藏；显示时保持禁用，代表未来模块位置。管理员在“系统设置 → 导航设置”中同时配置模块按钮和统一工作台的一级功能区顺序、页面显示名称、页面顺序；页面 ID、路由、权限资源、附件、审计及业务数据保持不变。系统版本只显示在左侧导航底部。

`interface.workspaceNavigation.v1` 为兼容既有安装继续保留原数据形状。读取时按 MES → MRP → ERP 的历史顺序合并页面，保留第一次出现的自定义名称和顺序，补回系统新增页面，然后将旧 MRP/ERP 容器设为禁用且清空。该兼容过程不迁移业务表，也不扩大任何账号权限。

当前 MRP-lite 只有 BOM 结构与用量检查基础，没有完整净需求、缺料、齐套和采购/生产建议引擎；现有经营协同也没有总账、应收应付、税务和完整采购。产品介绍必须明确这些边界，不能用顶层系统标签制造功能完整的假象。

### 7.2 后续模块行为

- 新增净需求、缺料、齐套和建议单时，进入“计划与物料”功能区，不重新增加顶层 MRP 工作区。
- 对接外部 ERP 时，通过接口所有权、字段只读规则、权限或部署配置控制经营功能，不重新增加顶层 ERP 工作区。
- 隐藏功能不等于删除数据，重新开放或接口同步时历史关系仍须可追溯。
- 若未来增加能力开关，页面、API、权限和搜索必须读取同一配置，不能只隐藏前端按钮。

## 8. 明确不建设的范围

以下能力不进入 MES-lite 主产品路线：

- 总账、会计凭证、财务报表、应收应付、资金和付款。
- 发票、税务、报税、薪资和完整人事管理。
- 完整 CRM、营销自动化、售后服务和供应链协同平台。
- 多组织合并报表、集团财务和跨法人结算。
- 高级需求预测、S&OP、复杂 APS 和全局最优排程。
- 专业 WMS 的波次、自动仓设备调度和运输路线优化。

这些能力通过稳定业务标识、状态回传和集成接口与专业系统协作，不在 MES-lite 内创建简化但不可维护的平行实现。

## 9. 建设优先级

1. **补强 MES 核心闭环**：工序报工、投退料、质量、不合格处置、批次/序列追溯、设备事件。
2. **统一共享主数据**：物料变体、版本化 BOM、工艺路线和单位规则，消除不同页面的隐含口径。
3. **建设 MRP-lite 垂直切片**：需求输入 → BOM 展开 → 可用量 → 缺料 → 建议生产/采购，全流程可解释、可追溯。
4. **收敛经营协同**：保留独立运行必要能力，增加外部 ERP 接口，不继续向财务系统扩张。
5. **统一边界页面**：按字段所有权拆分展示区和权限，而不是复制来料、库存、物料和工作台页面。

## 10. 新功能立项检查

每个新功能在开发前必须回答：

1. 业务事实由生产执行、计划、经营协同还是共享平台负责？
2. 独立运行和对接 ERP 两种模式下，谁是数据主控方？
3. 当前能力是否已真实形成输入、处理、输出、库存/成本/追溯/冲销闭环，还是只能作为规划？
4. 是否能复用现有物料、库存、附件、搜索、权限和页面框架？
5. 是否进入了本文件明确“不建设”的范围？如果是，应改为接口而非本地模块。

验收时至少确认：不存在重复主数据或重复库存账；不同功能区使用同一记录 ID；所有同步和状态变化可审计；隐藏经营辅助入口时 MES 仍能完整执行生产。
