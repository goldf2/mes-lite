# MES-lite 系统时序图

本文记录 v0.1.310 的关键交互与业务时序。系统定位为 MES 主体、有限 MRP/ERP 支持，不在当前阶段实现跨域自动编排。

## 1. 页面打开与形态切换

```mermaid
sequenceDiagram
  actor U as 操作人员
  participant N as 主导航
  participant H as 页面注册与应用壳
  participant P as 主显示区
  participant D as 公共 ModalDialog

  U->>N: 选择一级功能页面
  N->>H: navigate(pageKey)
  H->>P: 以页面模式渲染

  U->>P: 点击详情、新建或编辑
  P->>H: open(content, source=content)
  H->>D: 默认以弹窗模式渲染
  U->>D: 点击全屏图标
  D->>D: 同一业务组件占满可视窗口
  U->>D: 再次点击全屏图标或按 Esc
  D->>D: 还原原弹窗并保留上下文
```

规则：主导航始终进入主显示区；页内资源操作默认弹窗；公共弹窗只保留一个可逆的全屏图标，不再提供“在主页面打开”平行形态。命令型操作在当前上下文执行。复杂工作区可以在页面注册中声明例外，不在每个页面重复实现打开逻辑。

## 2. 销售订单与默认销售价

```mermaid
sequenceDiagram
  actor U as 销售人员
  participant UI as 销售订单页面
  participant API as Sales Order API
  participant M as Material
  participant SO as SalesOrder / Item
  participant A as AuditLog

  U->>UI: 新建销售订单并选择物料
  UI->>M: 读取默认销售价与币种
  M-->>UI: defaultSalePrice, salesCurrency
  UI->>UI: 自动带入价格，允许手工覆盖
  U->>UI: 保存订单
  UI->>API: 客户、日期、物料、数量、可选单价
  API->>M: 再次读取当前默认价
  API->>SO: 写入订单、单价、默认价快照、价格来源
  API->>A: 记录创建审计
  API-->>UI: 返回订单

  opt 尚未产生发货记录时调整价格
    U->>UI: 调整价格并填写原因
    UI->>API: PATCH prices
    API->>SO: 校验状态与发货关系
    API->>SO: 更新明细和订单合计
    API->>A: 写入调价前后快照与原因
    API-->>UI: 刷新订单
  end
```

价格是销售快照，不是动态引用。物料只保存默认销售价；成本继续由 BOM、来料成本层或手工成本流程计算，不在物料主数据增加成本字段。

## 3. 独立发货与可选来源关系

```mermaid
sequenceDiagram
  actor U as 仓库人员
  participant UI as 发货管理
  participant API as Shipment API
  participant SO as SalesOrder Item
  participant I as Inventory Service
  participant S as Shipment
  participant F as 附件与 PDF

  U->>UI: 新建发货单
  alt 关联销售订单
    U->>UI: 选择未发完的订单明细
    UI->>API: salesOrderItemId、库位、数量
    API->>SO: 校验订单状态和剩余数量
    API->>I: 校验库位可用量
    API->>S: 冻结订单客户、物料和单价快照
  else 独立发货
    U->>UI: 选择客户、物料、库位并可填凭证和单价
    UI->>API: customerId、materialId、locationId、数量
    API->>I: 校验库位可用量
    API->>S: 创建无销售来源的发货单
  end
  U->>F: 上传附件或调用 AI 识别
  F-->>S: 绑定附件
  API-->>UI: 返回发货单并输出 PDF

  Note over S,SO: 只有显式关联时才更新订单进度；独立发货不自动创建或修改销售订单
```

## 4. MES、MRP、ERP 当前协作边界

```mermaid
sequenceDiagram
  participant ERP as ERP 轻量能力
  participant MRP as MRP 轻量能力
  participant MES as MES 核心
  participant DB as 统一业务数据库

  ERP->>DB: 客户、销售订单、默认销售价
  MRP->>DB: BOM、需求和生产订单基础数据
  MES->>DB: 实绩、库位、库存流水、质量、设备
  Note over ERP,MES: 当前仅共享主数据和显式业务关系
  Note over ERP,MES: 不自动执行销售转计划、计划转工单、工单转发货
```

## 5. 权限组与人员授权

```mermaid
sequenceDiagram
  actor A as 权限管理员
  participant UI as 人员/组权限页面
  participant API as Permissions HTTP Adapter
  participant S as Identity Access Service
  participant DB as Prisma Transaction
  participant Audit as AuditLog

  A->>UI: 修改权限组或人员分组
  UI->>API: 提交字段化权限契约
  API->>S: 当前操作人 + 已校验输入
  S->>S: 校验资源 grant 与权限组可分配范围
  S->>DB: 原子替换权限组设置/人员分组
  DB-->>S: 变更前后快照
  S-->>API: 审计数据
  API->>Audit: 写入请求级操作审计
  API-->>UI: 权限已保存
```

权限 API 只处理 HTTP、会话入口、审计和错误映射；权限契约、授权规则与事务归 `modules/identity-access`，避免页面、API 和数据库写入各自维护一套授权逻辑。
