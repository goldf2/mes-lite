# MiniERP 功能模型

## 当前轻量主线

当前默认启用轻量生产业务模式。业务菜单优先保留：

- 生产日报：记录每日产出数量、产出库位、原料耗用和生产批次；成品、不良、报废等去向由库位配置表达。
- 仪表盘：同时汇总工单流和独立生产日报流。生产记录数分别展示工单/日报来源，产量由工序报工合格数与已确认日报产出组成；日报草稿进入待处理，已冲销日报不计入有效日报数量和产量。
- 物料与 BOM：作为物料主数据和 BOM 关系的统一一级入口。
- 物料管理：维护物料档案、分类、规格、单位和成本核算基础，列表不混入 BOM 编辑工作区。
- 物料 BOM 关联：同一产出物料可维护多个方案/版本和基准批量，并指定一个默认启用 BOM；界面同时显示单位用量。
- BOM 反查：按原材料汇总所有引用它的产品 BOM，并可跳转到物料 BOM 关联；物料列表的 BOM 简况同时显示自身组成和作为原材料被引用的数量及摘要。
- 来料管理：记录原材料到货、收货和库存增加；来料单并列保存件数、总长度、总重量，采购单价可按米、kg、件计价，并与总价格双向换算。
- 工单管理：记录生产计划、领料、报工和成品入库。
- 库存管理：查询物料库存、库存金额、库存预警和物料封面图，并通过存货调整处理盘点差异。
- 发货管理：记录成品出库、送货单和客户发货。
- 库位管理：在“配置”中维护库位；来料、生产日报、发货和退货使用同一套库位实物余额。生产日报确认的产出入库可直接作为对应库位库存，成品、不良、报废等业务类别不再写死。
- 退货管理：创建退货单时必须选择退回库位，处理后增加该库位与物料总库存；拒绝退货不改变库存。
- 供应商资料：业务人员只维护名称、联系人、电话和地址；内部唯一编码由系统自动生成且不在业务界面展示。
- 产品文档：选择产品后维护图片或 PDF；文档类别支持可配置的一级/二级结构，“作业指导书”是默认一级类别，可增加“机床作业、环境作业”等二级类别。产品文档不保存适用工序，通用说明使用备注；PDF 使用第一页缩略预览，打开文件默认进入全屏查看并按完整页面适配。每个文件可左右旋转并保存方向校正，卡片、全屏查看和产品全景图使用同一方向。产品全景图完整展示该产品的全部相关文档。
- 工作中心：在“配置”中维护锯切、钻孔、检验等逻辑能力区域；工艺文件可选择多个适用工作中心，未选择表示通用。
- 设备台账：作为“设备”一级入口维护实际设备、类型、厂商、型号、状态、位置、基础参数及工作中心归属；具体加工方法继续由工艺文件表达。
- 关键词筛选：物料、来料、工单、库存、发货、退货和产品文档等主列表必须支持输入文字快速检索，拉丁字母统一忽略大小写；当前搜索词可保存为当前浏览器、当前页面独立的快捷搜索，后续点击直接应用。

BOM 能力保留在轻量模式主线中，并收敛到顶部“物料”分类下的左侧分级菜单；派工暂时作为隐藏高级模块，不在轻量模式主菜单中展示。一级业务分类为工作台、物料、生产、设备、物流、库存、配置、工具：“设备”维护设备台账；“配置”收纳供应商资料、客户资料、库位配置、单位配置、工作中心、加工工艺、物料路线和系统设置；“工具”保留锯切成本、硬件工具、归档记录、操作记录和数据工具；右上角账户菜单只保留人员和权限。硬件工具第一阶段提供独立的 Honeywell 1900 扫码计数底座与 PC310T 标签打印底座，暂不把扫码结果绑定发货单或强制触发标签打印。

### 硬件工具底座

- Honeywell 1900 按 USB HID 键盘模式接入，默认以 Enter 或 Tab 作为一条扫码输入的结束符。
- 扫码计数会话独立保存目标条码、目标数量、累计数量、设备型号和状态。
- 每次扫码保存原始值、规范化编码、数量与匹配结果，支持撤销最后一次有效扫码。
- PC310T 配置固定为 203 dpi、网线连接；默认介质为 105 × 70 mm（840 × 560 dots），可选择已有 100 × 150 mm 介质或输入自定义宽高。
- 标签编辑、Code 128 渲染和浏览器打印独立于扫码会话；打印请求单独记录。
- 打印机 IP 目前作为客户机配置保存，网络静默打印后续通过 QZ Tray 或独立局域网打印桥接模块实现。

## 一级模块说明

### 1. 首页

目标：让老板或管理员打开系统就知道经营状态。

第一版指标：

- 当前库存 SKU 数
- 低库存 SKU 数
- 今日入库数量
- 今日出库数量
- 近 7 天销售数量
- 待确认单据数

### 2. 基础设置

目标：配置系统使用边界。

功能：

- 租户资料维护
- 员工账号维护
- 员工启用/停用
- 角色权限配置
- 门店维护
- 仓库维护

第一版可以预置角色，减少自定义权限配置工作。

人员注册和审核：

- 操作人员提交注册。
- 首位注册人员自动成为管理人员。
- 后续注册人员默认待审核。
- 审核通过后才能登录系统。
- 角色分为提交、审核、管理。

### 2.1 管理类页面

目标：维护不属于日常单据流转的基础数据，同时避免再套一层“系统管理”页内导航。

第一版包含：

- 加工工艺、物料路线从“生产”菜单进入
- 供应商、客户资料从“物流”菜单进入
- 归档记录、操作记录、数据工具和系统设置从“工具”菜单进入
- 人员管理、人员权限和组权限保留在右上角账户菜单
- 供应商新增、编辑、归档、搜索
- 业务页面只允许归档；“工具 / 归档记录”可永久删除没有有效业务引用的主数据、未生效单据，以及库存和成本净影响已完整冲销的来料单
- 永久删除前必须输入“永久删除”确认；自有附件随主体删除，未冲销库存、BOM、下游单据、扫码或打印记录等有效引用仍会阻止删除
- 数据工具可预检并一次性将全部物料编码删除空白、转换为大写；存在空编码或重复编码时禁止执行
- 物料编码转换同步内部兼容 `Product.sku`，使用事务并写入操作记录
- 数据工具可扫描 BOM 单位漂移、重复/自引用/无效明细、产出单位漂移、日报失效 BOM 指针和有效成本层旧单位风险
- 可安全处理的问题允许逐条同步单位标签或删除错误 BOM 明细；日报保留耗用快照，只清空失效指针；有效库存和成本层禁止直接删除
- 修复和删除执行前会在事务内重新扫描问题，全部写入操作记录；单位同步不换算任何数量和金额
- 系统设置可开启物料编码数字自然排序；设置对所有客户端生效，物料列表和导出统一得到 `2 < 12`、`A2 < A10` 的顺序
- 自然排序开关不修改编码内容，关闭后恢复数据库字符串排序

后续扩展：

- 物料路线维护
- 工单显式选择 BOM 版本并保存快照
- 工艺路线和工序维护
- 客户资料维护
- 新增或导入时的持续业务编码规则
- 系统备份和操作日志

### 2.2 成本计算

目标：先为小微制造企业提供独立于派工的物料关系型 BOM，再在数据稳定后扩展 BOM 成本测算。

当前实现：

- 物料 BOM 关联页可为同一产出物料新建多个方案/版本，设定方案名称、基准产出数量、生产转换/一对一基础转换类型和默认状态。
- 界面可用“标准用量 + 损耗”或“成品数量 : 原料数量”录入，操作员仍编辑每 1 个产出单位的用量；服务端按基准产出数量保存批量输入关系。
- 生产日报按 BOM 换算比例和总加工数量计算基准耗用；每种原料可选择本批次额外的固定或百分比损耗，并允许修正实际耗用。
- 当前轻量流程不设置领料步骤；日报确认时直接扣减实际耗用，并由库存成本层换算对应重量/参考数量与成本。
- BOM 反查页独立汇总某个物料被哪些 BOM 使用，并可点击结果跳转到物料 BOM 关联。
- 锯切费用计算器可保存为临时成本对象或绑定已有物料，并可加入指定物料 BOM。
- 成本对象保存单位材料成本、单位人工工时、单位机时和其他单位直接费用。
- BOM 成本页按产品筛选，以 BOM 单位消耗量乘数量基准，并结合人工费率、机时费率和固定费用分摊计算成本快照；生产日报的本次损耗不自动带入成本试算。
- BOM 成本快照保存汇总和明细行，可回看历史计算结果。
- BOM 成本页的“成本数据”页签可新增手工成本对象，并集中查看成本对象、物料 BOM、默认工艺路线、可计算加工工艺和最近成本快照。
- 物料全景图展示该物料关联的加工工艺参数、推导工艺路线成本、相关成本对象和产品最新 BOM 成本快照。

边界：

- BOM 第一阶段负责“成品对应哪些原材料、每一成品主单位标准消耗多少”，不保存生产批次损耗或实际耗用。
- 用户可以从物料 BOM 关联页维护多方案和批量输入/产出关系；单位用量是批量数据的界面派生值。
- 用户侧不再维护独立 `Product` 主数据；旧业务表需要产品外键时，由后端从物料自动生成内部兼容视图。
- 派工负责“怎么做、谁来做、何时做”。
- BOM 成本计算不生成派工、不占用库存；当前轻量流程没有领料步骤，生产日报确认时按实际耗用直接扣减库存。
- 房租、设备折旧等期间性固定费用不建议写入 BOM 本体，当前作为一次成本测算的分摊项保存。

### 3. 商品资料

目标：建立库存管理基础。

功能：

- 商品分类
- 商品档案
- SKU 规格
- 条码
- 单位
- 默认采购价
- 默认销售价

目标：管理客户和供应商。

功能：

- 客户列表
- 供应商列表
- 联系人
- 电话
- 地址
- 停用

客户和供应商底层可以共用一套数据。

### 5. 采购管理

目标：记录进货和入库。

第一版最小闭环：

```mermaid
flowchart LR
```

后续增强：

- 采购订单
- 部分入库
- 采购退货
- 供应商对账

### 6. 销售管理

目标：记录出货和客户销售。

第一版最小闭环：

```mermaid
flowchart LR
    A[选择客户] --> B[选择出库仓库]
    B --> C[添加SKU和数量]
    C --> D[校验可用库存]
    D --> E[保存出库单]
    E --> F[确认出库]
    F --> G[减少库存余额]
```

后续增强：

- 销售订单
- 部分出库
- 销售退货
- 客户对账

### 7. 库存管理

目标：保证库存数量可信。

功能：

- 当前库存查询
- 按仓库查库存
- 按 SKU 查库存流水
- 库存盘点
- 库存调整
- 低库存预警

### 9. 原始单据

目标：每一张业务单据都能保留原始凭证，方便追溯、对账和审计。

适用对象：

- 采购入库单
- 销售出库单
- 来料单
- 发货单
- 退货单
- 派工单
- 库存调整单
- 盘点单
- 生产工单

第一版能力：

- 上传单据照片
- 上传 PDF
- 查看附件缩略图
- 打开原图或 PDF
- 归档误传附件

附件不要分散存到每张业务表，应使用统一附件表，通过 `ownerType + ownerId` 关联业务对象。

## 关键验收场景

1. 管理员创建仓库、员工、商品和供应商。
2. 仓管在小程序创建采购入库单并确认入库。
3. 系统库存余额增加，并能看到采购入库流水。
4. 销售在小程序创建销售出库单并确认出库。
5. 系统库存余额减少，并能看到销售出库流水。
6. 管理员在 Web 后台查看当前库存、低库存预警和销售汇总。
7. 同一个微信用户可以选择进入不同租户身份。
