# MiniERP 功能模型

## 当前轻量主线

当前默认启用轻量生产业务模式。业务菜单优先保留：

- 生产订单：先保存目标产出、可选已发布 BOM、计划数量和凭据信息；使用 BOM 时冻结版本及全部投入/产出，不使用时建立临时生产/转换。班后在订单详情登记一名或多名员工、各项实际投入/损耗/来源库位和全部实际产出/去向库位；BOM 只负责预填，允许按实际增删和修正。投入可以是原材料、半成品或已有产品。
- 流程转移：独立于生产订单实绩，不使用 BOM；选择一名启用员工后，将同一物料按同一数量在两个不同库位或流程节点之间移动，总库存和总成本不变。草稿、确认移库和有原因冲销分别受通用页面权限、`flowTransferConfirm.update` 与 `flowTransferReverse.update` 控制。
- 仪表盘：订单按创建时间统计；完整生产订单实绩继续独立显示。BOM 快捷生产日报在自身页面汇总投入与产出，避免与订单实绩重复计数。
- 物料与 BOM：作为物料主数据和 BOM 关系的统一一级入口。
- 物料管理：维护物料档案、分类、规格、单位和成本核算基础，列表不混入常驻 BOM 编辑工作区；有 BOM 权限时继续显示可隐藏的 BOM 简况，支持按未建立、无启用方案、无默认方案和已有可用默认 BOM 筛选，并可从单个物料打开宽模态窗口快速创建 BOM，保存后留在当前列表并刷新简况。
- BOM 设置：左侧一条记录直接对应一个 BOM 版本，以 BOM 名称、版本号和草稿/已发布/已作废状态为主信息。BOM 用途分为生产和包装；包装 BOM 只允许一项产出，并参与库存包装穿透。右侧使用左输入、右输出的整批配方编辑器：两侧都可搜索并添加多项物料，每行填写每批数量；单位目录负责同量纲换算，物料配置标准单重或标准单位长度重量后还可按重量或长度录入并换算，保存主库存数量与原始录入/换算快照。全部输入共同对应全部输出，不建立逐输出投入关系。首项输出是主产出，废料、废屑和可回收料作为其他输出添加。草稿可保存和编辑；发布后自动成为当前用途的默认 BOM 且不可原地修改；变更必须复制为唯一新版本，已发布版本只能作废不能删除。
- BOM 全览：以统一物料为中心，同时汇总它“作为产出”和“作为投入”关联的全部直接 BOM；左侧筛选并选择物料，右侧分区显示双向关系，每项可精准跳转到对应 BOM 设置。物料列表的 BOM 简况继续显示自身产出关系和作为投入被引用的数量及摘要；“创建 BOM”在当前页打开快速创建模态窗口并将当前物料预选为主产出，复杂维护可再进入完整 BOM 设置。
- 来料管理：一张来料单可添加多种物料，所有明细先整单进入同一待分库库位，之后用流程转移分库；收货时每行生成内部批次并保留供应商批号。物料存在已发布的来料检验标准时，该行进入待检并自动生成标准快照任务；无标准时直接可用，多行单据允许两种路径并存。每行必须填写主单位实收量，双单位物料可填写一个辅助单位实测量。辅助实测缺失时，仅在至少 3 批同单位版本的已收货实测记录可用后按加权历史推算，推算记录不反向进入样本；采购单价可按主单位或辅助单位计价，并与总价格双向换算。
- 生产订单：已统一承载事前计划、产后补录和班后实绩；BOM 是可选标准转换预设，也允许无 BOM 临时生产/转换。确认实绩时以本批实际明细原子扣减全部投入、增加全部产出并累计订单目标产出数量；无 BOM 或含临时明细必须说明，已确认事实可合法冲销。
- 质量任务、标准与处置：标准按物料和生产/来料/退货来源版本化，支持全检、固定或比例抽样及有序项目；新实绩、客户退货和启用标准的来料为每个内部批次建立待检任务并快照当时生效标准、建议抽样数与项目。质量工作台支持逐项结果、整批/部分判定、附件、趋势、复检、返工开始与完成送检、报废、让步放行和解冻放行。每个动作原子更新批次余额、库存流水、成本层和审计人；普通领料、发货与调整只消费可用库存。
- 生产日报：使用“BOM 生产转换”，默认按“计划产出 → 已发布 BOM”建立预填基准，也可按现场已有投入辅助反查；系统把 BOM 比例直接填入可编辑的实际投入与实际产出行，主产出原位修改会同比例更新尚未手工修正的其它行，不再提供重复的计划数量输入框。每行显示所选库位及权限范围库存供审核参考，操作员复核实际明细后原子扣料、入库、结转成本和写审计。BOM 只是可选预设，仍允许有原因地无 BOM 临时生产/转换；确认后的日报作为不可覆盖流水保留，具备独立权限的岗位只能通过填写原因进行受控冲销，系统追加与原流水双向关联的反向库存流水。待检模式同时创建批次与质量任务，但不创建生产订单、派工或报工；库存盘点保持为库存菜单下的独立页面。
- 库存管理：查询物料总库存、库位余额、库存金额、库存预警和物料封面图；列表与详情显式展示可用、待检、冻结和返工中数量，按库位调整只处理可用余额，待检/冻结/返工中不能被普通调整或业务出库消费。报废数量保留在批次处置记录和流水中，不进入可用库存。包装 BOM 只读穿透整箱等包装物料库存，将散装实际库存与包装等效数量汇总展示，但不写回库存账。
- 销售订单：按客户登记一张订单中的多项成品、数量、单价和计划交付日期；物料默认销售价可自动带入并手工覆盖，订单本身不扣库存，也不派生或绑定发货单。页面按客户与物料动态显示需求、待发、已发、未发和超发参考。
- 发货管理：独立登记一个客户和一至多条实际发货物料，不保存销售订单 ID，也不回写订单明细或状态；数量允许超过销售需求，参考量不形成约束。待发货阶段可建立多个货箱单据，保存箱内数量、装箱人、重量/尺寸、封签与现场照片。没有货箱时兼容简化发货，一旦装箱则要求箱内合计等于发货数量。确认发货后逐明细扣减库位和总库存，按各库位可用内部批次 FIFO 保存实际发货批次及客户去向；货箱状态同步发货与签收。已发货记录可下载带发货二维码和货箱摘要的发货单 PDF，并从详情查看批次谱系。
- 业务单据打印：来料、销售订单、发货、退货、生产订单、派工和流程转移均在保存后从清单或详情独立打印，不把 PDF 生成并入保存事务。统一 A4 纵向模板提供紧凑/标准密度和 8–20 mm 页边距；默认 10 mm 紧凑版支持 14 条常规来料明细单页，更多明细自动分页，设置变化后补打会保留新归档版本。
- 库位管理：在“配置”中维护库位；来料整单先进入统一待分库库位，生产订单实绩、流程转移、发货和退货继续使用同一套库位实物余额。生产产出的待检、可用和冻结由库存状态表达，不再依赖库位名称模拟。
- 退货管理：创建退货单必须选择已发货/已签收且仍有可退数量的原发货单和退回库位；物料自动继承，服务端防止超额退货。确认收货后生成独立退货批次并先进入 `QUARANTINE`，保留原发货及原内部批次关系；质量整批放行后才进入可用库存，不合格转冻结。草稿、接收入库和有原因拒绝分别受 `return`、`returnReceive` 与 `returnReject` 控制；拒绝不改变库存并写操作审计。
- 供应商资料：业务人员只维护名称、联系人、电话和地址；内部唯一编码由系统自动生成且不在业务界面展示。
- 员工资料：在“业务配置”中维护姓名、部门、电话和启用状态，员工编码由系统按 `EMP-000001` 格式自动生成并锁定，供班后生产实绩与流程转移选择；可选绑定一个已注册账号且账号不可被其他员工重复绑定，账号审核、角色和权限在“账号与权限”一级导航中独立维护。
- 人员权限：当前 62 个资源把页面维护、CAD 预览设置、库存正向过账、销售履约确认和高风险逆向动作分开；在账号所属权限组之外配置本人/工作中心生产范围和库位库存范围。短期替岗使用有原因、授权人、开始时间和失效时间的个人临时授权，到期自动失效。列表、详情、统计、任务、附件和状态动作必须使用同一服务端范围。
- 产品文档：可在 MES-lite 内直接创建标题和富文本正文，支持标题层级、加粗、斜体、列表、引用、代码块及撤销/重做；正文与通用文件附件可独立或组合使用。文档类别支持可配置的一级/二级结构，产品关联可选；文档不分配工作中心，执行位置由工艺路线、计划、派工与实绩负责。文档页支持一次选择多个同类文件，按“一文件一文档”批量建档；也可勾选同一类别的多篇文档，只批量覆盖明确选择的公共字段。标题、类别、产品、版本、状态、备注和正文属于不可删除的基础字段；每个类别可在页面维护独立扩展字段，未使用字段可编辑或删除，已使用字段只能改名。列表可搜索标题、正文、产品、类别和备注；产品全景图只展示明确关联该产品的全部文档。XLS/XLSX/ODS 使用自托管 LibreOffice 核心查看器直接浏览并保留兼容 PDF，图片、PDF、文本和其他 Office 文件继续支持系统内预览，DWG/DXF 可由附件管理员手动重新生成只读 PDF 与缩略图且不改原文件，其他附件支持下载。
- 工作中心：在“配置”中维护锯切、钻孔、检验等逻辑能力区域；工艺文件可选择多个适用工作中心，未选择表示通用。
- 设备台账：作为“设备”一级入口维护实际设备、类型、厂商、型号、位置、基础参数及工作中心归属，并通过事件命令记录开机、停机、故障、恢复和持续时间；具体加工方法继续由工艺文件表达。
- 设备点检：按设备建立周期计划和稳定检查清单，到期后逐项保存实测值、正常/异常、说明与点检人；异常在设备可用或运行中时同事务生成故障事件，记录可追加现场附件。
- 关键词筛选：物料、来料、工单、库存、发货、退货和产品文档等主列表必须支持输入文字快速检索，拉丁字母统一忽略大小写；当前搜索词可保存为当前浏览器、当前页面独立的快捷搜索，后续点击直接应用。
- AI 协作助手：作为全局业务入口，自动携带当前页面上下文，通过工具白名单查询系统指导、物料、库存、BOM、生产订单和今日/月度经营概览。工具同时受 `aiAssistant` 和目标资源查看权限控制，第一阶段只读且不持久化对话正文；管理员在“配置 / 系统设置”维护国产模型参数并测试连接，页面 API Key 加密保存且不回传浏览器。大段教学说明可由 AI 问答承接，但页面继续保留字段、校验、状态和确认。

BOM 能力保留在轻量模式主线中，并收敛到顶部“物料”分类下的左侧分级菜单；派工暂时作为隐藏高级模块，不在轻量模式主菜单中展示。一级业务分类为工作台、物料、生产、文档、设备、物流、销售、库存、业务配置、系统设置、工具、账号与权限：“物流”保留来料管理，“销售”包含销售订单、发货管理和退货管理，“设备”维护设备台账与设备点检；“业务配置”收纳供应商资料、客户资料、员工资料、库位配置、单位配置、工作中心、加工工艺和物料路线；“工具”保留锯切成本、硬件工具、归档记录、操作记录和数据工具；“账号与权限”收纳登录账号和权限维护，右上角账号菜单只显示身份、版本与退出登录。硬件工具继续保留独立扫码计数底座，同时增加 BX 货箱单据与 SH 发货单据的扫码解析和二维码标签打印；扫码只打开有权访问的业务单据，不直接改变库存状态。

补充交互：普通新增产品文档的首个弹窗可点击或拖放选择附件，文档保存后自动上传并关联所选附件；未选择文件时仍可创建纯在线文档。“批量导入”则把每个所选文件独立建成一篇文档，共用本次填写的类别和元数据。轻量导航增加“销售”一级分类并包含销售订单、发货管理、退货管理，“物流”保留来料管理。

### 硬件工具底座

- Honeywell 1900 按 USB HID 键盘模式接入，默认以 Enter 或 Tab 作为一条扫码输入的结束符。
- 扫码计数会话独立保存目标条码、目标数量、累计数量、设备型号和状态。
- 每次扫码保存原始值、规范化编码、数量与匹配结果，支持撤销最后一次有效扫码。
- PC310T 配置固定为 203 dpi、网线连接；默认介质为 105 × 70 mm（840 × 560 dots），可选择已有 100 × 150 mm 介质或输入自定义宽高。
- 标签编辑、Code 128 渲染和浏览器打印独立于扫码会话；打印请求单独记录。
- 货箱码 `BX-*` 打开货箱详情及现场照片，发货码 `SH-*` 打开发货单据；承运商运单号仍是发货单独立字段。
- 单据二维码使用同一标签打印任务记录；浏览器打印是当前 P0，静默网络打印仍需 QZ Tray 或局域网打印桥。
- 打印机 IP 目前作为客户机配置保存，网络静默打印后续通过 QZ Tray 或独立局域网打印桥接模块实现。

## 使用角色

| 角色 | 主要目标 | 常用功能 |
| --- | --- | --- |
| 开发商运维 | 开通租户、配置小程序、处理迁移交接 | 租户管理、小程序配置、备份、操作日志 |
| 租户管理员 | 管公司资料、员工权限、看经营情况 | 员工角色、商品资料、仓库、报表 |
| 提交人员 | 录入和提交业务内容 | 创建单据、上传原始单据、提交 |
| 审核人员 | 审核注册和业务提交内容 | 人员审核、单据审核 |
| 管理人员 | 维护人员和权限 | 人员管理、角色调整、停用账号 |
| 仓管 | 保证库存准确 | 查库存、入库、出库、盘点、调整 |
| 采购 | 管供应商和进货 | 供应商、采购订单、采购入库 |
| 销售 | 管客户和出货 | 客户、销售订单、销售出库 |
| 财务查看 | 看业务汇总，不做会计凭证 | 采购汇总、销售汇总、库存金额 |

## 端侧划分

### Web 管理后台

适合录入、配置、审核和看报表。

| 模块 | 页面 | 第一版 |
| --- | --- | --- |
| 首页 | 经营摘要、待办提醒、低库存提醒 | 是 |

### 2.2 成本计算

目标：先为小微制造企业提供独立于派工的物料关系型 BOM，再在数据稳定后扩展 BOM 成本测算。

当前实现：

- BOM 设置页可为同一产出物料新建多个方案/版本，设定方案名称、基准产出数量和默认状态；不再维护换算模型类方案类型，仅保留生产/包装用途用于业务识别。
- BOM 编辑器右侧以并列输入/输出明细维护完整批次；首个输出是订单与成本基准。输入和输出都可连续添加；服务端先使用单位目录做同量纲换算，再按物料标准换算处理允许的主计量/参考计量转换，并冻结原始录入量和换算依据。
- 服务端直接保存每批输入和每批输出的绝对数量。所有输入构成整体消耗，不绑定某项输出；新记录的 `BOMItem.outputMaterialId` 置空。标准 BOM 不设置固定/百分比损耗，所有可识别的损耗物必须建为废料、废屑或可回收料输出。
- 生产订单创建时默认带出当前主产出物料的默认已发布 BOM，也可改选其他已发布 BOM；草稿和已作废版本不可用于新生产订单，不提供无 BOM 选项。订单引用的已发布 BOM 本身不可变，同时继续冻结 BOM 名称、版本、所有投入和所有产出，双重保证历史不漂移。
- 班后实绩按主产出实际数量计算冻结 BOM 的批次倍数并展开全部共同投入；每种投入可选择来源库位、本批次额外的固定或百分比耗用，并允许修正实际耗用。投入可以是原材料、半成品或已有产品。保存草稿时即校验每项来源库位可用量，确认时对并发变化再次复检。
- 班后实绩从启用员工中选择一人或多人；关联表同时保存员工 ID、工号和姓名快照，历史姓名不随员工资料修改。
- 班后实绩从订单派工和默认路线对应的工作中心筛选可用/运行设备，并从订单物料或工作中心筛选已生效作业文件；保存草稿时冻结设备、工作中心、文件版本、正文和附件清单。来源主数据后续修改不回写历史快照。
- 实绩确认必须满足“设备快照或设备例外原因”和“文件快照或文件例外原因”两组条件；确认/冲销后的执行上下文由数据库触发器保护，不允许更新或删除。
- 班后实绩确认时每个产出创建内部批次和待检成本层，并快照当前生效检验标准、抽样规则与项目；只有质量放行后的可用成本层可被后续 FIFO 消耗。不合格冻结保留原批次、库位、数量和成本。
- 班后实绩确认时，每项投入按来源库位可用批次 FIFO 分配，每个产出批次与全部实际投入批次建立谱系。来料详情、生产投入和产出质量卡可以打开同一批次追溯视图。
- 流程转移使用独立入口和转移单，不读取或创建 BOM；只保存一个 `materialId`，输入和输出由系统同时显示为该物料，数量严格 1:1，来源与目标库位必须不同；保存草稿时来源库位可用量必须足够。
- 流程转移从启用员工中选择一名操作员工，同时保存员工 ID、工号和姓名快照。
- 转移确认时只等量移动库位余额并写入一出一入流水，总库存、计价数量、总成本和成本层不变；支持草稿、确认和冲销。
- 当前轻量流程不设置领料步骤；日报确认时在同一事务内逐项扣减来源库位、结转库存成本并增加产出库位。
- 来料、生产订单实绩、流程转移、发货和退货等业务单据统一执行“保存即校验”；字段范围、有效主数据、单位、库位和当时可判断的数量关系不合规时不落草稿。确认/处理阶段仍在事务内复检状态与实时库存，处理保存后发生的并发变化。
- BOM 全览页独立汇总某个物料作为产出或投入关联的全部直接 BOM，并可点击结果跳转到对应的 BOM 设置。
- 锯切费用计算器可保存为临时成本对象或绑定已有物料，并可加入指定物料 BOM。
- 成本对象保存单位材料成本、单位人工工时、单位机时和其他单位直接费用。
- BOM 成本页按主产出筛选，以 BOM 单位消耗量乘数量基准，并结合人工费率、机时费率和固定费用分摊计算成本快照。BOM 可同时包含多项投入和多项产出；成本分摊到其他产出属于后续成本切片。
- BOM 成本快照保存汇总和明细行，可回看历史计算结果。
- BOM 成本页的“成本数据”页签可新增手工成本对象，并集中查看成本对象、物料 BOM、默认工艺路线、可计算加工工艺和最近成本快照。
- 物料全景图展示该物料关联的加工工艺参数、推导工艺路线成本、相关成本对象和产品最新 BOM 成本快照。

边界：

- BOM 负责“基准批量有哪些投入、会产生哪些产出”，投入不限物料分类；不保存具体生产批次损耗或实际耗用。
- 用户可以从 BOM 设置页维护多方案和批量输入/产出关系；单位用量是批量数据的界面派生值。
- 用户侧不再维护独立 `Product` 主数据；旧业务表需要产品外键时，由后端从物料自动生成内部兼容视图。
- 派工负责“怎么做、谁来做、何时做”。
- BOM 成本计算不生成派工、不占用库存；当前轻量流程没有领料步骤，班后实绩确认时按实际投入直接扣减库存。
- 房租、设备折旧等期间性固定费用不建议写入 BOM 本体，当前作为一次成本测算的分摊项保存。

## 第一版推荐导航

当前 MES-lite Web 后台：

```text
工作台
  仪表盘
  所有功能
物料
生产
物流
库存
配置
工具
```

工作台快捷入口支持系统默认、按当前账号主动访问次数智能排序和自定义摆放；“所有功能”按上述一级入口分组展示当前账号可读页面。整个系统只允许“一级入口 + 一级页面 + 可选二级详情/子页”，终端功能不超过三次跳转。

```text

```

## 关键验收场景

1. 管理员创建仓库、员工、商品和供应商。
2. 仓管在小程序创建采购入库单并确认入库。
3. 系统库存余额增加，并能看到采购入库流水。
4. 销售在小程序创建销售出库单并确认出库。
5. 系统库存余额减少，并能看到销售出库流水。
6. 管理员在 Web 后台查看当前库存、低库存预警和销售汇总。
7. 同一个微信用户可以选择进入不同租户身份。
