# MES-lite 扫码与标签打印底座

## 设备基线

| 设备 | 当前配置 |
| --- | --- |
| 扫码枪 | Honeywell Xenon 1900 |
| 扫码接入 | USB HID Keyboard |
| 结束符 | Enter，兼容 Tab |
| 标签打印机 | Honeywell PC310T |
| 连接 | 有线网络 |
| 分辨率 | 203 dpi，约 8 dots/mm |
| 默认标签 | 105 × 70 mm |
| 默认打印画布 | 840 × 560 dots |
| 可选标签 | 100 × 150 mm，或自定义宽高 |
| 条码 | Code 128 |

## 模块边界

扫码和标签打印可以独立部署或替换。

- `scannerAdapter` 只负责把 Honeywell 1900 的键盘输入转换为标准扫码值。
- 扫码 API 负责计数会话、事件、匹配、超量、撤销和完成状态。
- `labelProfiles` 保存 PC310T 的物理参数、常用介质预置和毫米到 dots 的换算。
- 标签模板按所选介质宽高渲染；105 × 70 mm 使用紧凑横向布局，较高标签使用纵向布局。
- 打印 API 记录打印请求、所选宽高和标签数据快照，不把尺寸写死在模板名中。
- 会话创建、单次扫码和打印任务均携带客户端幂等键；网络重试不能重复建会话、重复累计或重复登记打印任务。
- 当前不要求扫码完成后自动打印，也不修改发货单和库存。

## 客户机设置

### Honeywell 1900

1. 配置为 USB HID Keyboard。
2. 配置 Enter 后缀；页面同时兼容 Tab。
3. 光标位于“扫描条码”输入框时扫描。
4. 中文输入法不得拦截数字、字母、连字符和回车。

### Honeywell PC310T

1. 在客户机安装官方 PC310T 203 dpi 驱动。
2. 通过固定 IP 添加网络打印机。
3. 在驱动中新建与页面所选介质一致的纸张；当前默认使用 105 × 70 mm。
4. 执行标签间隙校准。
5. 浏览器打印选择该打印机、无边距、100% 缩放，并关闭页眉页脚。

## 当前打印语义

Web 页面调用浏览器系统打印对话框。记录 `LabelPrintJob.status = REQUESTED` 只能证明用户发起了打印请求，不能证明打印机已经成功出纸。

后续自动打印可增加独立桥接模块：

- 客户机 QZ Tray：适合 MES 部署在公网、打印机位于客户局域网。
- 局域网打印服务：适合 MES 服务和 PC310T 位于同一局域网。
- 桥接层负责打印机发现、RAW/驱动发送、重试、回执和离线队列，MES 只提交标准标签任务。

## 验收清单

- 正确条码累计目标数量。
- 错误条码记录为 `UNKNOWN` 且不累计。
- 超量扫码记录为 `OVER` 且不累计。
- 撤销只删除最后一次 `MATCHED` 事件并回退数量。
- 数量完全一致时才能完成计数。
- 页面刷新后能恢复未完成会话。
- Code 128 可被 Honeywell 1900 回扫。
- 105 × 70 mm、100 × 150 mm 和合法自定义尺寸均按所选宽高生成打印页，不跨页；驱动与浏览器必须选择相同纸张并使用 100% 缩放。
- 打印任务包含打印机型号、203 dpi、尺寸、份数和标签数据快照。
