# 铝型材定制 MES 阶段 4：可选钻孔、质检与成品入库

## 本阶段目标

用生产批次承接锯切合格件，使系统可以按产品工艺决定是否需要钻孔，并完成钻孔、返工、质检、成品入库和受约束冲销。

页面入口：顶部“生产” → 左侧“加工质检”。

## 生产批次如何生成

锯切任务完工时，系统按“锯切任务 + 切割需求”自动生成一个生产批次：

- 保存对应工单、成品物料、切割需求和锯切任务；
- 通过锯切任务继续追溯实际原料实体和余料；
- 保存锯切合格数量；
- 按合格件切长占比分配锯切任务净材料成本；
- 使用工单创建时冻结的工艺快照决定是否需要钻孔。

工艺快照含 `templateCategory = DRILLING` 时进入待钻孔；否则直接进入待质检。旧快照没有类别时，兼容识别明确的 `DRILLING` 模板编码或“钻孔”工序名称。

## 数量分桶

生产批次遵循：

```text
锯切合格数量
= 待钻孔
+ 待质检
+ 待返工
+ 质检合格
+ 报废
```

已入库是质检合格的子集：

```text
已入库数量 <= 质检合格数量
```

所有钻孔、质检和入库操作先校验分桶，不允许超额处理。

## 可选钻孔

有钻孔工艺的批次可提交：

- 初次钻孔：从待钻孔数量取数；
- 返工钻孔：从待返工数量取数；
- 合格数量：转入待质检；
- 返工数量：回到待返工；
- 报废数量：转入报废。

实绩可填写孔型、图纸号和备注。由于钻孔定义方式尚未确认，当前不强制固定孔位参数表，数据仍可稳定保存并追溯。

无钻孔工艺的批次不会出现强制钻孔步骤，调用钻孔接口也会被拒绝。

## 质量检验

质检可以从待质检或待返工数量取数，并记录：

- 本次质检数量与抽检数量；
- 合格、返工、报废；
- 检验结果 `PASSED / PARTIAL / FAILED`；
- 不合格原因、备注、检验员和时间。

质检合格才形成可入库数量。返工后可进入钻孔返工或返工复检，具体由现场按产品工艺选择。

## 成品入库

成品入库复用现有 `StockIn`，增加生产批次、成品物料、幂等键、双单位、成本和冲销信息。

- 入库数量不得超过 `质检合格 - 已入库`。
- 汇总库存使用现有 `Stock`。
- 入库流水使用 `StockLog`。
- 成本层使用 `InventoryCostLayer`。
- 当前入库材料成本按生产批次的单位材料成本计入；后续钻孔人工/机时成本可在成本归集阶段追加。
- 工单完成数量由关联生产批次已入库数量汇总，不再由页面任意覆盖。

## 冲销顺序

冲销必须按时间倒序：

1. 已入库成品先冲销入库；
2. 再冲销最后一笔质检；
3. 再冲销最后一笔钻孔；
4. 生产批次完全回到初始分桶且没有后续记录后，才允许冲销来源锯切任务。

成品已被占用、发货或成本层已被耗用时，入库冲销会被拒绝。

## 数据对象

| 对象 | 作用 |
| --- | --- |
| `ProductionLot` | 锯切到成品入库之间的生产批次和数量分桶 |
| `DrillingReport` | 初次/返工钻孔实绩 |
| `QualityInspection` | 初检/复检实绩 |
| `StockIn` | 兼容旧工单入库并增加生产批次入库字段 |

## 自动验证

```bash
npm run verify:production-lots
```

脚本在回滚事务内验证工艺类别冻结、可选钻孔、返工、质检、成品库存与成本、倒序冲销、无钻孔直达质检以及数量分桶不变量。
