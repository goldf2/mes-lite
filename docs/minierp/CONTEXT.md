# MES-lite 项目上下文

## 项目定位

MES-lite 是面向铝型材锯切、少量钻孔场景的轻量制造执行系统。系统保留现有物料/BOM、双单位库存、成本、生产日报、发货、扫码计数和标签打印底座，在其上逐步补齐不规则来料、排样锯切、余料、质检、包装发货和全链路追溯。

当前优先级是业务底层闭环。PC310T（203 dpi、网线）和 Honeywell 1900 的独立底座继续保留，扫码计数、标签打印与业务单据的自动联动后置。

## 当前成功标准

- 同一型材规格可同时持有多个不同实际长度的可用实体。
- 来料可按“实际长度 + 数量”快速登记，也可按需拆成单根追溯。
- 排样和锯切必须引用具体原料实体，不能只扣减普通 BOM 数量。
- 锯切实绩可形成合格品、不良品、可复用余料或废料，并保留原料谱系。
- 无钻孔产品可直接跳过钻孔；有钻孔产品可追踪加工、返工和不良。
- 质检通过后才能形成可发货成品；发货不得超过可用成品。
- 所有库存变化都在事务中写入不可改写的流水，并通过反向流水冲销。
- 现有物料、BOM、库存、生产和发货数据继续可用，不做破坏式迁移。

## 领域原则

1. `Material` 说明“是什么规格”，`Stock` 说明“该规格总共有多少”，`ProfileStockEntity` 说明“现场可实际选择哪一根或哪一批同长型材”。
2. 普通 BOM 只描述规范需求，不能代表实际领用了哪根型材。
3. 来料实体可采用同长批次或单根两种追溯粒度；精细追溯不应强迫所有收货逐根录入。
4. 余料是有来源和去向的实体，不是没有谱系的普通库存数量。
5. 切割方案与切割实绩分离，计划值不能覆盖实际值。
6. 工单创建时保存 BOM 和工艺快照，历史记录不随主数据修改漂移。
7. 锯缝、首尾切除、夹持死区、余料阈值和混单策略是配置，不写死在代码中。
8. 默认禁止负库存；合法纠错采用冲销或反向流水，不修改历史流水。

## 关键术语

- 型材规格：截面、牌号、状态、表面处理、图号等稳定属性，对应一个物料档案的扩展资料。
- 来料实测行：一次收货中具有相同实际长度的一组型材及数量。
- 型材实体：可被排样、占用和耗用的同长批次或单根型材。
- 同长批次：同物料、同实际长度、同来源的一组型材，以数量管理。
- 单根实体：数量固定为 1、可独立追溯的一根型材。
- 余料实体：锯切后仍可追溯到来源实体的剩余型材。
- 规格库存：现有 `Stock` 总账余额，用于兼容数量、双单位和成本核算。
- 实体子账：`ProfileStockEntity + ProfileStockMovement`，用于长度、状态、位置和谱系追溯。
- 切割需求：由工单/BOM快照产生的成品长度、数量、公差和交期需求。
- 排样方案：对具体原料实体的计划分配，包含锯缝、首尾损耗和预计余料。
- 锯切实绩：实际合格、不良、报废、损耗、操作者和时间记录。
- 锯切任务：由已确认排样方案下发的执行对象，保存设备、班次、开完工和冲销状态。
- 余料回收：锯切完工后，将达到阈值且明确选择复用的剩余长度生成子实体，并按长度比例回收入规格库存和成本。
- 生产批次：按锯切任务和切割需求生成，承接待钻孔、待质检、返工、质检合格、报废和入库数量。

## 当前实现进度

- 阶段 0：现状审计、领域文档和关键 ADR 已完成。
- 阶段 1：不规则来料实测行、同长批次/单根实体、实体查询、拆分和来料红冲已完成。
- 阶段 2：工单 BOM/工艺快照、切割需求、人工排样、实体与汇总库存预留已完成。
- 阶段 3：锯切任务下发、开工、逐根实绩、余料/废料、成本过账和合法冲销已完成。
- 阶段 4：生产批次、可选钻孔、返工、质检、成品入库和倒序冲销已完成。
- 下一阶段：包装、分批发货与全链路追溯。

## 目标业务闭环

来料单 → 实测长度登记 → 原料实体入库 → 切割需求 → 人工排样/系统推荐 → 领用具体实体 → 锯切报工 → 余料回库或废料 → 可选钻孔 → 质检 → 成品入库 → 装箱/分批发货 → 全链路追溯。

## 待业务确认但不阻塞建模

- 来料是否要求每根实测。
- 余料最小回库长度。
- 是否允许同一根型材混多个订单。
- 各设备的锯缝、首尾切除和夹持死区。
- 钻孔以孔型、图纸还是参数表为主。
- 包装按件、套、捆或箱管理。

这些值在 `ManufacturingConfig` 中保持未配置状态；唯一确定的默认值是禁止负库存。
