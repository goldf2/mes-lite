# MES-lite 公共前端模块使用指南

本文说明资源型功能页面如何复用统一骨架。适用于物料、文档、设备、客户、供应商、员工、工艺、路线等以“查询、新增、修改、归档、关联”为主的页面。

## 1. 模块边界

```txt
app/components/resource/    资源列表、卡片、详情、表单、筛选和页面骨架
app/components/relations/   一对一、一对多、多对一关系编辑与实体搜索
app/components/layout/      左右分区、窄屏模式和可移动边缘呼出按钮
app/components/             按钮、弹窗、搜索、工具栏等基础组件
lib/contrast-modes.ts       系统级柔和、标准、高对比配色模式
```

业务页面负责数据请求、权限、状态流转和字段定义。页面框架、工具弹窗、响应式布局、关系行和视觉层级由公共模块负责。

## 2. 标准资源页面

从 `app/components/resource` 导入：

```tsx
import {
  ResourceDetailPanel,
  ResourcePage,
  type ResourceTableColumn,
} from '@/app/components/resource'
```

`ResourcePage<T>` 的最小调用需要：

- `resourceKey`：稳定且全局唯一，用于保存搜索与布局偏好。
- `items / getKey`：当前列表及稳定主键。
- `columns`：列表列定义。
- `searchValue / onSearchChange / searchPlaceholder`：统一文字搜索。
- `viewMode / onViewModeChange`：列表与卡片模式。
- `selectedKey / onSelect / detail`：连续列表—详情工作区。

页面可按需传入 `filters`、`filterCount`、`actions`、`onCreate`、加载、错误和空状态。不要在业务页重新实现工具栏或主从布局。

## 3. 详情与编辑

`ResourceDetailPanel` 统一处理：

- 标题、编码摘要、状态与编辑标记。
- 上一条、下一条连续浏览。
- 桌面关闭与窄屏返回语义。
- 更多操作菜单。
- 同容器编辑与固定底部保存操作。

新增和独立编辑使用 `ResourceFormDialog`。归档、永久删除等动作必须继续使用公共确认弹窗。

## 4. 主从工作区

`AdaptiveMasterDetailWorkspace` 自动提供：

- 宽屏左右分区及可拖动分隔线。
- 窄屏列表弹窗、上下分区、列表/详情切换三种模式。
- 布局比例、显示模式和边缘按钮位置的浏览器持久化。
- 左侧列表与右侧页面工具互斥，避免遮挡。

业务页面不得监听视口后复制另一套详情页面。紧凑布局必须继续复用相同的列表和详情内容节点。

## 5. 关系模块

所有关系编辑从 `app/components/relations` 导入：

```tsx
import {
  ManyToOneRelationField,
  OneToManyRelationField,
  OneToOneRelationField,
  RelationSearch,
} from '@/app/components/relations'
```

### 5.1 一对一

使用 `OneToOneRelationField<T>`。适用于设备与当前点检模板、员工与专属账号等最多一个目标的关系。

### 5.2 一对多

使用 `OneToManyRelationField<T>`。适用于文档关联多个物料、BOM 多项投入/产出、订单多条明细等关系。

### 5.3 多对一

使用 `ManyToOneRelationField<T>`。适用于多个物料属于一个类别、多个设备属于一个工作中心等“所属对象”关系。它复用单关系交互，但保留明确的领域调用名。

### 5.4 统一搜索

`RelationSearch<T>` 接收实体数组、主键、显示文本、搜索关键词和禁用项；物料关系使用已经封装的 `MaterialRelationSearch` 与 `MaterialRelationIdentity`。其他实体应在通用搜索上增加自己的薄适配器，不复制弹层、键盘导航和外部关闭逻辑。

## 6. 系统级对比度

页面中性色统一通过 Tailwind `gray-*` 调用，底层映射到 `--mes-color-neutral-50` 至 `--mes-color-neutral-950`。系统设置提供柔和、标准和高对比三种模式。

- 不在业务组件写新的固定灰阶。
- 需要领域层级时先增加语义令牌。
- 蓝、绿、琥珀、红继续表达主操作、成功/新增、提醒/归档和危险/错误，不随对比度模式换色。

## 7. 完成定义

新的资源页面完成前至少验证：

1. 列表、卡片、详情、新增、编辑、归档、加载、空状态和错误状态。
2. 宽屏左右分区及刷新后分隔线不跳动。
3. 窄屏三种布局模式、左右呼出按钮移动和工具弹窗连续操作。
4. 键盘选择、焦点、可访问名称与 `Esc` 退出。
5. 柔和、标准、高对比三种页面效果。
6. 类型检查、lint、生产构建和目标浏览器验证。
