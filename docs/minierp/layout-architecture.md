# MES-lite 系统布局架构

本文是 `docs/minierp/系统交互与设计规范.md` 的应用壳和工作区专项说明。导航、滚动和响应式降级必须同时满足主规范定义的交互底线。

## 目标

MES-lite 使用“一级业务入口 + 最多两级页面”的稳定层级、两种公共应用壳和三类页面工作区，避免页面自行决定应用级布局。

```text
标准管理
┌────────────┬───────────────────────────────────────────────┐
│ 品牌/导航键 │ 搜索 / 高级搜索 / 视图 / 页面操作 / 全局控制 │
├────────────┼───────────────────────────────────────────────┤
│ 左侧导航    │                  页面正文                     │
│ 常驻/呼出   │                                               │
└────────────┴───────────────────────────────────────────────┘

画布工作
┌────────────────────────────────────────────────────────────┐
│ 品牌 │ 顶部一级导航 / 更多                    │ 全局控制     │
├──────────────────────────────────────────────┬─────────────┤
│                  页面正文                    │ 右侧页面工具 │
│                                              │ 独立滚动     │
└──────────────────────────────────────────────┴─────────────┘
```

职责边界：

- 标准管理的左侧导航显示业务域和页面，顶部只放当前页面工具；画布工作的顶部导航显示业务域和页面，右侧只放当前页面工具。
- 两种应用壳使用同一菜单注册、权限结果、页面组件和工具内容；业务页面不得感知或复制应用壳。
- 顶部一级菜单只切换业务域，不放具体业务操作；二级页面通过分组弹出菜单进入。
- 标准管理的左侧导航支持必要的分级展开、宽度调整、常驻和自动隐藏。自动隐藏面板临时呼出时覆盖正文，不改变正文宽度。
- 一级页面之下最多再进入一层详情或稳定子页，不允许继续派生第三级业务页面。
- 公共页面工具显示搜索、高级搜索、视图切换和主操作；标准管理横向放在顶部，画布工作纵向放在右侧。
- 中央区域始终是主显示区域；右侧辅助区承载详情、BOM 编辑或其它与当前选择有关的上下文功能，没有上下文内容时必须收起，不能保留空白栏。
- 应用壳形态是系统显示偏好，页面工作区选择单区、主从双区或并列双区；二者互相独立，页面不得自行改变应用壳。

## 桌面端应用壳

| 区域 | 标准管理 | 画布工作 |
| --- | --- | --- |
| 顶部应用栏 | 品牌/导航键、横向页面工具、全局控制 | 品牌、单行一级导航/更多、全局控制 |
| 导航 | 左栏默认宽度 224px，可在 184–320px 调整；支持常驻和自动隐藏 | 顶部一级导航，二级页面使用弹出菜单 |
| 页面工具 | 顶部横向单行，搜索靠左、其余靠右 | 右侧纵向分组并独立滚动 |
| 中央主工作区 | 常驻左栏时跟随保存宽度；自动隐藏时不预留左栏宽度 | 右侧为公共工具栏预留固定宽度；最小宽度为 0 |
| 上下文辅助区 | 仅在页面提供详情、BOM 或上下文功能时显示，可与中央区拖动分隔；普通页面自动收起 | 同标准管理；不得与应用壳右侧页面工具混为一栏 |
| 滚动 | 应用栏、导航与页面工具不随正文滚动；正文使用单一滚动容器，主从双区按规范各自滚动 | 应用栏和右侧工具固定；正文与右侧工具各自滚动 |

两种布局的全局切换入口固定在应用壳，持久化入口位于“系统设置 → 显示设置”。切换不得改变 URL、页面选中对象、搜索条件或未保存草稿。

标准管理的自动隐藏左栏收起后只保留一个导航图标。鼠标进入左侧感应区或点击图标时用 `transform` 覆盖呼出；鼠标离开后延时收回，面板内交互必须取消计时。图钉按钮将其切为常驻并使正文按侧栏宽度让位。

## 工作区类型

### 单区列表

用于仪表盘、生产订单、来料、库存、发货、退货、人员权限等以列表或统计为主的页面。

- 默认占满内容宽度。
- 大屏最大阅读宽度可限制在 1920px 内并居中。
- 不为了“充分利用大屏”强行拆分无关联信息。

### 主从双区

用于产品文档列表与详情、可选择对象与明细必须同时对照的页面。BOM 设置属于该类型：左侧是以 BOM 名称/版本为主信息的唯一已有 BOM 列表，产品、产出和投入物料只作为摘要和搜索条件；右侧负责新建和修改，上半区并列显示整批输入和整批输出，下方以单一“BOM 方案名称”字段完成新建命名或已有 BOM 重命名并提供唯一保存按钮。投入不按分类限制，可为原材料、半成品或已有成品。

- 左侧为主列表或选择区，建议 320–520px。
- 右侧为详情或编辑区，使用剩余宽度。
- 允许拖动分隔条，宽度保存到 `localStorage`。
- 桌面宽屏下可占满标题栏以下的剩余视口，左右两区必须各自使用单一滚动容器并阻止滚动链传递到页面；顶部应用栏和页面工具栏保持固定。
- 小于 1280px 时降级为单区，并通过详情页、抽屉或上下排列切换。

### 并列工具双区

用于硬件工具、两个独立计算器或需要同时观察输入和输出的页面。

- 两区语义平级，默认 50/50。
- 允许拖动到 35/65 至 65/35。
- 小于 1280px 时上下排列，不隐藏任一区域。
- 两区各自包含标题和局部操作，不重复页面级标题。

## 页面类型映射

| 一级域 | 页面 | 工作区 |
| --- | --- | --- |
| 工作台 | 仪表盘 | 单区统计 |
| 工作台 | 所有功能 | 按业务入口分组的单区入口目录 |
| 物料 | 物料管理 | 单区列表 |
| 物料 | BOM 设置 | 左侧直接列出已有 BOM、右侧以单一名称字段及投入/产出明细新建或修改的主从工作台 |
| 物料 | BOM 全览 | 左侧筛选并选择物料、右侧分区查看该物料作为产出和投入的全部直接 BOM |
| 生产 | 生产订单 | 单区列表，详情内展开班后生产实绩 |
| 文档 | 产品文档 | 单区列表，详情使用宽弹窗 |
| 物流 | 来料、发货、退货 | 单区列表 |
| 库存 | 库存管理 | 单区表格/卡片 |
| 工具 | 锯切成本 | 单区计算工作区 |
| 工具 | 硬件工具 | 并列工具双区 |

## 响应式降级

| 宽度 | 导航与工作区 |
| --- | --- |
| `>= 1280px` | 使用用户选择的标准管理或画布工作应用壳；允许左右双区 |
| `1024–1279px` | 使用用户选择的桌面应用壳；标准管理的双列导航降为单列，页面双区默认上下排列，画布顶部导航允许“更多”收纳 |
| `< 1024px` | 统一移动端外壳：顶部单行显示菜单按钮、弹性搜索区、页面“工具”和账户入口；页面二维码、筛选、视图与操作进入工具抽屉，菜单按钮打开按一级业务分组的左侧全高功能抽屉，底部只保留常用导航 |

响应式外壳只维护桌面端与移动端两种状态；移动端内部可以根据可用宽度调整卡片列数，但不得再增加独立的平板导航形态。

## 验收不变量

- 顶部一级菜单、左侧页面栏、页面标题不能表达同一层导航。
- 标准管理与画布工作必须复用同一页面注册和工具内容；切换后当前页面、搜索、选择与草稿保持不变。
- 自动隐藏左栏临时呼出不得改变正文边距或宽度；收起后必须保留可发现、可键盘访问的导航图标。
- 画布工作的顶部导航不得换行，右侧页面工具不得与正文争用同一滚动容器。
- 从工作台快捷入口或所有功能目录可直接打开一级页面；任何终端功能从应用入口起不超过三次跳转。
- 任何页面都不得产生页面级横向滚动。
- 除弹窗、下拉选项、明确的虚拟列表和已登记的桌面端主从双区工作台外，内容区不得嵌套 `overflow-y-auto` 或 `overscroll-contain`；主从双区每侧最多一个纵向滚动容器。
- 桌面端双区的任一侧不得小于可操作宽度。
- 双区分隔条必须支持键盘方向键调整并具有 ARIA 标签。
- 页面标题、筛选和主操作在 1024px 下仍可发现。
- 360、390、768、1024、1366、1440、1920 宽度必须实际模拟。

## 组件实现

- `app/components/interfacePreferences.tsx` 统一保存工作区形态和左栏行为；默认值保持“标准管理 + 常驻”，避免升级后改变现有用户布局。
- `DesktopNavigation` 和 `DesktopTopNavigation` 必须接收同一份 `DesktopNavigationGroup[]`，不得复制菜单常量或权限过滤。
- `ResponsiveToolbarActions` 同时提供标准管理的横向工具和画布工作的右侧纵向工具，两者复用相同 props、弹窗和业务动作节点。
- 自动隐藏左栏只保存“自动隐藏 / 常驻”偏好，不保存临时展开状态；临时展开由应用壳内存状态和鼠标/键盘事件管理。
- 左侧“物料与 BOM”分级菜单使用 Radix UI `Collapsible`，由组件原语负责展开状态、键盘交互和 ARIA 语义。
- 桌面左侧辅助区拖动范围为 184–320px，支持方向键调整、双击恢复 224px，并将个人宽度写入 `localStorage`。
- 菜单和硬件工具图标使用 Lucide，避免业务页面自行绘制 SVG。
- `app/components/layout/SplitWorkspace.tsx` 统一提供并列双区、35/65 到 65/35 限制、键盘方向键调整和本地比例记忆。
- 低于 `1280px` 时 `SplitWorkspace` 自动上下排列，不保留不可操作的窄分隔区。
- 分布在生产、物流和工具菜单中的管理类列表在低于 `1024px` 时强制使用卡片布局，避免表格列被压缩成逐字换行。
