# MES-lite 系统布局架构

本文是 `docs/minierp/系统交互与设计规范.md` 的应用壳和工作区专项说明。导航、滚动和响应式降级必须同时满足主规范定义的交互底线。

## 目标

MES-lite 使用“一级业务入口 + 最多两级页面”的稳定层级和三类工作区，避免页面自行决定应用级布局。

```text
┌────────────────────────────────────────────────────────────┐
│ 品牌区 │ 工作台 物料 生产 物流 库存 工具 │ 用户与系统菜单 │
├────────┼───────────────────────────────────────────────────┤
│ 左侧辅助区 │          中央主工作区          │ 右侧辅助区    │
│ 当前域菜单 ├────────────────────────────────┤ 详情/BOM/上下文│
│ 页面 1    │ 页面标题 / 搜索 / 筛选 / 主操作 │              │
│ 页面 2    │                                │              │
│ 页面 3    │          页面主体              │              │
└────────┴───────────────────────────────────────────────────┘
```

职责边界：

- 顶部一级菜单只切换业务域，不放具体业务操作。
- 左侧辅助区只显示当前业务域下的页面，支持必要的分级展开和宽度调整。
- 一级页面之下最多再进入一层详情或稳定子页，不允许继续派生第三级业务页面。
- 内容标题栏显示当前页面、搜索、筛选、视图切换和主操作。
- 中央区域始终是主显示区域；右侧辅助区承载详情、BOM 编辑或其它与当前选择有关的上下文功能，没有上下文内容时必须收起，不能保留空白栏。
- 页面工作区选择单区、主从双区或并列双区，不再自行改变应用壳。

## 桌面端应用壳

| 区域 | 规则 |
| --- | --- |
| 顶部应用栏 | 固定高度 64px，跨越整个窗口；左侧 224px 品牌区，中间一级菜单，右侧用户菜单 |
| 左侧辅助区 | 默认宽度 224px，可在 184–320px 内拖动，从顶部应用栏下方开始，到窗口底部结束；宽度保存到当前浏览器 |
| 中央主工作区 | 左偏移跟随左侧辅助区、上偏移 64px，最小宽度为 0，禁止撑破窗口 |
| 右侧辅助区 | 仅在页面提供详情、BOM 或上下文功能时显示，可与中央区拖动分隔；普通页面自动收起 |
| 页面工具栏 | 吸附在顶部应用栏下方；左侧辅助区已有当前页面选中态时不重复显示标题，只显示搜索、筛选、视图和页面操作；没有操作的仪表盘不保留空工具栏 |
| 滚动 | 应用栏、侧栏和页面标题/按钮工具栏均不滚动；桌面端单区页面只让标题栏下方的内容区纵向滚动。主从双区工作台让左右工作区各自纵向滚动；宽表格只允许自身横向滚动 |

## 工作区类型

### 单区列表

用于仪表盘、生产订单、来料、库存、发货、退货、人员权限等以列表或统计为主的页面。

- 默认占满内容宽度。
- 大屏最大阅读宽度可限制在 1920px 内并居中。
- 不为了“充分利用大屏”强行拆分无关联信息。

### 主从双区

用于产品文档列表与详情、可选择对象与明细必须同时对照的页面。BOM 设置属于该类型：左侧是以 BOM 名称/版本为主信息的唯一已有 BOM 列表，产品、产出和投入物料只作为摘要和搜索条件；右侧负责新建和修改，上半区并列显示整批输入和整批输出，下方以单一“BOM 方案名称”字段完成新建命名或已有 BOM 重命名并提供唯一保存按钮。投入不按分类限制，可为原材料、半成品或已有成品。

- 左侧为主列表或选择区，建议 320–520px。
- 右侧为详情或编辑区，使用剩余宽度。
- 允许拖动分隔条，宽度保存到 `localStorage`。
- 桌面宽屏下可占满标题栏以下的剩余视口，左右两区必须各自使用单一滚动容器并阻止滚动链传递到页面；顶部应用栏和页面工具栏保持固定。
- 小于 1280px 时降级为单区，并通过详情页、抽屉或上下排列切换。

### 并列工具双区

用于硬件工具、两个独立计算器或需要同时观察输入和输出的页面。

- 两区语义平级，默认 50/50。
- 允许拖动到 35/65 至 65/35。
- 小于 1280px 时上下排列，不隐藏任一区域。
- 两区各自包含标题和局部操作，不重复页面级标题。

## 页面类型映射

| 一级域 | 页面 | 工作区 |
| --- | --- | --- |
| 工作台 | 仪表盘 | 单区统计 |
| 工作台 | 所有功能 | 按业务入口分组的单区入口目录 |
| 物料 | 物料管理 | 单区列表 |
| 物料 | BOM 设置 | 左侧直接列出已有 BOM、右侧以单一名称字段及投入/产出明细新建或修改的主从工作台 |
| 物料 | BOM 全览 | 左侧筛选并选择物料、右侧分区查看该物料作为产出和投入的全部直接 BOM |
| 生产 | 生产订单 | 单区列表，详情内展开班后生产实绩 |
| 生产 | 产品文档 | 单区列表，详情使用宽弹窗 |
| 物流 | 来料、发货、退货 | 单区列表 |
| 库存 | 库存管理 | 单区表格/卡片 |
| 工具 | 锯切成本 | 单区计算工作区 |
| 工具 | 硬件工具 | 并列工具双区 |

## 响应式降级

| 宽度 | 导航与工作区 |
| --- | --- |
| `>= 1280px` | 顶部一级菜单 + 左侧页面栏；允许左右双区 |
| `1024–1279px` | 顶部一级菜单 + 左侧页面栏；双区默认上下排列 |
| `< 1024px` | 统一移动端外壳：顶部第一行显示菜单按钮、当前页标题和账户入口，第二行按需显示页面搜索/筛选/“工具”；菜单按钮打开按一级业务分组的左侧全高功能抽屉，底部只保留常用导航 |

响应式外壳只维护桌面端与移动端两种状态；移动端内部可以根据可用宽度调整卡片列数，但不得再增加独立的平板导航形态。

## 验收不变量

- 顶部一级菜单、左侧页面栏、页面标题不能表达同一层导航。
- 从工作台快捷入口或所有功能目录可直接打开一级页面；任何终端功能从应用入口起不超过三次跳转。
- 任何页面都不得产生页面级横向滚动。
- 除弹窗、下拉选项、明确的虚拟列表和已登记的桌面端主从双区工作台外，内容区不得嵌套 `overflow-y-auto` 或 `overscroll-contain`；主从双区每侧最多一个纵向滚动容器。
- 桌面端双区的任一侧不得小于可操作宽度。
- 双区分隔条必须支持键盘方向键调整并具有 ARIA 标签。
- 页面标题、筛选和主操作在 1024px 下仍可发现。
- 360、390、768、1024、1366、1440、1920 宽度必须实际模拟。

## 组件实现

- 左侧“物料与 BOM”分级菜单使用 Radix UI `Collapsible`，由组件原语负责展开状态、键盘交互和 ARIA 语义。
- 桌面左侧辅助区拖动范围为 184–320px，支持方向键调整、双击恢复 224px，并将个人宽度写入 `localStorage`。
- 菜单和硬件工具图标使用 Lucide，避免业务页面自行绘制 SVG。
- `app/components/layout/SplitWorkspace.tsx` 统一提供并列双区、35/65 到 65/35 限制、键盘方向键调整和本地比例记忆。
- 低于 `1280px` 时 `SplitWorkspace` 自动上下排列，不保留不可操作的窄分隔区。
- 分布在生产、物流和工具菜单中的管理类列表在低于 `1024px` 时强制使用卡片布局，避免表格列被压缩成逐字换行。
