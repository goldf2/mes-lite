# 统一物料主档与字段映射导入

本变更扩展现有 `Material`。所有库存、订单、生产、BOM、附件继续引用原 `Material.id`。不创建另一份零件主档，也不把数据平台的实际部件台账当作物料目录。当前变更提供 MES 本地开发候选和导入准备；未执行生产资料合并。

## 字段与关系

- `materialKind`：GENERAL（通用物料）/PART（零件），与既有库存分类 `category` 分开。已有记录默认 GENERAL；零件来源不据此推定原料或成品分类。
- `defaultSourceMode`：MAKE/BUY/SUBCONTRACT，可留空，仅表达默认取得方式。不是库存所有权或当前批次来源。
- 图号、图幅、现用材质、GB/JIS 栏参考、投料类别/规格/方式、热处理工艺、热处理及确认状态、加工工艺、毛重原文进入 Material 的可空工程字段。GB/JIS 来源栏不代表已认证标准或等价牌号；毛重单位未确认，不用作库存或计价换算。
- 成品/毛坯各有长、宽、厚、内径、外径、高度，共十二个可空数值字段，单位 mm，有限且非负；保留来源中的零，不将零解释成实测有效尺寸。
- `MaterialPurpose` 按 materialId + purposeCode 唯一：自有设备、自有产品、外来加工、其他，可同时多选。不自动推断来源零件的用途。
- `MaterialModelUsage` 按 materialId + modelCode + assemblyName 唯一，保存适用型号、部件分组和每台数量。分组为空表示未分组；数量空或零允许保存并提醒核对。它是适用资料，不自动发布 BOM 或生成领料需求。

名称、业务编码和库存单位仍为现有必填要求。缺少图号、机型、材质和工艺可后补。更新省略工程字段或关系时保持原值；显式空值或空数组才清空对应资料。稳定主键不由 Excel 映射或改写。

## 导入交互与接口

复用现有物料管理入口和公共弹窗、字段、按钮、关联编辑骨架。编辑和详情展示真实工程字段及用途/机型资料，检索能够使用新工程资料。

导入步骤为：选择 CSV/XLSX → 选择工作表和表头行 → 核对自动建议或手工选择列对应 → 预览逐行动作和问题 → 确认导入。源列只能对应已开发的目标字段，不在上传时创建数据库字段。未识别列显示为忽略；未知字段的业务含义不能由上传标题代替开发。

`POST /api/materials/import/preview` 只读。`POST /api/materials/import` 提交时重新解析同一文件、验证权限和目标数据库现状，再以事务写入；前端预览不是写入凭证。映射、工作表、表头行或跳过/更新策略改变后，必须重新预览。预览和提交均需要物料读取与创建权限；更新模式另需更新权限。

以业务编码匹配现有 Material，更新保留 id。归档占码、文件内重复编码、非法值和已有业务约束在预览中呈现。未映射的已有字段保留。源库存、成本、领料数量等不在可写映射中；导入不初始化历史库存、成本层、所有权或执行 BOM。正式新增沿用既有零余额库存记录机制。

## MDB 导入准备

来源 `宇峰数据库.mdb/零件总表` 共 5,360 行、38 列。剔除 10 条机型标题后有 5,350 个物料候选；两条疑似字段错位和两条无名称暂缓，准备文件共 5,346 条。缺少机型/图号的其余资料允许导入。原编码保持不变，不按“机型-图号”重算。件和 mm 已由用户确认。默认取得方式、用途、供应商、毛重单位和历史库存不猜测填充。

先以隔离测试数据库检验整文件，之后针对真实目标库重新做预览。部署迁移仅添加可空字段和默认类型，不随部署自动执行这批导入。

新增迁移前插入旧物料/库存后重放迁移，稳定 ID、数量与成本保持；CRUD 的省略保留、显式清空、零/false、多用途、多机型及检索通过。完整准备文件在隔离数据库预览 5,346 行、0 错误、29 项资料提示；事务新建 5,346 物料及 5,319 适用关系，逐字段与准备数据一致，库存数量/成本均为 0，重复导入全部跳过。新导入专项覆盖提交时重验、审计失败回滚、归档占码、单位保护与关系无损往返。
