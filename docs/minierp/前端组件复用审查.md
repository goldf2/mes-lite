# MES-lite 前端组件复用审查

审查日期：2026-08-04

## 1. 审查目标

本次审查聚焦 `app/components`：识别重复的视觉原语和交互实现，优先收口低风险、高复用的部分，并给后续页面拆分提供顺序。业务算法、接口和数据库模型不在本轮改造范围内。

## 2. 当前概况

- 前端 TSX 约 21,064 行。
- 最大页面为 `MaterialPage.tsx`（3,178 行）和 `SystemPage.tsx`（2,215 行）。
- `MaterialInPage.tsx`、`MaterialPanoramaPage.tsx`、`WorkInstructionPage.tsx` 均超过 1,300 行。
- 代码中约有 212 个原生按钮和 67 个 `AppButton` 调用。原生按钮包含表格行、选项和紧凑工具等合理场景，不能只按数量机械替换。
- 约有 31 个原生下拉框、43 个 `SearchableSelect` 调用和 7 个 `MaterialChoiceSearch` 调用。动态业务数据应继续迁移到可输入筛选的选择器。
- `BomCostPage.tsx` 当前没有被 `app/page.tsx` 或其他页面引用，属于保留但未接入的功能模块。确认产品方向前不直接删除；若不再启用，应连同专属接口和文档单独清理。

行数和标签数量只是定位信号。是否抽取组件仍以业务语义、交互一致性和重复修改风险为判断依据。

## 3. 本轮已收口

### 3.1 数值输入

新增 `NumberInputField.tsx`，统一标签、输入高度、焦点态、最小值、步长和单位后缀。锯切成本、BOM 成本和生产日报不再维护局部数值字段。

### 3.2 指标卡片

新增 `MetricCard.tsx`，提供常规与紧凑两种密度，并使用语义化的主值、成功、警告和危险色。锯切成本、BOM 成本、生产日报和流程转移共用同一实现。

### 3.3 物料搜索

扩展 `MaterialChoiceSearch.tsx`，支持空状态、结果上限和 BOM 版本徽标。两个成本页面删除各自的物料搜索弹层，统一获得输入筛选、键盘选择、Esc、点击外部关闭和焦点样式。`MaterialChoiceSearch` 与 `SearchableSelect` 共用弹层方向计算，在视口底部自动向上展开并限制可用高度。

本轮删除了 5 个页面中的重复局部组件；公共数值字段和指标卡片目前分别覆盖 26 和 35 个调用位置。

## 4. 后续优先级

### P1：继续迁移视觉原语

- 将普通表单输入逐步迁移到 `FormField` 和输入样式常量。
- 按语义审查原生按钮；页面主操作、保存、危险操作优先迁移到 `AppButton`，选项行和原生控件保留合理例外。
- 动态客户、物料、库位和人员选择不得新增普通 `select`。

### P2：拆分超大页面

- `MaterialPage.tsx`：按筛选工具栏、物料列表/卡片、详情编辑、BOM 简况和导入导出拆分。
- `SystemPage.tsx`：按设置分类拆分独立区块，页面只保留导航和数据协调。
- `MaterialInPage.tsx`：分离来料单编辑、已加入明细、历史列表和详情。
- `MaterialPanoramaPage.tsx` 与 `WorkInstructionPage.tsx`：按稳定业务视图拆分，避免只为缩短文件创建无语义的小组件。

拆分时保持数据请求和状态在最接近其所有者的位置；只有多个业务区块共享的状态才提升到页面层。

### P3：补齐公共能力

- 建立统一状态标签，消除页面内重复的状态文字与颜色映射。
- 评估通用数据表格和详情面板，只在至少两个稳定页面模式一致后抽取。
- 为公共选择器、弹窗和字段增加聚焦的交互测试，防止统一组件变更扩大回归范围。

## 5. 新代码约束

- 新需求先检查现有公共组件；能力不足时扩展公共组件，不复制一份局部实现。
- 业务页面保留业务组合和领域规则，颜色、尺寸、焦点、关闭方式等视觉交互由公共组件负责。
- 不以“消除所有原生标签”为目标；简单、语义正确且没有重复风险的原生控件可以保留。
- 单个页面持续增长时，优先按业务所有权拆分，不以任意行数切割文件。
