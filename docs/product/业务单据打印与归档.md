# 业务单据打印与归档

## 目标

业务单据保存与 PDF 输出分离。操作员在需要预览、打印、下载或留档时生成 A4 PDF；PDF 是业务数据快照，不是页面截图。

## 覆盖范围

- 来料入库单
- 销售订单
- 发货单
- 销售退货单
- 流程转移单
- 生产订单
- 派工单

上述范围对应当前系统全部 `transaction` 类型业务页面。标签打印继续使用独立标签画布，不与 A4 单据模板混用。

## 生成规则

1. 业务数据必须先由服务端校验并保存；保存失败不生成 PDF。
2. 来料、销售订单、销售退货、流程转移、生产订单和派工使用通用模板，并以 `SYSTEM_GENERATED_PDF` 类型追加归档。
3. 发货单使用唯一的发货文档服务，但按受众生成两种输出：`SYSTEM_GENERATED_SHIPMENT_CUSTOMER_PDF` 为客户发货单，`SYSTEM_GENERATED_SHIPMENT_INTERNAL_PDF` 为内部留档。
4. 客户发货单只展示客户交接所需的双方信息、物料、数量、金额、包裹、物流号、二维码和签收栏；内部留档才展示库位、批次、欠库、出库成本、操作人及冲销信息。
5. 同一受众的在线预览、浏览器打印和下载必须读取同一份归档字节；旧 `/api/shipments/:id/delivery-note` 下载地址也复用客户版归档，不再维护第二套渲染器。
6. 历史版本只追加、不覆盖。单据源数据、打印密度、页边距或企业抬头资料变化后生成新归档；没有变化时补打直接复用已有文件。
7. 系统生成 PDF 由单据动作按受众访问，不混入用户上传的原始附件列表。
8. PDF 包含企业抬头、单据标题和编号、状态、日期、凭据号、往来方、业务摘要、明细、数量单位、金额或成本、备注、签字栏、生成时间及页码；具体字段受单据类型和受众约束。

## 状态与风险边界

- 已确认、已完成、已发货等生效单据的历史 PDF 只追加，不覆盖。
- PDF 生成失败不得回滚已经成功保存的业务单据；界面明确提示可以从列表重新打印。
- 下载与补打复用原业务资源的查看权限，不建立绕过权限的公开文件地址。
- 发货 PDF 只允许在已发货或已签收状态输出，并同时校验有效库位数据范围。
- 生成文件通过附件存储根目录保存，未来切换对象存储时应继续复用统一附件存储服务。
- Office/CAD 在线预览 PDF 与 SOP 静态 PDF 属于不同用途，继续使用各自的转换或构建管线；标签使用独立标签画布，不冒充 A4 业务单据。
