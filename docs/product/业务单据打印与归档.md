# 业务单据打印与归档

## 目标

每次成功创建交易单据，系统同步生成适合 A4 打印、下载和审计留存的 PDF。PDF 是业务数据快照，不是页面截图。

## 覆盖范围

- 来料入库单
- 销售订单
- 发货单
- 销售退货单
- 流程转移单
- 生产订单
- 派工单

上述范围对应当前系统全部 `transaction` 类型业务页面。标签打印继续使用独立标签画布，不与 A4 单据模板混用。

## 生成规则

1. 新建表单使用“创建并输出 PDF”作为主要提交动作。
2. 业务数据必须先由服务端校验并保存；保存失败不生成 PDF。
3. 保存成功后为每一条新单据生成 PDF，并以 `SYSTEM_GENERATED_PDF` 类型附件归档到该单据。
4. 一次创建多条来料单或生产订单时，每条数据库单据分别生成自己的 PDF，界面自动打开第一份供预览，其余文件可从列表补打。
5. 草稿修改后重新生成新版本，旧 PDF 不覆盖；列表“打印”默认读取最新归档版本。
6. 若历史单据没有归档 PDF，首次点击“打印”时补生成并归档。
7. PDF 包含企业抬头、单据标题和编号、状态、日期、凭据号、往来方、业务摘要、明细、数量单位、金额或成本、备注、签字栏、生成时间及页码。

## 状态与风险边界

- 已确认、已完成、已发货等生效单据的历史 PDF 只追加，不覆盖。
- PDF 生成失败不得回滚已经成功保存的业务单据；界面明确提示可以从列表重新打印。
- 下载与补打复用原业务资源的查看权限，不建立绕过权限的公开文件地址。
- 生成文件通过附件存储根目录保存，未来切换对象存储时应继续复用统一附件存储服务。
