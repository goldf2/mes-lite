# 质量门禁

本文件记录项目在交给 AI、人类或发布前必须满足的最低质量标准。

## 检查分级

| 级别 | 适用场景 | 目标 |
| --- | --- | --- |
| Quick Check | 文档、小样式、小配置或低风险局部改动 | 快速确认没有明显破坏 |
| Standard Check | 功能、接口、数据结构、状态管理或提示词改动 | 确认相关能力可用且回归风险可控 |
| Release Check | 发布、部署、迁移、安全、数据、计费或高风险改动 | 确认可上线、可监控、可回滚 |

## 提交前检查

- [ ] 已查看当前工作区改动，确认没有混入无关文件
- [ ] 已选择本次应执行的检查级别：Quick / Standard / Release
- [ ] 已运行与本次改动相关的测试或写明无法测试的原因
- [ ] 已确认新增功能有可验证的验收标准
- [ ] 已确认错误、空状态和边界输入不会破坏核心流程
- [ ] 已确认文档中的命令仍然可用
- [ ] 已更新 `CURRENT_STATE.md`、`SESSION_LOG.md` 或其它相关交接文件

## 发布前检查

- [ ] 版本号、变更日志或发布说明已更新
- [ ] 生产环境配置与本地配置差异已确认
- [ ] `RISK_REGISTER.md` 中的高风险项已处理或明确接受
- [ ] 数据迁移、回滚方式和备份状态已确认
