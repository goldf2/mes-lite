# 安全与隐私

本文件记录 AI 协作开发中的安全边界、敏感数据约定和外部服务使用规则。

## 敏感信息规则

禁止写入仓库或交接文档：

1. API Key、访问令牌、私钥、密码和一次性验证码。
2. 生产数据库连接串、云账户凭证和第三方平台 Cookie。
3. 未脱敏的客户数据、身份证件、联系方式、支付信息或医疗信息。
4. 仅限个人设备使用的本地路径、账户名或调试凭证。

如必须说明配置，请使用变量名和占位符：

```text
OPENAI_API_KEY=TODO
DATABASE_URL=TODO
```
