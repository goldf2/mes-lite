# 项目简报

## 一句话说明

MES-lite 是面向中小型加工制造企业的轻量化 Web MES/MRP 工具，用统一物料、BOM、库存和生产事实建立可追溯业务闭环。

## 目标用户

- 车间、仓库、质量、计划和销售岗位。
- 需要低人员配置、低学习成本但仍要求库存与生产事实可追溯的制造企业。

## 核心目标

1. 用物料作为统一主数据，BOM 作为可选标准转换预设。
2. 用不可覆盖的业务流水、受控冲销和库存事务保持事实闭环。
3. 在同一 Web 工作台提供物料全景、生产、物流、库存、质量和成本辅助工具。

## 当前范围与边界

- 当前包括物料、BOM、库存、来料、生产、质量、销售发货、文档、设备和辅助成本工具。
- 锯切成本可保存为成本对象，关联物料并可选写入草稿 BOM。
- `Product` 是旧外键兼容投影，用户侧主数据统一为 `Material`。
- 不把 MES-lite 扩成专业 APS、QMS、OEE 或重型 WMS；需要独立产品边界的现场工具另建项目。

## 成功标准

1. 业务事实可追溯、可受控冲销，库存和成本不依赖界面临时状态。
2. 领域模块、数据模型、操作文档和回归验证保持同步。
3. 通过候选分支精确 CI 后进入 `main`，并在 Con01 Coolify 生产环境完成真实页面验证。

## 重要约束

- 保护生产数据和已发布 BOM；历史事实不原地覆盖。
- 生产部署只使用 Con01；除非用户明确撤销限制，不访问 AL02。
- 密钥、令牌、连接串和生产数据不得写入仓库或交接文档。
