# 研发讨论记录

本文件保存会影响后续实现的讨论结论、关键理由和开放问题，不保存逐字聊天或完整思维过程。讨论形成正式决策后，将结论写入 `DECISIONS.md` 或独立 ADR，并在此链接。

## 记录规则

- 每个主题使用稳定编号 `DISC-YYYYMMDD-NN`。
- 最新主题放在顶部；只记录具有后续价值的内容。
- 明确区分用户需求、事实、候选方案、已确认结论和未决问题。
- 被否决或暂缓的方案保留简短理由，避免后续无依据地重复讨论。
