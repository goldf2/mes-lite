# MES-lite 单厂商业交付验收基线

状态：`v0.1.362` 可执行基线

适用范围：单工厂、单应用实例、SQLite 持久数据库、文件附件持久目录。MRP-lite 与 ERP-lite 是生产履约辅助能力，不等同于完整 APS、财务或采购系统。

## 1. 交付范围

### 1.1 本次可验收

- 物料、版本化 BOM、工艺、工作中心、设备和受控作业文档。
- 生产订单、派工、班后实绩、来料、库位、库存和业务流水。
- 来料内部批次、生产投入/产出谱系、待检/可用/冻结/返工库存、质量判定与不合格处置。
- 销售订单、客户发货批次、退货回流与退货质检。
- 48 项细粒度权限、岗位任务、生产命令、本人/工作中心和库位数据范围、个人临时授权。
- SQLite 与附件一致备份、迁移前备份、非覆盖恢复候选、健康检查和审计记录。

### 1.2 不在本次承诺

- 多工厂、多租户、多实例高可用。
- APS 高级排程、完整 MRP、财务总账、应收应付、税务和完整采购。
- 逐件序列号、设备协议全覆盖、设备事件/OEE 完整闭环。
- 在未配置独立存储前承诺异地容灾；在未做实例切换前承诺完整恢复 RTO。

## 2. 交付物清单

| 类别 | 必须交付 |
| --- | --- |
| 软件 | 精确 Git 提交、版本号、Dockerfile、迁移目录和依赖锁文件 |
| 配置 | 环境变量清单、域名、健康检查、三个持久挂载、固定提交和自动部署策略 |
| 数据 | 初始化/迁移报告、数据范围审批表、备份归档 SHA-256、恢复候选记录 |
| 文档 | 当前事实手册、全流程截图 SOP、部署/备份/回滚手册、版本记录 |
| 验证 | CI 结果、类型检查、Lint、生产构建、领域回归、生产健康与业务抽查 |

## 3. 环境准入

- HTTPS 域名、可信 Origin 和 Secure Cookie 正常。
- 生产公开注册关闭；初始管理员令牌已删除；不存在共享默认密码。
- `/app/data`、`/app/public/uploads`、`/app/backups` 分别持久挂载且可写。
- SQLite 只允许一个在线写实例；需要滚动多实例时先迁移 PostgreSQL 与共享对象存储。
- Coolify 固定到已批准完整提交；自动部署默认关闭，维护窗口人工切换版本。
- 每日一致备份、失败通知和备份新鲜度已验证；异地副本必须记录目标、账号和取回验证。

## 4. 业务验收矩阵

| 流程 | 输入 | 处理 | 输出与闭环证据 |
| --- | --- | --- | --- |
| 来料 | 供应商、物料、数量、供应批号、库位 | 收货并生成内部批次 | 库存、成本层、流水和供应批号可追溯 |
| 生产 | 已发布订单/BOM、投入批次、人员、工作中心 | 登记并确认实绩 | 产出待检批次、投入谱系、库存与成本守恒 |
| 质量 | 待检/冻结批次、抽样、结论、审批依据 | 放行、冻结、复检、返工、报废、让步/解冻 | 状态库存、处置记录和操作人可回放 |
| 发货 | 客户、发货单、库位和可用批次 | FIFO 分配并确认出库 | 客户去向、批次余额、成本和流水一致 |
| 退货 | 原发货、剩余可退量、回库库位 | 生成隔离退货批次并送检 | 可反查客户、原发货、生产和供应来源 |
| 冲销 | 原业务单据、权限、原因 | 事务化逆操作 | 数量/成本/状态恢复且保留原记录和审计 |

每条流程至少用一个正常用例和一个越权/异常用例验收；不能只检查页面存在或成功提示。

## 5. 权限与岗位签署

- 企业负责人批准岗位职责和高风险动作分离。
- 权限管理员配置组权限、人员数据范围和临时授权有效期。
- 计划、生产、仓储、质量、销售、人事和运维分别使用真实岗位账号验收菜单、按钮、列表范围和 HTTP 403。
- 旧全厂兼容范围和历史永久个人覆盖逐项复核；未审批项不得视为最小权限完成。

## 6. 发布与回滚门禁

1. CI、类型检查、Lint、生产构建和受影响领域回归全部通过。
2. 版本号、发布记录、当前事实文档和 SOP 同步。
3. 生成并验证迁移前一致备份，记录归档与 SHA-256。
4. 用生产副本执行迁移演练；确认迁移清单和 checksum。
5. 在维护窗口固定目标提交并部署；验证首页、live、ready、登录和关键闭环。
6. 失败时停止写入，先生成非覆盖恢复候选；代码与数据按同一回滚点切换。
