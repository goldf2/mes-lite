# ADR 0010：工作中心、设备与工艺文档的职责边界

- 状态：已采纳
- 日期：2026-08-03

## 背景

MES-lite 需要逐步形成“人、机、料、法、环”闭环。现有 BOM 已负责材料组成，产品文档已支持版本、类别、图片和 PDF，但系统缺少工作中心及生产设备主数据。若把设备参数、加工方法直接写入 BOM，会把材料定义、资源能力和操作方法混为一体，也会导致替换同类设备时修改 BOM。

## 决策

1. BOM 只表达材料组成和单位消耗，不保存工作中心、设备或加工方法。
2. `WorkCenter` 表示锯切、钻孔、检验等逻辑生产能力区域，作为基础主数据放在“配置”菜单。
3. `Equipment` 表示实际设备，保存类型、厂商、型号、状态、位置和基础能力参数；每台设备必须归属一个启用的工作中心。设备台账作为“设备”一级业务入口。
4. “工艺文件”继续作为可配置产品文档类别。`WorkInstruction` 可以关联多个适用工作中心；未关联时表示不限制工作中心。图片、PDF、版本和说明仍复用产品文档及统一附件能力。
5. 后续派工/生产日报应记录本次实际工作中心、实际设备和工艺文档版本快照；该执行快照不反向修改 BOM 或工艺文档。

## 结果

- 更换同一工作中心内的设备不需要修改 BOM。
- 同一产品可以在不同工作中心采用不同工艺文件。
- 工作中心和设备主数据可以独立扩展点检、维护、停机与能力负荷。
- 本次只建立主数据及工艺文档适用关系，执行快照和环境记录留给后续垂直切片。
