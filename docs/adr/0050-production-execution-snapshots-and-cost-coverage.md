# ADR-0050：生产执行冻结工艺与成本覆盖关系

- 日期：2026-09-06
- 状态：已接受
- 范围：BOM 成本、生产订单、生产实绩、快捷生产日报和物料全景

## 背景

工艺路线、工序工作中心费率和 BOM 会继续演进。若生产订单只保存路线 ID 或在物料全景中按物料取一条“最近成本”，历史执行就会被后续主数据修改解释，且同一物料多个 BOM 的成本可能串到一起。锯切成本又可能已经作为成本对象包含材料和人工，若再按路线工序叠加会重复计费。

## 决策

1. `BomCostRun` 保存工艺路线、工序、工作中心和参数的序列化快照；成本明细行仍保存本次计算的分类金额、工时和来源。
2. 创建生产订单时，按目标物料、明确 BOM 和默认工艺路线寻找匹配成本运行；订单同时保存 BOM、路线和成本快照。订单不再依赖可变路线来解释历史计划。
3. 生产实绩和快捷生产日报复制订单/成本快照，查询历史详情优先读取快照。没有快照的旧记录只在读取时兼容当前默认路线，新的写入不得省略快照。
4. BOM 成本页按物料展示全部已发布 BOM 并要求明确选择 `bomId`；物料全景按 `bomId` 建立最近成本运行映射，并展示对应路线和工序明细，禁止按物料唯一成本覆盖多个 BOM。
5. 若成本对象语义已覆盖路线中的同名工序（当前重点为 `SAWING_COST`/“锯切成本”），保留 `PROCESS_OPERATION` 追踪行但成本为零，并记录覆盖说明；其他工序仍按工作中心费率计入。
6. 工作中心保存人工、机时和能源默认费率。成本计算的有效费率按工序正值、工作中心默认值、本次计算页面费率的顺序回退；序列化路线时写入实际采用值，避免工作中心后续调整改变已保存事实。费率为 0 表示未配置，当前不提供“显式强制零费率”开关。
7. 纯计算规则和快照序列化器位于共享 `lib`，领域模块通过公开契约调用，不穿透其他模块的内部实现。

## 后果

- 历史订单、实绩和日报可以在路线、工作中心费率或成本对象变化后继续重现当时依据。
- 新增可空列和索引，不需要回写历史业务数据；旧数据需要在后续业务写入或受控重算时逐步补齐。
- 工作中心费率迁移以 0 初始化既有记录；旧路线/成本运行没有工作中心费率时仍按其已保存的工序费率或当次页面费率兼容计算。
- 标准成本与实际库存成本保持分离，差异分析仍需比较成本快照和实际投入成本。
- 成本计算页已经显式选择 BOM 版本；生产订单仍自动选择默认路线/最近匹配成本运行。若同一 BOM 需要在生产订单中并存多套成本假设，后续应增加订单级成本运行选择，而不是覆盖既有快照。

## 验证

验证脚本覆盖成本工序展开与重复计费保护、成本运行路线快照、订单冻结、实绩继承、快捷日报继承、物料全景按 BOM 映射以及模块边界和架构基线。
