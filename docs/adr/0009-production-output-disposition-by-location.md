# ADR 0009：生产产出去向由库位表达

- 状态：已采用
- 日期：2026-08-01

## 背景

生产日报原来同时保存合格、不良和报废数量，但确认库存时只有合格数量进入所选库位。不良和报废既像质量分类，又没有对应库存去向；引入可配置库位后，这套固定分类与实际库存模型重复，并容易造成“日报有数量、库存没有实物”的歧义。

## 决策

1. `DailyProductionReport` 只保存一个 `outputQty` 和一个 `outputLocationId`。
2. 成品、不良、报废、待检或其他去向由可配置库位表达，不在日报模型和界面中写死。
3. 日报确认时，全部 `outputQty` 增加到物料总库存和所选产出库位；BOM 原料耗用同样按 `outputQty` 计算。
4. 同一生产日期存在多个实物去向时，分别登记日报，使每一笔库存过账只有一个明确库位，便于独立确认和冲销。
5. 历史已确认或已冲销日报只迁移原来实际入库的 `goodQty`；历史草稿尚未过账，可将原三项数量相加迁移为 `outputQty`。

## 结果

- 日报、库存和物流使用同一套“物料 + 数量 + 库位”口径。
- 新增业务类别只需配置库位，无需修改数据库字段和业务代码。
- 质量率等统计不能再从生产日报固定字段推导；需要时应基于指定库位集合或独立质检记录计算。
