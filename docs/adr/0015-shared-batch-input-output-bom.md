# ADR-0015：BOM 使用整批输入与整批输出

- 状态：已接受
- 日期：2026-08-04
- 取代：ADR-0014 中“每项产出分别绑定投入”的决策

## 背景

冲压、锯切、拆分和联产品生产中，一次生产批次可能同时消耗多种物料，并同时得到主产品、副产品、废屑或可回收料。把同一批投入重复绑定到每项产出，会造成录入重复，也可能在生产实绩中重复扣减库存。

## 决策

1. 一个 BOM 表示一次完整的生产批次：左侧全部输入共同消耗，右侧全部输出同时产生。
2. `BOMItem.quantity` 保存每批投入物料按主库存单位归一化后的绝对数量，`unit` 保存主库存单位，`entryUnit` 保存用户选择的录入单位；同一投入物料在一个 BOM 中只能出现一次。
3. `BOMOutput.quantity` 同样按产出物料主库存单位保存同一批次的绝对产出，`entryUnit` 只负责恢复录入显示；每个 BOM 保留且只保留一个主产出，用于订单计划、完成量和成本归集基准。
4. 新保存的物料投入不再绑定某项产出，`BOMItem.outputMaterialId` 写入 `null`。该字段仅为旧 BOM 和历史订单快照保留兼容读取。
5. 编辑器使用左输入、右输出的并列结构。长度和重量允许选择同量纲录入单位，切换单位时同步换算数值；新行长度默认 `mm`、重量默认 `g`。数量类和其他类保持物料主库存单位，不提供跨量纲转换。
6. 生产计划按主产出数量计算批次倍数，再等比例展开整批输入和全部计划产出。生产实绩中的某项副产出偏差不会重复增加整批投入。
7. 标准 BOM 不记录固定或百分比损耗；可识别的废料、废屑和可回收料作为输出物料记录，实绩层另记本批计划外额外耗用。
8. 已冻结的历史订单快照继续按其原有 `outputMaterialId` 解释，不追改历史业务数据。

## 示例

一次冲压批次可录入带钢 `350 mm`，同时输出冲压件 `2 件`和废屑 `120 g`。系统分别保存为主库存口径 `0.35 m`、`2 件`和 `0.12 kg`。生产 `100 件`主产出需要 `50` 个批次，因此计划消耗带钢 `17.5 m`，并计划产生废屑 `6 kg`。

## 结果

- BOM 可以表达多投入、多产出，但不存在逐输出分摊投入。
- 不同量纲只在各自物料行内记录，不进行相加或强制换算。
- 同量纲录入单位只影响编辑体验，不改变生产、库存和成本的主单位口径。
- 后续若需要副产品成本分摊，应作为独立成本政策实现，不能恢复逐输出投入映射。
