# ADR 0007：物料单位变更只修改主数据并记录审计

> 该决策关于“已有业务历史的物料仍可直接修改库存口径”的部分由 [ADR 0045](./0045-explicit-bom-measure-and-immutable-stock-basis.md) 取代。历史数据仍按本 ADR 的快照规则读取；新的单位变更必须遵守库存记账口径冻结规则。

- 状态：已采纳
- 日期：2026-07-31

## 背景

物料可能因录入错误或管理口径调整而需要修改计量方式和单位。不同计量方式可能属于不同量纲，系统无法可靠推断数量应该如何换算，操作员也可能已经在外部完成核对和处理。

原有界面先要求浏览器确认，后端又因库存、流水或 BOM 关系禁止修改，导致操作员无法完成主数据修正。

## 决策

物料编辑允许直接修改计量方式和单位：

1. 系统只修改当前物料主数据，不换算库存、预留、成本、BOM 比例或任何业务数值。
2. 不改写来料单、库存流水、成本层、生产日报、发货、退货和既有 BOM 中保存的历史单位。
3. 单位配置版本递增，并写入 `UNIT_CHANGE` 审计记录，保存修改前后设置以及“未换算数值、未改写关联记录”的声明。
4. 数值核对和必要的业务调整由操作员负责。

## 影响

- 用户可直接完成“件改为 m”等计量设置变更，不再遇到前后端重复确认和拦截。
- 物料当前库存界面会按新的主单位展示当前数值，但历史业务记录仍保留过账时的单位快照。
- 操作员需自行确认当前数值和既有 BOM 是否需要后续调整。
