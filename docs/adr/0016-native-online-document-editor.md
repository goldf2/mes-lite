# ADR 0016：MES-lite 原生在线文档使用结构化正文

## 状态

已采纳，2026-08-04。

## 背景

产品文档原来必须绑定成品物料，内容只能通过图片或 PDF 附件表达。这适合归档外部文件，但不适合直接维护设备参数、作业步骤和跨产品通用规范，也使现场编辑继续依赖外部 Office 或 Wiki 工具。

## 决策

- 沿用现有“产品文档”入口和 `WorkInstruction` 技术模型，不单独引入 Wiki 服务或 MDX 构建链。
- 每篇文档必须维护独立 `title`，`materialId` 改为可空；空值表示跨产品通用文档，非空时产品全景图按 `materialId` 精确展示。
- 在线正文使用 Tiptap JSON 保存到 `contentJson`。服务端解析正文并生成只读 `contentText` 搜索投影，客户端不能单独指定搜索文本。
- 第一版提供标题层级、加粗、斜体、列表、引用、代码块和撤销/重做；在线正文与图片/PDF附件可以独立或同时存在。
- 类别、版本、状态、工作中心、权限、审计和附件继续复用现有模型。具体工序实绩和设备加工参数仍不进入 BOM。

## 结果

- MES-lite 可以直接创建、编辑和搜索基础作业指导书，不依赖外部文档平台。
- 结构化 JSON 比保存任意 HTML 更容易控制渲染安全，也为后续目录、表格、图片嵌入、发布版本和 PDF 导出保留稳定数据源。
- `contentText` 是可重建投影，不是第二份正文事实源。
- ADR 0002 中“必须绑定成品物料、不保存独立标题”的决定由本 ADR 取代；其附件生命周期和产品全景图精确关联原则继续有效。
