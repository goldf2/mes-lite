# ADR 0027：来料单头多明细与 BOM 物料级跨计量换算

## 状态

已采纳，2026-08-10。

## 背景

原来每条来料明细实际生成一张独立单据，无法表达一张供应商来料凭据包含多种物料。界面允许添加多行，但编号、状态、附件、打印、归档和红冲仍按单行处理。与此同时，物料虽已有主计量、参考计量和换算率，BOM 只允许同量纲单位换算，不能直接使用加工行业常见的标准单重或标准米重。

## 决策

- 新增 `MaterialReceipt` 单头，保存单号、供应商、凭据号、日期、状态、统一待分库库位、收料人和备注。
- `MaterialIn` 作为来料物料明细和库存成本来源行，通过 `receiptId + lineNo` 归属单头；既有单行记录迁移为一单一行，原 ID 作为单头 ID 以保持附件引用。
- 创建、编辑、收货、拒收、红冲、归档、打印和附件均以单头为事务边界；任一明细失败则整单回滚。
- 一张来料单只选择一个待分库库位，全部明细确认后先进入该库位；最终库位分配复用既有 `FlowTransfer`，来料单不重复实现调拨。
- `Material.conversionRate` 统一解释为“1 主库存单位 = N 参考单位”。数量到重量表示标准单重，长度到重量表示标准单位长度重量。
- BOM 单位目录继续处理同量纲换算；只有物料配置有效参考计量和换算率时，才允许主计量与参考计量互换。
- `BOMItem` 和 `BOMOutput` 保存主库存数量，同时冻结原始录入量、换算率、来源和单位版本。之后修改物料换算率不改写历史 BOM。

## 结果

- 操作员可用一张来料单登记多种物料，并整单确认、打印、归档和红冲。
- 来料接收与分库成为两个明确步骤，避免不同物料在收货时重复选择最终库位。
- 长度库存物料可按重量填写 BOM，数量库存物料可按总重量填写 BOM；实际库存仍只按物料主库存单位记账。
- 历史单据、BOM 和附件保持可读，新的换算快照避免主数据变更造成历史漂移。
