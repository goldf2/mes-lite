# ADR 0006：计量方式基准单位与可配置单位目录

## 状态

已采用。

## 背景

物料主库存单位和参考/计价单位原先使用自由文本，容易出现 `m`、`米`、`M` 等同义写法，也无法证明自定义单位与系统计算单位之间的数量关系。BOM、库存和成本计算需要稳定、可校验的计量口径。

## 决策

1. 每种计量方式使用固定系统基准单位：
   - 长度：`m`
   - 重量：`kg`
   - 数量：`件`
   - 其他：`项`
2. 系统预置常用单位及其基准换算系数；预置单位不可修改或删除。
3. 管理员可在“工具 → 单位配置”新增单位，必须填写所属计量方式、单位编码、显示名称和“1 自定义单位等于多少基准单位”。
4. 物料主库存单位和参考/计价单位只能从相应计量方式的单位目录选择，不再允许自由输入。
5. 自定义单位被物料使用后，只允许修改显示名称，不允许修改编码、计量方式、换算系数或删除。
6. 部署前已经存在但未登记的旧单位继续显示，并允许在单位不变时编辑物料其它字段；新增物料、单位变更和批量导入必须使用单位目录。
7. 长度 BOM 仍统一保存为 `m/成品主单位`；尺寸录入单位来自长度单位目录，并按目录换算系数转换。
8. 物料的跨计量换算（例如 `1 m = 2.5 kg`）仍是该物料的实际/参考换算关系，不能用通用单位目录替代。

## 结果

- 单位拼写和所属计量方式可统一校验。
- 自定义单位有明确、可审计的基准关系。
- 单位目录变化不会悄悄改变已存在库存和 BOM 数值的含义。
- 旧数据可以逐步规范，不要求上线时一次性迁移。
