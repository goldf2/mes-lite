# ADR 0039：以已发布来料标准显式启用收货检验

状态：已接受

日期：2026-08-14

## 背景

来料收货原本直接生成可用内部批次、库存与成本层。质量领域已经拥有版本化标准、任务快照、逐项检验和库存状态转换，但如果把所有收货一律改成待检，会在没有质量标准和检验岗位准备的物料上制造停线；如果另建来料 QC 表，则会产生与生产、退货质量不同的事实和权限口径。

## 决策

1. `MATERIAL_IN` 成为检验标准的第三种来源，与生产产出和客户退货共用 `QualityInspectionStandard`、`QualityInspection`、逐项结果、附件、趋势和质量处置事实源。
2. 已发布且物料、来源完全匹配的 `MATERIAL_IN` 标准是自动送检的显式开关。收货逐行判断：有标准进入 `QUARANTINE` 并建立任务；无标准继续进入 `AVAILABLE`。一张多物料来料单允许两种路径并存。
3. 来料任务必须保存收货时的标准、版本、抽样和项目快照。标准在标准查询与任务建立之间失效时，整个收货事务失败，不能留下只有隔离库存而没有任务的半成品状态。
4. 仓库岗位使用 `materialIn.update` 确认收货，但不能因此读取或判定质量任务。任务查询、判定、处置、授权放行和附件继续分别使用既有质量权限，并叠加库位数据范围。
5. 待检来料红冲时，尚未执行且没有处置的首轮任务改为 `CANCELLED`，并从隔离库存反向冲销。首轮已合格且批次、余额和成本层未被下游使用时，可以从可用库存红冲。
6. 已失败、存在后续轮次/处置，或批次、成本层已被使用的来料不得直接红冲；必须先按质量与逆向业务流程处理，不能通过普通库存调整绕过事实链。
7. 数据库触发器允许 `MATERIAL_IN` 来源并保护已取消任务不可再修改，服务与数据库共同维护生命周期不变量。

## 结果

- 企业可以按物料逐步上线来料检验，不会因版本升级把全部来料突然冻结。
- 仓库收货、质量判定和库存状态在一个事实链中交接，同时保持动作权限分离。
- 来料、生产和退货质量可以使用同一趋势口径，历史标准修订不会改变既有任务。
- 当前实现仍是批次级检验，不包含 SPC、过程能力、供应商质量评分或多级审批。

## 回滚

应用回滚时固定到上一个已验证提交并暂停新的来料收货、检验和红冲写入。保留 `MATERIAL_IN` 标准、任务快照及取消记录，不执行破坏性降级。若旧版本无法识别来料质量任务，应在恢复服务后继续暂停受控物料收货，优先重新部署本版本；只有数据库或迁移损坏且应用回滚无效时，才经业务确认恢复部署前数据库与附件一致备份。
