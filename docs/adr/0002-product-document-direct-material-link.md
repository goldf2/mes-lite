# ADR 0002：产品文档直接关联成品物料

## 状态

已接受，2026-07-30。

## 背景

原 `WorkInstruction` 同时保存指导书编码、标题、客户和可选物料，录入重复，且客户可能与物料所属客户不一致。实际需要的是围绕产品集中维护作业指导书、PDF 图纸、工艺文件、检验文件等资料，并在产品全景图直接查看。

## 决策

- 用户侧模块命名为“产品文档”，数据库技术模型暂保留 `WorkInstruction`。
- 每条产品文档必须直接关联一个 `Material.category = FINISHED` 的产品；允许同一产品维护多条不同类别或版本的文档。
- 不再保存或录入指导书编码、标题和独立客户；列表标题、编码和客户均来自关联产品。
- 文档类别为：作业指导书、图纸、工艺文件、检验文件、包装文件、设备文件、其他。
- 每条产品文档可以上传多张图片或多个 PDF，全景图显示文档类别、版本、状态和附件数量。
- 本次迁移不兼容旧指导书：删除旧 `WorkInstruction`、对应附件元数据，并在迁移首次执行前清理专属附件目录。
- 产品文档永久删除时，其自有附件是级联删除对象，不作为删除阻断；物料、单据等其他资源仍保持附件引用保护。

## 影响

- 创建和编辑产品文档时，产品为唯一必填主数据。
- 客户筛选通过 `Material.customerId` 计算，不再存在双客户来源。
- 产品被永久删除前，仍会被关联产品文档阻止；应先归档并永久删除产品文档。
- 首次部署此迁移会不可恢复地删除旧指导书及其附件，部署前如需保留文件必须自行备份。
