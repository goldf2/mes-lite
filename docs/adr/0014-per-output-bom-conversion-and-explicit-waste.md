# ADR-0014：按产出绑定 BOM 转换关系并显式记录损耗物

- 状态：已接受
- 日期：2026-08-04

## 背景

多产出 BOM 可以同时产生主产品、副产品、可回收料、废料和废屑。若所有投入仍只按主产出数量归一，其他产出就没有自己的换算依据；若同时在 BOM 中填写固定或百分比损耗，又把废料、废屑列为产出，还会重复核算物料。

## 决策

1. 每条库存物料投入 `BOMItem` 必须通过 `outputMaterialId` 绑定一项 `BOMOutput`。
2. `BOMItem.quantity` 表示对应产出基准数量所需的投入量，单位用量为 `BOMItem.quantity / 对应 BOMOutput.quantity`。
3. 同一个投入物料可以分别服务多个产出，唯一关系是“BOM + 投入物料 + 对应产出物料”；每项产出至少要有一条投入转换关系。
4. 每项产出分别提供两种内置录入模型：
   - 单位标准用量：直接填写每 1 产出主单位所需的投入；
   - 投入总量 ÷ 产出总量：按量纲显示为长度→件数、重量→件数、数量→数量等。
   两种方式只用于界面换算，数据库保存统一比例和对应产出，不保存计算器参数。
5. 标准 BOM 不再设置固定损耗或百分比损耗。可识别的损耗物必须作为废料、废屑或可回收料产出记录；这样投入和全部去向可以守恒，且不会与损耗字段重复。
6. 生产订单冻结投入对应产出关系。班后实绩按各产出实际数量分别计算投入贡献，再按投入物料汇总扣库。实绩层现存的固定/百分比字段只表示本批次计划外额外耗用，不改变标准 BOM。
7. 旧 BOM 迁移时将已有物料投入绑定到主产出；旧生产订单快照缺少 `outputMaterialId` 时也回退到主产出，以保证历史可解释。

## 后果

- 多个产品、副产品和损耗物都拥有独立且可审计的投入换算关系。
- 同一种投入可被多个产出引用，生产实绩会合并为一条实际领用/扣库记录。
- 标准损耗不再与废料产出重复，BOM 更接近物料守恒模型。
- 当前成本计算仍只展开绑定主产出的投入；联产品成本分摊需要后续单独定义。
