# ADR 0032：来料批次、生产投入分配与父子谱系

- 状态：已接受
- 日期：2026-08-13
- 适用版本：v0.1.355

## 背景

v0.1.354 已将生产产出写为内部批次并进入待检，但供应商批号只保存在来料行，生产投入只扣总库存和成本层，无法回答某批成品用了哪一批原料，也无法从供应批次查到下游产出。

## 决策

1. 每条已收货 `MaterialIn` 生成一个唯一 `InventoryLot`，内部批次号为 `RM-<来料行号>`，供应商批号保存在 `supplierLotNo`。
2. 生产实绩确认时，在所选库位按内部批次 `receivedAt` 先进先出分配可用库存，写入 `InventoryLotAllocation`。
3. 每个投入分配与每个产出批次建立 `InventoryLotGenealogy` 父子边。多投入、多产出均显式保留，不按成本归集比例推断谱系。
4. 流程转移同步移动批次余额；总库存和成本层保持不变。
5. 历史未跟踪可用库存首次参与批次动作时，生成 `LEGACY-<物料>-<库位>` 兼容批次。它的来源类型为 `LEGACY_INVENTORY`，不得填写或推断供应商批号。
6. 成本核算继续由 FIFO/加权平均成本层负责；批次余额用于实物追踪，两者保持引用但不强行一一等同。
7. 生产冲销恢复父批次余额，并将投入分配和谱系边标记为 `REVERSED`；不物理删除历史事实。

## 不变量

- 有效批次余额不得为负，且不得大于同物料、同库位、同状态库存余额。
- 有效投入分配的物料必须等于生产投入物料，数量必须大于 0，父批次必须处于 `OPEN`。
- 有效谱系边只能连接有效投入分配和 `OPEN` 的父/子批次。
- 来料批次已投入生产或余额已变化时，禁止整单红冲。
- 同一实绩的批次分配、库存出库、成本出库、产出批次和父子谱系必须处于同一数据库事务。

## 回滚

- 迁移只新增一个可空外键和两张表，可先部署数据库再部署应用。
- 尚无 v0.1.355 写入时可回退应用，保留空列和空表。
- 已产生批次分配或谱系后不得删除新表；应回滚应用后保持只读，或修复并向前部署。生产冲销使用业务冲销，不使用数据库删表回滚。

## 暂不覆盖

- 发货与客户退货批次分配。
- 部分批次拆分、合并、返工、报废、让步和解冻。
- 跨多代递归图谱的独立查询页；当前弹窗可沿任一相邻批次继续导航。
