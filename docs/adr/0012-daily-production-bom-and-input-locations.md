# ADR-0012：生产日报显式选择 BOM 并按投入明细记录来源库位

## 状态

历史过渡决策；生产入口后续由 [ADR-0013](0013-multi-output-bom-and-production-order-convergence.md) 收敛到生产订单。

## 背景

同一产出物料已经允许维护多个 BOM 转换方案，但生产日报原先总是读取默认方案，且所有投入共用一个原料库位。这样无法准确表达“本批实际使用哪个转换关系”以及“不同投入分别从哪个库位消耗”。

## 决策

1. 日报界面默认预选产出物料的默认启用 BOM，但提交时显式保存 `bomId`。
2. 日报同步保存 BOM 名称、版本、类型和基准产出数量/单位；每条耗用继续保存物料、单位用量、损耗、计划量和实际量快照。
3. `DailyProductionConsumption.locationId` 保存每项投入的实际来源库位。日报级 `consumptionLocationId` 降为默认值和历史兼容回退。
4. 日报确认在单一事务中按各明细库位扣减投入、消费成本层，并将产出增加到所选产出库位；任一步失败则全部回滚。
5. 冲销恢复到原投入明细库位，并从原产出库位扣回；流水保留原移动与反向移动关联。
6. 该限制已由 ADR-0013 解除：BOM 使用独立产出行表达多项产出，不在执行单据中临时绕过。

## 上线前数据处理

- 上线前日报均为测试数据，迁移会删除旧日报并撤回其库存流水净影响，不保留旧结构兼容。
- 新接口要求显式提交 `bomId` 和每条投入的 `locationId`。
- 后续修改或重命名 BOM 不回算既有日报快照。
