# ADR 0004：锯切执行使用实体分账与库存总账双轨事务

- 状态：已接受
- 日期：2026-07-30

## 背景

型材 BOM 的用量描述成品需要几段及每段切长，但不能直接推导实际领用几根原料。实际根数只有在排样选定具体型材实体后才能确定。若工单创建仍按 BOM 成品件数预留库存，会把“段数”误当成“根数”，并与后续实体占用重复。

现有 MES-lite 同时存在：

- `Stock`：按物料规格汇总的库存与成本总账；
- `ProfileStockEntity`：记录实际长度、批次、单根/同长批次及谱系的实体分账；
- `InventoryCostLayer`：FIFO 或加权平均成本基础。

锯切执行必须同时维护三者，且完工冲销后能够回到可继续执行或取消排样的状态。

## 决策

1. 带有效 `cutLengthMm` 且启用型材实体追踪的 BOM 行，在创建生产工单时不创建传统领料项，也不预留汇总库存。
2. 排样确认时，按实际参与切割的原料根数同时：
   - 将实体分账从可用转为占用；
   - 将 `Stock` 的同等根数及估算计价数量从可用转为预留；
   - 写入两套可审计流水。
3. 排样方案与锯切任务分离。方案保存计划值；任务保存开工、实绩、合格/不良/报废、实际损耗及操作信息。
4. 锯切完工时：
   - 从 `Stock` 总量和预留量扣减实际领用根数；
   - 使用现有计价方法消耗成本层；
   - 将来源实体的占用数量转为已耗用；
   - 达到配置阈值的剩余长度生成带父子谱系的余料实体，并按剩余长度比例将数量、核算数量和成本回收入 `Stock`；否则只记录为废料/损耗。
5. 完工冲销必须在余料实体尚未被后续占用、拆分或耗用时执行。冲销恢复成本层、库存总账、来源实体占用和需求完成量，并把方案恢复为已确认状态。
6. 取消排样只允许在没有未冲销完工实绩时执行，并释放实体分账和库存总账预留。
7. 所有写操作使用客户端请求号或稳定业务键保证幂等；默认禁止负库存。

## 结果

- BOM 继续表达“需要什么”，排样和锯切实绩表达“实际用了哪根、用了几根”。
- 汇总库存数量、实体数量和成本层在同一事务中变化。
- 余料保留来源谱系，废料不会伪装成可用库存。
- 冲销路径受约束，但能完整恢复到排样确认后的状态。

## 兼容策略

- 未填写切长或未启用型材实体追踪的 BOM 行继续使用原有领料与库存预留流程。
- 阶段 2 已创建但没有汇总库存预留数据的旧排样方案仍可查看和取消；进入锯切执行前必须重新确认形成完整预留。
- 现有物料、BOM、生产、库存及发货 API 不删除、不改写历史记录。
