# ADR 0005：BOM 单位消耗量与生产日报损耗

## 状态

已采用。本决策替代 ADR 0004 第 7 条中“BOM 只表达关联”的部分，其它主计量与来料批次决策继续有效。

## 背景

成品需要一个稳定的标准用料口径，才能按本次生产数量计算原料基准耗用。该标准可能是长度、重量或数量，取决于原料的主计量方式；它不是不规则来料的标准长度，也不能替代来料批次的实测长度和重量。

生产过程还会产生损耗。损耗可能按每一成品主单位固定增加，也可能按基准耗用的百分比增加；实际耗用仍可能与计算值不同。

## 决策

1. `BOMItem.quantity` 保存单位消耗量，单位固定为原料主库存单位。
2. 当前 BOM 基准产出量为 `1`。长度原料的单位消耗量表示每一成品主单位的标准用料长度；数量原料表示每一成品主单位的标准用料数量。界面使用真实业务单位（如 `mm/件`、`根/套`），不使用 `unit` 作为显示单位。
3. 物料主数据仍不保存原料标准长度。不同来料批次继续记录实测根数、总长度和总重量。
4. 生产日报按合格、不良和报废之和计算总加工数量，并为每种 BOM 原料选择损耗方式：
   - `FIXED_PER_UNIT`：每一成品主单位固定损耗；
   - `PERCENT`：按基准耗用量的百分比损耗。
5. 计算公式：

```text
基准耗用 = 总加工数量 × 单位消耗量
固定损耗 = 总加工数量 × 每产出单位固定损耗
百分比损耗 = 基准耗用 × 损耗百分比 ÷ 100
计算耗用 = 基准耗用 + 损耗
```

6. 计算耗用默认作为实际耗用，操作员可以在日报草稿中修正实际耗用；确认库存时只扣减实际耗用。
7. 日报耗用行保存 BOM 单位消耗量、损耗方式、损耗值、损耗数量、计算耗用和实际耗用快照，后续 BOM 修改不影响历史日报。
8. BOM 成本试算使用单位消耗量乘数量基准，不自动套用某张生产日报的损耗。

## 结果

- 成品拥有稳定、可复用的标准用料换算。
- 长度、重量、数量原料共用一套主单位公式。
- 标准、损耗、计算值和实际值可以独立追溯。
- 不规则来料仍按批次实测，不需要建立单根实体库存或原料标准长度。
