# ADR 0005：BOM 换算比例与生产日报损耗

> 来料批次数量部分已被 [ADR 0028](./0028-receipt-actual-first-history-fallback.md) 取代；BOM 和生产实绩决策继续有效。

## 状态

部分被 ADR 0011、ADR 0014 和 ADR 0015 替代。历史快照原则继续有效；当前 BOM 保存整批共同投入和同时产出，不再保存逐产出转换关系。生产实绩中的计划外差异字段继续兼容。

## 背景

成品需要一个稳定的标准用料口径，才能按本次生产数量计算原料基准耗用。该标准可能是长度、重量或数量，取决于原料的主计量方式；它不是不规则来料的标准长度，也不能替代来料批次的实测长度和重量。

生产过程还会产生损耗。损耗可能按每一成品主单位固定增加，也可能按基准耗用的百分比增加；实际耗用仍可能与计算值不同。

## 决策

1. `BOMItem.quantity` 保存归一后的换算比例，单位固定为原料主库存单位；`BOM.outputQuantity` 固定为 `1`，因此一条关系的含义始终是“每 1 个成品主单位对应多少原料主库存单位”。
2. 界面提供两种录入算法，但不长期保存算法参数：
   - “标准用量 + 损耗”将固定或百分比标准损耗计入标准用量；
   - “成品数量 : 原料数量”直接用原料数量除以成品数量。
   两种算法最终都归一为同一换算比例。长度原料在界面使用系统长度单位目录录入（预置 `mm`、`cm`、`m`），标准尺寸与固定损耗共用该尺寸单位，保存时统一换算为 `m/成品主单位`；其它原料使用其主库存单位。
   用量和比例允许录入小数，按最多 6 位小数保存和显示，例如 `0.001 kg/件`。
3. 物料主数据仍不保存原料标准长度。不同来料批次继续记录实测根数、总长度和总重量。
4. 生产日报按合格、不良和报废之和计算总加工数量，并为每种 BOM 原料选择损耗方式：
   - `FIXED_PER_UNIT`：每一成品主单位固定损耗；
   - `PERCENT`：按基准耗用量的百分比损耗。
5. 计算公式：

```text
基准耗用 = 总加工数量 × BOM 换算比例
固定损耗 = 总加工数量 × 每产出单位固定损耗
百分比损耗 = 基准耗用 × 损耗百分比 ÷ 100
计算耗用 = 基准耗用 + 损耗
```

6. 计算耗用默认作为实际耗用，操作员可以在日报草稿中修正实际耗用；确认库存时只扣减实际耗用。
7. 日报耗用行保存 BOM 换算比例、损耗方式、损耗值、损耗数量、计算耗用和实际耗用快照，后续 BOM 修改不影响历史日报。
8. 录入算法中的标准损耗已经折入 BOM 比例；生产日报损耗表示本批次额外偏差。BOM 成本试算使用换算比例乘数量基准，不自动套用某张生产日报的额外损耗。

## 结果

- 成品拥有稳定、可复用的标准用料换算。
- 长度、重量、数量原料共用一套主单位公式。
- 标准、损耗、计算值和实际值可以独立追溯。
- 不规则来料仍按批次实测，不需要建立单根实体库存或原料标准长度。
