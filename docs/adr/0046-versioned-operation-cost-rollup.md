# ADR 0046：按工序核价并汇总零件加工成本

- 状态：已接受，2026-09-05

## 背景

锯切、钻孔、车削、铣削等工序的成本构成不同。单独保存一个零件的总成本会丢失工序依据，也无法解释材料成本、人工工时、机时和其他直接费用分别来自哪里。

## 决策

1. 每个加工工序通过对应的计算器或工艺模板生成一个版本化的工序成本对象。锯切计算器先计算成品材料、锯屑、余料和回收价值，再保存单件材料成本、人工工时、机时和其他直接费用。
2. 工序成本对象统一保存单位成本、人工小时、机时、直接费用、费率、有效版本和来源快照；不同工序可以使用不同的专用计算页面，但不能各自建立不兼容的成本结构。
3. BOM 或工艺路线引用工序成本对象。成本计算运行时按目标产出数量展开所有有效工序，汇总材料成本、人工成本、机时成本、其他直接费用和可选的期间费用，形成零件级成本快照。
4. 防止材料成本重复计算：转换型工序由工序成本对象承担原料成本时，BOM 不再重复计入同一原料；装配型工序可以由 BOM 承担投入材料成本，工序对象只承担加工成本。
5. 已保存或已用于 BOM/成本运行的工序成本版本不可覆盖；参数变化必须复制为新版本，并保留来源工序、物料、BOM 和计算输入快照。

6. 工序成本与工作中心联动：BOM 描述投入与产出，工艺路线描述工序顺序，工作中心描述工序执行位置、能力、资源和费率。BOM 可关联一条默认工艺路线，也可以在成本运行或生产订单中显式选择适用路线。
7. 成本运行必须同时冻结 BOM 版本、工艺路线版本、工序快照和工作中心/设备费率快照；后续修改工作中心或工艺模板不得改变已经发布的 BOM、生产订单和历史成本运行。

## 结果

- 可先在锯切页面核算一个工件的材料成本，再叠加锯切人工、机时和其他费用。
- 钻孔、车削等页面可以按相同结构扩展，最终由 BOM/工艺路线形成零件完整加工成本。
- 物料全景、BOM 成本页和成本运行记录可以分别查看总成本与每道工序的成本构成。
- 可以按“BOM → 工艺路线 → 工序 → 工作中心 → 成本对象”追溯一件零件的材料、人工、机时和其他直接费用。
