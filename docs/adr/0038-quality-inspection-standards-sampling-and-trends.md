# ADR 0038：检验标准版本、任务快照与质量趋势共用质量事实源

状态：已接受

日期：2026-08-14

## 背景

生产产出和客户退货已经能形成待检任务、库存隔离及不合格处置，但检验人员仍需人工决定抽样数，任务也没有保存当时适用的检验项目。若直接在已完成检验上回查“当前标准”，后续标准修订会改变历史任务的解释；若另建统计台账，又会与实际检验和批次事实产生双重口径。

## 决策

1. 使用 `QualityInspectionStandard` 与 `QualityInspectionStandardItem` 保存检验标准。标准身份由编码和版本组成，固定适用物料与任务来源；生命周期仅允许 `DRAFT → RELEASED → OBSOLETE`。
2. 只有草稿可修改。发布后标准及项目不可覆盖或删除；修订必须复制为新版本。同一物料与任务来源最多只有一个已发布版本，新版发布在同一事务自动停用旧版。
3. 抽样模式为全检、固定数量或比例；可叠加最低和最高抽样数，最终建议值不超过待检数量。建议抽样数是受控提示，实际抽样数仍作为检验事实独立保存。
4. 创建生产或退货待检任务时，系统自动选择当时已发布标准，并把编码、版本、名称、抽样规则、建议抽样数和全部项目复制到 `QualityInspection` 与 `QualityInspectionCheckItem`。没有生效标准时仍允许建立兼容待检任务，但明确显示无标准快照。
5. 复检沿用原任务快照，不自动切换到后来发布的版本。标准修订只影响新建任务，历史任务语义保持不变。
6. 带项目的任务完成判定时必须逐项提交 `PASS/FAIL`；项目结果与整单结论必须一致，完成后不可覆盖或删除。库存放行、冻结和后续处置仍由既有质量服务在同一事务处理。
7. 质量趋势只聚合已完成 `QualityInspection` 和实际 `QualityInspectionCheckItem`，输出检验批次通过率、样本通过率、按日/物料汇总和失败项目排行；查询继续叠加当前人员库位数据范围，最多读取 5000 条并显式返回截断标记。
8. 标准维护使用独立 `qualityStandards` 权限；任务读取、判定、处置与授权放行继续使用既有四层质量权限。检验附件继续复用公共附件模块，并同时校验附件权限、质量资源和质量任务数据范围。

## 结果

- 新检验任务可以回答“按哪个版本、抽多少、检哪些项目”，历史任务不会被标准修订改写。
- 检验标准、逐项结果、库存状态和质量趋势共用同一事实链，不建立平行统计台账。
- 当前趋势是描述性质量统计，不等同于 SPC 控制图、过程能力分析或多级质量审批。
- 来料收货仍未自动生成来料检验任务；本版标准来源仅覆盖生产产出和客户退货。

## 回滚

应用回滚时固定到上一已验证提交并暂停新的标准、检验和处置写入；保留新增标准、项目、任务快照和逐项结果，不执行破坏性降级。旧版本会忽略新增表和字段，但仍可读取原有质量、批次和库存事实。只有迁移或数据库损坏且应用回滚无效时，才经业务确认恢复部署前数据库与附件一致备份。
