# ADR 0008：总库存与库位实物余额双层模型

## 状态

已采纳，2026-08-01。

## 背景

`Stock` 已承担物料总数量、双单位核算、库存金额和成本层汇总。来料、生产日报、发货与退货也已经通过统一过账服务更新该总库存。业务现在需要配置库位，并要求生产日报确认入库后的产出能被物流发货直接读取和扣减。

如果把成本金额复制到每个库位，会同时引入库位成本分摊、调拨成本和历史重算，超出当前轻量 MES 的需要；如果只在单据上保存库位而不维护余额，又无法校验某一库位的可用数量。

## 决策

1. 保留 `Stock` 作为物料总库存、双单位数量和成本的唯一汇总账。
2. 增加 `InventoryLocation` 作为可配置库位主数据，并保证至少有一个启用的默认库位。
3. 增加 `StockLocationBalance`，只记录主库存单位下的现存、占用和可用实物数量；其各库位合计必须与 `Stock` 的对应数量一致。
4. `MaterialIn` 记录收货库位；`DailyProductionReport` 分别记录原料出库库位和产出入库库位；`Shipment` 记录发货库位；`ReturnOrder` 记录退回库位。
5. `StockLog` 保存每次变动的库位，形成可审计轨迹。
6. 来料确认、日报确认、发货确认、退货处理及合法冲销必须在同一数据库事务内同时更新总库存和库位余额。
7. 发货草稿允许数量暂时超过当前可用量，但确认发货时必须同时通过物料总库存和所选库位可用量校验，默认禁止负库存。
8. 历史库存、流水和单据迁移到 `DEFAULT / 默认库位`；不改写原有数量、双单位换算和成本金额。

## 结果

- 日报产出入库和物流发货直接共享同一物料、同一库位余额，不再靠页面间复制数据。
- 库位可独立新增、改名、设为默认和归档；仍有库存或待处理单据引用时禁止归档。
- 成本继续按物料总库存核算，库位页面不展示虚假的分库成本。
- 仓库、库存状态、库位调拨和盘点单仍是后续能力，不在本次决策中提前实现。
