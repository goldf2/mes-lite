# ADR-0048：BOM 作为可选生产预设，实绩保存现场事实

- 状态：已接受；修正 ADR-0013 第 7–8 项的“生产订单必须选择 BOM”约束
- 日期：2026-08-24

## 背景

BOM 用于标准化描述一个基准批次的共同投入和共同产出，但现场会出现试制、返工、临时转换、材料替代和计划外副产出。若生产订单与实绩只能逐项复制 BOM，系统会迫使操作人员修改已发布标准，或把实际偏差隐藏在错误数据中。

## 决策

1. 生产订单必须选择目标产出物料，BOM 改为可选标准预设。
2. 选择 BOM 时只能引用已发布版本，并冻结 BOM 身份、版本及投入/产出快照；不选择 BOM 时建立临时生产/转换订单，BOM 引用和快照为空。
3. 班后实绩从快照预填标准明细，但投入和产出均允许按本批实际增加、移除或修正；目标产出必须存在且数量大于零。
4. 与预设对应的实际行保留 `bomItemId / bomOutputId`，人工增加的行保持为空。无 BOM 或含人工行时必须保存说明。
5. 库位、可用库存、人员、设备、作业文件、质量、批次、成本、审计、确认与冲销规则不因无 BOM 而放宽；确认始终只按本批实际明细原子过账。
6. 已发布 BOM 永久只读。实绩偏差和临时生产不能回写 BOM；需要形成新标准时另行复制并发布新版本。
7. `v0.1.438` 起，快捷生产日报同样采用“BOM 可选预设、实际明细独立保存”的原则：允许无 BOM 临时生产/转换，并允许增删实际投入和多个实际产出。快捷入口仍不采集订单、派工、人员、设备、作业文件和批次谱系；需要完整履历时使用生产订单。

## 数据边界

生产订单实绩沿用既有结构；快捷生产增加一项迁移：

- `ProductionOrder.bomId / bomSnapshot` 可空，区分标准订单与临时订单。
- `ProductionOrderActualInput.bomItemId` 可空，区分预设投入与临时投入。
- `ProductionOrderActualOutput.bomOutputId` 可空，区分预设产出与临时产出。
- 实际行继续独立保存物料、数量、单位、库位、成本和批次事实。
- `DailyProductionOutput` 保存快捷生产的多项实际产出、主产出标记、库位和过账成本；`DailyProductionReport` 的原单产出字段只保留主产出兼容快照。

## 后果

- 标准与事实分离：BOM 保持可复用和不可变，现场偏差保持真实且可审计。
- 试制、返工和临时转换不需要先伪造 BOM，但必须说明原因。
- 生产订单承担完整生产履历；快捷入口承担不需要订单组织过程的轻量库存转换，两者使用相同的“预设与事实分离”原则。
- 计划成本可继续使用 BOM；无 BOM 或临时行的成本以实际库存成本层为准。
