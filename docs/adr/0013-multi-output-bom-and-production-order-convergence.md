# ADR-0013：多产出 BOM 与生产订单单轨化

- 状态：已接受；投入与产出的绑定方式及标准损耗口径由 ADR-0014 补充
- 日期：2026-08-03

## 背景

旧 BOM 使用“方案类型”区分生产转换和一对一转换，且只能表达一种产出。实际生产可同时得到主产品、副产品、可回收料或废料；一对一只是数量比例，不是独立的 BOM 类型。

系统同时存在“工单”和“生产日报”两条生产路径。生产日报原用于跳过 BOM 直接记产，但现在已确定所有非纯移库的生产转换必须选择 BOM，继续保留两套生产口径会导致重复报产。

## 决策

1. 删除 BOM 的“方案类型”概念；一对一、一对多和多对多都由基准批量数量表达。
2. 新增 `BOMOutput`，每个 BOM 必须有且只有一项主产出，可有多项其他产出。`BOMItem` 与具体产出的绑定方式由 ADR-0014 定义。
   `BOMItem` 的物料不受“原材料”分类限制，半成品或已有产品也可作为投入，以表达二次加工；分类仅用于筛选和展示。
3. `BOM.productId` 及 `outputQuantity/outputUnit` 暂作为主产出索引和已有成本算法的兼容投影；真实产出集合以 `BOMOutput` 为准。
4. 同一物料不得在同一 BOM 中同时作为投入和产出。同物料跨库位移动使用“流程转移”，不创建 BOM。
5. “工单”收敛为“生产订单”：可事前建立基本信息并在班后登记实绩，也可在产后直接补录。两种方式共用 BOM 快照、投入/产出实绩、库位过账、成本和冲销。
6. 独立“生产日报”将不再作为生产入口；其菜单位置改为“每日盘点”。盘点只记录账面数、实盘数、差异和原因。发现漏报生产时应生成关联的补录生产订单，不得伪装成盘盈。

7. 创建生产订单时必须显式选择启用 BOM，并冻结名称、版本、全部投入和全部产出快照。订单先保存基本信息；班后生产实绩按冻结快照记录员工、实际投入、损耗、每项来源库位、全部实际产出和每项去向库位。
8. 实绩草稿保存时校验字段、BOM 快照、库位和当时可用库存；确认时再次复检并在同一事务中扣减全部投入、增加全部产出、结转投入成本、累计订单主产出完成数量。已确认实绩只能合法冲销，不能直接编辑。
9. 当前成本口径把全部投入成本归集到主产出；其他产出按零成本入库。若未来需要联产品成本分摊，应单独引入明确的分摊规则，不能由物料分类隐式决定。

## 实施分片

- 已实现无类型的多投入/多产出 BOM，并将旧 BOM 主产出回填为 `BOMOutput`。
- 已实现生产订单 BOM 快照、班后实绩草稿、确认过账、订单累计和合法冲销；旧独立生产记录入口已从业务导航移除，但旧表暂留用于后续清理迁移。
- `v0.1.432` 已上线“生产日报（每日盘点）”快捷入口：按一个库位录入多物品实盘数，整单原子写入 `StockLog` 调整流水与审计；不创建生产实绩、人员、设备、工序或质量记录。旧日报历史模型仍按既有兼容边界保留。

## 后果

- BOM 可正确表达一次生产的全部投入和全部产出。
- 已有产品可作为另一产品的投入，二次加工不需要伪装成原材料。
- 生产计划与产后统计使用同一订单身份，避免仪表盘和库存重复统计。
- 盘点差异与生产实绩分账，日后可追溯每个库存差异的真实原因。
