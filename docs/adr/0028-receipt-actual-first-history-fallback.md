# ADR 0028：来料辅助数量实测优先与历史兜底

- 状态：已采纳
- 日期：2026-08-11

## 背景

物料已经有一个主库存单位和一个辅助/计价单位。旧来料界面同时维护件数、总长度、总重量和比例联动，既增加操作负担，也让“物料标准换算、本批实测、历史经验值”混成同一来源。

## 决策

1. 每条新来料行必须填写主单位实收量，最多再填写一个辅助单位实测量。
2. 已填写辅助量时，来源为 `DOCUMENT_ACTUAL`，本批换算率等于辅助量除以主量。
3. 未填写辅助量时，只查询同物料、同单位标签、同单位版本、已收货且来源为 `DOCUMENT_ACTUAL` 的最近最多 100 行。
4. 有效样本至少 3 批后，使用 `sum(辅助实测量) / sum(主实收量)` 的加权换算率推算；保存来源 `HISTORICAL_ESTIMATE` 和样本数。
5. 样本不足时拒绝保存并要求本批实测。历史推算行不进入后续样本。
6. 单单位物料保存来源 `SAME_UNIT`。物料标准换算继续供 BOM 计划使用，不直接兜底来料。
7. 旧 `pieceCount`、`stockQtyMode`、`stockQtyInput`、`totalLength`、`totalWeight` 列保留数据库兼容，但新界面和新写入不再依赖。

## 结果

- 操作员只处理两个与当前物料相关的数量。
- 每笔库存和成本层都能追溯辅助量是实测还是历史推算。
- 单位版本变化后不会误用旧口径样本。
- 若未来需要根数、包装或单根余料追踪，应建立独立批次/包装模型，而不是重新扩展普通来料行。
