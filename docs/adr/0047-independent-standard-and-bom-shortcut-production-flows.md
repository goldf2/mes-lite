# ADR-0047：标准生产与 BOM 快捷生产双轨独立运行

状态：已接受<br>
日期：2026-08-22

## 背景

完整生产订单适合需要派工、人员设备、质量检验和批次谱系的场景，但简单稳定的生产如果强制经过全部节点，会增加现场补录和维护成本。系统此前收敛到单一生产实绩入口，不能同时满足两类现场作业。

## 决策

系统提供两套独立生产流程：

1. 标准流程：`来料 → 派工 → 生产实绩 → 检验 → 入库 → 发货`。它使用 `ProductionOrder / ProductionOrderActual`，保存人员、设备、作业文件、质量任务和批次谱系。
2. 快捷流程：`来料形成可用库存 → BOM 生产日报 → 可选质检 → 入库`。它使用 `DailyProductionReport`，只接受已发布 BOM，在一个事务中扣减实际投入、增加单一主产出、结转成本并写审计；不创建生产订单、派工或报工。操作者可选择产出直接进入可用库存，或先进入待检库存并生成质量任务，后续复用统一质量判定和处置。
3. 两条流程不保存彼此的单据 ID，不互相回写状态；只共享物料、已发布 BOM、库位库存、成本层和库存流水。
4. 库存盘点校准是第三种独立事实，只修正账实差异，不代表生产。
5. 同一批实物只能选择一条生产路径。快捷流程没有共同订单可用于自动判重，因此页面必须明确提示，现场通过日报号、日期、备注和库存流水审计避免重复登记。

本决策替代 ADR-0013 中“生产日报不再作为生产入口”的第 6 条，以及 ADR-0026 的单一生产实绩入口结论；ADR-0030 的写入冻结继续适用于旧通用生产日报接口，但不限制本 ADR 定义的专用快捷接口。

## 结果

- 简单生产可省略生产订单与派工，仍保持 BOM、库存、成本和审计完整，并可按产品风险选择后续质检。
- 受监管或需要完整追溯的生产继续使用标准流程，不能用快捷日报替代质量和批次责任链。
- 两条路径的统计默认分开，避免将同一批产量重复汇总；需要经营合并报表时必须明确来源类型和去重口径。
- 快捷流程当前只支持一个主产出；多产出、副产品、质量待检或谱系必须进入标准流程。
