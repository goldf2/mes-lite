# 生产日报 BOM 快捷过账与回滚

适用版本：`v0.1.433`

## 功能边界

“BOM 生产转换”用于已经知道实际产出、但不需要生产订单、派工、报工、人员、设备和质检过程的快速记账。系统仍要求选择已发布 BOM，按 BOM 展开投入并记录实际投入、主产出、库位、成本和操作人。

该入口适合班后汇总、简单稳定生产和经授权的漏报补录；需要多产出、质量待检、批次谱系、人员设备或作业文件追溯时，必须使用完整生产订单实绩。

系统同时保留两条互不关联的路径：标准流程为“来料 → 派工 → 生产实绩 → 检验 → 入库 → 发货”，快捷流程为“来料形成可用库存 → BOM 生产日报 → 直接入库”。同一批实物只能选择一条，禁止先走标准实绩又补一张快捷日报。

## 操作步骤

1. 从“生产 → 生产日报”进入，默认打开“BOM 生产转换”。
2. 选择日期、主产出物料和已发布 BOM。
3. 填写主产出实际数量、投入来源库位和产出入库库位。
4. 核对系统按 BOM 比例展开的理论投入；如果当天实耗不同，在对应行填写实际投入。
5. 点击“确认投入并产出”。系统在一个事务内创建并确认日报、FIFO 扣减投入、主产出入库、结转投入成本并写确认审计；任一步失败都会整单回滚且不留下草稿。
6. 在“最近生产日报”和“库存流水”核对日报号、BOM 版本、投入和产出。

## 与库存盘点的区别

- “BOM 生产转换”记录生产事实，必须有正式 BOM，同时形成投入和产出流水。
- “库存盘点校准”只记录账面数与实盘数差异，不推断生产，不建立 BOM 投入产出关系。
- 两种模式都不能绕过库存不足、预留量或受控库存保护。

## 更正与回滚

- 当前页面只提供快捷正向过账；需要冲销时使用保留的生产日报冲销服务或由管理员按日报号处理，不能删除库存流水或直接改数据库。
- 产出已经被后续发货或生产消耗时，冲销会被拒绝，应先处理下游业务。
- 错误只是实盘数时使用“库存盘点校准”；错误属于 BOM、投入或产出时必须冲销原日报并重新登记，不能用盘点掩盖生产事实。
