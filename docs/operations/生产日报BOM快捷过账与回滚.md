# 生产日报 BOM 快捷过账与回滚

适用版本：`v0.1.448`

## 功能边界

“快捷生产 / 转换过账”用于不需要生产订单、派工、报工、人员和设备过程的快速记账。BOM 是可选预设：默认按计划产出筛选，也可用现场已有投入辅助反查，或同时使用两项条件取交集；主产出、副产出和其它 BOM 产出都能定位整套 BOM。选定后完整展开全部投入和同时产出，实际过账仍以用户核对后的明细为准。

该入口适合班后汇总、简单稳定生产、临时转换和经授权的漏报补录；允许多投入、多产出和有原因的无 BOM 临时生产。需要完整投入产出批次谱系、人员设备或作业文件追溯时，必须使用完整生产订单实绩。

系统同时保留两条互不关联的路径：标准流程为“来料 → 派工 → 生产实绩 → 检验 → 入库 → 发货”，快捷流程为“来料形成可用库存 → BOM 生产日报 → 可选质检 → 入库”。快捷流程省略生产订单和派工，但可选择产出直接可用，或进入待检并生成质量任务。同一批实物只能选择一条，禁止先走标准实绩又补一张快捷日报。

## 操作步骤

1. 从“生产 → 生产日报”进入，默认打开“BOM 生产转换”。
2. 优先选择准备形成的计划产出。系统列出能形成该物品的已发布 BOM；复杂 BOM 的副产出也可作为入口，但候选会同时标明真实主产出。
3. 选择生产方案（BOM）。系统按 BOM 基准批次把全部理论投入和全部同时产出的数量直接填入下方实际明细，不再另设重复的计划数量输入框；在主产出原位置修改数量时，尚未手工修正的投入和其它产出会同比例更新。
4. 如需进一步缩小 BOM 范围，可选择现场已有投入物料。只选产出或只选投入都可，两项都选时取交集；也可以保持无 BOM，手工添加本次实际投入和产出。
5. 操作员逐项审核预填的实际投入、实际产出、来源/入库库位和数量，并直接在原数量字段按现场事实增删或修正。每一项同时显示所选库位可用库存与账号权限范围内的总可用库存；投入超过来源库位可用量时会高亮提示，最终仍由事务校验。筛选条件只负责定位 BOM，不会缩减实际过账范围；无 BOM 或偏离预设时填写原因。
6. 选择“直接进入可用库存”或“进入待检并生成质量任务”，再点击“确认实际投入并产出”。系统在一个事务内创建并确认日报、按各来源库位的可用批次 FIFO 扣减全部投入并记录实际批次、逐项登记实际产出、结转投入成本并写确认审计；待检模式为各项产出建立批次和质量任务。任一步失败都会整单回滚且不留下草稿。
7. 在页面“生产日报流水”和“库存流水”核对日报号、状态、BOM 版本、实际投入、实际产出、确认人和确认时间；需要追溯时再在批次详情核对每条投入实际耗用的来料/库存批次。
8. 选择待检时，从统一质量任务进入检验；合格数量由待检转为可用，不合格数量转为冻结，质检只改变库存状态，不改变实际库位。

## 与库存盘点的区别

- “快捷生产 / 转换过账”记录生产事实，可使用正式 BOM 预设，也可有原因地无 BOM 登记，同时形成投入和产出流水。
- “库存盘点校准”只记录账面数与实盘数差异，不推断生产，不建立 BOM 投入产出关系。
- 两种模式都不能绕过库存不足、预留量或受控库存保护。

## 更正与回滚

- 已确认日报可由具备“生产实绩冲销”权限的岗位在“生产日报流水”点击“冲销日报”，填写原因后执行。原日报永久保留并标记为“已冲销”，不会删除，也不会改回草稿。
- 冲销与日报状态、反向库存流水、原投入批次恢复和操作审计在同一事务内保存；反向流水与原投入/产出流水双向关联。批次恢复只使用确认时的原耗用事务，不会按冲销时的当前 FIFO 重新选批。需要纠正时必须新建一张日报，不能覆盖原事实。
- 原耗用批次事务缺失、批次已非开放状态或批次事务未关联对应正式耗用流水时，系统会拒绝冲销并保持全部账本不变。先通过数据维护导出故障明细并按审批方案修复数据，不得人工选当前批次强行补账。
- 直接可用产出在尚未被后续发货或生产消耗时可以冲销；待检或整批冻结产出在尚未分批处置、进入返工或下游消耗时，可以连同质量任务和批次一起冲销。
- 待检产出已经放行，或已经分批处置、进入返工及下游消耗时，直接冲销会被拒绝，应先按质量和下游业务处理。
- 错误只是实盘数时使用“库存盘点校准”；错误属于 BOM、投入或产出时必须冲销原日报并重新登记，不能用盘点掩盖生产事实。
