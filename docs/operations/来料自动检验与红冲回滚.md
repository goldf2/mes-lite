# MES-lite 来料自动检验与红冲回滚

适用版本：`v0.1.374`

## 1. 上线前准备

1. 固定本版本精确 Git 提交，确认 Coolify 部署前已完成 SQLite 与附件同一时点备份、SHA-256 校验和恢复候选抽查。
2. 由质量负责人确定需要来料检验的物料；未准备好检验标准的物料不要发布 `MATERIAL_IN` 标准，它们会继续直接进入可用库存。
3. 仓管员需要 `materialIn:RCU`、`materialInReceive:U` 和收货库位范围；只有仓库主管按审批获得 `materialInReverse:U`。质检员需要 `quality:RU`、`qualityDecision:U`、`qualityStandards:R` 和同一库位范围。来料编辑、收货/拒收、红冲和质量判定互不替代。
4. 准备一个受控原料、一个非受控原料和同一待分库库位，用于验证一张多行来料单的两种分流。

## 2. 启用来料检验

1. 进入“生产 → 质量任务 → 检验标准”，点击“新建检验标准”。
2. 选择物料，任务来源选择“来料入库待检”，配置全检、固定数量或比例抽样及项目清单。
3. 保存草稿并由质量负责人复核，确认后发布。只有 `RELEASED` 标准会影响后续新收货；草稿和已停用版本不会触发送检。
4. 标准变更时复制新版本再发布，不覆盖历史版本；已有来料任务继续使用建立时的快照。

## 3. 仓库收货与质量交接

1. 进入“物流 → 来料管理”，登记供应商、待分库库位和一条或多条来料明细。
2. 具有 `materialInReceive.update` 的仓管员点击“确认收货”；仅有 `materialIn.update` 的账号不会看到按钮，直接调用接口也返回 403。系统逐行检查已发布来料标准，并提示生成的来料检验任务数量。
3. 在来料列表或详情复核内部批号、质量状态和检验单号：受控行应显示“待检”，无标准行应显示“可用”。
4. 受控行的总库存增加，但数量位于 `QUARANTINE`，普通领料、发货和库存调整不能消耗；非受控行位于 `AVAILABLE`。

## 4. 质量判定与趋势

1. 质检员进入“生产 → 质量任务”，按来料入库来源搜索任务；没有授权库位的质检员看不到该任务，仓管员访问质量任务接口应返回 403。
2. 核对标准编码/版本、建议抽样数和逐项快照，填写实际抽样、合格/不合格数量、项目结果和说明。
3. 合格后批次从 `QUARANTINE` 转为 `AVAILABLE`；不合格转为 `HOLD`，必须使用质量处置继续处理。
4. 在“质量趋势”选择“来料入库”，核对完成批次、通过率、样本通过率和失败项目排行。

## 5. 安全红冲

1. 待检阶段发现送错料时，由具有 `materialInReverse.update` 的仓库主管执行整单红冲并填写原因；普通仓管和仅有来料编辑权限的账号调用红冲接口返回 403。系统把未执行的首轮任务改为“已取消”，从隔离库存、库位余额、批次余额和成本层反向恢复。
2. 已合格但尚未被领用、转移、发货或改变成本层的来料，也允许整单红冲；反向流水从可用库存恢复。
3. 已完成失败判定、存在复检/处置、批次余额变化、有效批次分配或成本消耗时，系统阻断直接红冲。不得先手工调库存再删除业务单；应由质量负责人确定退供应商、报废或其他逆向流程。
4. 红冲后核对来料单为 `REVERSED`、内部批次为 `REVERSED`、相关余额为零，并保留 `REVERSE_IN` 流水、批次反向交易、操作人和原因。

## 6. 部署验收

1. 应用启动执行第 81 个迁移；确认质量标准来源允许 `MATERIAL_IN`，取消任务保护触发器存在。
2. 用一张包含受控和非受控物料的来料单收货，确认只生成一个任务且两行分别进入待检和可用。
3. 用仅有 `materialIn.update` 的账号验证收货、拒收和红冲均返回 403；用普通仓管验证可收货但红冲和质量任务均为 403；用仓库主管验证有原因红冲；用授权质检员与其他库位质检员验证质量可见性和判定范围。
4. 分别验证合格放行、待检红冲取消、未使用合格批次红冲和失败批次红冲阻断。
5. 核对库存总量、状态量、库位、批次、成本层、库存流水、趋势和审计记录一致。

## 7. 应用回滚与数据恢复

1. 暂停新的来料收货、检验、处置和红冲写入，在 Coolify 固定到上一个已验证提交重新部署；不要使用会拉取最新分支的普通 Redeploy 代替精确版本回滚。
2. 不删除来料标准、任务或取消记录。旧应用若无法安全识别来料质量任务，应保持受控物料停收并优先恢复本版本。
3. 只有迁移失败或数据库损坏且应用回滚无效时，才切换到部署前的一致恢复候选。恢复后重新验证登录、来料单、标准版本、待检任务、批次状态、库存/成本守恒和附件原文件。
