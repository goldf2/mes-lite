# MES-lite 全流程作业指导书

- 交付版本：v0.1.358
- 截图基线：v0.1.350-v0.1.358（112 张真实页面流程截图）
- 数据范围：隔离本地临时演示库，不含生产业务数据
- 编制日期：2026-08-13

> 重要：供应商批号、来料内部批次、生产投入产出、客户发货、退货回流、质量判定、不合格处置和跨批次搜索全景已贯通；本机临时数据与截图不等于真实 Coolify 服务器已部署。

## 推荐业务顺序

单位/库位/员工/供应商/客户/工作中心 → 物料 → BOM/工艺路线 → 生产订单/销售订单 → 派工/来料/发货 → 实绩 → 质量判定/处置/复检 → 收货/退货 → 库存与审计复核。

## 1. 登录与工作区导航

### 登录系统

目的：使用分配的操作员账号进入系统。

1. 打开系统登录页。
2. 输入登录账号和密码。
3. 点击“登录”，等待工作台加载。

结果检查：顶部显示当前人员名称，左侧出现有权限的功能菜单。

![登录系统](screenshots/v0.1.350/01-login.png)

### 查看工作台

目的：在班前确认生产、库存和待办概况。

1. 进入 MES 工作区。
2. 查看常用功能、生产负荷和待处理事项。
3. 发现红色或橙色预警时进入对应功能核查。

结果检查：统计卡片与当前演示业务数据一致。

![查看工作台](screenshots/v0.1.350/02-dashboard.png)

### 使用所有功能

目的：从完整功能目录进入业务页面。

1. 在工作台点击“所有功能”。
2. 按业务分组找到目标功能。
3. 只会显示当前账号拥有权限的页面。

结果检查：页面按物料、生产、物流、库存、配置、工具等分组。

![使用所有功能](screenshots/v0.1.350/03-all-functions.png)

### 切换 ERP 工作区

目的：进入销售、发货和退货业务。

1. 点击左上角“ERP”工作区。
2. 点击“所有功能”。
3. 选择销售订单、发货管理或退货管理。

结果检查：左侧菜单切换为 ERP 业务导航。

![切换 ERP 工作区](screenshots/v0.1.350/23-erp-all-functions.png)

## 2. 物料与 BOM 主数据

### 查询物料

目的：查询物料编码、规格、单位和库存概况。

1. 进入 MES > 物料 > 物料管理。
2. 使用顶部搜索框输入编码、名称或规格。
3. 需要时切换列表/卡片视图并打开详情。

结果检查：目标物料及库存单位正确显示。

![查询物料](screenshots/v0.1.350/04-material-list.png)

### 新建物料

目的：建立可用于库存和生产的统一 Material 主数据。

1. 点击“新建物料”。
2. 填写编码、名称、规格、分类、库存单位和主要计量方式。
3. 按需要填写默认价格、安全库存和客户。
4. 保存后返回列表复核。

结果检查：新物料可被 BOM、订单、收发货等业务选择。

![新建物料](screenshots/v0.1.350/05-material-create.png)

### 进入 BOM 工作区

目的：查找物料并维护 BOM 版本。

1. 进入 MES > 物料 > BOM 设置。
2. 搜索并选择目标产出物料。
3. 查看当前版本、状态、输入项和输出项。

结果检查：BOM 工作区显示目标物料和版本状态。

![进入 BOM 工作区](screenshots/v0.1.350/06-bom-workspace.png)

### 维护并发布 BOM

目的：定义整批投入、主产出和副产出。

1. 新建或打开草稿 BOM。
2. 填写基准产量、投入物料、数量和单位。
3. 维护主产出与副产出比例。
4. 校验无误后发布，生产只能引用已发布版本。

结果检查：发布版本显示“已发布”，投入单位与物料计量方式一致。

![维护并发布 BOM](screenshots/v0.1.350/07-bom-detail.png)

## 3. 生产订单与班后实绩

### 查看生产订单

目的：查看生产计划及统一状态。

1. 进入 MES > 生产 > 生产订单。
2. 按订单号、物料或状态搜索。
3. 关注草稿、已发布、生产中、已完成和已取消状态。

结果检查：列表显示计划数量、日期、BOM 和当前状态。

![查看生产订单](screenshots/v0.1.350/08-production-order-list.png)

### 新建生产订单

目的：建立物料化生产计划。

1. 点击“新建生产订单”。
2. 选择产出物料、已发布 BOM、计划数量和计划日期。
3. 填写班组或备注后保存。

结果检查：订单以“草稿”创建，此时不可登记实绩。

![新建生产订单](screenshots/v0.1.350/09-production-order-create.png)

### 发布生产订单

目的：将已复核计划转为可执行任务。

1. 打开草稿订单详情。
2. 核对物料、数量、日期和 BOM。
3. 点击“发布订单”并确认。

结果检查：状态由“草稿”变为“已发布”。

![发布生产订单](screenshots/v0.1.350/10-production-order-release.png)

### 确认订单可执行

目的：确认发布后实绩入口已经解锁。

1. 发布完成后重新查看订单详情。
2. 确认状态为“已发布”。
3. 确认“登记班后产量”按钮可用。

结果检查：发布状态与操作按钮保持一致。

![确认订单可执行](screenshots/v0.1.350/11-production-order-released.png)

### 登记班后生产实绩

目的：按真实投入和产出记录班后实绩。

1. 点击“登记班后产量”。
2. 填写员工、工作中心、实际日期和产出数量。
3. 按现场记录填写实际投入、主产出、副产出及库位。
4. 保存后核对实绩与库存流水。

结果检查：实绩保存成功，投入与产出生成可追溯记录。

![登记班后生产实绩](screenshots/v0.1.350/12-production-actual-entry.png)

## 4. 生产产出批次与质检

### 查看产出批次与质量状态

目的：从生产实绩核对内部批次、检验单和当前库存状态。

1. 进入生产订单详情并展开已确认实绩。
2. 在每项产出下查看内部批次号和检验单号。
3. 区分待检、已放行和冻结状态。

结果检查：每项新产出具有唯一内部批次，待检任务只允许判定一次。

![查看产出批次与质量状态](screenshots/v0.1.354/66-production-quality-lots.png)

### 填写合格判定

目的：记录抽样结果并准备整批放行。

1. 在待检批次点击“合格放行”。
2. 录入抽检数量、合格数量和不合格数量。
3. 填写检验结论说明并核对批次号。

结果检查：合格数量与不合格数量之和等于抽检数量，整批合格时不合格数为 0。

![填写合格判定](screenshots/v0.1.354/67-quality-pass-form.png)

### 确认整批放行

目的：把检验合格的整批产出从待检转为可用。

1. 点击“确认整批放行”。
2. 等待保存成功并刷新订单详情。
3. 核对批次状态、判定人和抽样结果。

结果检查：批次显示“已放行”，待检库存减少、可用库存增加。

![确认整批放行](screenshots/v0.1.354/68-quality-pass-result.png)

### 填写不合格判定

目的：记录不合格样本和冻结原因。

1. 在另一待检批次点击“不合格冻结”。
2. 录入抽检、合格和不合格数量。
3. 在说明中写清不合格现象和冻结原因。

结果检查：抽样关系校验通过，说明可供后续处置人员理解。

![填写不合格判定](screenshots/v0.1.354/69-quality-fail-form.png)

### 确认整批冻结

目的：阻止不合格产出进入领料或发货可用量。

1. 点击“确认整批冻结”。
2. 等待保存成功并刷新订单详情。
3. 核对批次状态、判定人和抽样结果。

结果检查：批次显示“冻结”，待检库存减少、冻结库存增加。

![确认整批冻结](screenshots/v0.1.354/70-quality-fail-result.png)

### 核对库存状态

目的：在库存总账复核质量判定后的可用、待检和冻结数量。

1. 进入 MES > 库存 > 库存管理。
2. 搜索质检涉及的产出物料。
3. 核对总量、可用、待检、冻结及库位余额。

结果检查：总库存等于可用、待检和冻结之和，质量判定不改变总量或总成本。

![核对库存状态](screenshots/v0.1.354/71-inventory-status-review.png)

### 核对质量状态流水

目的：确认放行或冻结可以从统一库存流水回放。

1. 进入 MES > 库存 > 库存流水。
2. 搜索产出物料或质量来源。
3. 核对 QUALITY RELEASE / QUALITY HOLD、批次、状态方向、操作人和时间。

结果检查：状态转换流水数量变化为 0，但明确记录待检到可用或冻结的转换。

![核对质量状态流水](screenshots/v0.1.354/72-inventory-quality-movements.png)

## 5. 质量任务与不合格处置

### 进入质量任务工作台

目的：按车间待办集中查看待检和待处置批次。

1. 进入 MES > 生产 > 质量任务。
2. 先查看待检任务数量，再查看待处置批次数量。
3. 按检验单、批次、物料或来源单据搜索。

结果检查：页面显示待检、待处置和全部记录三个任务视图。

![进入质量任务工作台](screenshots/v0.1.357/89-quality-task-workbench.png)

### 填写部分判定

目的：把同一待检批次按合格和不合格数量拆分。

1. 在待检任务点击“部分判定”。
2. 填写抽检、合格和不合格样本数量。
3. 填写放行数量、冻结数量和结论说明。
4. 确认放行与冻结之和等于本轮待检数量。

结果检查：表单通过样本关系和整批处置数量校验。

![填写部分判定](screenshots/v0.1.357/90-quality-partial-form.png)

### 核对部分放行结果

目的：确认合格部分可用、不合格部分冻结。

1. 提交部分判定后切换“待处置批次”。
2. 找到刚处理的内部批次。
3. 核对已放行、冻结、抽检结果和判定人。

结果检查：同一批次同时显示已放行和冻结余额，总量与判定前一致。

![核对部分放行结果](screenshots/v0.1.357/91-quality-partial-result.png)

### 查看判定与处置记录

目的：审计同一批次的每次状态变化。

1. 展开“判定与处置记录”。
2. 核对判定放行和判定冻结的数量。
3. 核对原因、操作人和独立处置编号。

结果检查：每个动作都有独立、不可覆盖的质量处置记录。

![查看判定与处置记录](screenshots/v0.1.357/92-quality-disposition-history.png)

### 申请复检

目的：从冻结库存抽取指定数量进入新一轮待检。

1. 在冻结批次点击“申请复检”。
2. 填写处置数量。
3. 填写复检申请号、原因或审批依据。
4. 点击“确认送复检”。

结果检查：指定数量由冻结转为待检，并生成新的检验轮次。

![申请复检](screenshots/v0.1.357/93-quality-reinspect-form.png)

### 核对复检任务

目的：确认新一轮检验单与批次余额同步生成。

1. 切换到“待检任务”。
2. 找到复检批次。
3. 核对冻结余量、待检数量、新检验单号和轮次。

结果检查：页面显示第 2 轮检验单，原冻结余额按复检数量减少。

![核对复检任务](screenshots/v0.1.357/94-quality-reinspect-result.png)

### 返工完成送检

目的：把完成返工的数量重新送入质量检验。

1. 在含返工余额的批次点击“返工完成送检”。
2. 填写本次完工数量。
3. 填写返工单号和完工说明。
4. 确认返工完成送检。

结果检查：本次数量由返工中转为待检并生成复检任务。

![返工完成送检](screenshots/v0.1.357/95-quality-rework-complete-form.png)

### 核对返工复检任务

目的：确认返工不会直接恢复为可用库存。

1. 切换到“待检任务”。
2. 找到返工完成批次。
3. 核对冻结余量、待检数量和第 2 轮检验单。

结果检查：返工完成数量保持待检隔离，必须再次质量判定。

![核对返工复检任务](screenshots/v0.1.357/96-quality-rework-followup.png)

### 转入返工

目的：把可返修的冻结数量转为返工中状态。

1. 在冻结批次点击“转返工”。
2. 填写返工数量。
3. 填写返工单号、返工内容和审批依据。
4. 确认转返工。

结果检查：冻结库存减少，返工中库存等量增加。

![转入返工](screenshots/v0.1.357/97-quality-rework-start-form.png)

### 核对返工中状态

目的：确认返工库存不能被领料或发货。

1. 提交转返工后留在待处置视图。
2. 核对冻结余额和返工中余额。
3. 展开处置记录核对返工动作。

结果检查：返工中数量单独列示，不计入可用库存。

![核对返工中状态](screenshots/v0.1.357/98-quality-rework-start-result.png)

### 提交质量报废

目的：从冻结库存中报废无法返修的数量。

1. 在冻结批次点击“报废”。
2. 填写报废数量。
3. 填写报废审批号和原因。
4. 确认报废前再次核对批次与数量。

结果检查：报废表单包含明确审批依据，且只能使用冻结余额。

![提交质量报废](screenshots/v0.1.357/99-quality-scrap-form.png)

### 核对报废结果

目的：确认报废同步减少库存数量与批次成本。

1. 提交报废后查看成功提示。
2. 核对冻结余额按报废数量减少。
3. 展开处置记录核对报废动作和审批号。
4. 在库存流水复核质量报废记录。

结果检查：总库存与总成本按批次比例减少，处置历史保留。

![核对报废结果](screenshots/v0.1.357/100-quality-scrap-result.png)

### 执行让步放行

目的：依据客户偏差许可放行指定冻结数量。

1. 具有授权放行权限的主管点击“让步放行”。
2. 填写数量。
3. 填写客户偏差许可号和适用条件。
4. 确认让步放行。

结果检查：只有配置质量放行权限的人员可以提交。

![执行让步放行](screenshots/v0.1.357/101-quality-concession-form.png)

### 核对让步放行结果

目的：确认让步数量恢复为可用并可追溯审批依据。

1. 提交后核对已放行和冻结余额。
2. 展开处置记录。
3. 核对让步放行数量、操作人和偏差许可号。

结果检查：可用库存增加、冻结库存等量减少，总库存和总成本不变。

![核对让步放行结果](screenshots/v0.1.357/102-quality-concession-result.png)

### 执行解冻放行

目的：在冻结原因已纠正后授权恢复可用。

1. 具有授权放行权限的主管点击“解冻放行”。
2. 填写数量。
3. 填写解冻审批号、纠正措施和复核说明。
4. 确认解冻放行。

结果检查：解冻原因和审批依据不能为空。

![执行解冻放行](screenshots/v0.1.357/103-quality-unfreeze-form.png)

### 核对授权放行历史

目的：从同一批次回放让步、解冻和初始判定。

1. 提交解冻后展开处置历史。
2. 核对解冻放行和让步放行分别记录。
3. 向下核对初始判定冻结与放行记录。

结果检查：四条动作各自保留数量、原因、人员和处置编号。

![核对授权放行历史](screenshots/v0.1.357/104-quality-release-history.png)

### 核对五类库存状态

目的：在库存总账确认可用、待检、冻结和返工中守恒。

1. 进入 MES > 库存 > 库存管理。
2. 搜索质量处置物料。
3. 核对总库存、预留、可用、待检、冻结和返工中。
4. 核对库位明细使用相同状态口径。

结果检查：可用量等于总量减预留、待检、冻结和返工中；返工品不可出库。

![核对五类库存状态](screenshots/v0.1.357/105-inventory-quality-statuses.png)

### 配置质量操作权限

目的：按岗位拆分查看、判定、处置和授权放行权限。

1. 进入账号与权限 > 组权限。
2. 分别配置质量任务查看、质量判定、复检/返工/报废处置、让步/解冻放行。
3. 按岗位只勾选必要的查、增、改权限。
4. 保存后使用目标账号复核菜单和按钮。

结果检查：检验员、处置人员和质量主管的高风险操作可以分离授权。

![配置质量操作权限](screenshots/v0.1.357/106-quality-permission-layers.png)

## 6. 来料到生产批次谱系

### 核对来料内部批次

目的：确认收货后的内部批号与供应商炉批号并存。

1. 进入 MES > 物流 > 来料管理。
2. 打开状态为“已收货”的来料单详情。
3. 在物料明细的批次列同时核对供应批号和内部批号。

结果检查：内部批号以 RM- 开头，供应批号与原始单据一致。

![核对来料内部批次](screenshots/v0.1.355/73-receipt-internal-lot.png)

### 查看原料批次追溯

目的：从来料批次查看来源、库位余额和下游产出。
