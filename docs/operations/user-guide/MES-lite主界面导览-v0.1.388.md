# MES-lite 主界面导览

交付版本：v0.1.388

## 1. 适用范围

本文用于首次登录后的主界面认识，覆盖左上角 MES-lite 首页入口、桌面导航、仪表盘、页面模式、顶部功能按钮、导航设置和帮助入口。它不替代各业务页面的流程 SOP。

## 2. 界面区域

| 区域 | 用途 | 使用要点 |
| --- | --- | --- |
| 左上角 MES-lite | 当前主模块和仪表盘首页入口 | 在任意业务页面点击后返回仪表盘；MRP/ERP 仍是禁用的预留按钮 |
| 左侧导航 | 搜索并进入业务功能 | 按工作台、物料、生产、文档、设备、物流、库存等分组展开；当前页保持高亮 |
| 中央工作区 | 显示当前页面和业务数据 | 仪表盘用于概览和待办，业务登记在对应功能页完成 |
| 顶部页面工具 | 当前页搜索、筛选、视图和主操作 | 内容跟随当前页面变化，没有相关能力时不会显示无效操作 |
| 顶部全局按钮 | 帮助、页面模式、AI、二维码和账户 | 鼠标悬停可查看按钮说明；可用性继续受当前账号权限控制 |
| 左侧导航底部 | 系统版本 | 用于核对截图、SOP、离线文档和运行系统是否同版 |

## 3. 页面模式切换

- “标准管理”使用左侧导航和顶部页面工具，适合日常列表、表单和主从页面。
- “画布工作”使用顶部导航和右侧页面工具，适合需要更宽主显示区的场景。
- 切换只改变应用壳布局，不改变 URL 中的当前页面、权限、筛选条件、选中对象或业务数据。
- 常用模式可在“系统设置 → 显示设置”保存；顶部模式按钮用于快速切换。

## 4. 常用按钮

1. 点击左上角 **MES-lite**：返回“仪表盘”首页。
2. 点击顶部 **问号**：打开当前页面帮助；可再在新页面全屏查看，或打开完整帮助中心。
3. 点击顶部 **布局按钮**：在标准管理和画布工作之间切换。
4. 点击 **AI 标记**：打开只读业务协作助手；仅在账号有权限且服务已配置时可用。
5. 点击 **二维码**：生成当前页面入口，供移动设备打开或扫码使用。
6. 点击右上角 **账户菜单**：查看当前账号、系统版本并退出登录。

## 5. 推荐日常路径

```text
MES-lite 首页
  → 查看岗位待办和生产/库存概况
  → 使用左侧导航进入业务页面
  → 使用顶部页面工具完成搜索、筛选和业务动作
  → 通过问号帮助核对步骤和结果
```

## 6. 视频解说

运行以下命令可根据同仓库分镜、已验收界面截图和中文旁白生成 MP4，并生成与成片时间轴一致的 UTF-8 SRT 字幕：

```bash
npm run tutorial:build:main-interface
```

成品输出到 `output/tutorials/MES-lite主界面导览-v0.1.388/`，目录只保留全同步 MP4、对应 SRT 和剪映配音底版三个交付文件；分镜、参考音频、时间线和抽帧预览仅用于本次构建并在成功后自动清理。`-剪映配音底版.mp4` 不含参考语音和底部旁白字幕，用于与 SRT 一起导入剪映后重新配音。画面内字幕、参考语音和 SRT 使用同一段 `narration` 文稿；SRT 与完整 MP4 的画面内字幕采用实际参考语音的起止时间。替换为时长不同的人工或第三方配音后，应以新音轨为准重新微调字幕结束点。`output/` 不进入 Git 或 Docker 发布树；需要对外交付时，将最终 MP4 和 SRT 上传到对象存储，并把下载地址登记到产品文档库。

视频使用仓库内已验收截图制作。截图角落可能显示其最初验收版本，旁白、字幕和行为说明以本导览的 v0.1.388 合同为准；本版本未把静态分镜冒充为实时录屏。非封面镜头使用上下安全区承载标题和字幕，避免覆盖系统界面控件。
