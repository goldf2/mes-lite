# 库存盘点操作与更正

适用版本：`v0.1.432+`（`v0.1.434` 起为“库存”菜单下的独立“库存盘点”页面）

## 功能边界

“库存盘点”用于快速对齐某一库位的账面库存与实盘库存。它只产生库存差异流水，不补造生产订单实绩、BOM 快捷日报或质量任务。

以下保护不能绕过：FIFO 成本层、库位预留量、待检、冻结和返工库存。需要投入、产出、批次谱系或成本追溯的漏报生产，仍应补录生产订单实绩。

## 操作步骤

1. 从“库存 → 库存盘点”进入独立页面。
2. 选择盘点日期和唯一盘点库位，填写可以解释差异的原因。
3. 搜索加入多种物品；需要全盘时可加入该库位全部有账面库存的物品。
4. 核对系统带出的账面数，只修改有差异物品的实盘数。
5. 点击“确认整单”。系统跳过账实一致行，其余行在同一数据库事务内更新库位余额、总库存、内部批次余额、库存流水和操作审计；库存金额按调整前移动平均单位成本同步增减。
6. 到“库存流水”核对类型 `ADJUST`、备注中的日期与原因；到“操作记录”核对动作 `RECONCILE` 和当前登录操作人。

## 失败处理与回滚

- 任一行违反库存保护时整单失败，不会留下部分调整或孤立审计；修正物品、库位或业务状态后重新提交。
- 已成功盘点发生录入错误时，不修改数据库或删除历史流水。重新建立一张库存盘点单，填写“更正 YYYY-MM-DD 盘点录入错误”等原因，以正确实盘数再次校准。
- 如果差异来自漏报生产，不使用第二张盘点继续冲平；应补录生产订单实绩，使投入、产出、成本和批次关系完整。
- 涉及 FIFO 或受控质量库存时，由仓库、成本或质量负责人按对应业务流程处理，不通过普通调整强行放行。
