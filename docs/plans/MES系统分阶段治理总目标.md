# MES-lite 系统分阶段治理总目标

状态：执行中

建立日期：2026-08-12

当前阶段：阶段 0（安全、数据与运维止血）

## 1. 全局目标

在不推倒现有 Next.js 单体、不破坏单厂 SQLite 运行基线的前提下，将 MES-lite 从“功能较多的制造管理后台”治理为“具有质量、批次、库存状态和可信审计闭环的轻量 MES”，并形成可验证、可备份、可恢复、可升级的单厂商业交付基线。

所有阶段必须同时满足：

1. 先写回归或结构守卫，再修改实现。
2. 页面、API、权限、模型和文档同步更新。
3. 数量、成本、库存状态和批次变化可通过业务流水与审计回放。
4. 每个交付版本通过类型检查、Lint、生产构建和受影响领域的临时数据库回归。
5. 每个阶段保留明确回滚点；生产数据迁移前必须完成备份与恢复演练。

## 2. 阶段路线

| 阶段 | 目标 | 主要交付物 | 完成标准 |
| --- | --- | --- | --- |
| 0 | 安全、数据与运维止血 | 附件对象级鉴权、可信操作人、认证防护、仓库数据清理、一致性备份和恢复演练 | 已知高风险访问路径关闭；测试和生产数据不进入 Git；备份可恢复到新实例 |
| 1 | 产品与核心数据定盘 | 单厂 MES 边界、`Material` 唯一主档、旧生产模型盘点和退出方案、统一状态机 | 新代码不再增加 `Product/Material` 和新旧生产兼容关系；迁移可校验、可回滚 |
| 2 | MES 现场事实闭环 | 内部批次、批次谱系、待检/可用/冻结库存、检验任务、不合格处置 | 可从供应商批次正向追到成品和客户，也可从客户退货反查原料和检验结论 |
| 3 | 角色任务型工作区 | 操作员、仓管、质检、计划员和管理员工作台；确认/放行/冲销等动作权限与数据范围 | 移动端优先呈现岗位待办；管理员功能退出普通车间导航；越权用例全部返回 403 |
| 4 | 商业交付基线 | 当前事实文档、CI、监控、备份保留策略、升级/回滚手册和交付验收表 | 新环境可自动构建；发布可回滚；恢复演练有 RPO/RTO 记录；交付范围不混入规划功能 |

## 3. 当前执行状态

### 阶段 0A：附件与审计身份（v0.1.345）

- [x] 附件读取、上传、预览、缩略图、更新和归档同时校验附件权限与所属业务资源权限。
- [x] 校验 `ownerType/ownerId` 是否对应受支持且真实存在的业务对象。
- [x] 暂存附件只允许创建它的登录账号读取、绑定和清理。
- [x] 禁止通过 `/uploads/*` 绕过附件 API 直接读取持久文件。
- [x] AI 单据识别复用同一附件对象级权限。
- [x] 生产、转移、来料、发货、退货、成本和兼容过账的操作人只来自服务端登录会话。

### 阶段 0B：认证与管理员初始化（v0.1.346）

- [x] 公开注册默认关闭；密码和微信注册永不自动获得管理员身份。
- [x] 初始管理员通过一次性服务器令牌显式安装，已有管理员后拒绝重复安装。
- [x] 账号连续失败持久锁定，登录、注册和安装入口按来源持久限流并返回重试时间。
- [x] 生产 Cookie 显式启用 `Secure`，所有写 API 在 Middleware 执行 Origin 同源校验。
- [x] 登录页依据服务端注册开关显示或隐藏注册入口。

### 阶段 0C：运行时数据与灾备（v0.1.347-v0.1.348）

- [x] 停止跟踪 SQLite 数据库、journal/WAL/SHM 与 TypeScript 构建缓存，保留当前本地数据。
- [x] 建立 SQLite 一致快照、附件引用校验、逐文件 SHA-256、保留策略和非覆盖恢复候选。
- [x] 增加 liveness/readiness 分层，readiness 覆盖数据库、失败迁移和持久目录可写性。
- [x] 对齐 Compose、Dockerfile、Coolify 挂载、迁移前备份、每日调度和恢复演练手册。
- [x] 依据当前 Coolify 应用配置，将生产来源和微信回调示例统一为 `mes.szxiangshu.com`。

### 阶段 0 维护窗口待办

- [ ] 历史 commit 仍含旧 SQLite 快照；需在维护窗口完成备份、协作者通知、Git 历史重写、远程强制更新及账号/密钥轮换。
- [ ] 在 Coolify 配置实际异地备份目标，完成一次部署环境恢复演练并记录真实 RPO/RTO。

## 4. 暂停线

- 阶段 0 未完成前，不开放公网注册，不扩展多租户或多实例。
- 阶段 1 未完成前，不继续增加依赖 `Product` 的库存和生产字段，也不恢复旧生产入口。
- 阶段 2 未完成前，不把当前系统宣传为完整质量追溯 MES。
- PostgreSQL 和对象存储迁移不能替代领域模型治理；先固定单厂业务不变量，再迁移基础设施。
