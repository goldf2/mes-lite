# MES-lite v0.1.264

发布日期：2026-08-09

## 更新内容

- 修复移动功能抽屉点击一级菜单时跳转到该分组首个页面、继而立即关闭抽屉的问题。
- 单列导航新增独立展开状态，一级菜单点击只负责展开或收起，不再触发页面跳转。
- 当前页面所属分组仍在打开菜单时自动展开；只有点击二级页面才执行页面跳转并关闭移动抽屉。
- 增加响应式导航回归校验，阻止一级菜单恢复为页面跳转入口。

## 影响范围

- 影响桌面单列导航与移动功能抽屉的一级菜单点击行为。
- 不改变二级页面跳转、菜单数据、页面归属、权限、顺序和业务数据。

## 验证结果

- 响应式导航校验和 TypeScript 类型检查通过。
- Next.js 生产构建通过。
