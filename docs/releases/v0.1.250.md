# MES-lite v0.1.250

发布日期：2026-08-08

## 更新内容

- 来料、生产订单、派工、销售订单、发货和退货的新建表单统一增加“原始凭据与附件”区域，可在创建单据前上传、预览和归档常用业务文件。
- 新增公共暂存附件生命周期：附件先绑定当前表单草稿，创建成功后自动转绑新单据，取消新建时同步清理附件记录、原文件和派生预览。
- 新增服务端 AI 单据识别接口，复用系统设置中的 OpenAI Compatible 视觉模型配置，按单据类型输出结构化字段并自动回填当前表单。
- AI 识别校验附件归属和权限，只自动应用置信度不低于 0.7 的字段；识别不保存、确认、过账或改变任何业务状态，用户仍需核对并主动创建。
- 附件上传或 AI 识别进行中时禁止提交和关闭新建表单，避免产生未绑定的暂存文件。

## 影响范围

- 影响六类核心业务单据的新建表单、公共附件面板、附件 API 和 AI 服务接口。
- 不修改数据库结构、库存核算、单据状态机和既有附件数据。
- 多明细来料单或生产订单的原始凭据当前绑定到该批创建结果的首条主记录，其余明细仍可通过分组关系追溯。

## 验证结果

- TypeScript 类型检查和定向 ESLint 通过（仅保留既有 Hook 与原生图片性能提示）。
- 单据原始凭据、附件管理、页面模块和版本文档专项校验通过。
- 已在本地销售订单新建弹窗验证公共附件区域显示、取消关闭和浏览器控制台无错误。
- 生产构建通过。
