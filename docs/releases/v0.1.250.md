# MES-lite v0.1.250

发布日期：2026-08-08

## 更新内容

- 建立商业化 SaaS 数据与存储总架构，明确控制平面、数据平面、文件平面和 DataCell 扩容边界。
- 制定 SQLite 到 RDS PostgreSQL 的多租户数据结构、RLS、备份恢复、切换和回滚计划。
- 制定本地附件到私有 OSS 的统一存储、租户对象键、派生预览、历史迁移和维护工具计划。
- 通过 ADR 固化共享多租户为主、企业独立数据单元为高阶套餐的决策，并明确图数据库只作为可重建读模型。

## 影响范围

- 本次只更新架构、规划、ADR 和版本文档。
- 不修改 Prisma Schema、生产数据库、附件存储、页面交互、接口或 Coolify 配置。
- 文档中的 `Tenant`、`DataCell`、RLS、OSS 和计量结构均为后续实施目标，不表示已经上线。

## 验证结果

- PostgreSQL、OSS、租户隔离、商业运行和图关系扩展之间的事实源边界已统一。
- 新增文档相互链接，并与现有数据库分析、功能规划和模块边界保持一致。
- 项目版本、发布说明和发布索引校验通过。
