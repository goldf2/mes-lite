# MES-lite v0.1.289

日期：2026-08-09

## 更新内容

- 删除已从页面注册、导航和应用壳退出的旧 `StatsPage.tsx`，不再维护第二套不可达生产实绩界面。
- 生产实绩唯一入口收敛为“生产订单 → 详情 / 登记实绩”，继续使用现有草稿、确认过账、投入与多产出库存原子更新和冲销闭环。
- 删除失效的 `stats` 工作台快捷键，历史偏好中的旧键会自动过滤，默认快捷入口改由仪表盘补位。
- 清理高级搜索与模块规模校验中的旧页面残余，并新增 ADR 固化旧日报数据兼容边界。

## 影响范围

- 前端 TSX 减少 936 行，根级存量领域页面从 14 个降至 13 个，超过 800 行的页面从 3 个降至 2 个。
- `stats` 权限资源仍保留，统计接口与流程转移权限不受影响。
- 为兼容服务器历史正式数据，本次保留 `DailyProductionReport` 数据模型、数据库迁移、关联保护和 `/api/daily-production-reports*` 接口；不执行数据库迁移。

## 验证结果

- 工作台偏好、MES/MRP/ERP 导航、生产订单实绩事务、模块边界、高级搜索、页面注册、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建只报告既有的图片元素和 Hook 依赖警告，没有新增错误。

## 数据安全

- 本次不连接、不读取和不修改服务器正式数据库。
- 本机 SQLite 测试数据继续隔离保存，数据库文件和 TypeScript 构建缓存不纳入提交。
