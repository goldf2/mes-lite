# v0.1.402 AI 助手多模态输入

日期：2026-08-17

## 更新内容

- AI 助手增加浏览器语音输入；转写内容仍作为可编辑文字进入原有对话流程。
- 新增受控图片识别接口 `/api/ai/image-recognition`，支持不超过 5 MB 的图片生成摘要。
- 图片识别结果只填入待确认输入，不直接触发业务写入；用户确认后才进入后续对话。
- 继续复用系统设置中的 AI 提供方配置、`aiAssistant.read` 权限、请求限流和审计边界。

## 影响范围

- 不新增数据库模型、迁移、业务页面或业务写命令。
- 浏览器不支持 Web Speech API 时仅隐藏语音能力，不影响文字输入。
- 审计不保存图片二进制、识别请求正文或 AI 密钥。

## 验证结果

- 多模态专项验证、类型检查、生产构建和既有 AI 助手基线在该版本候选提交上通过。
- 图片大小、权限、限流、错误降级和“识别后人工确认”边界均有自动验证。

## 回滚

代码可回退到 `v0.1.401`，无需数据库迁移回滚；回滚后文字 AI 助手保持可用，语音和图片识别入口消失。
