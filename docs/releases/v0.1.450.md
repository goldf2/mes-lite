# v0.1.450 — 代码架构量化与非回退基线

日期：2026-09-01。

## 更新内容

- 新增 `audit:architecture`，统一统计源码规模、模块与 API 数量、依赖环、跨层访问、巨型文件、跨文件代码克隆和 Product/Material 双轨模型；支持 `--json` 输出。
- 新增 `verify:architecture-baseline` 并纳入 CI，阻止已量化的边界、耦合、规模和冗余指标继续恶化。
- 扩大 UI 边界检查到模块 `ui/` 下的 TS Hook；SOP 目录请求改由模块 client 封装，UI 直接 `fetch` 从 1 处降至 0。

## 影响范围

- 不修改页面入口、交互、API、权限、Prisma Schema、迁移、库存事务或生产数据。
- 基线只冻结当前上限；后续拆分巨型文件、消除依赖环或删除克隆后，应同步下调预算。

## 验证结果

- 本机执行 `audit:architecture`、`verify:architecture-baseline`、`verify:structural-goal`、`verify:module-boundaries`、`verify:sop-fullscreen-help`、`verify:development-docs`、`verify:release-notes`、TypeScript、Lint 与生产构建。
- 当前量化结果为 17 个模块、164 条 API、100 个 Prisma 模型；深层跨模块导入、路由直连 Prisma 和 UI 直接 `fetch` 均为 0。
- 本版不连接或修改生产数据库，不访问 AL02；部署结果与源码发布分开核验。
