# MES-lite v0.1.327

日期：2026-08-10

## 更新内容

- 将 `/api/orders/:id/pick`、`reports` 和 `stock-in` 的输入 Schema、状态规则、工序顺序、查询及库存/成本事务迁入 `modules/production`。
- 三条兼容 Route Handler 合计从 501 行降至 80 行，只保留权限、参数解析、领域服务、领料审计与 HTTP 错误映射。
- 新增纯 TypeScript 工序规则：上一工序按排序位置判断，不再假设 `stepNo` 必须连续。
- 修复旧入库首次创建库存余额时缺少 `StockLog` 的问题，确保兼容余额和库存流水一致。
- 新增 `verify:production-order-execution`，通过运行后删除的临时完整 SQLite 验证领料成本、预留释放、跨序阻断、报工状态、质检后入库和重复入库拒绝。

## 影响范围

- 当前生产页面没有调用上述三条旧 URL；正式投入、产出、成本结转和冲销仍只走生产订单详情中的 `ProductionOrderActual`。
- 三条旧 URL 仅因服务器可能存在 `PickItem`、`WorkReport`、`StockIn` 历史数据而保留，不恢复前端入口。
- 后续删除旧模型或 URL 前必须先盘点服务器数据、备份并准备可回滚迁移；本机测试数据不能作为下线依据。
- 本版本不修改 Prisma Schema、迁移、页面入口、权限资源和服务器正式数据。

## 结构影响

- `modules/production` 新增兼容契约、纯规则、HTTP 错误适配和三个专用服务。
- 直接访问 Prisma 的 Route Handler 从 29 条降至 26 条。
- `modules/` 保持 15 个领域/平台目录，共 320 个 TypeScript 文件。
