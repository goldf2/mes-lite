# MES-lite v0.1.251

发布日期：2026-08-08

## 更新内容

- 新增 MES / MRP / ERP 功能矩阵，确定“MES 为核心、MRP 与 ERP 有限支持”的产品边界。
- 按主数据、需求计划、生产执行、库存物流、商业财务和共享平台六个领域，标记各能力的业务负责人、使用方、接口方和当前建设状态。
- 将现有页面映射到 MES、MRP-lite、ERP-lite 和共享平台，并明确来料、库存、物料、销售订单等边界对象的字段所有权。
- 定义独立运行与对接外部 ERP 两种模式的数据主控关系，以及 MRP-lite、ERP-lite 模块关闭后的行为。
- 明确排除总账、应收应付、税务、薪资、复杂 APS 和专业 WMS 等非核心范围，作为后续功能立项的检查基线。

## 影响范围

- 本版本仅新增架构与产品边界文档，不修改页面、API、数据库结构和现有业务行为。
- 后续功能和页面标准化改造应先依据矩阵确认工作域、数据所有权和模块开关行为。

## 验证结果

- 版本文档专项校验通过。
- 文档格式检查通过。
