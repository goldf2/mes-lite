# MES-lite v0.1.185

发布日期：2026-08-05

## 更新内容

- 新增全局 AI 协作入口：桌面端位于应用页头，移动端固定显示“问 AI”。
- 新增响应式 AI 侧栏，支持当前页面上下文、快捷提问、停止回答、清空对话、未配置状态和回答数据来源。
- 接入国产 OpenAI 兼容模型服务端适配层，默认支持阿里云百炼配置，不在浏览器暴露 API 密钥。
- 新增系统指导、物料、库存、BOM、生产订单和经营概览六个只读工具。
- 新增 `aiAssistant` 权限资源；每个业务工具同时继承目标模块的查看权限。
- 成功查询写入模型、工具、数据来源和页面上下文审计，不保存用户问题和模型回答正文。
- 新增 AI Agent 项目规则、专项规范、ADR、Coolify 环境变量说明和自动边界校验。
- 固化六级能力范围和五类回答范式，要求结论先行、事实与建议分离，并明确数量单位、统计时间和只读声明。
- 压缩工作台常用功能卡片高度与留白，超宽屏提高到 8–10 列，让仪表盘经营指标更早进入首屏。

## 影响范围

- 影响桌面端全局页头、移动端底部导航和权限配置页。
- 新增 `/api/ai/status` 与 `/api/ai/chat`；没有模型配置时保持现有业务功能正常，只显示 AI 未配置状态。
- 第一版不创建、修改、确认或删除业务数据，不改变库存、BOM 和生产业务状态。
- 不修改 Prisma 数据模型；权限默认记录通过现有权限初始化逻辑自动补齐。

## 验证结果

- `npm run verify:ai-agent` 通过：模型配置门槛、只读工具白名单、资源权限过滤和回答范式约束正确。
- `npm run verify:permissions` 通过：录入角色默认具有 AI 助手查看权限，原权限组逻辑保持正确。
- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 使用本地 OpenAI 兼容模拟服务完成登录、状态查询、工具调用、经营概览回答和数据来源返回的完整 API 验证。
- 通过浏览器检查桌面端 AI 页头入口、右侧协作面板、移动端“问 AI”底部入口和全宽移动面板，无文字重叠或底部输入遮挡。
- 在 2048 × 1000 超宽桌面验证常用功能区为单行紧凑卡片，卡片高度约 78px，经营指标进入首屏。
