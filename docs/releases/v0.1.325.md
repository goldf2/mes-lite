# MES-lite v0.1.325

日期：2026-08-10

## 更新内容

- 将文档类别页面、树形管理面板、浏览器 client、输入 Schema、名称/层级规则、查询和写入事务集中到 `modules/documents`。
- `/api/document-categories` 从 100 行降至 73 行，只保留权限、Schema、领域服务、审计和 HTTP 错误映射，不再直接访问 Prisma。
- 删除根级 `DocumentCategoryManagerModal`、配置领域页面副本和 `lib/document-categories.ts`；业务配置菜单只通过文档模块公开入口挂载。
- 继续复用公共 `ResourcePageShell`、`ResourceAdvancedSearch`、`AppButton` 和 `SearchableSelect`，未建立第二套页面或控件骨架。
- 直接访问 Prisma 的 Route Handler 从 31 条降至 30 条；14 个领域/平台模块共有 302 个 TypeScript 文件。

## 影响范围

- “业务配置 / 文档类别”入口、`/api/document-categories` URL、`workInstructions` 权限和 GET/POST/PUT/DELETE 响应保持兼容。
- 文档类别仍最多两级，继续执行同层重名、父级层次、含子级和被文档引用时禁止删除等规则。
- 本版本不修改 Prisma Schema、迁移、业务流程或页面导航，不改写本机测试数据和服务器正式数据。
