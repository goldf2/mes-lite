# MES-lite v0.1.290

日期：2026-08-09

## 更新内容

- 将库存响应、库位、包装穿透、一致性问题与调整草稿结构迁入库存领域契约。
- 将库存查询、库存记录补齐、客户/库位选项和调整提交集中到库存领域客户端；协调页不再直接调用 HTTP。
- 将分类、数量、库位、显示名称、调整草稿和调整后总量集中到纯视图模型。
- 按稳定用户任务提取库存集合、右侧详情、存货调整与一致性错误提示，保留原列表/卡片、包装穿透、库位明细、自动补齐和调整能力。
- `StockPageModule.tsx` 从 853 行降至 304 行，并新增库存模块边界校验。

## 影响范围

- 只调整库存前端代码所有权与内部装配，不修改 `/api/stocks` 契约、库存事务、权限、URL 参数、偏好键或数据库模型。
- 前端 TSX 总量从 29,061 行降至约 29,017 行；超过 800 行的页面从 2 个降至 1 个。

## 验证结果

- 库存模块、库存调整事务、包装穿透、数据一致性、模块边界、高级搜索、页面注册、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建只报告既有的图片元素和 Hook 依赖警告，没有新增错误。

## 数据安全

- 本次不执行数据库迁移，不连接或修改服务器正式数据库。
- 本机 SQLite 测试记录继续隔离保存，数据库文件与构建缓存不纳入提交。
