# MES-lite v0.1.343

日期：2026-08-12

## 更新内容

- 公共 `SearchFieldWithPresets` 增加 `instant / explicit` 两种提交模式，原有页面默认行为保持不变。
- 物料主列表启用显式搜索：输入关键词不再立即请求，按回车或点击搜索图标后才执行。
- 待执行关键词使用主色搜索按钮提示；已执行后恢复普通状态，按钮保留公共深色提示和无障碍名称。
- 清空输入立即恢复完整列表；快捷搜索预置点击后直接执行，不停留在待搜索状态。

## 影响范围

- 复用公共智能搜索、快捷搜索、提示标签和工具栏框架，只扩展公共搜索组件并由物料工具栏声明启用。
- BOM、销售、来料、库存、文档等现有调用方仍使用默认即时模式，没有行为变化。
- 不改变搜索字段、API 参数、权限和数据库结构。

## 验证结果

- 浏览器验证：输入 `004` 后列表保持原 4 条，点击搜索后仅显示 `MAT-004`。
- 浏览器验证：输入 `QT` 并按回车后仅显示 `QT-500`；清空输入后立即恢复 4 条。
- TypeScript 类型检查、公共搜索回归、物料服务、模块边界、开发文档和发布记录校验。
- 生产构建与 `git diff --check`。
