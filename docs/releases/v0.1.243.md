# MES-lite v0.1.243

发布日期：2026-08-08

## 更新内容

- 在公共 `AttachmentPanel` 中为单据原始凭据增加“AI 识别并填充”入口，上传、查看和识别入口继续使用同一个附件资源。
- 新增单据原始凭据类型注册表，集中声明来料、生产、派工、销售、发货和退货的后续识别能力。
- 销售订单补齐公共原始凭据面板，与来料、生产、发货和退货使用相同的上传与识别入口。
- 当前版本不执行真实识别：没有附件时禁用按钮，存在附件时明确提示识别与字段填充服务将在下一阶段接入。
- 增加单据凭据静态校验，并补充公共前端与 AI Agent 安全边界文档。

## 影响范围

- 影响公共附件面板及六类已接入附件面板的核心单据页面。
- 不修改数据库模型、附件接口、单据创建流程、库存过账或状态流转。
- 不向模型发送附件，不产生自动字段修改或业务写操作。

## 验证结果

- 单据原始凭据静态校验、TypeScript 和定向 ESLint 通过；定向 ESLint仅保留附件面板已有 Hook 和原生图片警告，无错误。
- 页面模块与版本发布文档校验通过。
