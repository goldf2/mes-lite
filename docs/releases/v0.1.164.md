# MES-lite v0.1.164

发布日期：2026-08-04

## 更新内容

- BOM 设置改为左“输入”、右“输出”的整批配方编辑器，两侧均支持搜索并添加多项物料。
- 输入和输出直接填写各自主库存单位下的每批绝对数量；移除逐输出投入映射和内置跨量纲转换模型。
- 所有输入作为一个整体共同消耗并对应全部输出，新保存的投入不再绑定某项输出。
- 生产订单实绩按主产出计算批次倍数后展开共同投入，副产出实绩偏差不会重复追加投入。
- BOM 全览、物料全景图、成本试算、生产日报提示和数据检查统一为整批投入语义。
- 新增 ADR-0015，明确整批输入/输出模型并保留旧 BOM 与历史订单快照兼容读取。

## 影响范围

- BOM 设置、BOM 全览、物料全景图、BOM 成本试算和生产实绩。
- BOM 保存接口、数据完整性检查、批次投入计算及相关领域与界面文档。
- 不修改数据库表结构；`BOMItem.outputMaterialId` 继续作为历史兼容字段，新数据写入空值。

## 验证结果

- `npm run verify:bom-versions` 通过，验证 `0.35 m → 2 件 + 0.12 kg` 整批关系及百件展开结果。
- `npm run verify:production-order-actuals` 通过，验证共同投入只随主产出批次倍数展开。
- `npm run verify:data-integrity` 通过，验证共同投入空关联合法且重复物料仍可检出。
- Next.js 生产构建与 TypeScript 类型检查通过；仅保留仓库已有 ESLint 警告。
- 浏览器验证桌面端多投入/多输出添加、搜索和数量单位显示通过；移动端无横向溢出。
