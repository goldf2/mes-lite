# MES-lite v0.1.225

发布日期：2026-08-07

## 更新内容

- 新建文档并上传附件成功后，自动打开第一个新附件的全屏预览；多附件可在同一查看器内前后切换。
- 在已有文档中追加附件后，自动定位并预览本次上传的第一个附件。
- 关闭附件预览后保留文档详情，已有附件时将大面积拖拽上传区收起为“添加附件”按钮。
- 没有在线正文时不再显示空白正文编辑器，附件列表直接成为详情主要内容。

## 影响范围

- 影响产品文档新增、附件追加、详情展示和文件预览交互。
- 不修改附件格式、存储方式、数据库结构、权限或归档规则。
- 同步更新桌面端和移动端界面开发规范。

## 验证结果

- TypeScript 无输出类型检查通过。
- 在线文档结构化正文与可选产品关联验证通过。
- Next.js 生产构建通过；现有 ESLint 警告未增加新的阻塞项。
- 本机文档页面加载正常；测试库无现有文档，因此未写入测试业务数据执行真实上传。
