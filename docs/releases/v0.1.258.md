# MES-lite v0.1.258

发布日期：2026-08-09

## 更新内容

- 合入商业化 SaaS 数据与存储总架构，明确控制平面、数据平面、文件平面和 DataCell 扩容边界。
- 补充 SQLite 到 RDS PostgreSQL 的多租户数据结构、RLS、备份恢复、切换和回滚计划。
- 补充本地附件到私有 OSS 的统一存储、租户对象键、派生预览、历史迁移和维护工具计划。
- 通过 ADR 固化共享多租户为主、企业独立数据单元为高阶套餐的规划决策；图数据库仅作为可重建读模型。

## 影响范围

- 本次仅合并架构、规划、ADR 和版本文档。
- 不修改 Prisma Schema、生产数据库、附件存储、页面交互、接口或 Coolify 配置。
- 文档中的 `Tenant`、`DataCell`、RLS、OSS 和计量结构均为后续实施目标，不表示已经上线。
- 旧版阿里云 OSS 代码原型已独立归档，未合入当前主分支，避免覆盖新版附件预览与图片处理能力。

## 验证结果

- PostgreSQL、OSS、租户隔离、商业运行和图关系扩展之间的事实源边界已统一。
- 发布版本、发布说明和版本索引保持一致。
- 文档链接、类型检查与生产构建在合并提交前验证。
