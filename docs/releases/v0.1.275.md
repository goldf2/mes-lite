# MES-lite v0.1.275

发布日期：2026-08-09

## 更新内容

- 将物料新建/编辑表单提取为 `MaterialEditDialog`，表单初始化、单位换算选项、保存状态和创建/更新动作由该领域切片自行管理。
- 将 CSV 批量导入提取为 `MaterialImportDialog`，文件、覆盖模式、加载状态、错误明细和导入动作不再占用主页面状态。
- 新增物料领域选项目录，统一物料分类与计量方式的值、标签和筛选选项。
- `MaterialPage.tsx` 从 2,984 行降至 2,564 行，主页面只协调列表、详情、BOM 与切片完成后的数据刷新。
- 收紧 `verify:material-bom-modules`，禁止保存和导入状态回流主页面，并为三个切片设置规模边界。

## 影响范围

- 不改变物料 API、Prisma 模型、权限资源、字段含义、导入格式或页面视觉结构。
- 新建、编辑和导入仍使用原有公共弹窗、选择器、消息反馈和刷新路径。

## 验证结果

- TypeScript 类型检查通过。
- 物料/BOM 模块边界、页面模块和高级搜索契约验证通过。
- Next.js 生产构建通过。
