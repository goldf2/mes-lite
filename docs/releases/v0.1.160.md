# MES-lite v0.1.160

发布日期：2026-08-04

## 更新内容

- 每条 BOM 投入通过对应产出绑定，同一投入物料可以分别服务主产品、副产品、废料、废屑或可回收料。
- 每项产出拥有独立的内置转换模型；确认产出数量后自动进入该产出的投入配置，完成至少一项转换关系后才可继续添加下一产出。
- BOM 转换模型收敛为“单位标准用量”和“投入总量 ÷ 产出总量”，长度、重量、数量会按实际量纲显示。
- BOM 不再提供固定或百分比损耗，所有可识别损耗物都通过明确产出记录，避免重复核算。
- 生产订单冻结投入对应产出关系；班后实绩按各产出实际量分别计算投入贡献，再按投入物料汇总扣库。
- BOM 反查、数据关系检查、旧快照兼容和主产出成本试算同步适配新的对应关系。

## 数据迁移

- 新增 `BOMItem.outputMaterialId`，建立到产出物料的外键、索引和组合唯一约束。
- 既有 BOM 物料投入迁移时绑定其主产出；旧生产订单快照缺少绑定字段时继续回退到主产出解释。

## 影响范围

- BOM 编辑、保存、反查、生产订单快照与班后实绩耗用计算。
- Prisma 模型和数据库迁移。
- 领域模型、功能流程、界面规则、响应式验收规范及 ADR。

## 验证结果

- Prisma 格式化、校验和客户端生成通过。
- TypeScript 类型检查与生产构建通过。
- BOM 多版本、生产订单多产出实绩、BOM 比例、数据关系和生产库位脚本通过。
- 浏览器验证每项产出显示自己的转换目标和已配置数量，页面只保留两种无损耗内置模型。
- 发布说明与 Docker 依赖检查通过。
