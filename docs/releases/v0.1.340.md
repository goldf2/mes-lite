# MES-lite v0.1.340

日期：2026-08-11

## 更新内容

- 来料明细统一为“主库存数量必填、辅助数量可选”；不再要求操作员填写件数、总长、总重等多组重叠字段。
- 有辅助单位时优先使用本批实测数量；缺少实测值时，仅允许使用同一物料、同一单位版本且已收货的有效历史实测批次加权推算。
- 历史推算至少需要 3 批有效实测；样本不足时明确要求补录本批辅助数量，推算记录不会反向成为历史样本。
- 来料记录冻结换算来源、样本数、换算率和物料单位版本，成本计价数量与库存过账复用同一结果。
- 来料编辑器、详情和历史查询进入既有 receiving 领域模块，旧数量字段继续保留数据库和接口读取兼容。

## 影响范围

- Prisma 为 `MaterialIn` 增加 `conversionSampleCount` 和 `unitVersionUsed`，部署时通过兼容 migration 增量添加字段。
- 物料仍只维护一个主库存单位和一个可选辅助单位，不引入多换算关系表。
- 本机 SQLite、构建缓存和与本任务无关的 Excalidraw 本地状态不进入提交。

## 验证结果

- TypeScript 类型检查
- 来料实测、历史加权推算、样本门槛及“推算不污染样本”领域回归
- 物料单位、库存、库位、流程转移、生产耗用与业务单据回归
- 宽屏和窄屏来料编辑器人工预览
- 模块边界、开发文档事实基线、发布记录和生产构建
