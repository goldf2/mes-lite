# v0.1.400 管理员安全重置人员密码

日期：2026-08-17

## 更新内容

- 人员管理的列表和卡片视图增加“重置密码”入口，仅系统管理员可见和可执行。
- 管理员必须连续输入两次相同且至少 10 位的新密码；系统不会显示、恢复或返回旧密码。
- 新密码继续使用随机盐 PBKDF2-SHA512 哈希保存，明文和哈希均不进入 API 响应或审计记录。
- 重置事务会撤销目标人员全部登录会话，并清除登录失败次数、临时锁定时间和最近失败时间。
- 重置不改变账号状态、角色、权限组、个人授权或数据范围；停用账号仍须单独恢复。
- 重置当前管理员自身密码后，当前会话同样失效，页面返回登录入口并要求使用新密码登录。

## 影响范围

- 新增 `POST /api/operators/password` 薄适配层、identity-access 密码重置契约、领域命令、client 和确认弹窗。
- 继续复用 `operators.update` 资源权限，并额外要求实际角色为 `ADMIN`；权限组授予更新动作不会获得密码重置能力。
- 新增 `PASSWORD_RESET` 审计动作，只记录目标账号、状态、撤销会话数量和锁定清除结果。
- 不修改 Prisma Schema，不新增数据库迁移，不改变生产、库存、质量或成本业务数据。

## 验证结果

- 覆盖密码长度、双重输入不一致、非管理员越权、旧会话撤销、锁定清除、旧密码失效和新密码登录。
- 验证账号状态保持不变，并确认审计前后数据不包含新密码或 `passwordHash`。
- 密码重置接口加入高风险写命令审计门禁；执行身份认证、身份权限、全量 CI、类型检查、Lint 和生产构建。

## 回滚

代码可回退到 `v0.1.399`，无需数据库迁移回滚。已经重置的密码和已经撤销的会话不会因代码回滚自动恢复；用户继续使用重置后的密码登录。
