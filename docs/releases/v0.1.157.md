# MES-lite v0.1.157

发布日期：2026-08-03

## 更新内容

- 当 BOM 总产出达到 4 项时，桌面端右侧产出明细改为限高滚动区域，不再持续向下撑开并遮蔽转换模型和后续表单。
- 产出搜索框、标题和已添加数量保持在滚动区域外，滚动时仍可继续添加物料并确认当前产出总数。
- 滚动区域保留稳定滚动槽并提供清晰的轨道和滑块样式，便于发现可滚动内容。
- 滚动到产出区域边界后保留正常页面滚动衔接，不拦截鼠标在页面其他区域的滚动。
- 移动端不启用产出明细内层滚动，继续使用页面正文单一纵向滚动。

## 影响范围

- 仅影响 BOM 编辑器多项产出的桌面端布局和滚动行为。
- 不修改 BOM 数据、保存接口、生产订单快照或库存过账逻辑。

## 验证结果

- TypeScript 类型检查通过。
- 浏览器桌面视口验证多项产出区域显示独立滚动条，搜索框和后续转换模型仍保持可见。
- 响应式样式检查确认滚动规则仅在 `1024px` 及以上启用，移动端不会产生该内层滚动。
- 发布说明、Docker 依赖检查及生产构建通过。
