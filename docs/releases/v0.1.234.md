# MES-lite v0.1.234

发布日期：2026-08-08

## 更新内容

- 新增“标准管理”和“画布工作”两种桌面工作区布局，并在全局右上角提供固定的快速切换按钮。
- 标准管理布局支持左侧导航常驻或自动隐藏；自动隐藏时只保留一个入口，鼠标靠近、点击或键盘聚焦可覆盖呼出，不挤压主内容。
- 画布工作布局使用单行顶部一级导航，宽度不足时自动收进“更多”，二级功能与功能搜索继续复用同一权限菜单数据。
- 画布工作布局将公共页面工具移至 320px 独立右栏，统一承载关键词搜索、高级搜索、视图、页内选项、二维码和当前页面操作。
- 系统设置的显示设置新增工作区布局和左侧导航行为选项；偏好仅保存在当前浏览器，切换和刷新不影响当前业务页面与数据。
- 高级搜索在画布右栏中改用居中弹层，避免字段面板被窄工具栏裁切。

## 架构约束

- 两种工作区只切换公共应用外壳，不复制业务页面、菜单注册、权限判断或页面工具实现。
- 左侧导航临时呼出必须使用覆盖层位移；只有切换为常驻显示时才允许主内容发生明确重排。
- 小于 `1024px` 时继续使用既有移动端导航和页面工具抽屉，不启用桌面工作区切换。

## 影响范围

- 公共桌面应用外壳、导航偏好、顶部工具 Portal、公共页面工具和系统显示设置。
- 业务页面、接口、权限、数据库结构和业务数据均未修改；现有页面自动继承两种工作区形态。

## 验证结果

- TypeScript、定向 ESLint、工作区应用壳静态契约与发布说明校验通过。
- 浏览器实测左栏自动隐藏/呼出、刷新保持、两种工作区往返、顶部导航溢出、右侧页面工具和字段式高级搜索弹层。
- 实测 1280px 桌面下无页面级横向溢出；自动隐藏呼出前后主内容宽度不变。
