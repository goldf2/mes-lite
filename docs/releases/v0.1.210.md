# MES-lite v0.1.210

发布日期：2026-08-06

## 更新内容

- 公共显示模式切换器改为 Finder 风格弹出按钮，收起时使用当前模式图标，菜单使用图标、文字和当前项标记。
- 公共资源骨架新增真实分栏模式：主列表变为紧凑单列，详情区获得更多宽度，并单独保存分栏比例。
- 公共资源骨架新增真实画廊模式：使用带大预览区的卡片展示视觉资源。
- 产品文档公共框架实验页启用图标、列表、分栏和画廊四种模式；其他页面继续按实际能力声明选项。

## 影响范围

- 全部复用 `ViewModeToggle` 的页面由并排按钮改为紧凑弹出入口，现有卡片/列表状态值保持兼容。
- `ResourcePage`、`ResourceToolbar`、`ResourceCollection`、`ResourceCardGrid` 与桌面主从布局增加显示模式能力，不复制业务数据和详情组件。

## 验证结果

- TypeScript、Lint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证弹出菜单的四个选项、当前项状态、选择后关闭、画廊预览卡片及分栏主从比例变化。
