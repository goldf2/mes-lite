# MES-lite v0.1.214

发布日期：2026-08-06

## 更新内容

- 全局桌面和移动工具栏新增公共“当前页面二维码”，二维码可携带页面、子页面、列表/卡片视图、允许分享的筛选条件和选中记录。
- 二维码弹窗支持编辑信息卡标题、功能路径、说明、页脚和显示字段，可复制深链接、保存当前浏览器模板并下载 PNG。
- “工具 → 数据工具”升级为数据维护与关系检查，新增库存归属异常扫描。
- 零余额、无库位、无库存流水的孤立库存可逐条安全清理；带余额或业务引用的异常库存只报警，不提供自动删除。

## 影响范围

- 新增公共 `PageQrCodeButton`，主应用壳和公共资源实验页面统一调用。
- 页面深链接仍执行登录和资源权限校验，二维码不作为授权凭证，也不包含未保存表单和临时弹窗状态。
- 数据维护操作在单个事务中重新扫描问题并写入审计，不自动修改实际业务数量和金额。
- 无数据库迁移；本次不会自动清理现有异常记录，管理员需在数据工具中明确确认。

## 验证结果

- TypeScript、数据完整性专项校验、页面模块校验、工作台偏好校验、版本文档校验和生产构建通过。
- 浏览器验证桌面端与移动端二维码入口、二维码生成、页面状态深链接和刷新恢复。
- 浏览器验证孤立库存扫描、安全清理确认和风险阻断文案；测试使用事务回滚数据，不修改正式业务记录。
