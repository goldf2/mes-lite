# MES-lite v0.1.330

日期：2026-08-10

## 更新内容

- 将密码注册/登录/注销和微信绑定的契约、状态规则、会话事务与 HTTP 错误映射统一归入 `modules/identity-access`。
- 将 AI 文档识别的附件归属校验、提示字段、JSON 解析、置信度规则和 Provider 调用归入 `modules/attachments`。
- 将工作区偏好与使用量、物料导出/兼容产品查询、生产/质量统计和配置人工排序归入已有领域模块，并让页面控制器通过公开 client 访问。
- 12 条剩余 Route Handler 均成为无 Prisma 的薄 HTTP 适配层；跨领域配置排序只通过 `modules/configuration` 公开入口调用。

## 影响范围

- 不修改页面入口、交互、权限资源、Prisma Schema、数据库迁移或现有 API URL。
- 认证状态、AI 识别响应、CSV 导出和工作区偏好响应契约保持不变。
- 本机 `prisma/mes_lite.db` 和服务器正式数据均未改写。

## 结构影响

- 直接访问 Prisma 的 Route Handler 从 12 条降至 0 条。
- `modules/` 保持 15 个领域/平台目录，共 362 个 TypeScript 文件。
- `package.json` 共有 73 个 `verify:*` 局部契约命令。
