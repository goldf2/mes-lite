# MES-lite v0.1.466

## 更新内容

生产订单创建现在可以在选定目标物料和已发布 BOM 后，继续选择一条已保存的 BOM 成本运行。候选按最新创建时间倒序展示，每条记录显示工艺路线、单位成本和创建时间；服务端会再次校验成本运行属于当前物料与 BOM，且其工艺路线仍存在。

创建成功后，订单保存所选 `bomCostRunId`、BOM 成本快照和工艺路线快照，后续生产实绩继续使用冻结依据。未明确选择成本运行时保持兼容行为：自动采用当前 BOM/默认路线下最新匹配运行；不使用 BOM 的临时生产仍可创建。

## 影响范围

- 无 Prisma 迁移。
- 不改写现有生产订单、成本运行、库存或历史快照。
- 仅扩展生产订单创建契约和候选查询返回的成本运行列表。

## 回滚边界

本版本无数据库迁移。若发布失败，保留上一版本健康容器并回滚代码；若新订单已经写入显式成本运行快照，回滚代码前先停止新写入并保留数据库事实，不删除成本运行或订单快照。
