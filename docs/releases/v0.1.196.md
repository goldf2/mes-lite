# MES-lite v0.1.196

发布日期：2026-08-05

## 更新内容

- 由服务端在首屏直接注入已发布的 AI 图标参数，消除刷新时“默认图标→设定图标”的瞬时切换。
- 新增系统级“页面加载 AI 图标”开关，关闭后等待状态仅显示加载文字。
- 提高全屏加载层级和图标尺寸，并统一设备、生产记录、流程转移、员工、销售订单、BOM 与系统配置等页面的等待状态。
- 图标调参发布后仍会即时同步到当前页面的 AI 入口和加载指示器。

## 影响范围

- 根布局改为运行时服务端渲染，每次首屏请求读取轻量系统设置，不改变业务数据请求顺序。
- 加载图标开关使用现有 `SystemSetting` 持久化，默认开启，无需数据库迁移。
- 按钮提交、配置读取等局部小型状态继续使用简短文字，避免频繁动画干扰操作。

## 验证结果

- `npm run verify:ai-mark` 通过，包含图标参数安全和加载图标开关默认值、持久化校验。
- 指定文件 ESLint 检查通过，仅保留项目既有 Hook 依赖与图片优化警告。
- `npm run build` 通过，首页正确标记为运行时服务端渲染。
