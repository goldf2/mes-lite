# MES-lite v0.1.335

日期：2026-08-10

## 更新内容

- 新增“库存 → 库存流水”主导航页面，复用现有 `stocks` 读取权限和公共页面骨架。
- 既有 `StockLog` 现在可以按物料、流水类型、收发方向、库位、来源、操作人、备注和日期查询，并显示库存、核算数量和成本前后变化。
- 智能搜索按空格拆分关键词，允许多个关键词分别命中物料、来源、库位和人员字段；高级搜索继续使用全系统公共字段式搜索。
- 库存流水支持卡片/列表、偏好保存和服务端分页，两个视图共用同一接口和筛选条件。
- 新增库存流水领域契约、client、查询服务、薄 API 和临时 SQLite 回归，不修改 Prisma Schema、迁移、本机测试库或服务器正式数据。
- 新增《MES 核心能力缺口与建设路线》，明确下一阶段依次补质量判定、批次追溯、不合格处置、设备事件和库存状态，不继续扩张财务或复杂 APS。

## 影响范围

- 新增一个只读页面、一个只读 API 和库存领域查询切片；不修改库存过账、成本层、Prisma Schema 或迁移。
- 本地功能回归使用临时独立 SQLite；不读写本机 `prisma/mes_lite.db` 或服务器正式数据。
- 页面注册从 38 个增加到 39 个，公共顶部工具栏继续保持零例外。
