# MES-lite v0.1.181

发布日期：2026-08-04

## 更新内容

- 新增统一的数值输入字段和指标卡片，收口锯切成本、BOM 成本、生产日报和流程转移中的重复实现。
- 两个成本页面统一复用物料搜索选择器，支持键盘选择、点击外部关闭、空状态和 BOM 版本徽标。
- 动态选择器靠近视口底部时自动向上展开，并按可用空间限制列表高度。
- 新增前端组件复用审查文档，记录超大页面、旧控件迁移和保留未接入模块的后续整理顺序。

## 影响范围

- 影响锯切成本、BOM 成本、生产日报、流程转移页面的字段与统计卡片展示。
- 影响 `SearchableSelect` 和 `MaterialChoiceSearch` 的弹层展开方向。
- 不改变成本算法、业务接口、数据库模型或库存数据。

## 验证结果

- TypeScript 类型检查通过。
- Next.js 生产构建通过；保留项目已有的 Hook 依赖和图片优化警告。
- 桌面视口 `1280×720` 下，物料搜索弹层在底部自动向上展开并完整位于视口内。
- 移动视口 `390×844` 下，数值字段、单位后缀、指标卡片和物料搜索弹层无横向溢出。
- 物料编码输入筛选、列表结果更新和弹层键盘语义正常。
