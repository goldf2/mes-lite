# MES-lite v0.1.470

## 更新内容

- 来料管理新增历史核查：日期范围、包含归档、跨页状态/单位汇总和单据分页。
- 发货管理、退货管理归入物流，销售分类仅保留销售订单。
- 发货详情支持后补/修改各行单价，覆盖待发货、已发货、已签收，原因必填；与修改前后审计原子保存，拒绝旧版本覆盖。取消/冲销/归档单不可改价。

## 影响范围

GET /api/material-ins 新增 startDate、endDate、includeArchived、includeSummary 可选参数及 summary 返回字段；汇总匹配整单，按单据单位与当前明细状态统计。日期采用北京时间，包含起止日。归档查询另需 archive.read；所有结果保留原数据范围。无新增数据迁移，不修改库存余额或历史数据；版本包含前序 v0.1.469 变更与其迁移。

界面复用 AppButton、FormField、ResourceTable 和来料集合/详情组件。导航复用统一页面注册表，无领域目录搬迁。

## 验证结果

来料垂直回归、销售订单与发货回归、销售模块、页面模块、模块边界、SOP、发布说明与 TypeScript 已通过。新增验证覆盖跨页汇总、日期端点、无效日期、归档、签收后改价、审计、过期版本拒绝、异单明细拒绝和库存流水不变。

PATCH /api/shipments/:id 仅接受 updatedAt、reason 和明细 id/unitPrice，使用 shipment.update 与原库位数据范围；服务端按固定发货数量重算行金额/整单金额，更新源版本以生成新版 PDF，不回写历史下载文件、库存成本、退货或销售订单。
