# MES-lite v0.1.233

发布日期：2026-08-08

## 更新内容

- 所有可搜索数据页面统一使用公共字段式高级搜索：弹层完整列出当前资源声明的字段，并为每个字段提供匹配方式和值输入。
- 物料、设备、员工、文档类别、BOM 全览、所有功能和人员权限补齐结构化精确搜索；主要业务单据的原筛选条件迁入同一公共弹层。
- 公共 `ResourcePage` 统一执行高级搜索条件，列表、卡片、图标、分栏和画廊共享同一结果集。
- 物料接口支持编码、名称、规格、分类、客户、计量方式、单位、计价方法、BOM 状态、备注和日期组合查询，并保持 BOM 权限校验。
- 移除旧工具栏 `filters` 兼容入口，禁止业务页用分类或状态标签集合冒充高级搜索。

## 影响范围

- 产品文档、物料与 BOM、设备、员工、来料、发货、退货、销售订单、派工、流转、统计、库存、工单、文档类别、权限和业务配置页面。
- 仅调整查询与前端工具栏结构，不修改业务数据、单据状态或数据库结构。

## 验证结果

- 14 个搜索页面公共高级搜索契约验证通过，资源搜索逻辑与 TypeScript 校验通过。
- 浏览器实测产品文档、物料、设备、来料、文档类别和人员权限均显示相同字段式弹层。
- Next.js 生产构建、页面模块契约、发布说明和 Docker 依赖校验通过。
