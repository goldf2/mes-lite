# MES-lite v0.1.187

发布日期：2026-08-05

## 更新内容

- AI 图标使用固定等比容器，桌面入口从 40px 增大到 48px，移动端图标同步增大。
- 图标默认以 28 秒一周缓慢旋转，并以 5.2 秒周期轻微呼吸；鼠标悬停或键盘聚焦时暂停旋转，按压时短促收拢。
- 去除 AI 图标外围的常驻方形底色、边框和阴影，仅保留标志本身与必要的焦点提示。
- 在“配置 → 系统设置”增加 AI 助手配置，可维护启用状态、国产模型提供商、兼容接口地址、模型 ID、API Key、请求超时和最大工具轮次。
- 新增页面配置连接测试；AI 面板管理员可从设置图标或未配置提示直接进入配置页面。
- 页面 API Key 使用 AES-256-GCM 加密后保存到 `SystemSetting`，前端只读取配置状态和脱敏提示；Coolify 中的 `AI_AGENT_CONFIG_SECRET` 是唯一解密主密钥。
- 页面配置优先于环境变量；未建立页面配置或未保存页面密钥时继续使用 Coolify 环境变量。

## 影响范围

- 影响桌面端和移动端 AI 入口、AI 对话面板、系统设置页面及 AI 服务配置读取方式。
- 复用既有 `SystemSetting` 键值表，不修改 Prisma schema，也不需要数据库迁移。
- AI 业务工具仍然只读，工具白名单、账号权限和审计边界不变。

## 验证结果

- AI 专项校验覆盖环境变量回退、页面密钥加密、前端脱敏、主密钥变化拒绝解密及只读工具权限。
- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 版本文档与 Docker 依赖清单校验通过。
- 浏览器验证桌面图标保持正方形、常驻旋转与呼吸、悬停暂停旋转、点击打开面板，以及系统设置 AI 配置表单。
- 移动端验证增大后的图标不挤压底部导航，AI 配置表单单列显示且无横向滚动。
