# MES-lite v0.1.219

发布日期：2026-08-07

## 更新内容

- 新增公共资源页面骨架，统一业务配置页的顶部工具、标题说明、数量摘要、内容容器、视图切换与新建入口。
- 工作中心、库位、单位、供应商、客户、加工工艺和工艺路线迁移到同一页面框架，库位与单位的新建表单统一使用弹窗。
- 默认搜索升级为配置化的多关键词模糊筛选；新增组合条件精确搜索，并允许把关键词搜索和条件搜索分别保存为快捷搜索。
- 将桌面导航、一级菜单样式和弹窗视觉等全局偏好收口到“系统设置 → 显示设置”，页内选项仅保留 BOM 新建默认值。
- 统一创建类按钮为“新建 + 业务对象”，已有对象内部追加行或关联项继续使用“添加”。
- 将业务数据顺序调整与个人显示排序明确分离，配置页业务顺序入口统一命名为“调整顺序”。

## 开发规范

- 新资源页必须优先接入公共页面骨架，不得在业务页面重复组装搜索、视图切换、快捷搜索和新建工具。
- 每个页面通过搜索配置显式声明可搜索字段；公共搜索模块不扫描未声明字段。
- 全局界面设置不得重复放入各页面的页内选项；页内选项只保存当前主视图专属偏好。

## 影响范围

- 本次调整主要影响业务配置页、系统显示设置、页面工具栏和资源搜索交互，不修改数据库结构或既有业务数据。
- 旧版纯文本快捷搜索会在读取时自动兼容；新保存内容会标记为关键词搜索或条件搜索。
- 业务排序字段和服务器端手动顺序保持不变，仅统一入口文案与页面布局。

## 验证结果

- 公共搜索、多关键词、组合条件和数值比较回归验证通过。
- 页面模块与配置顺序契约校验通过。
- TypeScript、ESLint、Docker 依赖一致性检查和生产构建通过。
- 公共资源页面实验室完成本机渲染验收。
