# MES-lite v0.1.204

发布日期：2026-08-06

## 更新内容

- 移除桌面侧栏中与菜单高亮重复的“功能导航 / 当前页面”摘要，让菜单从应用栏下方直接开始。
- 一级菜单收紧为约 `36px`，二级菜单收紧为约 `30px`，同步缩小图标、内边距、分组间距和展开区缩进。
- 保留侧栏独立滚动、一级展开提示、二级选中态、拖动排序和宽度调节能力。

## 影响范围

- 仅调整桌面公共应用壳的左侧导航密度，不改变移动端导航、菜单注册、页面权限或业务功能。

## 验证结果

- 在 `1280 × 720` 视口展开“配置”分组时，可直接看到 19/20 个当前菜单按钮；更高的常见笔记本视口可完整展示。
- TypeScript、ESLint、页面模块覆盖校验、版本文档校验和生产构建通过。
