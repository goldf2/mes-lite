# MES-lite v0.1.324

日期：2026-08-10

## 更新内容

- 将员工输入契约、自动编号、资料规范化、查询、账号一对一绑定和写入事务集中到 `modules/configuration`。
- `/api/employees` 从 185 行降至 61 行，只保留权限、查询参数/Schema、领域服务、审计和 HTTP 错误映射，不再直接访问 Prisma。
- 删除 `lib/employees.ts`；生产实绩与旧日报改为通过配置模块公开出口解析有效员工和生成姓名快照，员工规则只有一个所有者。
- 直接访问 Prisma 的 Route Handler 从 32 条降至 31 条；14 个领域/平台模块共有 295 个 TypeScript 文件。

## 影响范围

- 员工仍是业务资料，账号仍是登录身份；绑定不会修改账号审核状态、角色或权限，相关管理继续归 `modules/identity-access`。
- 既有 `/api/employees` GET/POST/PATCH、`system` 权限、响应结构、自动编码和审计行为保持兼容。
- 停用员工不能用于新生产实绩；已保存的工号和姓名快照不随员工资料修改。
- 本版本不修改 Prisma Schema、迁移、页面结构，不自动改写本机测试数据或服务器正式数据。
