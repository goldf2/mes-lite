# MES-lite v0.1.169

发布日期：2026-08-04

## 更新内容

- 产品文档新增原生在线富文本编辑与阅读能力，支持标题、标题层级、加粗、斜体、列表、引用、代码块及撤销/重做。
- 文档增加独立标题，产品关联改为可选；通用指导书无需为绑定产品而创建虚拟物料，仍可关联多个适用工作中心。
- 在线正文保存为结构化 JSON，服务端自动生成纯文本搜索投影；主搜索同时覆盖标题、正文、产品、类别和备注。
- 图片与 PDF 继续作为独立附件维护，可与在线正文同时存在。

## 数据与兼容性

- 新增 `WorkInstruction.title`、`contentJson`、`contentText`，并将 `materialId` 改为可空。
- 迁移自动使用原关联产品名称回填历史文档标题，原产品、类别、版本、状态、工作中心、备注和附件关联保持不变。
- 旧验证脚本同步补充必填标题，新增在线文档专项迁移与数据验证。

## 影响范围

- 影响产品文档的数据库结构、创建/编辑/搜索 API、列表与详情界面，以及 Docker 前端依赖清单。
- 不改变 BOM、生产订单和设备台账边界；在线文档正文不作为生产过账数据。
- 部署时会执行数据库迁移，历史产品文档标题由原关联产品名称自动回填。

## 验证结果

- Prisma schema 格式化和 Client 生成通过。
- 在线文档结构化正文、纯文本搜索投影与可选产品关联专项验证通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有 ESLint 警告。
