# MES-lite v0.1.237

发布日期：2026-08-08

## 更新内容

- 顶部一级菜单明确区分三态：当前页面使用浅蓝弱高亮，临时选择使用实心蓝主高亮，其余释放状态使用中性灰。
- 关闭弹层或点击空白处只释放临时选择，当前页面标识保持不变。
- 二级弹层改为从对应一级入口下方展开，并在导航可用区域内自动防止越界。
- 只有一至两个功能的菜单使用紧凑单列尺寸，功能较多、功能搜索和“更多”菜单继续使用宽型双列尺寸。
- 保留 180ms 鼠标意图延迟，避免快速扫过一级菜单时连续闪切。

## 影响范围

- 仅调整画布工作布局顶部导航的选中反馈、弹层定位和尺寸。
- 标准管理侧栏、移动端导航、菜单权限和业务数据均不受影响。

## 验证结果

- 工作区应用壳静态契约、TypeScript、定向 ESLint 和生产构建通过。
- 浏览器验证打开项主高亮、当前页面项弱高亮、紧凑菜单尺寸及左右边界定位均符合预期。
