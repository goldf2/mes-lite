# MES-lite v0.1.284

发布日期：2026-08-09

## 更新内容

- 新增物料请求 Schema，集中新建、修改、高级搜索、分页和排序契约。
- 将智能多关键词搜索、字段式高级搜索、自然编码排序、BOM 简况排序、分页和主图装配迁入物料查询服务。
- 将配置单位校验、编码唯一性、物料与库存原子创建、单位版本和单位变更审计迁入物料写入服务。
- `app/api/materials/route.ts` 从 549 行降至 73 行，并从存量巨型路由基线移除。
- 新增 `verify:material-server`，支持纯边界校验和临时完整数据库集成验证。

## 影响范围

- 不改变物料页面、接口地址、查询参数、响应结构、权限、Prisma 模型或数据库迁移。
- 不改变物料编码冲突、配置单位约束、自然编码排序、BOM 简况排序或主图选择的既有语义。
- 单位变更仍明确不换算历史数值，并在物料更新事务内递增单位版本、写入 `UNIT_CHANGE` 审计。

## 数据隔离

- 自动集成验证按全部迁移在 `/tmp` 创建独立 SQLite 数据库，验证完成后删除。
- 测试不会写入本机常用 SQLite，也不会连接或修改服务器正式数据库。

## 验证结果

- 物料 Schema、查询/写入服务边界和薄 API 校验通过。
- 临时数据库中物料与库存原子创建、重复编码、智能多关键词查询、普通更新、单位变更审计和非法单位拒绝均通过。
- TypeScript 类型检查、模块边界、物料/BOM 模块、开发文档、版本说明和生产构建通过。
