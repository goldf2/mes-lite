# MES-lite v0.1.255

发布日期：2026-08-09

## 更新内容

- “系统设置 → 导航与工作区”新增当前工作区的一级菜单顺序设置，可直接前移或后移菜单分组，包括账号与权限入口。
- MES、MRP、ERP 分别保存自己的一级菜单顺序，切换工作区后互不覆盖。
- 同一顺序同时驱动桌面侧栏、画布顶部导航和移动端功能菜单，避免三套导航出现不同排列。
- 一级菜单顺序与页面唯一归属、页面显示名称和组内页面顺序共同存入现有工作区配置。

## 影响范围

- 旧配置未包含一级菜单顺序时自动使用系统默认顺序，无需数据库迁移。
- 新增一级菜单或旧配置缺少分组时会自动补齐，不会因为历史配置隐藏新菜单。
- 不改变业务页面、路由、权限、业务数据或菜单唯一归属规则。

## 验证结果

- 一级菜单顺序规范化、自动补齐和数据库持久化验证通过。
- 桌面侧栏、顶部导航和移动菜单统一读取工作区一级菜单顺序的静态契约验证通过。
- 页面唯一归属、版本说明、TypeScript 类型检查和生产构建通过。
