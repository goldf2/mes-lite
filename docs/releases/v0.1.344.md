# MES-lite v0.1.344

日期：2026-08-12

## 更新内容

- BOM 建立 `DRAFT -> RELEASED -> OBSOLETE` 单向生命周期：草稿可编辑，已发布和已作废版本永久只读。
- 新增发布、复制新版本和作废 API；发布时自动成为同产品、同用途的默认 BOM。
- `productId + version` 继续作为数据库唯一约束，复制时生成唯一新版本并保留源版本和变更原因字段。
- 生产订单、包装库存穿透、BOM 成本和 AI BOM 查询只使用已发布版本。
- 数据库触发器阻止正式 BOM 主体、投入、产出被直接改写或状态回退；锯切成本自动派生草稿，数据维护对正式版本只告警。
- 已有启用 BOM 自动迁移为已发布，已停用 BOM 迁移为已作废，不中断现有生产数据。

## 影响范围

- BOM 列表显示草稿、已发布和已作废标记。
- 新建 BOM 先保存草稿，再明确发布；正式版本变更时使用“创建新版本”，不再原地覆盖。
- 生产订单仍保存 BOM ID、名称、版本和完整投入/产出快照，历史订单不随后续作废变化。

## 验证结果

- BOM 生命周期、版本唯一性、数据库不可变触发器和生产候选回归。
- 物料/BOM 模块边界、BOM 成本、锯切成本派生、数据维护、包装库存和 AI BOM 查询回归。
- TypeScript 类型检查、生产构建、开发文档、发布记录和 `git diff --check`。
- 本机浏览器验收：BOM 工作区正常渲染，草稿入口与版本状态已接入，控制台无运行错误。
