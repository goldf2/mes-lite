# MES-lite v0.1.339

日期：2026-08-10

## 更新内容

- 新增 `MaterialReceipt` 来料单头，一张来料单可包含多种物料；编辑、整单收货、拒收、红冲、附件、归档和 PDF 统一以单头为边界。
- 一张来料单的所有明细先进入同一待分库库位，确认后通过既有流程转移分配到实际原料、待检或生产库位。
- 物料现有换算率明确为“1 主库存单位 = N 参考单位”，可表达标准单重或标准单位长度重量。
- BOM 在单位目录同量纲换算之外，支持按物料标准换算在长度与重量等主/参考计量之间录入，并冻结原始数量、换算率、来源和单位版本。
- 既有单行来料记录兼容迁移为一单一行，保留原 ID 作为单头 ID，避免附件引用失效。

## 影响范围

- 新增 Prisma 模型与迁移；部署时自动兼容既有来料单，不删除正式库存流水、成本层或附件。
- 收货和红冲改为整单原子事务；任一物料明细不满足条件时整笔回滚。
- 本机 SQLite、构建缓存和与本任务无关的 Excalidraw 本地状态不进入提交。

## 验证结果

- TypeScript 类型检查
- 来料多物料、整单收货/红冲、成本层与库位回归
- BOM 版本、物料跨计量换算与历史快照回归
- 流程转移、库位归档、归档永久删除与业务单据 PDF 回归
- 模块边界、开发文档事实基线、发布记录和生产构建
