# MES-lite v0.1.212

发布日期：2026-08-06

## 更新内容

- 新增系统级图片优化工具，第一阶段可扫描并批量处理物料图片，显示总数、已优化数、待处理数、存储量和逐批进度。
- 原始图片作为不可变事实源继续保留；服务端生成 320px WebP 缩略图和 1600px WebP 展示图，新上传的物料图片自动生成两个规格。
- 物料列表、BOM、库存、生产统计和流程转移等小图场景统一使用缩略图，物料详情使用展示图，只有主动打开原图时才读取原始文件。
- 派生图 URL 包含原图大小、方向和规则版本；缩略图使用 90 天私有不可变缓存，展示图使用 30 天私有不可变缓存，浏览器缓存不作为备份。
- 永久删除附件时同步清理原图、通用缩略图和 WebP 派生图。

## 影响范围

- 新增附件图片派生服务、版本化图片接口和物料图片批量优化接口。
- “工具 / 数据工具”接入图片优化公共面板，当前范围固定为物料图片，后续可扩展其他附件范围。
- 物料图片 API 增加 `thumbnailUrl`、`displayUrl` 和 `originalUrl`，保留 `url` 作为展示图兼容字段；无数据库迁移。

## 验证结果

- 图片派生专项校验通过：尺寸限制、WebP 输出、原图不变、版本化 URL 和删除清理均符合预期。
- 真实数据副本批量验收：5 张历史物料图中 4 张成功生成派生图，原图 2.1 MB 对应两种派生图合计 322.3 KB；1 张无效的 30 字节测试图片保留为失败项且原文件未变。
- 浏览器验证桌面端与 390px 窄屏布局、批量进度、失败反馈、物料列表缩略图、主详情展示图、详情画廊缩略图和原图入口。
- 权限、页面模块、版本文档、TypeScript、Lint 和生产构建通过；Lint 仅保留仓库已有警告。
