# MES-lite v0.1.212

发布日期：2026-08-06

## 更新内容

- 原“配置”一级入口更名为“业务配置”，继续维护企业资料、单位、库位、供应商、客户、员工、工艺、路线和业务排序规则。
- 新增独立一级“系统设置”，首批包含“显示设置”和“AI 服务”两个有真实内容的子入口。
- 原混合设置页拆分：企业资料与物料编码排序进入业务配置；配色与磨砂效果进入显示设置；AI 加载图标、服务、模型、接口和密钥进入 AI 服务。
- AI 面板的设置快捷入口改为直接打开“系统设置 → AI 服务”。
- 历史工作台 `systemSettings` 快捷入口自动迁移为“企业与业务规则”。

## 影响范围

- 调整桌面双列/单列导航、移动端功能抽屉、所有功能页、工作台快捷入口和页面模块注册表。
- 设置数据键和 API 保持不变，不迁移数据库业务数据。
- 新增 ADR 0021，固化业务配置、系统设置和个人偏好的边界。

## 验证结果

- TypeScript、Lint、页面模块校验、工作台偏好校验、版本文档校验和生产构建通过。
- 浏览器验证“业务配置”和“系统设置”为独立一级入口，并确认企业与业务规则、显示设置、AI 服务三页内容没有交叉。
