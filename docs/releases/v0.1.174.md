# MES-lite v0.1.174

发布日期：2026-08-04

## 更新内容

- 生产工单支持在同一张工单中连续添加多个产品，每个产品可分别选择 BOM 和计划数量。
- 同一张工单的产品明细使用统一工单号分组，列表和详情页可查看并切换各产品。
- 建单时不选择库位，库位仍在登记实际投入和产出时确定。
- 修复快捷搜索弹窗被物料表格吸顶表头文字覆盖的层级问题。

## 数据结构

- 生产工单新增分组工单号和明细序号，原有单产品工单保持兼容。
- 同一张工单的多个产品使用事务一次性创建，任一明细校验失败时不会产生部分工单。

## 影响范围

- 影响生产工单的创建、列表和详情查看，不改变原有实绩登记与库存记账方式。
- 快捷搜索层级修复适用于所有使用该通用组件的页面。

## 验证结果

- Prisma 客户端生成与数据库迁移执行通过。
- TypeScript 类型检查通过。
- 浏览器验证生产工单页可连续添加产品，且建单页无库位选择。
