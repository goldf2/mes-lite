# MES-lite v0.1.240

发布日期：2026-08-08

## 更新内容

- 新增公共业务单据 A4 PDF 输出引擎。
- 来料、销售订单、发货、退货、流程转移、生产订单和派工单在创建后自动生成 PDF。
- PDF 作为系统生成附件归档，支持直接预览、下载和历史补打。
- 一次创建多条来料单或生产订单时，每条单据分别生成 PDF。
- 草稿修改后生成新归档版本，旧版本不被覆盖。

## 影响范围

- 调整当前全部交易单据的新建提交动作，并新增统一打印入口。
- 不改变单据校验、状态流转、库存过账和成本核算规则。

## 验证结果

- TypeScript 和定向 ESLint 通过。
- 公共 PDF 渲染契约验证输出有效 `%PDF-` 文件。
- 使用现有发货单、生产订单和派工单验证打印接口均返回 200。
