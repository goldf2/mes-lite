# MES-lite v0.1.239

发布日期：2026-08-08

## 更新内容

- 修复物料卡片视图在筛选后只有一条记录时被拉伸占满整行的问题。
- 物料卡片改为明确的响应式一至四列布局，单条结果保持正常卡片宽度。
- 同步修正文档卡片的同类 `auto-fit` 问题，文档预览卡最多显示三列。

## 影响范围

- 调整物料管理和产品文档的卡片网格，不影响列表视图、搜索结果、分页和业务数据。

## 验证结果

- 页面模块静态契约、TypeScript、定向 ESLint 和生产构建通过。
- 浏览器在宽屏下筛选为一条物料记录后，卡片仅占一个响应式列；列表视图仍保持全宽。
