# MES-lite v0.1.190

发布日期：2026-08-05

## 更新内容

- 存货调整新增必填库位，支持输入库位编码或名称进行筛选。
- 切换库位时显示该物料在各库位的当前数量，数量字段改为“调整后库位库存”。
- 弹窗实时显示调整后的物料总库存；核算库存和库存金额继续作为物料总账数据维护。

## 影响范围

- 存货调整 API 由物料总数量入参改为 `locationId + newLocationQty`，服务端按库位差额同步更新库位余额和物料总库存。
- 库位不存在、停用、归档或调整后数量低于该库位已预留数量时拒绝提交。
- 调整流水和审计记录明确保存库位、库位调整前后数量及物料总库存变化；数据库结构未变化。
- 同步更新库存领域规则、数据模型说明、功能流程和桌面/移动交互规范。

## 验证结果

- `npm run verify:stock-location-adjustment` 通过：空库位盘盈、已有库位盘亏、总库存汇总、流水库位归属和库位预留校验正常。
- `npx tsc --noEmit` 与 `git diff --check` 通过。
