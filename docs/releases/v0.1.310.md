# MES-lite v0.1.310

日期：2026-08-09

## 更新内容

- 将工作台生产订单、班后实绩和确认产出装配规则从扁平 `lib` 迁入 workspace 领域。
- 新增工作台查询服务，集中日/月时间窗口、并行统计、状态分布、待处理事项和库存预警过滤。
- 仪表盘 API 从 141 行降至 17 行，只保留权限、服务调用和 HTTP 错误映射。
- 工作台专项守卫扩展到 contracts/client/model/ui/domain/server 全垂直切片。

## 影响范围

- 工作台指标定义、旧字段兼容和页面展示保持不变。
- API 路径、Prisma Schema、权限资源和数据库数据保持不变。
- 本机 SQLite 测试数据与构建缓存不纳入版本提交。

## 验证结果

- 工作台生产流、模块边界和开发文档专项校验通过。
- 生产订单/实绩统计、旧字段归一化和指标装配确定样例通过。
- 仪表盘 API 不再直接访问 Prisma，行数受自动守卫约束。
- TypeScript 类型检查和 Next.js 生产构建通过。
