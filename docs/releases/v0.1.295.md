# MES-lite v0.1.295

日期：2026-08-09

## 更新内容

- 将物料导入模式、行数据和汇总结构迁入领域契约，将 CSV 表头、中文别名、双单位、客户与销售价校验提取为纯解析器。

- 物料/BOM 模块、模块边界、高级搜索、页面注册、版本文档和开发文档校验通过。
