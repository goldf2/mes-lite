# MES-lite v0.1.309

日期：2026-08-09

## 更新内容

- 生产订单建立独立 contracts、HTTP client 和视图规则，列表、候选、详情和创建请求退出页面。
- 提取生产订单分组和创建输入纯规则，协调页从 535 行降至 448 行。
- 工作台建立统计契约、HTTP client、兼容归一化和指标装配模型，稳定展示面板独立成组件，协调页从 397 行降至 74 行。
- 公共页内选项改用能力注入读取配置领域单位目录，避免公共框架反向依赖业务模块。
- 全局模块守卫新增页面零直接请求约束，38 个页面入口现全部通过所属领域 client 访问接口。

## 影响范围
