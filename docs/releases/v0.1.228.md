# MES-lite v0.1.228

发布日期：2026-08-08

## 更新内容

- 将手机断点的页面工具触发器从右侧漂浮按钮恢复为顶部行内“工具”按钮，避免工具入口脱离顶部导航后难以识别。
- 常规手机宽度显示“工具”图标和文字；极窄屏只隐藏文字，仍保留图标、筛选数量角标和无障碍名称。
- 工具按钮继续打开原有页面工具抽屉，二维码、高级搜索、视图、页内选项和业务操作的归属不变。

## 影响范围

- 影响宽度小于 `640px` 的公共页面顶部工具入口。
- 不修改搜索、筛选、二维码、业务操作或权限逻辑。
- 同步更新移动端与系统交互规范。

## 验证结果

- 公共响应式工具栏 ESLint 检查通过。
- TypeScript 无输出类型检查通过。
- 36 个页面模块及强制公共顶部工具栏契约校验通过。
- Next.js 生产构建通过。
