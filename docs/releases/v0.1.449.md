# v0.1.449 — 来料详情只读与统一附件编辑

日期：2026-08-31。

## 更新内容

- 来料详情仅查看、预览、下载、打印；有更新权限可直接切换到编辑，不再在详情提供上传、归档和 AI 回填。
- 待收货单复用原整单编辑器管理附件；已收货、拒收或冲销单只打开附件编辑，业务字段和库存状态保持锁定。已有单据附件独立即时保存，归档为软删除、保留原文件；操作中禁止关闭。
- 复用 `Material.note`，来料物料搜索、候选和明细显示备注，详情明确“当前资料”；整单备注记录本批说明。未增加数据库字段或变体模型。
- 公共 `BusinessDocumentDetailDialog` 增加兼容的只读/忙碌/AI 开关，复用 `AttachmentPanel`、原有附件鉴权、归档与审计服务；其余详情调用方保持默认行为。关闭编辑后刷新列表附件数量。

## 影响范围

同步交互规范、功能模型、业务流程、来料 SOP；新增 [物料变体研究与最小方案](../plans/物料变体研究与最小方案.md)，明确半成品、批次说明、库存状态和变体的区别。变体仅研究，本版未开发。

## 验证结果

- 来料回归：多物料保存、半成品备注、编辑后附件仍归原单据、已处理单据禁止改业务数据、收货与红冲闭环。
- 附件回归：详情只读契约、已有已收货单附件上传/归档、软删除保留、无更新权限拒绝。
- 本机通过：`verify:receiving-module`、`verify:attachment-management`、`verify:business-document-print`、`verify:related-document-dialogs`、`verify:fullscreen-dialogs`、`verify:module-boundaries`、`verify:development-docs`、`verify:release-tree`、`verify:release-notes`、`verify:sop`、TypeScript 与 Lint。
- 浏览器使用隔离 SQLite 和合成供应商/半成品/来料：待收货与已收货详情均无上传/归档/AI 入口，切换编辑不叠窗；备注搜索能找到物料，保存已有单据后留窗且附件仍在；已收货附件编辑无业务输入框。桌面 1280×720、手机 390×844 验收，手机页面宽度为 390、弹窗边界 16–374，无页面横向溢出。实际上传/归档与权限拒绝由隔离服务回归验证，未在生产页面试单。
- 完整生产构建与治理门禁由候选提交 MES-lite CI 执行，发布前核对精确 SHA；该记录不等同生产部署成功。
- 未连接或修改生产数据库，未访问 AL02；推送与生产部署验收分开报告。
