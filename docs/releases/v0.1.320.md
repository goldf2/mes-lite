# MES-lite v0.1.320

日期：2026-08-10

## 更新内容

- 在 `modules/configuration` 增加库位输入契约、领域错误、编码/默认状态/库存判断纯规则、查询服务和命令事务服务。
- 将库位数量汇总、新增、更新、默认库位切换、归档前库存与五类待处理业务引用复检迁入配置领域。
- 库位 Route Handler 从 156 行降至 84 行，不再直接访问 Prisma 或持有事务；直接访问 Prisma 的 API 从 40 条降至 39 条。
- 禁止通过普通更新直接停用有效库位；系统没有有效默认库位时，新建首个库位自动成为启用默认库位。

## 影响范围

- 页面、API URL、读取范围和成功响应形状保持兼容，配置页继续复用公共 `ResourcePage`。
- 外部调用若要停用有效库位，必须使用 `DELETE /api/inventory-locations?id=...` 受保护归档入口；`PATCH isActive=false` 现在返回明确错误。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
