# MES-lite v0.1.183

发布日期：2026-08-05

## 更新内容

- 将“单一 Web 业务系统 + 平台薄壳”写入项目级 AI 协作规则和系统交互规范。
- 新增 ADR 0017，明确 Next.js 是唯一业务代码源，桌面端优先使用 Tauri，移动端优先使用 Capacitor。
- 规定扫码、拍照、打印、文件等原生能力通过适配层接入，并明确多平台发布顺序、版本号与签名管理要求。

## 影响范围

- 本版本只调整项目规范、架构决策记录和版本元数据。
- 不改变运行时代码、业务流程、API、权限、数据库模型或现有部署方式。

## 验证结果

- 发布说明完整性检查通过。
- Git 差异格式检查通过。
- 本次为纯文档与版本元数据更新，无需重复运行 TypeScript 类型检查和生产构建。
