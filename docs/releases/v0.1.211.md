# MES-lite v0.1.211

发布日期：2026-08-06

## 更新内容

- 恢复独立“卡片”显示模式，继续承载文档缩略图、业务摘要、状态和操作，不再与 Finder 风格图标视图混用。
- 新增独立“图标”显示模式，与列表、卡片、分栏、画廊共同组成五种可声明布局。
- 图标模式支持 72–160px 尺寸调节，弹出菜单提供滑杆及放大、缩小按钮，调整时菜单保持打开。
- 图标尺寸按资源页面保存，刷新后继续使用上次尺寸；历史 `card` 偏好保持兼容并显示为卡片。

## 影响范围

- 公共 `ViewModeToggle`、`ResourcePage`、`ResourceToolbar`、`ResourceCollection` 和 `ResourceCardGrid` 增加图标与卡片分离能力。
- 产品文档公共框架实验页启用图标、列表、卡片、分栏、画廊五种模式作为标准样例。

## 验证结果

- TypeScript、Lint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证五种菜单项、卡片模式恢复、图标从 104px 放大到 160px、连续调节不关闭菜单以及尺寸刷新记忆。
