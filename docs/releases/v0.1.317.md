# MES-lite v0.1.317

日期：2026-08-10

## 更新内容

- 在 `modules/production` 增加派工创建输入契约、领域错误、日期编号、五态流转规则以及查询、命令和状态事务服务。
- 将派工列表/详情、创建/归档、工单状态与工序归属校验，以及派工/开工/完工/取消迁入生产领域服务。
- 派工主路由、详情和 4 条状态路由共 6 条 Route Handler 均移除直接 Prisma 访问，只保留权限、Schema、服务调用、请求级审计和 HTTP 错误映射。
- 派工编号改为读取当日最大历史序号后递增，避免归档、取消或断号后复用已存在编号。
- 直接访问 Prisma 的 Route Handler 从 52 条降至 46 条；14 个领域/平台模块共有 246 个文件。

## 影响范围

- 页面操作和 API URL 保持兼容；生产订单必须处于 `PICKED / RUNNING` 且所选工序属于该订单产品路线才允许创建派工单。
- 派工状态继续按待派工、已派工、进行中、已完成流转；只有待派工或已派工状态允许取消，非法重复操作返回明确业务错误。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
