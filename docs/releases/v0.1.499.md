# v0.1.499 — 仓库装箱、货箱标签与选箱发货

日期：2026-10-21。状态：本地实现与验收完成的候选，精确提交远端 CI 待核对；未将本地代码、建表或打印请求视为生产发布/实物打印完成。

## 更新内容

仓库可先从真实可用批次建立装箱记录，再逐箱打印产品标签，发货时选择或扫描已有箱。纸箱、金属网箱、塑料周转盒仅记录包装类型，装箱编号属于本次货物内容，不建立有状态容器台账。

原散货录入保留，同一张发货单支持纯散货、纯货箱及混合。选箱自动带出实际产品、批次、库位和数量；产品行显示“箱内量 + 散货量”的发货总量，客户发货单不以箱号代替产品内容。保存待发货占用货箱，取消释放；归档仍占箱的待发单同时取消，恢复后只读历史不能再次出库，需要重新选箱新建发货；出库消费所选箱真实批次与成本，散货继续按原规则处理。人员标签信息可以从真实来源带出或明确人工补录，不等同质量放行。

## 影响范围与模型兼容

- 扩展既有 `PackageDocument` / `PackageDocumentItem`，独立仓库箱允许无发货单引用，保留原发货现场箱、箱号及照片。
- 新增货箱占用 `ShipmentPackageAllocation`、明细来源 `ShipmentItemSource` 及标签内容版本 `PackageLabelRevision`。
- 新增唯一当前位置 `GoodsPlacement`、移动历史 `GoodsMovement`；未知坐标留空，不虚构精确定位。
- 新增仓库/布局版本/空间节点模型，为后续真实尺寸、楼层、货架、层和库位的三维展示提供关联；本期没有三维界面、布局发布或拖动移库入口。
- 装箱不增加库存、成本或库存流水。各库存出口识别有效装箱分配，防止重复消费；标签保存本箱内容，不取发货单第一项产品。

迁移为加性结构调整，旧箱不伪造批次和坐标。部署前须验证一致备份及恢复候选；新装箱与选箱关系写入后，旧版库存写入代码可能忽略包装分配，不能直接回退旧写版本或删表，故障时应停止相关写入并前滚修复。

## 界面与权限复用

新 `warehousePackages` 页面位于库存分区，复用公共主从/资源页面、搜索、字段、详情、关系编辑和打印能力。新建及作废沿用 `stocks.update`，读取沿用 `stocks.read`，标签叠加 `scanPrint.create`；发货候选/选箱沿用 `shipment.create`。所有动作按原库位范围再次校验，确认/签收/取消/冲销保持原分权。本版不新增权限资源、不覆盖既有人员授权。

打印复用二维码及 `LabelPrintJob`，保留介质尺寸和内容快照；浏览器 `REQUESTED` 只代表打印请求发起，未新增静默网络打印或设备出纸回执。客户连续纸/A4发货单与箱签使用各自纸型。
