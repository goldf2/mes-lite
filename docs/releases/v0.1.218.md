# MES-lite v0.1.218

发布日期：2026-08-06

## 更新内容

- 双列导航的全局功能搜索框改为横跨整个侧栏置顶，明确搜索范围不是当前二级分类。
- 一级与二级菜单统一从搜索框下方开始分栏，恢复清晰的父子层级关系。
- 移除二级列中重复的“功能菜单 / 当前分类”标题，由一级高亮和二级入口直接表达当前位置。
- 搜索状态继续固定一级列，匹配结果仅在二级列按业务分组显示。

## 影响范围

- 只调整桌面双列导航结构和视觉层级，不改变搜索范围、导航目标、移动端菜单或业务数据。
- 单列折叠导航保持原有结构；一级菜单三种显示偏好继续生效。

## 验证结果

- TypeScript和导航组件 lint 检查通过。
- 浏览器验证搜索框覆盖整个侧栏、重复标题消失、一级列稳定及跨分类搜索结果正确。
- 页面模块、版本文档、Docker 依赖一致性检查和生产构建通过。
