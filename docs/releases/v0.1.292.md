# MES-lite v0.1.292

日期：2026-08-09

## 更新内容

- 提取库存查询契约、查询服务和命令服务，库存 API 不再直接执行 Prisma 查询、包装 BOM 装配或库存调整事务。
- 将总量、预留、可用量、核算量和库位余额一致性规则提取为纯领域函数，并加入有效与异常余额回归样例。
- `app/api/stocks/route.ts` 从 449 行降至 79 行，系统超过 300 行的存量 API 从 6 个降至 5 个。
- 扩展库存模块守卫，限制 API 不超过 100 行并要求查询、修复、调整与一致性规则持续通过领域服务。

## 影响范围

- 保留 `/api/stocks` 的 GET、PATCH、POST 方法、响应格式、权限资源、审计内容和错误状态。
- 不修改 Prisma 模型、数据库迁移、库存数量或服务器正式数据。

## 验证结果

- 库存模块、模块边界、高级搜索、页面注册、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有的图片与 Hook 依赖警告。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
