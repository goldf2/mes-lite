# MES-lite v0.1.163

发布日期：2026-08-04

## 更新内容

- “物料”二级菜单统一为“物料管理 / BOM 设置 / BOM 全览”。
- BOM 设置左侧改为一张卡片对应一个已有 BOM，以 BOM 名称和版本作为主信息，产出和投入物料作为摘要及搜索条件。
- BOM 设置右侧移除方案下拉与重复新建入口，统一使用“BOM 名称”字段完成新建命名和已有 BOM 重命名。
- 新增独立 BOM 全览页：左侧按物料名称、编码或规格筛选，右侧分别展示该物料作为产出和作为投入关联的全部直接 BOM。
- BOM 全览结果可精准跳转到 BOM 设置并自动选中对应方案；筛选结果变化时同步更新右侧物料详情。

## 影响范围

- 物料与 BOM 二级菜单、BOM 设置工作区和 BOM 全览页面。
- BOM 页面状态衔接、物料筛选以及相关界面和流程规范。
- 本次不修改数据库结构、BOM 保存格式、库存或生产过账逻辑。

## 验证结果

- Next.js 生产构建与 TypeScript 类型检查通过；仅保留仓库已有 ESLint 警告。
- 浏览器验证双向 BOM 关系、物料文字筛选和目标 BOM 精准跳转通过。
- 本地服务健康检查返回 `200`。
