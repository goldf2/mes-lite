# MES-lite v0.1.296

日期：2026-08-09

## 更新内容

- 新建 `modules/identity-access`，集中权限管理输入契约、权限组编码规则、资源授权检查、权限查询和原子写入。
- `app/api/permissions/route.ts` 从 350 行降至 79 行，只保留会话入口、请求解析、服务调用、请求级审计和错误映射。
- 新增 `verify:identity-access-module`，锁定薄路由、契约、授权规则、事务服务和审计边界。
- 系统超过 300 行的存量 API 从 6 个降至 1 个。

## 影响范围

- 保留管理员、权限组、人员分组、资源级 `grant` 校验、组设置覆盖和审计行为。
- 不修改 Prisma Schema、迁移、现有权限数据或服务器正式数据。

## 验证结果

- 身份权限模块、模块边界、页面模块、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有警告。

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
