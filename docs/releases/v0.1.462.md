# v0.1.462 — 冻结生产工艺与成本快照

日期：2026-09-06

## 更新内容

- BOM 成本页可按物料明确选择任一已发布 BOM 版本和工艺路线，并保存工序参数和工作中心信息的完整快照。
- 工作中心可维护人工、机时和能源默认费率（能源按台·小时计）；成本计算按“工序正值 > 工作中心默认 > 本次计算页面费率”确定实际采用费率，并将结果写入路线快照。费率修改只影响新成本运行，不回算历史事实。
- 新建生产订单时，自动匹配目标物料的默认工艺路线和对应 BOM 成本运行，并把 BOM、路线、工序、工作中心及成本明细冻结到订单。
- 生产实绩和快捷生产日报继承订单/成本运行快照；历史详情优先读取冻结数据，只有旧记录没有快照时才兼容读取当前路线。
- 物料全景按具体 BOM 展示对应的最新成本运行和工序成本明细，不再把一个物料的成本误显示到所有 BOM。
- 当锯切成本对象已经覆盖路线中的同名锯切工序时，保留零成本追踪行并明确提示“未重复计入”，避免材料、人工和机时重复核算；其它历史成本对象只按编码/名称精确匹配，不用模糊包含关系误跳过工序。
- 将纯成本计算规则和工艺路线快照序列化器下沉到共享 `lib`，消除 BOM 与生产模块之间的深层内部依赖。

## 影响范围

生产订单、生产实绩、快捷生产日报、BOM 成本、物料全景和相关数据模型。快照列和关联外键可空，保证旧记录可以继续读取；工作中心费率列为非空数值并以 0 初始化既有记录，0 表示未配置。新建执行事实会写入冻结快照。成本运行仍是标准/核算成本，不替代实际投入的库存成本；实际投入和产出仍由生产实绩事务确认。

本版本不改变既有页面入口和已发布 BOM 的不可变规则。成本计算页已经要求/带出明确 BOM 版本；生产订单创建仍按目标物料默认已发布 BOM 和默认路线匹配最近成本运行，后续可增加订单创建时的显式成本运行选择。

## 数据迁移与回滚

新增迁移 `20260905150000_freeze_production_route_and_cost_snapshots` 和 `20260906100000_add_work_center_cost_rates`。前者仅增加可空快照列、可空外键和索引，后者为工作中心增加默认费率并以 0 填充既有记录；均不改写历史业务数据。回滚代码前应先停止新版本写入并备份数据库；若已产生新快照或工作中心费率，保留新增列和数据，旧版本忽略未知列即可，不直接删除迁移。
