# MES-lite v0.1.278

发布日期：2026-08-09

## 更新内容

- 新增 `useMaterialViewPreferences.ts`，统一管理物料可见字段、BOM 简况、列宽持久化和拖动生命周期。
- 新增 `MaterialPageOptions.tsx`，组合公共页面选项弹窗和工具栏排序设置，不再由主页面展开配置 JSX。
- `MaterialPage.tsx` 从 2,005 行降至 1,704 行，只消费视图偏好结果和稳定列宽控制契约。
- 收紧 `verify:material-bom-modules`，禁止物料视图本地存储和列宽拖动状态回流主页面。

## 影响范围

- 不改变物料查询、排序、卡片/列表切换、字段显示、BOM 简况或列宽调整行为。
- 不改变 API、数据库模型、权限资源或业务状态流转。
- 页内选项继续复用公共 `PageOptionsDialog` 和 `ToolbarOrderSettings`，没有建立平行框架。

## 验证结果

- TypeScript 类型检查通过。
- 物料/BOM 模块边界、页面模块和高级搜索契约验证通过。
- 开发文档事实基线和版本记录验证通过。
- Next.js 生产构建通过。
- 本机浏览器验证页内选项、字段显示、刷新后偏好恢复和卡片/列表表格正常工作。
