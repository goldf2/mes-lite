# v0.1.383 单 OSS 地址的 SOP 离线发布基线

日期：2026-08-15

## 更新内容

- 增加 `SOP_PUBLIC_BASE_URL`：只配置一个 HTTPS 对象存储或自定义下载域名，应用即按当前版本生成 PDF、DOCX 两个只读下载地址。
- 完整帮助中心在地址有效时显示“下载 PDF / 下载 DOCX”；未配置、协议不安全或地址包含凭据时不显示，在线帮助不受影响。
- 增加 `npm run sop:prepare:release`，将最终冻结的 PDF/DOCX 复制到 `output/sop-release/v<版本>/`，同时生成版本清单和 `latest/manifest.json`，记录文件大小与 SHA-256。
- 增加 `npm run sop:release`，在最终交付时一次完成多格式生成、成品校验和 OSS 发布目录准备；开发期仍只运行 Markdown 源校验。
- 将单 OSS 发布契约纳入 CI，验证版本目录、latest 清单、安全 URL、文件大小和 SHA-256；没有任何云密钥进入 Git、浏览器或 Docker 镜像。

## 对象路径契约

假设公开地址为 `https://downloads.example.com/mes-lite/sop`，本版本文件固定为：

```text
v0.1.383/MES-lite全流程作业指导书-v0.1.383.pdf
v0.1.383/MES-lite全流程作业指导书-v0.1.383.docx
v0.1.383/manifest.json
latest/manifest.json
```

应用始终链接自己的精确版本，而不是 `latest`。因此应用回滚到旧版本时会自动回到旧版文档，不需要修改数据库。

## 影响范围

- 页面：只在完整帮助中心增加条件式下载按钮；快捷帮助、搜索、权限过滤和截图流程不变。
- API：既有 `/api/sop` 响应增加 `downloads` 数组，不新增路由或权限资源。
- 数据库：不新增 Prisma 模型或迁移，迁移总数保持 84。
- 文档库：现有通用产品文档仍可保存不关联物料的系统教学文档及本地附件；自动登记生产文档库尚未执行，必须在最终成品发布和数据库备份后单独验收。

## 验证结果

- 专项回归覆盖无配置、HTTPS、公网 HTTP 拒绝、地址凭据拒绝、本地开发 HTTP、精确版本目录、latest 清单及 SHA-256。

## 回滚

- 回滚应用时恢复上一提交即可；也可只删除 Coolify 中的 `SOP_PUBLIC_BASE_URL` 并重新部署，下载按钮会隐藏，在线帮助继续可用。
- 对象存储中的旧版本目录不得随应用回滚删除；发布凭据只允许写入目标前缀，公开域名只读。
