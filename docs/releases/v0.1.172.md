# MES-lite v0.1.172

发布日期：2026-08-04

## 更新内容

- 物料列表的“BOM 简况”表头支持点击排序，首次点击升序，再次点击降序。
- 排序依据统一为当前展示 BOM 的组成行数与被引用行数之和，同分时按物料编码稳定排列。
- BOM 简况排序在服务端覆盖完整筛选结果后再分页，避免只重排当前页。

## 影响范围

- 影响物料管理列表及排序下拉框。
- BOM 简况排序继续受 BOM 查看权限控制。
- 不改变 BOM 数据、默认方案或物料库存。

## 验证结果

- TypeScript 类型检查通过。
- 浏览器验证 BOM 简况表头可在升序和降序间切换，排序结果与页面统计一致。
- Next.js 生产构建通过。
