# v0.1.372 检验标准、自动抽样、逐项判定与质量趋势

发布日期：2026-08-14

## 更新内容

- 新增检验标准编码/版本、生产与退货来源、全检/固定/比例抽样、最低/最高抽样数和完整检验项目。
- 标准使用草稿、已发布、已停用生命周期；已发布标准和项目不可覆盖，新版发布在同一事务自动停用同物料同来源旧版。
- 新生产/退货待检任务自动快照当时生效标准、建议抽样数和项目；复检沿用原任务快照，逐项结果与整单结论一致后方可完成。
- 质量任务页增加“检验标准”和“质量趋势”工作区，趋势按日期、物料和来源汇总批次通过率、样本通过率及失败项目。
- 新增第 52 个权限资源 `qualityStandards`；质量附件接入公共附件模块和既有库位数据范围。
- SOP 增至 161 个流程，新增 7 张真实本地页面截图，并同步站内帮助、Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 数据库：新增 `QualityInspectionStandard`、`QualityInspectionStandardItem`、`QualityInspectionCheckItem`，并为 `QualityInspection` 增加标准与抽样快照；当前共 91 个模型、80 个迁移。
- 页面/API：复用 `qualityTasks` 页面和公共弹窗、关系选择、附件组件，新增 6 条 Route Handler；当前为 44 个页面模块定义、149 条 API、52 个权限资源。
- 质量闭环：标准、任务快照、逐项事实、检验结论、库存状态和趋势共用既有 `QualityInspection` 事实链，没有复制库存或另建统计台账。
- 不包含：来料收货自动检验、SPC 控制图、过程能力分析、原因分类主数据和多级质量审批。

## 验证结果

- Prisma validate/generate、全量 80 个迁移从零重放通过。
- 质量领域与真实 HTTP 回归覆盖版本生命周期、已发布不可变、单一生效版本、自动抽样、任务快照、逐项结果、复检继承、趋势统计、权限 403、数据范围和附件授权。
- 真实本地页面完成标准版本、新建、发布、任务快照、逐项判定、附件和趋势 7 个流程截图。
- SOP、开发文档、发布说明、类型检查、Lint、30 项 CI 领域基线和生产构建通过；[本地合成候选应用级恢复演练](../operations/drills/2026-08-14-local-synthetic-v0.1.372.md)完成候选复制、80 个迁移、readiness、登录、业务/附件抽查和账号清理，完整应用 RTO 为 24.728 秒。

## 部署与回滚

1. 部署前固定精确提交，完成 SQLite 与附件一致备份并校验。
2. 应用启动执行第 80 个迁移；用质量工程师验证标准新建/发布，用质检员验证只读标准、逐项判定、附件和授权库位内趋势。
3. 复核旧安装继承出的 `qualityStandards` 权限，不把兼容继承视为企业审批结论。
4. 应用回滚时固定到上一个已验证提交；保留新增标准、项目和任务快照，不执行破坏性降级。
5. 只有迁移/数据库损坏且应用回滚无效时，才经业务确认恢复部署前一致备份；恢复后重新验证登录、质量、批次、库存、成本和附件连续性。
