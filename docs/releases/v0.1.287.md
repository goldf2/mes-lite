# MES-lite v0.1.287

日期：2026-08-09

## 更新内容

- 新建 `modules/receiving` 垂直领域模块，集中来料契约、请求校验、HTTP 客户端、展示模型、集合视图、编辑任务、详情任务和服务端交易规则。
- `MaterialInPage.tsx` 从 1,679 行降至 684 行，只保留查询、分页、弹窗状态和用户任务协调；集合、编辑和详情不再挤在单一页面内。
- `app/api/material-ins/route.ts` 从 295 行降至 90 行，只处理权限、HTTP 参数、审计与错误响应；多关键词查询、多明细创建、计量计价换算和归档进入来料领域服务。
- 扩展公共 `SearchableSelect` 的异步检索能力，来料供应商和物料继续使用同一公共选择器，不再维护两套局部联想控件。
- 新增 `verify:receiving-module`，锁定薄 API、领域服务、公共选择器与页面规模，并支持临时 SQLite 集成验证。

## 影响范围

- 影响来料列表、卡片、详情、新建/编辑、异步供应商与物料选择，以及 `/api/material-ins` 主查询和创建接口的代码所有权。
- 不改变数据库 Schema、接口 URL、单据状态、库存过账规则或服务器正式数据。

## 验证结果

- TypeScript 类型检查、来料模块专项验证、搜索/附件/打印/原始凭据回归与 Next.js 生产构建通过。
- 临时完整 SQLite 数据库中的多明细创建、查询、归档和无效供应商校验通过。
- 模块边界校验通过：10 个领域模块、14 个存量根页面、4 个存量巨型页面和 6 个存量巨型路由均未增长。

## 数据安全

- 集成测试只使用临时 SQLite 数据库，执行完毕即删除；未连接或修改服务器正式数据库。
- 本机常用 SQLite 中的一条隔离测试记录继续保持未提交，不纳入代码版本或部署产物。
