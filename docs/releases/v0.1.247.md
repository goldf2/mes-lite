# MES-lite v0.1.247

发布日期：2026-08-08

## 更新内容

- 销售订单卡片移除列表内“上传文件”和附件标签，只保留“附件 N 个”摘要。
- 销售订单新增统一详情弹层，集中展示单据来源、订单字段、明细和附件管理。
- 上传、预览、下载、归档及 AI 识别统一进入详情中的“附件管理”执行。

## 影响范围

- 仅调整销售订单的附件入口和详情展示，不修改订单、发货或库存业务逻辑。
- 附件继续复用现有 `DocumentAttachment` 数据和公共预览组件，不需要数据库迁移。

## 验证结果

- 附件管理、单据原始凭据和发布文档静态契约通过。
- TypeScript 与生产构建通过。
