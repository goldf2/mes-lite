# MES-lite v0.1.282

发布日期：2026-08-09

## 更新内容

- 将加工工艺与物料路线迁入现有 `modules/production`，避免建立重复的生产工程顶级领域。
- 新增生产工程 `contracts/client/model/ui` 分层，集中工艺模板、路线、工序契约、API 调用、类别、默认表单、千件成本与搜索模型。
- 加工工艺页和物料路线页共用生产工程资源页壳，并继续使用公共高级搜索、卡片/列表、手工排序、物料选择、可搜索选择器和弹窗。
- `SystemPage.tsx` 从 811 行降至 31 行，最终成为业务配置、系统设置、运维工具和生产工程的纯领域分派兼容层。
- 新增 `verify:production-engineering-modules`，并更新高级搜索与模块边界校验，阻止请求、成本和页面实现回流。

## 影响范围

- 不改变加工工艺、物料路线 API、Prisma 模型、权限、菜单入口、手工排序或千件成本公式。
- 不改变工艺模板关联物料、路线模板带入、默认路线和工序编辑的既有业务语义。
- 工艺与路线页面仍保留窄屏强制卡片、宽屏卡片/列表切换和字段式高级搜索。

## 公共模块复用

- 页面复用 `ResourcePageShell`、`ResourceAdvancedSearch`、`AppButton`、`FormField`、`ModalDialog`、`MaterialChoiceSearch`、`SearchableSelect` 和 `SortableTableHeader`。
- 手工排序继续使用 `ConfigurationManualOrder`，没有创建生产领域专属排序工具。
- 新增的 `ProductionEngineeringPageShell` 仅组合既有资源页能力，不建立第二套页面工具栏或搜索实现。

## 验证结果

- 生产工程、模块边界、高级搜索、配置排序、页面模块、配置模块和系统设置模块专项校验通过。
- TypeScript 类型检查、开发文档事实校验、版本发布说明校验和生产构建通过。
