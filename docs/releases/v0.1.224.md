# MES-lite v0.1.224

发布日期：2026-08-07

## 更新内容

- 新增公共 `ControlTooltip`，统一桌面顶部纯图标工具的深色提示标签样式、悬停延迟和键盘聚焦反馈。
- 快捷搜索改为纯图标按钮；已保存搜索数量继续使用右上角数字徽标表达。
- 快捷搜索、高级搜索、视图方式、页内选项、页面二维码和 AI 助手接入同一提示组件。
- 新建、导入、导出等业务动作及页面正文按钮继续保留文字，不对全系统业务按钮批量添加重复提示。
- 公共搜索框新增“智能”选项并默认开启：空格拆分多个关键词，每个词可分别命中页面配置的不同字段，全部关键词命中才显示记录；关闭后恢复整句查询。
- 物料、库存、文档、来料、生产订单、员工、设备、销售、发货、退货、客户和供应商等服务端列表统一采用相同的多关键词组合语义。

## 影响范围

- 影响桌面端顶部通用工具按钮的文字提示、快捷搜索按钮宽度和公共关键词搜索行为。
- 不修改工具按钮的位置、功能、弹窗、权限或业务数据。
- 不修改数据库结构和业务流程。

## 验证结果

- 浏览器确认快捷搜索仅保留图标，顶部通用工具使用一致的深色提示标签。
- 公共搜索校验确认跨字段多关键词、整句模式和高级条件组合可同时工作。
- TypeScript、ESLint、页面模块契约、版本文档校验和 Next.js 生产构建通过。
