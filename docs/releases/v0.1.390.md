# v0.1.390 桌面导航确定性交互

日期：2026-08-16

## 更新内容

- 桌面左栏取消鼠标悬停、屏幕边缘感应及延时关闭，自动隐藏状态只响应明确点击。
- 左上角导航按钮在常驻和自动隐藏状态下始终显示，点击常驻状态的按钮可直接收回为自动隐藏。
- MES-lite、MRP、ERP 产品模块按钮不再随左栏状态出现或消失，并保持 MES-lite 全名可见。
- 常驻和弹出侧栏复用相同的标题、宽度、菜单结构和面板外观；两者只在是否占用正文宽度上存在差异。
- 自动隐藏侧栏在点击页面空白处、导航成功或按 `Esc` 时收回；正文和顶部区域使用平滑过渡。

## 影响范围

- 影响桌面标准管理布局的公共导航壳及“系统设置 → 显示设置”说明。
- 更新 SOP 流程 `55-display-settings`。
- 不改变移动端导航、业务页面、HTTP API、权限资源、数据库模型或迁移。

## 验证结果

- 静态回归验证覆盖统一入口、模块按钮保留、无悬停计时器、面板外观一致和正文平滑过渡。
- 本机真实页面验证覆盖常驻、收回、点击弹出、点击空白处收回及重新固定。
- 类型检查、导航专项验证、Lint 和生产构建通过。

## 回滚

本版本没有数据库迁移。代码可回退到 v0.1.389；浏览器中已保存的常驻/自动隐藏偏好仍可被旧版本读取。
