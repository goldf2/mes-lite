# MES-lite v0.1.350

日期：2026-08-12

## 更新内容

- 新 Material 生产订单统一使用 `DRAFT → RELEASED → IN_PROGRESS → COMPLETED/CANCELLED` 状态机。
- 订单详情为具有 `orders.update` 权限的人员增加“发布生产订单”动作；发布不再错误写入开工时间。
- 发布动作记录订单前后状态和当前登录操作人审计。
- 未发布订单禁止派工或登记班后实绩；首次确认实绩进入进行中，达到计划数量后完成，冲销全部确认实绩后回到已发布。
- 派工候选、生产订单筛选、仪表盘和 AI 查询把历史 `CONFIRMED / PICKED / DISPATCHED` 归并为 `RELEASED`，把 `RUNNING / QC_WAITING / QC_DONE` 归并为 `IN_PROGRESS`。
- 模型收敛审计同时输出生产订单原始状态、归并状态和历史别名行数，为后续生产迁移提供统计基线。
- `materialId=null` 的历史工单继续按旧状态完成兼容收尾，不批量改写数据库历史值。

## 影响范围

- 不修改 Prisma Schema，不执行数据库迁移或批量状态更新。
- 新订单必须先在详情页发布，才能派工或登记生产实绩；这是有意增加的业务控制点。
- 回退到 `v0.1.349` 前需检查是否已经写入 `RELEASED / IN_PROGRESS`，旧版本不能完整解释这两种状态。

## 回滚

本版本没有 Schema 或批量数据迁移。若尚未产生 `RELEASED / IN_PROGRESS` 订单，可直接回退应用版本；若已经产生，应保留本版本或先提供旧版本状态兼容补丁，不能直接让旧应用读取未知状态。
