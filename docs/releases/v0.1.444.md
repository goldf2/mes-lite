# MES-lite v0.1.444

发布日期：2026-08-28

## 更新内容

- 修复“库存 → 仓库全景”被通用库存列表完整性门禁整页阻断、并误显示全部为 0 的问题。
- 仓库全景改用独立只读查询，直接投影当前账号授权的库位余额。
- 如果存在库存完整性问题，白板继续只读展示并给出黄色警告，不再以红色错误替换整张白板。

## 安全边界

- 仅新增 `stocks.read` 保护的只读查询，继续应用账号库位数据范围。
- 不修改生产 SQLite 数据，不自动修复 BOM、库存、成本层或批次记录。
- 库存列表及库存写入流程的完整性门禁保持不变，警告不代表允许带错过账。

## 影响范围

- 仅影响仓库全景的读取和异常提示；不改变库存列表、BOM、库存事务、成本、批次和库位数据。

## 验证结果

- 专项回归锁定独立只读端点、`stocks.read` 权限、库位数据范围、完整性警告和不绕过写入门禁。
- TypeScript、ESLint、生产构建和候选 CI 纳入发布门禁。

## 回滚说明

- 回滚只恢复仓库全景旧读取方式，不需要数据库回滚。
