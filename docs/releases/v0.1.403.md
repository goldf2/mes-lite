# v0.1.403 销售订单物料详情联动

日期：2026-08-18

## 更新内容

- 销售订单卡片和订单详情中的物料名称、编码改为可点击的物料引用入口。
- 点击后打开只读物料详情；关闭物料详情时恢复原销售订单详情和上下文。
- 复用 `modules/materials` 的公开 `MaterialReferenceButton`、`MaterialDetailDialog` 与详情查询控制器，销售模块不复制物料请求或展示逻辑。
- 订单详情与物料详情使用同一弹窗层级切换，避免叠加同层遮罩。

## 影响范围

- 查看订单仍要求 `salesOrder.read`；查看关联物料详情同时要求岗位已有的 `materials.read`。
- 不新增 API、权限资源、数据库模型或迁移，不改变订单、库存、价格和发货数据。
- 物料详情在销售订单上下文中为只读，不显示编辑和物料全景命令。

## 验证结果

- 销售模块、物料/BOM 模块专项验证和 TypeScript 类型检查通过。
- 本机登录态使用临时订单验证：卡片和订单详情均可打开物料；页面只有一个弹窗，附件命令隐藏，关闭后恢复原订单；临时订单和客户已在验证后清理。
- SOP 工作流 `26-sales-order-detail` 已增加“查看物料详情并返回订单”的步骤。
- 精确候选提交将在 `ci/v0.1.403` 通过 GitHub Actions 生产构建门禁后进入 `main`。

## 回滚

代码可回退到 `v0.1.402`，无需数据库迁移或数据回滚；回滚只移除订单明细中的物料详情入口。
