# MES-lite v0.1.281

发布日期：2026-08-09

## 更新内容

- 将企业资料与物料编码自然排序迁入 `modules/configuration`，明确其属于会影响业务数据与导出的业务配置。
- 建立 `modules/system-settings`，分别拥有显示设置、导航与工作区、AI 服务三个页面，并通过统一设置页壳保持布局一致。
- 设置页面通过模块 client 访问 `/api/system/settings` 与 `/api/ai/config`；页面 UI 不再直接发起请求，各页面只读取自身所需数据。
- `SystemPage.tsx` 从 1,474 行降至 811 行，只保留领域分派以及尚待迁移的工艺模板与物料路线职责。
- 新增 `verify:system-settings-modules`，并扩展配置、模块边界、工作区和响应式导航校验，阻止设置职责回流聚合页面。

## 影响范围

- 不改变设置 API、AI 配置 API、Prisma 模型、权限资源或页面入口。
- 不改变企业资料、自然排序、对比度、工作区偏好、导航配置和 AI 密钥的既有保存语义。
- 浏览器级显示偏好继续保存在当前浏览器；对比度、AI 加载图标和业务设置继续通过服务端设置对所有客户端生效。

## 公共模块复用

- 业务设置复用 `ResourcePageShell`、`FormField` 和 `AppButton`。
- 系统设置复用 `ResourcePageShell`、现有界面偏好 Hook、`ContrastModeSelector`、`WorkspaceNavigationSettings` 和 `ModalDialog`。
- 新增模块内 `SystemSettingsPageShell` 与 `TogglePreferenceRow`，供三个系统设置分区统一调用，没有创建第二套应用壳、导航或工具栏。

## 验证结果

- 配置模块、系统设置模块、模块边界、工作区布局、响应式导航、导航配置和 AI 边界专项校验通过。
- TypeScript 类型检查、开发文档事实校验、版本发布说明校验和生产构建通过。
- 自然排序数据校验在应用完整迁移后的临时 SQLite 数据库执行，避免修改本机缺少 `SystemSetting` 表的旧开发库。
