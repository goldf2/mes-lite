# v0.1.493 宇峰平台一级应用与同部署双域入口

## 问题与结果

此前 MES Lite 首页、全部功能和宇峰业务平台在同一侧栏并列，平台又重复显示 MES 快捷目录，应用与业务分类层级不清。493 将宇峰平台作为独立一级应用入口 `https://work.csyufeng.com/`，以 MES Lite、客户管理两个真实应用卡片配合全局搜索、个人收藏及次级功能目录；原 `https://mes.csyufeng.com/` 的 MES 首页、统计、完整本地菜单和业务深链保留。

本版本为待发布候选。以下本地验证已经取得证据；精确候选 CI、Con01 发布、正式域与真实 Casdoor 双域回调仍待验收，不将配置说明或本地测试写成已上线。

## 更新内容

- 同一 Web 部署承载两个域。平台域根路径精确 rewrite 到 `/platform`，MES 根路径继续原首页；旧 `/workbench` 导向 Runtime 平台入口。公开 `APP_ORIGIN/PLATFORM_ORIGIN` 由服务器传入应用壳，未来换域不改业务页代码。
- 一级应用从现有已授权真实目录派生，不创建空 ERP/WMS/管理应用。MES Lite 已包括生产、销售、物料、库存、收发和本厂设备，属于制造经营工作台；客户应用聚合数据平台的正式客户、联系人、地点、地图及客户设备服务八个真实目标。
- 平台总览无 MES 长侧栏、默认快捷目录或 MES 统计请求。原 MES 目录/搜索/收藏与菜单仅本地，客户应用只显示数据平台目标；全局搜索保留跨应用能力，本地功能完整导航回 MES 域精确页面，物料 section 保留。
- 492 未单独发布的侧栏遮挡修复折入本版：临时展开与常驻侧栏按同一实际宽度给正文让位，关闭恢复全宽，普通/双列及拖动调宽同步；画布和手机抽屉保留原槽位。一级菜单主体单组/箭头多组的操作继续保留。
- 两个代码库、数据平台部署、数据库、业务权限与数据归属继续独立。未启用共享联系人候选迁移，未实现 MES 订单统计上图，无生产业务测试写入或数据库迁移，原历史单据和打印不改。

## 认证配置与安全影响

```env
APP_ORIGIN=https://mes.csyufeng.com
PLATFORM_ORIGIN=https://work.csyufeng.com
APP_AUTH_CALLBACK_ORIGINS=https://work.csyufeng.com
```

保留原 MES canonical origin、Casdoor 客户端、issuer、人员绑定及业务权限；仅在既有客户端追加 `https://work.csyufeng.com/api/auth/casdoor/callback`，原 `https://mes.csyufeng.com/api/auth/casdoor/callback` 保留。不新建组织、客户端、用户或管理员。

`PLATFORM_ORIGIN` 只决定公开入口，不自动扩大认证清单。额外回调仅允许精确 HTTPS origin，拒绝通配、路径、查询、片段、用户名密码、无效代理头及生产 HTTP。每次挑战绑定发起 origin 与随机 state/nonce/PKCE，跨 origin 不能交换挑战；别名移除或在交换期间撤销后不能建立会话。新增别名不旋转既有身份代际，原 canonical 挑战与会话保持；原 identity 配置变化仍执行原代际策略。

两个域的挑战/会话 Cookie 都保持 host-only、HttpOnly、SameSite=Lax、生产 Secure。分别正常登录，各自退出；不共享跨子域 Cookie，不宣称身份中心、另一域或数据平台已全局退出。真实身份中心会话是否免去再次输入，须由生产正常流程验收，不通过客户端转发 Token 或 Cookie 实现。

## 验证结果

- 认证协议与会话回归 **48/48** 通过，含 **14 项真实 loopback Next HTTP**：实际 RS256 签名、临时迁移数据库和合成身份传输；覆盖 canonical 兼容、精确别名、挑战跨域/篡改/重放/撤销拒绝、在途退出、原权限和私有 API 401。无真实 Casdoor 请求、无生产写入。安全回执：`work/mes-auth-dual-origin-493-receipt.json`。
- 原登录 UI **15 组**、TypeScript、定向 Lint、身份模块及模块边界检查通过，记录在上述安全回执。仍须以最终候选 SHA 的完整 CI 为发布门禁。
- 独立真实 Next 浏览器的两 loopback host **8 项**通过：MES 原根与平台根区分、不同 host-only 会话、平台到 MES 地址及 BOM section、返回平台、客户模块刷新、当前域退出后私有接口拒绝且原 MES 会话仍有效。使用合成 builtin 账号，不是生产 Casdoor/SSO 验收。回执：`work/platform-entry-0.1.493/dual-origin-browser-receipt.json`。
- 一级应用、全局/本地目录、收藏及撤权、服务专用受限账号、390px、画布搜索与实际指针点击已有隔离 UI 回执；最终证据由主 IA 检查与定向 pointer/几何补验组成，并非单次不间断测试。回执：`work/platform-entry-0.1.493/browser-receipt-final.json`；侧栏几何与交互原始回执在 `work/sidebar-content-0.1.492/`，作为493折入修复证据。
