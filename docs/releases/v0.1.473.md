# MES-lite v0.1.473

## 更新内容

来料辅助长度可按“单根长度 × 正整数根数”录入，保留直接总长度录入。不同长度分行添加。服务端重算总长度，不信任客户端总值；编辑、详情、收货流水及 CSV 保留计算来源，计算值不进入历史实测样本。

## 影响范围

复用现有 SearchableSelect、ModalDialog、来料编辑/明细及库存过账服务；没有新数据库列。新增可选接口字段 lengthPerPiece，复用 pieceCount 与 totalLength 保存计算依据，主单位实收量与计价口径不变。模型说明更新于 data-model.md。

本版是分阶段交付，**尚不支持历史样本不足且完全不提供长度的双单位来料入库**。该部分需要把未知辅助数量与零值分开，并调整辅助数量参与的成本、出库、BOM 及展示逻辑；不得将此版视为该需求全部完成。

## 验证结果

来料定向回归、TypeScript、模块边界、架构基线、开发文档、发布说明和 SOP 校验通过。覆盖服务端重算、重量计价、编辑回存、导出计算依据、收货库存/金额、红冲、无效根数、计算值不污染历史样本。定向 Lint 无错误，有 3 条原有 Hook 警告。未执行本地完整生产构建；候选 CI 与生产部署须单独核验。
