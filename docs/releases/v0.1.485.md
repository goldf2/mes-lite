# v0.1.485 — 宇峰工作台接入真实功能

## 更新内容

此前对话中的功能总览只是交互草图，点击不会打开 MES 业务。此版本在现有应用壳实现真实工作台：首页、全部功能、搜索、个人收藏和侧栏使用实际注册目录，销售订单、生产订单、生产日报、库存和发货继续使用既有 UI/API。统一平台入口独立为 /workbench（规范化到 businessWorkbench）；原 MES Lite 首页 dashboard 保留，仍使用原岗位待办与统计。业务分组使用明确名称。

数据平台客户、联系人、地点、客户设备和地图由独立应用提供，工作台提供经过校验并保留登录目的地的真实链接。服务器原权限继续生效，不新增用户或授权，不将 MES 订单地图等规划项列为已接入。首页统计失败明确提示和重试，不再将接口失败当作零统计。

复用：公共应用壳、页面注册/渲染、搜索预设与高级搜索、按钮、弹窗、偏好服务及原领域页面。新增的 WorkspaceFunctionCatalog 只统一工作台卡片、功能搜索和收藏交互。

## 影响范围

没有 Prisma/数据库迁移；不合入另行待启用的共享联系人 v0.1.484，业务数据、历史单据及打印规则保持。同步真实工作台规范、界面/流程/功能模型、SOP 与交接记录。

## 验证结果

本地实际目录与外链语义、工作台偏好/导航、页面/壳/搜索/架构门禁、TypeScript 和定向 lint 已通过。隔离真实 Next 浏览器19项及最新双首页边界重验通过，覆盖原功能、业务读取、新增表单、权限、收藏重载、偏好GET/PUT并发和390px布局；外部目标只校验精确URL，生产跨应用登录另行验收。远端完整生产构建和精确提交 CI 必须成功后才可推进 main；具体发布与真实账号验收以交接/发布记录为准。
