# MES-lite v0.1.238

发布日期：2026-08-08

## 更新内容

- 画布工作布局的顶部一级菜单改为只响应点击。
- 鼠标经过一级入口只显示悬停反馈，不再打开或切换二级弹层。
- 点击其他一级入口切换菜单；再次点击当前选择、关闭按钮或点击空白处释放选择。
- 保留当前页面、临时选择和释放状态三态高亮，以及弹层跟随定位和内容自适应尺寸。
- 公共高级搜索的预置条件改为可编辑联想框，既可直接键入，也可从随输入筛选的候选值中选择。
- 输入完整候选标签或底层值会统一映射为真实搜索值；未匹配输入仍按用户原文保留。

## 影响范围

- 调整画布工作布局顶部一级菜单的展开触发方式，并升级全页面共用的高级搜索条件控件。
- 标准管理侧栏、移动端导航、菜单权限和业务数据均不受影响。

## 验证结果

- 工作区应用壳静态契约、TypeScript、定向 ESLint 和生产构建通过。
- 浏览器验证鼠标经过不展开，点击后正常展开、切换和释放。
- 浏览器验证预置搜索条件可手动键入、显示联想候选并正确映射搜索值。
