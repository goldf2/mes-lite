# MES-lite v0.1.262

发布日期：2026-08-09

## 更新内容

- 新增公共 `UnifiedNavigationMenu`，统一渲染一级分组、二级条目、选中状态、图标、拖动状态和条目尾部操作。
- 桌面单列侧栏、桌面双列二级区、桌面顶部弹层和窄屏功能抽屉共同使用公共菜单骨架，不再分别维护分组与条目循环。
- 保留各导航容器必要的差异：桌面侧栏可折叠或分列、顶部导航使用定位弹层、窄屏使用全高抽屉；差异不再改变菜单层级与数据。
- 明确移动常用入口和同级菜单是统一导航模型上的快捷入口，不作为第二套主菜单。
- 扩展响应式导航静态校验，阻止桌面与窄屏重新出现独立菜单结构。

## 影响范围

- 影响公共应用壳、桌面侧栏、桌面顶部导航和窄屏功能抽屉。
- 不改变菜单归属、页面名称、页面顺序、权限、路由和业务数据。
- 不改变“显示同级菜单按钮”以及移动常用入口的现有设置。

## 验证结果

- 响应式导航、工作区导航、工作区设置、账号菜单边界和页面模块校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。
