# MES-lite v0.1.438

发布日期：2026-08-24

## 更新内容

- 将生产日报的旧“BOM 快捷生产过账”改为“快捷生产 / 转换过账”。
- BOM 改为可选标准预设：可以按投入物料反查 BOM、直接选择 BOM，也可以不选 BOM 建立临时生产或转换。
- 实际投入和实际产出统一使用公共一对多关联骨架，允许增删现场实际明细；每项明细独立选择库位和数量。
- 支持一个快捷记录包含主产出、副产品、回收料等多个实际产出；无 BOM 或计划外明细必须填写备注。

## 数据与事务

- 新增 `DailyProductionOutput`，逐项保存产出物料、数量、库位、BOM 关系、主产出标记、折算与成本。
- `DailyProductionReport` 原单产出字段继续保存主产出兼容投影，既有历史日报无需回填即可读取和冲销。
- 确认时原子扣减全部实际投入并逐项入库；耗用成本归集到主产出，副产出成本暂记零。
- 待检模式为每项产出分别生成批次和质量任务；直接模式逐项进入可用库存；冲销逐项校验并恢复。

## 业务边界

- BOM 仍采用不可变发布版本，只负责标准计算和表单预填，不被实际偏差回写。
- 快捷入口不创建生产订单、派工、报工、人员、设备、作业文件或投入产出谱系；需要完整履历时使用生产订单。
- 同一批实物只能选择快捷流程或标准订单流程之一，避免重复扣料与重复报产。

## 影响范围

- 影响生产日报快捷入口、专用 API、日报查询/确认/冲销服务、质量任务关联和最近记录展示。
- 新增一项向前兼容迁移；既有生产订单、生产实绩、旧日报和库存流水保持不变。

## 验证结果

- 临时完整 SQLite 回归覆盖已发布 BOM 多产出、无 BOM 临时转换、直接与待检入库、质量放行、待检/冻结冲销、成本与失败回滚。
- Prisma Schema、迁移、TypeScript、ESLint、模块边界及正式候选 CI 由发布门禁验证。

## 回滚说明

- 回滚代码不会自动删除 `DailyProductionOutput` 表，也不会撤销已经确认的库存事实；需回退业务记录时应先执行合法冲销。
