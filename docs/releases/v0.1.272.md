# MES-lite v0.1.272

发布日期：2026-08-09

## 更新内容

- 新增公共 `useApplicationNavigationController`，集中管理页面权限过滤、MES/MRP/ERP 工作区菜单、菜单排序持久化和页面跳转。
- 宽屏侧栏、画布顶部菜单、窄屏抽屉和移动快捷入口继续从同一导航分组模型派生。
- `HomeApp.tsx` 从 854 行降至 522 行，只保留应用壳视图装配和少量全局弹层状态。
- 升级应用壳、页面注册、工作区导航和响应式菜单契约，防止公共职责回流应用入口。

## 影响范围

- 只调整应用壳内部代码边界，不改变 API、Prisma 模型、权限资源、菜单配置、页面布局或业务流程。
- 后续新增或修改页面时，应继续通过页面注册表和应用导航控制器接入，不再直接扩展 `HomeApp.tsx` 的菜单逻辑。

- TypeScript 类型检查通过。
