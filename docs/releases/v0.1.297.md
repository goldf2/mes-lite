# MES-lite v0.1.297

日期：2026-08-09

## 更新内容

- 将 BOM 成本输入和明细迁入领域契约，将库存/计价单位成本、产出折算、损耗、成本对象、锯切方案和固定费用分摊提取为纯规则。
- 将可计算物料与最近快照装配迁入查询服务，将物料映射、有效 BOM 校验和成本快照写入迁入命令服务。
- `app/api/bom-costs/route.ts` 从 340 行降至 45 行，系统超过 300 行的页面和 API 均已清零。
- 新增 `verify:bom-cost-module`，覆盖材料、人工、机时、直接费用、固定分摊、单位成本和缺失投入数量规则。

## 影响范围

- 保留 BOM 主产出折算、库存/计价单位成本选择、成本快照、最近记录、权限和审计行为。
- 不修改 Prisma Schema、数据库迁移、既有成本快照或服务器正式数据。

## 验证结果

- BOM 成本模块、模块边界、页面模块、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有警告。

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
