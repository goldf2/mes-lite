# MES-lite v0.1.180

发布日期：2026-08-04

## 更新内容

- 多物料来料单在宽屏下改为左侧当前明细录入、右侧已加入明细的双区布局。
- 两个工作区可独立滚动，弹窗标题和底部提交栏保持固定。
- 已加入明细展示物料、数量、金额、库位和合计，并保留移除操作。
- 窄屏下自动改为上下布局，已加入明细位于完整表单底部。

## 影响范围

- 影响物流模块的新增多物料来料单弹窗。
- 不改变来料单 API、数据模型、库存入账或采购计价逻辑。

## 验证结果

- TypeScript 类型检查通过。
- 桌面视口 `1280×720` 下，已加入明细在右侧 `320px` 独立区域显示。
- 窄屏视口 `900×720` 下，已加入明细紧跟完整录入表单之后，未与表单重叠。
- 弹窗标题、底部操作区、移除明细和提交项数保持正常。
