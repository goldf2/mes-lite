# MES-lite v0.1.415

发布日期：2026-08-20

## 更新内容

- 新增 LibreDWG CAD 预览服务的 Coolify 逐字段配置手册，覆盖第二 Application 创建、Dockerfile 路径、私网别名、端口、Secret、资源限制和健康检查。
- 明确转换器必须先健康，再给 MES-lite 主应用写入内部服务地址和同值令牌；真实令牌不得进入仓库、聊天、工单或截图。
- 增加真实 DWG/DXF 样本验收、常见故障、回滚步骤和人工配置记录表。
- 从总部署说明和文档中心链接到独立手册，避免把简要架构说明当作可直接照填的运维步骤。

## 影响范围

- 仅修改部署和发布文档，不修改业务代码、Prisma Schema、数据库、权限、页面、附件存储或容器镜像。
- 本版本不代表 LibreDWG 服务已经在真实 Coolify 上部署；必须由运维人员完成手册中的配置、健康检查和真实图纸验收。
- MES-lite 与转换器的内部 HTTP 契约、未配置时的降级行为和 v0.1.414 的许可证边界保持不变。

## 验证结果

- 检查手册字段与 `services/cad-preview/Dockerfile` 的 `8080` 端口、内置健康检查、令牌和默认限制一致。
- 检查 MES-lite 环境变量名称与现有客户端、readiness 和 `docs/deployment/coolify.md` 一致。
- 运行 `npm run verify:release-notes`，确认版本号与发布记录一致。
