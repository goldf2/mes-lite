# MES-lite v0.1.155

发布日期：2026-08-03

## 更新内容

- 在 BOM 创建与修改工作区恢复四种直接可见的内置转换模型：标准净用量、百分比损耗、固定损耗和批量投入/产出换算。
- 批量换算模型按物料计量类型动态显示“长度 → 件数”“重量 → 数量”等业务含义；长度可用配置单位录入，最终仍换算为米保存。
- BOM 继续只保存统一的投入/产出比例，转换模型只承担录入换算，不增加重复数据结构。
- 在工作区标题右侧补充唯一的“保存 BOM”按钮；组成明细修改、添加或移除后统一由该按钮持久化，取消底部重复保存入口和遮挡风险。
- 将转换模型提前到工作区首屏，先选择换算方式，再填写明细；补充标准净用量和通用批量换算验证。
- 新增按账号保存的页面连续性：刷新后恢复当前一级页面、物料子页面及其纵向滚动断点；失效或无权限入口自动回退到默认可访问页面。

## 影响范围

- 影响物料与 BOM 页面中的 BOM 创建、编辑、换算和保存交互。
- 影响 BOM 比例换算工具的录入模式与用户提示文案。
- 影响主页面导航和浏览器本地页面断点记录；不自动保存未提交的业务表单。
- 不修改 Prisma 数据模型、BOM API 和既有 BOM 比例数据；现有记录仍按原比例兼容读取和保存。

## 验证结果

- TypeScript 类型检查通过。
- BOM 版本与比例换算脚本通过，覆盖标准净用量、百分比损耗、固定损耗、长度转数量及通用投入/产出换算。
- 浏览器实测：修改已有组成比例后顶部保存按钮启用，保存成功并重新读取持久化结果。
- 浏览器实测：停留在 BOM 子页面刷新后仍返回 BOM 子页面，而不再跳回工作台。
- 发布说明、Docker 依赖检查及生产构建通过。
