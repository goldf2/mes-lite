# MES-lite v0.1.227

发布日期：2026-08-07

## 更新内容

- 公共顶部工具栏固定为单行，关键词搜索占据左侧弹性空间，页面工具和业务操作统一靠右排列。
- `1024–1279px` 紧凑桌面只保留“搜索 + 工具”；高级搜索、视图、页内选项、页面二维码和业务操作收进同一个工具菜单，不再换到第二排。
- 移动端顶部改为菜单、搜索、页面工具和账户入口的单行结构，移除独立页名和二维码占位行。
- 页面二维码宽屏继续显示全局图标，紧凑桌面和移动端从工具菜单打开同一个二维码弹窗。
- 页内选项只调整右侧工具顺序，关键词搜索固定在左侧，避免用户配置破坏基础对齐规则。

## 影响范围

- 影响所有通过 `TopBarPortal` 和 `ResponsiveToolbarActions` 接入的页面顶部工具栏。
- 不修改搜索语义、视图数据、二维码内容、权限或业务数据。
- 同步更新桌面端、移动端、响应式断点、布局架构和公共组件使用规范。

## 验证结果

- 36 个页面模块及其强制公共顶部工具栏契约校验通过。
- 公共按钮提示标签回归校验通过。
- TypeScript 无输出类型检查通过。
- 相关文件 ESLint 通过；仅保留 `app/page.tsx` 中既有的 Hook 依赖警告。
- Next.js 生产构建通过。
