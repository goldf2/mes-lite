# MES-lite v0.1.433

发布日期：2026-08-22

## 更新内容

- 生产日报默认升级为“BOM 生产转换”：选择已发布 BOM、主产出数量和库位后，系统自动展开理论投入，并允许填写当天实际投入。
- 保留 `v0.1.432` 的“库存盘点校准”作为第二模式，生产转换与库存差异不再混为一种业务事实。
- 快捷生产绕过生产订单、派工、报工、生产人员、设备和质检，但不绕过 BOM、库存、成本和审计。
- 正式确立双轨生产：标准流程“来料 → 派工 → 生产实绩 → 检验 → 入库 → 发货”和快捷流程“来料形成可用库存 → BOM 生产日报 → 直接入库”互不关联；同一批实物只能选择一条路径。

## 事务与数据边界

- `POST /api/daily-production-shortcut` 在单一事务内创建并确认 `DailyProductionReport`、FIFO 扣减投入、增加主产出、结转投入成本并写 `CONFIRM` 审计；任一步失败时整单回滚，不留下日报草稿。
- 只接受状态为 `RELEASED` 的 BOM；BOM 身份、版本、主产出基准和实际投入明细进入日报快照。
- 不创建 `ProductionOrder`、`ProductionOrderActual`、派工、报工或 `QualityInspection`；需要人员、设备、作业文件、待检批次和谱系时仍使用完整生产订单实绩。
- 两条生产路径只共享物料、已发布 BOM、库存和成本账，不互相保存单据 ID 或回写状态；详细边界见 [ADR-0047](../adr/0047-independent-standard-and-bom-shortcut-production-flows.md)。
- 本版复用现有日报、库存、成本和审计模型，不新增数据库表或迁移。

## 页面与权限

- “生产日报”页面提供“BOM 生产转换”和“库存盘点校准”两个明确入口，默认打开 BOM 转换。
- 页面读取和过账继续复用 `stocks.read/update` 与库位数据范围，不新增权限资源。
- 新页面通过生产领域 client 与服务调用，不恢复已删除的大型旧生产日报页面；库存盘点继续通过库存领域公共入口复用。

## 影响范围

- 影响生产日报页面注册、生产领域 client/契约/事务服务、专用 API、库存流水与操作审计。
- 不改变生产订单、派工、报工、质检、销售、来料和发货状态机。
- 同步更新功能模型、领域模型、权限接口矩阵、系统结构/时序、模块边界和专项操作文档。

## 验证结果

- 临时完整 SQLite 回归验证正式 BOM、投入扣减、产出入库、成本结转、可信操作人审计、无订单/无质检和失败整单回滚。
- 旧日报历史更新/确认/冲销、库存盘点整单、TypeScript 和差异格式检查通过。
- 正式构建、完整领域基线和候选提交精确 SHA 由 `MES-lite CI` 执行。

## 回滚说明

- 应用可回滚到 `v0.1.432`；已经确认的生产日报和库存流水仍是合法业务事实，不得随代码回滚删除。
- 本版无数据库迁移；回滚不需要回退 Schema。
- 业务录入错误应按日报号执行受控冲销后重录，不能直接删除流水或用库存盘点掩盖错误生产事实。
