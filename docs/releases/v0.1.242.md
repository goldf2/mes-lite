# MES-lite v0.1.242

发布日期：2026-08-08

## 更新内容

- 将 `app/page.tsx` 收缩为只挂载应用的稳定入口，公共鉴权、导航、权限和页面装配迁入 `app/HomeApp.tsx`。
- 将导航分组、功能目录和页面连续性读写集中到 `app/app-navigation.ts`。
- 将工作台、生产订单和库存拆为独立领域页面模块，各模块自行管理请求、筛选、表单、详情及局部 URL 状态。
- 保留公共页面边界、顶部工具栏、导航、权限和响应式应用壳，未复制业务页面或修改既有操作流程。
- 新增拆分任务计划，并同步公共前端模块指南与组件复用审查。

## 影响范围

- 影响前端应用入口和工作台、生产订单、库存三个页面的代码组织与加载边界。
- 不修改数据库模型、API 契约、权限资源、业务状态流转或页面视觉设计。

## 验证结果

- `npm run verify:page-modules`、TypeScript 和定向 ESLint 通过；定向 ESLint 保留一条原有 Hook 依赖警告，无错误。
- `npm run build` 生产构建通过。
- 浏览器验证工作台、生产订单列表/新建切换和库存列表可正常装配，生产订单 `view=list` URL 可恢复列表视图。
- 390px 窄屏下应用壳、顶部工具和底部导航正常显示，无页面级横向溢出；宽表格在内容容器内滚动。
