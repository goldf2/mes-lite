# MES-lite v0.1.315

日期：2026-08-10

## 更新内容

- 在 `modules/sales` 增加销售订单与履约输入契约、日期编号、定价、订单状态、领域错误以及查询、命令、状态和发货单 PDF 服务。
- 将销售订单创建/确认/取消/调价、独立或关联发货、发货/签收/取消、退货登记/处理/拒绝/归档迁入销售领域服务。
- 销售订单、发货、退货共 16 条 Route Handler 只保留权限、Schema、服务调用、审计和 HTTP 错误映射，全部移除直接 Prisma 访问。
- 删除扁平 `lib/sales-orders.ts`，订单剩余量与状态回写归入销售领域；修正发货时原始物料 ID 未经过兼容产品映射的问题。
- 单号生成改为读取当日最大历史序号后递增，避免按数量生成时因归档或断号发生碰撞。
- 直接访问 Prisma 的 Route Handler 从 72 条降至 56 条；14 个领域模块共有 234 个文件。

## 影响范围

- 用户行为和 API URL 保持兼容：销售订单仍不直接扣库存，发货可独立创建或显式关联订单明细，只有确认发货才扣减库存并回写关联订单进度。
- 待发货单继续占用订单可发数量；确认发货原子扣减总库存、库位余额与成本，处理退货按原发货成本恢复库存。
- 调价仍只允许草稿或尚未执行的已确认订单；已确认订单必须填写原因，产生发货记录后价格锁定并在同一事务写审计。
- 本版本不修改 Prisma Schema、数据库迁移或页面布局；本机 SQLite、服务器正式数据和构建缓存不纳入提交。

## 验证结果

- `verify:sales-module` 锁定 16 条薄路由、领域文件、纯编号和状态规则，`verify:sales-pricing-boundary` 锁定销售价与独立发货边界。
- `verify:sales-order-flow` 使用运行后删除的临时完整 SQLite，覆盖订单编号/定价/调价、分批发货、库存成本扣减、送达、PDF、退货成本恢复、拒绝、查询、归档和重复状态拒绝。
- `verify:module-boundaries`、TypeScript 类型检查、开发文档与发布文档校验、Next.js 生产构建均通过；构建仅保留既有 `<img>` 优化提示。
