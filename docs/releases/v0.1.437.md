# MES-lite v0.1.437

发布日期：2026-08-24

## 更新内容

- 生产订单创建改为“目标产出必选、BOM 可选”，支持不使用 BOM 的临时生产与物料转换。
- 选择已发布 BOM 时继续冻结完整快照，并在班后实绩中预填标准投入与产出。
- 班后实绩的投入和产出改为可增删的公共一对多关联骨架，可按本批实际修正 BOM 预设或添加计划外明细。
- 目标产出始终必须保留；无 BOM 或含临时投入/产出时必须填写说明。
- 兼容尚未配置工作中心关系的旧作业文件，打开生产实绩编辑器时不再因缺失关系数组而中断。

## 业务边界

- BOM 仍采用草稿、已发布、已作废生命周期；已发布和已作废版本不可修改或删除，实绩偏差不会回写 BOM。
- BOM 只是标准计算与预填关系，库存、成本、批次、质量、人员、设备、作业文件、确认和冲销继续以实际生产事实为准。
- 快捷生产日报仍只使用已发布 BOM，不扩展为第二个临时生产入口。

## 数据与兼容性

- 不新增 Prisma 模型或数据库迁移。现有可空的订单 BOM 引用和实绩 BOM 明细引用用于区分标准预设与人工明细。
- 既有 BOM 订单、快照、确认实绩和历史追溯保持兼容。

## 影响范围

- 影响生产订单创建候选、订单 BOM 展示、班后实绩投入/产出编辑、说明门禁和对应 SOP。
- 复用现有生产订单、实绩、库存、批次、质量与成本表，不影响快捷生产日报和流程转移。

## 验证结果

- 临时完整 SQLite 回归覆盖无 BOM 订单、BOM 预设偏差、临时投入/产出、说明门禁、确认过账、成本、批次和冲销恢复。
- 生产订单模块回归覆盖无 BOM 物料候选、创建和可空快照。
- TypeScript、Lint、模块边界、相关生产/质量/批次回归和正式候选 CI 由本版发布门禁验证。

## 回滚说明

- 本版无数据库迁移，可回滚到 `v0.1.436`。已经确认的临时生产实绩属于库存和批次事实，回滚代码不会自动撤销；如需撤销应在新版本界面中先执行合法冲销。
