# v0.1.404 来料单右侧清单滚动修复

日期：2026-08-18

## 更新内容

- 宽屏来料新增/编辑弹窗使用受约束的正文高度，防止双栏网格被右侧多条明细撑高后被弹窗裁切。
- “本单已加入”标题保持固定，只让明细清单在底部提交栏上方独立纵向滚动。
- 右侧清单增加稳定滚动槽与明确的滚动条颜色，避免 macOS 自动隐藏滚动条时无法识别可滚动区。

## 影响范围

- 仅影响来料新增/编辑弹窗的宽屏双栏布局和右侧清单滚动外观。
- 手机端仍保持单列整体滚动，不增加嵌套滚动条。
- 不修改来料请求契约、库存过账、成本层、数据库模型或历史单据。

## 验证结果

- `npm run verify:receiving-module`
- `npx tsc --noEmit`
- `git diff --check`
- 使用现有 14 项待收货来料单量取修复前布局，确认右栏 1520px 内容被 800px 弹窗正文裁切。
- 候选提交将在 GitHub Actions 通过后进入 `main`，并在生产页面重新验证滚动区尺寸与可滚动性。

## 回滚

回退本版本代码即可恢复原来布局，无需数据库迁移或业务数据回滚。
