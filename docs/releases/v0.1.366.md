# MES-lite v0.1.366

发布日期：2026-08-13

## 更新内容

- 为旧容器 `/app/public/uploads` 附件绝对路径增加严格的当前挂载重定位，恢复到新目录后附件 API 仍可读取原文件。
- 增加 `storage:drill:application`：非覆盖复制恢复候选，校验数据库和全部附件 SHA-256，部署迁移并启动生产构建，完成 readiness、临时管理员登录、物料/库存/生产单只读抽查及附件原文件哈希验证。
- 应用级演练结束后清理临时管理员并复核源候选 SHA-256，脱敏报告不保存业务明细、附件名称、账号或密码。
- SOP 新增“执行应用级恢复演练”，扩展为 17 章 141 个流程，并重新生成 Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 不修改 Prisma Schema、迁移或在线生产数据；附件路径只在读取文件时安全映射。
- 生产恢复候选的本地只读副本已完成应用级隔离验收；Coolify 生产继续固定在 v0.1.361，Auto Deploy 保持关闭，本次不部署生产。
- 异地副本、真实 Coolify 挂载切换、Product→Material 生产回填及企业岗位审批仍是外部门禁。

## 验证结果

- 自动演练夹具通过非覆盖候选、当前迁移、生产构建、readiness、管理员登录、三类业务只读 API、附件 SHA-256、临时账号清理和报告脱敏验证。
- 真实生产候选隔离副本验证 252 个附件文件，当前库包含 45 个有效物料、62 条库存、1 张有效生产订单和 83 个有效附件；所有应用检查通过，RPO 35,632.927 秒、完整应用 RTO 1.582 秒。
- 源候选 SHA-256 演练前后均为 `7a16075992b5f0f4d0b5f3711e7d2b0fb0fa4541f2b31ca62a4122a138479845`，隔离临时管理员已清理。
- 类型检查、Lint、生产构建、19 项领域/治理基线、独立应用级恢复演练、SOP 同步门禁及 DOCX 逐页渲染检查通过。

## 回滚说明

本版本没有数据库迁移，可回退代码到 v0.1.365。回退后旧绝对附件路径在非标准挂载的恢复实例中会再次无法读取，因此回滚前应保留 v0.1.366 应用演练报告和候选目录；不要删除或改写源候选。应用演练生成的目标目录是独立副本，可在取证完成后移入废纸篓，不影响生产数据。
