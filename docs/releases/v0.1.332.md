# MES-lite v0.1.332

日期：2026-08-10

## 更新内容

- 将 `modules/**/*.{js,ts,jsx,tsx,mdx}` 纳入 Tailwind 内容扫描，恢复模块化迁移后领域 UI 的完整样式生成。
- 修复 Excel、Word、PowerPoint 经 PDF 转换后，文档查看器可能只显示深色背景而不显示页面、加载状态或错误提示的问题。
- 扩展 `verify:structural-goal`，以后若 Tailwind 再次遗漏模块目录，结构验收会直接失败。

## 影响范围

- 影响所有位于 `modules/*/ui` 的页面与组件，重点包括附件预览、文档详情、物料、库存、生产、销售、设置和运维工具页面。
- 不修改文档文件、附件记录、Office 转换方式、API 契约、权限、Prisma Schema 或正式数据库数据。
- 仍复用公共 `ModalDialog`、`DocumentFileViewer` 与 `PdfDocumentViewer`，没有为 Excel 单独创建平行查看器。

## 验证结果

- 回归检查先在旧配置下失败，确认能捕获 `modules/` 扫描遗漏。
- 本机使用 XLSX 附件完成 LibreOffice 转换，生成 29 页 PDF，并在文档详情弹窗中成功渲染 29 页画布。
- `npm run verify:structural-goal`
- `npm run verify:attachment-management`
- `npm run verify:attachment-file-types`
- `npm run verify:release-notes`
- `npx tsc --noEmit`
- `npm run build`
