# MES-lite v0.1.177

发布日期：2026-08-04

## 更新内容

- PDF 缩略图改用 Poppler 的 `pdftoppm` 进行服务端渲染，避免扫描 PDF 触发原生 Canvas 崩溃。
- Docker 运行镜像加入 `poppler-utils`，确保 Coolify 部署后同样可生成 PDF 缩略图。
- 保留 PDF 缩略图的旋转与尺寸压缩能力。

## 影响范围

- 影响 PDF 附件的首页缩略图生成。
- 不改变 PDF 完整预览、下载和文件名搜索逻辑。

## 验证结果

- 使用 CamScanner 生成的 `P12项目 21#图纸20260804.pdf` 生成首页缩略图成功。
- 缩略图为可读的 PNG 图像，服务进程保持正常。
