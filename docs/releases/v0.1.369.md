# MES-lite v0.1.369

发布日期：2026-08-14

## 更新内容

- 新增 `EquipmentEvent`：记录开机、停机、故障、恢复和归档的来源/目标状态、原因、说明、可信操作人、发生时间与持续时间。
- 设备状态只允许由服务端状态机改变；基础资料输入严格拒绝 `status`，新设备固定从“可用”开始，非法转换返回 409。
- 恢复会关闭最近一条未结束的故障、停机或维护事件，把持续时间写回被关闭事件；恢复事件只记录恢复时点，避免重复显示同一段停机时间。
- 归档同样关闭尚未结束的故障、停机或维护事件；SQLite 触发器强制新设备从可用开始、状态只能跟随最新事件改变，事件业务事实不可删除或篡改。
- 新增 `GET/POST /api/equipment/:id/events`、事件时间线和故障/恢复命令弹窗；状态快照与事件在同一事务更新。
- 新增第 49 个权限资源 `equipmentEvents`。设备只读岗位可回放，运行命令必须具有 `equipmentEvents.update`；设备维护组新安装预置为 `equipment:RCUA + equipmentEvents:RU`。
- 设备台账、新建设备、细粒度权限、故障命令和事件时间线共 5 个流程使用真实本地浏览器截图；SOP 扩展到 144 个流程并同步站内、Markdown、DOCX、PDF 和离线 Web。

## 影响范围

- Prisma 由 77 个模型、76 个迁移变为 78 个模型、77 个迁移；迁移只新增事件表和索引，不改写既有设备状态。
- Route Handler 由 131 增至 132；权限资源由 48 增至 49。
- 升级安装首次补齐 `equipmentEvents` 时从原 `equipment` 设置继承，以保持既有操作连续；生产部署后必须按岗位审批复核并收窄。
- 点检、保养、维修工单、备件、设备协议、自动产量采集和 OEE 不在本版。
- Coolify 生产继续固定既有批准版本且 Auto Deploy 保持关闭；本版只推送代码和文档，不自动部署生产。

## 验证结果

- `verify:equipment` 覆盖合法/非法转换、故障持续时间归属、归档事件和模块边界。
- `verify:equipment-events-http` 覆盖只读岗位 POST 403、设备维护岗位 POST 201、设备只读岗位 GET 200。
- `verify:fine-grained-permissions` 覆盖 49 个资源、旧角色/组继承和设备维护组最小权限。
- 类型检查、Lint、生产构建、23 项领域/治理 CI 与 SOP 同步门禁均纳入发布验证。

## 部署与回滚

部署前生成 SQLite 与附件一致备份，在生产副本先执行 77 个迁移并验证 readiness、登录、设备读取、越权 403、故障/恢复和时间线。代码可回退到 `v0.1.368`，新增 `EquipmentEvent` 表应保留，因为旧代码不会读取它；禁止删除已写事件或篡改迁移历史。只有数据库损坏或迁移异常时才使用部署前一致备份生成非覆盖恢复候选。
