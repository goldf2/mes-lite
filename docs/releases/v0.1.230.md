# MES-lite v0.1.230

发布日期：2026-08-08

## 更新内容

- 将“文档类别”新增为“业务配置”下的独立设置页面，统一维护一级、二级类别。
- 产品文档顶部工具移除“类别管理”，仅保留与当前文档页面直接相关的“新建文档”操作。
- 类别配置页复用既有类别数据规则，继续支持同层防重、最多两级、引用保护及权限控制。
- 类别配置页接入公共顶部工具栏、关键词搜索和设置页响应式骨架。
- 工作台功能目录、桌面导航、页面模块注册和开发规范同步登记文档类别入口。

## 影响范围

- 产品文档页面及其公共工具弹层。
- 业务配置导航、所有功能目录和工作台快捷功能候选项。
- 文档类别配置页面、权限与类别 API；不修改已有文档和类别数据。

## 验证结果

- 产品文档顶部仅显示“新建文档”，不再出现“类别管理”。
- “业务配置 → 文档类别”可正常打开并展示已有一级、二级类别。
- 1280px 桌面与 390px 窄屏页面均无横向溢出，表单和类别列表保持可操作。
- TypeScript、ESLint、工作台偏好、文档类别数据规则和 37 个页面模块契约校验通过。
- Next.js 生产构建通过。
