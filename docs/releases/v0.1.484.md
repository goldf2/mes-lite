# v0.1.484 — 数据平台联系人作为 MES 共享主档

## 更新内容

候选实现，生产尚未启用。两个代码库独立。MES 通过当前 Casdoor 用户委托读取正式客户/联系人/地点，明确绑定原客户或创建兼容引用；共享模式停止本地客户维护，供应商保持原流程。销售订单和发货单保存选定资料快照，历史打印不随源资料变化。

## 影响范围

新增追加式 Prisma 迁移，无业务数据重写。复用资源页、ModalDialog、AppButton、SearchableSelect。专用短期签名只在服务端生成，数据平台仍按当前用户权限核验，未新增生产授权。

## 验证结果

规范与上线/回退边界：[共享客户主档](../architecture/shared-customer-master.md)。已通过 6 组隔离服务/HTTP/PDF、15 组 client/UI、7 组跨仓库真实 HTTP 联调及类型、lint、原客户/供应商、销售订单、认证、模块、架构与文档门禁；另通过真实 Next dev + Chromium 5 组桌面/390px 浏览器交互，未出现 pageErrors；会话为合成测试身份。原业务单据打印与发货退货批次闭环回归通过。精确候选 CI 和生产启用单独记录。不得将配置保存、候选推送或容器健康视为生产联系人共享验收。
