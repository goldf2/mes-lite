# v0.1.389 视频帮助接入现有 SOP

日期：2026-08-16

## 更新内容

- 新增 `sop/videos.json` 视频目录；每条视频必须关联现有 SOP 主章节和至少一个流程。
- 页面关系从关联流程的 `pageKey` 自动推导，视频读取继续复用现有权限资源。
- 完整帮助中心把视频显示在对应业务章节内，并将视频标题与说明纳入搜索。
- 顶部问号快捷帮助可直接播放当前页面相关视频。
- 支持对象存储 MP4/WebM/Ogg、哔哩哔哩 BV 号和 YouTube 视频 ID；第三方播放器点击后才加载，并保留新页面来源入口。
- 登记 v0.1.388 主界面快速导览为首个自托管视频条目。

## 发布配置

- 自托管视频与 PDF/DOCX 复用唯一只读 `SOP_PUBLIC_BASE_URL`。
- 首个视频应上传到 `v0.1.388/videos/MES-lite主界面导览-v0.1.388-全同步版.mp4`。
- 未配置合法公开地址或对象尚未上传时，文件播放器不显示，在线文字 SOP 保持可用。
- 视频二进制继续保存在忽略的 `output/` 和对象存储，不进入 Git、Docker 镜像或站内文档发布清单。

## 影响范围

- 更新“使用站内帮助中心”和“查看当前页面操作帮助”两个 SOP 流程。
- 不新增页面、HTTP API、权限资源、数据库模型或迁移。
- B站与 YouTube 的可访问性依赖企业网络和平台服务；关键教程建议使用自托管文件。

## 验证结果

- `verify:sop-media` 覆盖三类来源、地址白名单、章节/流程引用、权限过滤、当前页过滤和第三方延迟加载。
- `verify:sop` 覆盖 181 个流程和 v0.1.389 影响声明。
- 类型检查、Lint 和生产构建通过。

## 回滚

本版本没有数据库迁移。代码可回退到 v0.1.388；对象存储中的视频文件可以保留，不会被旧版本读取。若只需临时隐藏自托管视频，可删除 Coolify 中的 `SOP_PUBLIC_BASE_URL` 并重新部署，在线文字 SOP 仍可使用。
