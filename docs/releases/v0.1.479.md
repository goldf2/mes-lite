# v0.1.479 企业业务平台只读目录接入

## 更新内容

- 新增默认关闭的 `business-directory.v1` 企业、联系人和地点 GET API。复用现有客户查询，输出固定来源和严格白名单投影、稳定关联 ID、分页；无独立联系人和坐标时如实标记投影/空值。
- 只保存入站密钥 SHA-256 摘要，并要求明确委托有效期，绑定精确已有人员，每请求重新检查 ACTIVE 和原 `customers.read`；Cookie 不能替代密钥，不接受客户端指定人员/租户，不创建会话或权限。原权限解析增加兼容的只读选项，既有调用默认行为不变。
- 现有设置框架新增仅 ADMIN 可见的 API 接入状态与目录，不显示密钥。保留 MES 本地登录、全部业务 CRUD 和独立部署。

## 影响范围

- 新增 `modules/platform-integration` 及四条薄路由；客户模块仅增加只读公开查询出口，无 Prisma 结构或迁移变更。
- 新增设置页注册和 `adminOnly` 导航规则，不新增或扩大人员权限。
- 接口、来源标签和部署说明见 [企业业务目录 API](../architecture/business-directory-api.md)。原业务流程不变；部署诊断按该手册覆盖，不纳入普通业务人员 SOP，原指南沿用 v0.1.477。
- 本版只提供读取适配；不是 Casdoor 统一登录完成，不自动同步或合并企业、联系人、地点，不修改独立企业地图。

## 验证结果

- 已通过隔离迁移 SQLite 的目录回归：三类 DTO、来源/派生 ID、搜索分页、空白/归档排除、委托撤权/停用、错误凭据/查询、轮换旧密钥和过期、禁用与原 CRUD 中间件保护；读取前后逻辑数据库摘要一致。
- 原权限、身份服务、真实本机 HTTP 诊断授权、页面/设置/模块/架构与结构门禁、TypeScript、定向 Lint、开发文档/SOP/发布与 Docker 依赖门禁均通过；精确候选 CI 待推送后核对。
- 不运行无关本机生产构建；遵循 MES 候选 CI 构建流程。main 推进和生产部署未执行，不将源码或配置就绪记为上线验收。
