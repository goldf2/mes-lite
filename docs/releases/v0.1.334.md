# MES-lite v0.1.334

日期：2026-08-10

## 更新内容

- 文档与物料全景中的文件全屏查看器统一通过公共 `ModalOverlay` 挂载到根级顶层，不再被来源详情弹窗遮挡。
- 公共浮层补充多层归属判断，`Esc` 和焦点圈定只作用于当前最上层弹窗；退出全屏后继续保留原详情窗口和浏览上下文。
- 页面形态回归新增全屏层级与多层键盘行为约束，防止独立查看器重新使用低层级页面内固定定位。

## 影响范围

- 调整公共弹窗遮罩、产品文档全屏预览和物料全景附件预览，不修改附件文件、业务数据、API、权限或数据库结构。
- 本机交互验证使用临时 XLSX 附件；验证结束后已删除测试附件记录，并将临时文件移入废纸篓。

## 验证结果

- `npm run verify:fullscreen-dialogs`
- `npm run verify:material-bom-modules`
- `npm run verify:attachment-management`
- `npm run verify:structural-goal`
- `npm run verify:release-notes`
- `npx tsc --noEmit`
