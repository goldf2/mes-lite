# MES-lite v0.1.208

发布日期：2026-08-06

## 更新内容

- 宽屏顶部原有的页面选项图标增加“页面选项”文字，明确导航布局设置入口。
- 手机和窄屏顶部将图标入口调整为“选项”按钮，避免只能依靠图标含义寻找设置。
- 页面选项弹窗内的“桌面导航布局”继续提供单列折叠与双列导航切换。
- 双列导航的一级菜单增加独立拖动分隔线，可在 72–140px 调整；支持方向键、双击恢复默认和浏览器持久化。

## 影响范围

- 调整公共应用头部的页面选项入口和双列一级菜单宽度，不改变页面工具、权限或业务数据。
- 1024–1279px 桌面仍保留紧凑图标，1280px 及以上显示完整文字，避免压缩页面工具栏。

## 验证结果

- TypeScript、Lint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证宽屏文字入口、弹窗内导航布局选项和移动端按钮的可访问名称。
