# MES-lite v0.1.207

发布日期：2026-08-06

## 更新内容

- 桌面左侧菜单新增“搜索功能”输入框，可跨全部一级分组查找当前用户有权访问的功能。
- 单列模式在菜单顶部固定搜索框，并按一级模块展示匹配结果。
- 双列模式保持一级菜单列稳定，在二级菜单列展示跨分组搜索结果，避免搜索时失去导航位置。
- 支持 `Esc` 和清空按钮恢复完整菜单；搜索状态下关闭拖拽排序，避免误改菜单顺序。

## 影响范围

- 只调整公共桌面导航组件，不改变页面顶部业务搜索、移动端导航、权限判断、菜单路由或业务数据。
- 搜索数据直接来自已经完成权限过滤的公共菜单模型，不维护第二份功能索引。

## 验证结果

- TypeScript、ESLint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证双列与单列功能搜索、无结果状态、清空和结果跳转。
