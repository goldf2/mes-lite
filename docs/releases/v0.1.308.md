# MES-lite v0.1.308

日期：2026-08-09

## 更新内容

- 为归档记录、操作记录和物料编码规范化建立统一的运维维护契约与 HTTP client。
- 将九类归档数据的标签映射和时间排序从页面提取为可测试纯规则。
- 归档、审计和数据工具 3 个页面不再直接调用 `fetch`，只负责页面状态与交互。
- 新增运维维护工具模块守卫，防止接口路径、归档映射和页面级请求回流 UI。

## 影响范围

- 归档恢复、永久删除、审计展示和物料编码规范化交互保持不变。
- API 路径、Prisma Schema、权限资源和页面布局保持不变。
- 本机 SQLite 测试数据与构建缓存不纳入版本提交。

## 验证结果

- 运维维护工具、模块边界和页面模块专项校验通过。
- 归档标签映射与时间排序确定样例通过。
- TypeScript 类型检查和 Next.js 生产构建通过。
