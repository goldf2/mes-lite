# MES-lite v0.1.422

发布日期：2026-08-21

## 更新内容

- 产品文档页增加“批量导入”，一次选择最多 50 个同类文件；每个文件独立创建一篇文档和一个原始附件，共用本次填写的类别、产品、工作中心、版本、状态、备注及扩展字段，并返回逐文件结果。
- 增加“字段设置”：标题、类别、产品、工作中心、版本、状态、备注和正文作为基础字段固定保留；每个现有文档类别可独立增加文本、数字、日期、布尔或单选扩展字段。
- 扩展字段没有任何文档值时才允许删除；一旦使用，页面显示使用数量并禁用删除，服务端和数据库外键同时拒绝破坏历史数据。
- 卡片和表格增加文档复选框、当前页全选及“批量修改”。批量修改只接受同一类别的文档，并且只覆盖操作者显式勾选的基础字段或扩展字段。
- 普通新增、详情编辑、批量导入和批量修改复用同一字段契约；写接口继续执行权限、字段归属/类型校验和操作审计。

## 数据模型与迁移

- 新增 `DocumentFieldDefinition`，保存类别扩展字段定义和单选项。
- 新增 `WorkInstructionFieldValue`，保存文档与字段定义之间的非空值，并以复合唯一键防止同一字段重复保存。
- 迁移 `20260820213000_add_document_extension_fields` 只新增表、索引和外键，不改写既有文档、类别或附件。
- 文档切换类别时清除旧类别扩展值；批量修改跨类别时整批拒绝，避免字段语义串用。

## 影响范围

- 影响产品文档的新增、编辑、列表选择和类别字段维护流程；不改变文档类别层级主数据、既有附件原文件、预览转换链路或生产实绩中的历史文档快照。
- 新增两张非破坏性数据表和三个写接口；既有文档继续保持原字段和值，不要求人工补录扩展字段。
- 部分批量导入失败不会回滚已经成功的其他文件；页面会按文件名返回失败项，操作者可修正后只重试失败文件。
- 当前没有跨类别字段映射；需要共同修改的文档必须属于同一类别，避免同名字段含义不同却被批量覆盖。

## 页面与权限

- 批量导入要求同时具备产品文档新增和附件新增权限；批量修改复用产品文档修改权限。
- 字段新增/删除沿用文档类别新增/删除权限，不增加平行权限资源；字段设置只配置现有类别，不替代“业务配置 → 文档类别”。
- 继续复用 `ResponsiveToolbarActions`、`AppButton`、`ModalDialog`、`ModalActions`、`SearchableSelect`、公共表单样式、一对多关系选择和公共附件上传/查看能力，没有增加第二套全局组件。

## 验证结果

- Prisma Schema 格式化、全新 SQLite 数据库 88 个迁移部署和 Schema 校验通过。
- `verify:document-metadata` 已覆盖字段新增、未使用字段删除、已使用字段删除拒绝、字段使用计数、同类别批量修改、跨类别拒绝，以及两个文件分别建档和上传。
- `verify:document-server`、`verify:document-categories`、TypeScript 和定向 ESLint 通过；ESLint 仅保留文档页既有的 3 个 Hook 依赖警告，没有新增错误。
- 标准生产构建、完整 CI 和部署后桌面/移动交互由候选提交及生产版本门禁继续验证。

## 回滚说明

- 应用代码可以回滚到 v0.1.421；新增表不会影响旧版本读取既有文档。
- 回滚前应导出新增的字段定义和值。不要直接删除新表；确认不再需要且完成备份后，才可另行编写受控清理迁移。
