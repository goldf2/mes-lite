# MES-lite v0.1.260

发布日期：2026-08-09

## 更新内容

- 建立统一导航分组模型，桌面顶部、桌面侧栏、移动抽屉、移动常用入口和窄屏同级菜单共用同一份权限过滤后的菜单数据。
- 将原本只用于物料和 BOM 的窄屏同级菜单抽成公共组件，对生产、销售、配置等包含多个页面的当前分组同样生效。
- 在“系统设置 → 显示设置”增加“显示同级菜单按钮”开关，作为当前浏览器的个人显示偏好。
- 增加响应式菜单结构校验，防止后续再出现桌面与移动端并行菜单数据源。

## 影响范围

- 影响公共应用壳、桌面导航、移动抽屉、移动底部常用入口与窄屏同级菜单。
- 不改变页面 ID、工作区归属、菜单名称、排序、权限和业务数据，不包含数据库迁移。
- 同级菜单开关只影响窄屏页面顶部的快速入口，关闭后完整功能仍可从统一导航抽屉进入。

## 验证结果

- 响应式导航、工作区导航、工作区设置、账号菜单边界和页面模块专项校验通过。
- TypeScript 类型检查通过。
- 本机浏览器验证统一菜单正常显示，“显示同级菜单按钮”开关可立即切换并持久化。
- Next.js 生产构建通过。
