# MES-lite v0.1.333

日期：2026-08-10

## 更新内容

- 将物料详情主图从全宽固定比例改为受限的响应式高度：手机 256px、较宽手机 320px、桌面 384px、大屏最高 448px。
- 图片继续使用 `object-contain` 完整展示，不裁切内容；点击图片仍可打开原图，详情弹窗的全屏能力保持不变。
- 在物料模块回归验证中固定主图高度约束，防止以后重新使用全宽比例把详情内容推到屏幕之外。

## 影响范围

- 仅调整物料详情弹窗主图展示尺寸，不修改图片原文件、缩略图、展示图、附件记录、API、权限或数据模型。
- 继续复用公共 `ModalDialog` 和附件管理模块，没有增加独立图片查看器。

## 验证结果

- `npm run verify:material-bom-modules`
- `npm run verify:structural-goal`
- `npm run verify:release-notes`
- `npx tsc --noEmit`
- `npm run build`
- 浏览器分别以桌面视口和 390px 窄屏检查物料详情，主图均保持受限高度，基础信息直接可见。
