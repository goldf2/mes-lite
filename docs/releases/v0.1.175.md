# MES-lite v0.1.175

发布日期：2026-08-04

## 更新内容

- 新建或编辑产品文档时，文档标题改为可选。
- 标题留空时，服务端根据关联产品、文档类别和创建时间自动生成可搜索标题。
- 同一张来料单可连续添加多种物料，每项可分别记录实测数量、采购计价、批次号和收货库位。
- 已加入的来料明细可在提交前查看和移除，供应商、凭据号、收货人和备注作为整张单据的共用信息。

## 影响范围

- 影响产品文档的创建与编辑校验，已有文档标题不变。
- 影响来料单创建界面与创建接口，现有单物料接口请求、来料编辑、收货、拒收和红冲保持兼容。

## 验证结果

- TypeScript 类型检查通过。
- 双单位全流程与物料主计量、来料实测、计价回归验证通过。
- 浏览器确认新建文档标题可留空。
- 浏览器确认来料单可将当前物料加入明细，保留单据级信息后继续录入下一种物料。
