# v0.1.393 精简桌面导航控制区

日期：2026-08-16

## 更新内容

- 将桌面导航的常驻/自动隐藏图钉从侧栏内部移到 `MES-lite` 产品模块按钮右侧，与导航入口组成单一顶部控制区。
- 删除桌面侧栏中无额外信息的“全部功能”标题行，展开后直接显示功能搜索与一级/二级菜单。
- 图钉继续提供“固定导航 / 改为自动隐藏”提示、按下状态和键盘可访问按钮语义。
- 保留左侧 `30px` 即时感应呼出、点击锁定、移出延时收回、侧栏宽度调整和版本号显示。

## 影响范围

- 仅影响桌面标准管理布局的公共应用壳与显示设置 SOP。
- 移动端“全部功能”抽屉、工作台“所有功能”页面、画布工作布局、业务页面和产品模块配置保持不变。
- 不新增 HTTP API、权限资源、数据库模型或迁移。

## 验证结果

- 静态回归确认图钉位于产品模块按钮同一顶部控制区，桌面侧栏不再输出“全部功能”标题行。
- 本地 `1440×900` 实测确认图钉可切换常驻/自动隐藏；常驻时正文按 `224px` 侧栏宽度让位，恢复自动隐藏后正文边距归零。
- 工作区应用壳、响应式导航、控制器、SOP、发布文档、类型检查、Lint 与生产构建通过。

## 回滚

本版本没有数据库迁移。代码可回退到 v0.1.392；浏览器中已保存的导航偏好不受影响。
