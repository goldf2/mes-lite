# MES-lite v0.1.203

发布日期：2026-08-06

## 更新内容

- 将工作台、物料、生产、文档、设备、物流、销售、库存、配置和工具统一移入桌面左侧一级导航，当前分组在原位展开二级页面。
- 顶部应用栏不再重复承载业务导航，改为集中显示当前页面的搜索、筛选、视图和主操作，并保留 AI、页面选项和账号入口。
- 公共 `TopBarPortal` 根据设备形态自动选择桌面顶部工具区或移动工具区；`1024–1279px` 使用紧凑工具菜单，避免临界宽度拥挤。

## 影响范围

- 只调整公共应用壳、导航和页面工具挂载位置，不改变业务页面、权限、接口或数据库结构。
- 移动端继续使用菜单抽屉和页面工具呼出按钮，桌面端与移动端共用同一套页面操作定义。

## 验证结果

- TypeScript、ESLint、页面模块覆盖校验、版本文档校验和生产构建通过。
- 浏览器验证桌面一级/二级导航切换、页面工具随业务页更新及窄屏工具回收行为。
