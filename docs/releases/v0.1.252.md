# MES-lite v0.1.252

发布日期：2026-08-08

## 更新内容

- 新增 MES / MRP / ERP 功能矩阵的独立 HTML 展示页，完整呈现架构文档中的功能归属、当前状态、数据所有权和模块边界。
- 增加可定位的页面目录、MES/MRP/ERP/共享平台配色、概览指标和宽表格横向滚动。
- 页面支持桌面、窄屏和打印布局，可通过 `/mes-mrp-erp-function-matrix.html` 直接访问。
- 在架构源文档中增加 HTML 展示版入口，方便从 Markdown 与网页两个视图查阅同一矩阵。

## 影响范围

- 本版本只增加静态展示页面和文档入口，不修改应用业务页面、API、数据库结构与运行逻辑。
- HTML 页面由现有矩阵文档生成，后续修改功能边界时应同步更新两个文件。

- 本机静态资源访问返回 HTTP 200。

- 版本文档专项校验和 HTML 基础结构检查通过。
