# MES-lite v0.1.294

日期：2026-08-09

## 更新内容

- 将物料全景的库存/库位、BOM/成本、工单/领料、来料/流水、工艺和文档聚合迁入物料查询服务。
- 提取产品/工艺选择集与附件分类、正式作业文档附件装配，避免把 412 行路由整体搬成单个巨型服务。
- `app/api/materials/[id]/panorama/route.ts` 从 412 行降至 20 行，系统超过 300 行的存量 API 从 6 个降至 3 个。
- 扩展物料/BOM 模块守卫，限制全景 API、查询服务与附件服务规模，并加入附件分类回归样例。

## 影响范围

- 保留物料全景接口的 URL、响应 `data` 结构、权限资源、404 与通用错误状态。
- 不修改 Prisma 模型、数据库迁移、物料资料或服务器正式数据。

## 验证结果

- 物料/BOM 模块、模块边界、高级搜索、页面注册、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有的图片与 Hook 依赖警告。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
