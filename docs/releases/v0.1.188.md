# MES-lite v0.1.188

发布日期：2026-08-05

## 更新内容

- Next.js 生产构建启用 standalone 输出，Docker 运行镜像不再复制整套生产 `node_modules` 和完整 `.next` 目录。
- 运行镜像仅额外保留数据库迁移所需的 Prisma CLI、Prisma 引擎，以及 PDF 缩略图子进程所需的原生 Canvas 包。
- 容器启动改为直接运行 Prisma CLI 和 standalone `server.js`，不再依赖 `npx` 和 `next start`。
- 增加 Coolify 在 `exporting layers` 阶段失败的诊断与主机空间清理指引。

## 影响范围

- 仅影响 Docker/Coolify 镜像构建、镜像导出和容器启动方式。
- 不修改 Prisma schema、数据库迁移、业务流程、页面或 API 契约。
- SQLite 数据和上传文件的持久化挂载方式不变。

## 验证结果

- Next.js 生产构建成功生成 standalone 输出。
- standalone 服务目录约 94 MB，对比本地完整 `node_modules` 约 632 MB。
- 已检查 standalone 服务器、Prisma Client、PDFKit 和原生 Canvas 的运行依赖边界。
- 当前本机没有 Docker CLI，无法本地执行最终镜像构建；需以 Coolify 下一次详细构建日志完成镜像导出验收。
