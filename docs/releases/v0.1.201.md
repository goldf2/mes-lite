# MES-lite v0.1.201

发布日期：2026-08-06

## 更新内容

- 新增正式公共资源页面骨架，统一搜索、筛选、列表/卡片、加载、空状态、错误反馈、新增、连续详情、同容器编辑和归档交互。
- 新增自适应主从工作区：宽屏左右分区可调宽，窄屏支持列表弹窗、上下分区和列表/详情切换，并提供可移动的左右边缘呼出按钮。
- 页面工具在手机端收进右侧非全屏弹窗，搜索、筛选、布局和页面操作支持连续使用；布局设置不再单独占用页面空间。
- 新增一对一、一对多、多对一关系字段以及统一实体搜索适配器；产品文档实验页已使用一对多模块关联多个物料。
- 新增柔和、标准、高对比三种系统级页面对比度配色，统一调整背景、容器、边框、标题、正文和辅助文字，保持按钮与业务状态颜色语义不变。
- 修复主从分隔线刷新跳动、搜索选择鼠标提交时序和弹层层级问题，并补充公共模块调用与开发规范。

## 影响范围

- 新增 `resource`、`relations` 和自适应 `layout` 公共模块，后续资源型页面应优先迁移和复用。
- 系统设置 API 新增 `contrastMode`，使用现有键值设置表保存，无需数据库迁移。
- 新增独立实验入口 `/resource-framework-lab`，只使用内存模拟数据，不写业务记录。
- 不改变现有业务 API、BOM 计算、库存、生产、销售和文档数据模型。

## 验证结果

- 公共资源实验页完成宽屏与窄屏浏览器验证，覆盖三种紧凑布局、可移动呼出按钮、工具弹窗、筛选、列表/卡片、详情编辑和多物料关系。
- 柔和、标准和高对比模式均完成浏览器切换与刷新持久化验证；高对比模式不改变蓝色主按钮和业务状态色。
- TypeScript、ESLint、生产构建、差异空白检查和版本文档校验通过；ESLint 仅保留项目既有警告。
- `package.json`、`package-lock.json`、版本文档和发布索引均为 `v0.1.201`。
