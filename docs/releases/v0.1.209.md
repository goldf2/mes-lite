# MES-lite v0.1.209

发布日期：2026-08-06

## 更新内容

- 公共显示模式切换器改用 Finder 风格分段图标，替换原有字符图标和重复文字。
- 统一“图标、列表、分栏、画廊”四种显示模式语义，并为图标按钮保留中文提示和可访问名称。
- 当前资源页面继续只显示已经实现的图标与列表，不出现无法工作的分栏或画廊按钮。
- 页面选项中的单列折叠与双列导航增加对应布局图标。

## 影响范围

- 调整全部复用 `ViewModeToggle` 的资源、订单、库存、文档和配置页面外观，不改变已有卡片/列表状态值和浏览器偏好。
- 新增的分栏与画廊只是公共组件能力声明，业务页面未实现对应正文布局前不会显示。

## 验证结果

- TypeScript、Lint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证图标/列表切换、选中状态、提示文字，以及页面选项中的导航布局图标。
