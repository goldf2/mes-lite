# MES-lite v0.1.178

发布日期：2026-08-04

## 更新内容

- Docker 安装 Poppler 时默认使用阿里云 Debian 镜像，避免 `deb.debian.org` 在部署服务器上长时间超时。
- APT 索引和安装包接入 BuildKit 持久缓存，失败重试和后续构建可复用已下载内容。
- 为 APT 下载设置有限重试和超时，减少镜像不可用时的无效等待。

## 影响范围

- 只影响 Coolify/Docker 构建中 Poppler 的系统依赖安装阶段。
- PDF 缩略图的生成逻辑与业务数据不变。
- 可通过 Docker 构建参数 `DEBIAN_MIRROR` 替换默认镜像地址。

## 验证结果

- 部署日志确认失败点为 `deb.debian.org` 连接超时，非 Next.js 构建错误。
- Dockerfile 使用的 BuildKit 缓存指令与项目现有 `docker/dockerfile:1.7` 语法一致。
- 版本文档校验、TypeScript 类型检查和 Next.js 生产构建通过。
