# v0.1.370 设备周期点检与全屏帮助

发布日期：2026-08-14

## 更新内容

- 新增设备点检页面、到期/逾期/异常任务、周期计划、完整项目清单、逐项执行、暂停/恢复和最近记录。
- 新增四张点检事实表及 SQLite 不变式：计划/项目不可覆盖，记录/结果不可修改删除，完整清单、异常说明和汇总结果由服务与数据库共同保护。
- 异常点检在设备可用或运行中时同事务创建故障事件；记录支持现场附件，并按工作中心数据范围过滤。
- 新增第 50 个权限资源 `equipmentInspections`、设备维护岗位预置、旧角色/组/个人覆盖递归继承和真实 HTTP 越权回归。
- 快捷帮助增加“新页面全屏查看”；“打开完整帮助中心”同样在新页面打开。两个入口保留登录保护和服务端 SOP 权限过滤，不中断当前业务操作。
- SOP 增至 148 个流程，新增 6 个真实浏览器流程截图，并重生成 Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 数据库：新增 `EquipmentInspectionPlan`、`EquipmentInspectionPlanItem`、`EquipmentInspectionRecord`、`EquipmentInspectionResult`，迁移总数为 78。
- 页面/API：新增 `equipmentInspections` 页面键和 3 条 Route Handler，当前为 43 个页面模块定义、135 条 API、82 个模型、50 个权限资源。
- 权限：新安装设备维护组获得点检 RCU 和附件 RCUA；升级安装从已有设备事件/设备设置继承且不覆盖已有新资源设置，部署后必须复核。
- 帮助：新增 `/help` 登录保护页面；原工作区内帮助中心继续保留。
- 不包含：设备保养、维修工单、备件、自动产量采集和 OEE。

## 验证结果

- Prisma validate/generate、全量 78 迁移从零重放通过。
- 设备点检领域与真实 HTTP 回归通过：工作中心范围、权限 403、正常/异常、幂等、不可变事实、故障联动、审计和附件授权均符合契约。
- 全屏帮助回归通过：两个新页入口、`noopener` 隔离、登录保护、页面定位和同源权限过滤均生效。
- 真实本地浏览器完成到期任务、新建计划、逐项点检、异常记录、快捷帮助入口和全屏帮助页截图。
- SOP、开发文档、发布说明、类型检查、Lint、CI 领域基线和生产构建在提交前执行。

## 部署与回滚

1. 部署前固定精确提交，完成 SQLite 与附件一致备份并校验。
2. 应用启动执行第 78 个迁移；用设备维护岗位验证授权工作中心内的计划、执行、异常联动和附件。
3. 复核既有岗位继承出的 `equipmentInspections` 和 `attachments`，不把兼容继承视为审批结论。
4. 应用回滚时固定到上一个已验证提交；保留四张新增表和事实记录，旧代码会忽略它们，不执行破坏性降级。
5. 只有迁移/数据库损坏且应用回滚无效时，才经业务确认恢复部署前一致备份；恢复后重新验证登录、设备事件、点检连续性和附件。
