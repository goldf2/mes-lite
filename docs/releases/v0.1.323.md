# MES-lite v0.1.323

日期：2026-08-10

## 更新内容

- 将单位新增、修改、删除输入契约，身份判等、同量纲编码判重、语义变更规则，以及目录/使用量查询和写入事务集中到 `modules/configuration`。
- `/api/system/units` 从 228 行降至 79 行，只保留登录/权限、Schema、服务调用、审计和 HTTP 错误映射，不再直接访问 Prisma、读取设置 JSON 或计算引用数量。
- 直接访问 Prisma 的 Route Handler 从 33 条降至 32 条；14 个领域/平台模块共有 287 个 TypeScript 文件。
- 单位查询只读取一次物料与 BOM 引用快照并统一装配三类使用量，修改和删除共用同一身份规则。

## 影响范围

- 既有 `/api/system/units` URL、GET/POST/PATCH/DELETE、`system:update` 权限、审计动作和响应结构保持兼容。
- 预置单位仍不可修改或删除；已被物料或 BOM 使用的自定义单位仍只允许修改显示名称，不能改变编码、量纲、换算系数或删除。
- `lib/unit-catalog.ts` 继续作为物料、BOM 和排序共用的目录读取/换算基础能力；单位写入生命周期由配置领域唯一拥有。
- 本版本不修改 Prisma Schema、迁移、页面结构，不自动改写本机测试数据或服务器正式数据。
