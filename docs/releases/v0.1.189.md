# MES-lite v0.1.189

发布日期：2026-08-05

## 更新内容

- 新增“销售”一级业务模块，包含销售订单、发货管理和退货管理。
- 销售订单支持一个客户、多项物料、数量、库存单位、单价、客户订单号、订单日期和计划交付日期。
- 新建发货单必须选择已确认销售订单的未发明细；支持分批发货，待发货单占用可发数量，确认发货后回写已发数量及订单状态。
- 发货单 PDF 增加甲方客户、乙方供货方、销售订单号、客户订单号和双方签收栏；乙方企业资料可在“配置 / 系统设置”维护。
- 新增产品文档的首个弹窗支持直接点击或拖放选择多张图片/PDF，保存文档后自动上传并关联附件。

## 影响范围

- 新增 `SalesOrder`、`SalesOrderItem` 数据模型，并为 `Shipment` 增加销售订单及明细关联。
- 新增销售订单查询、创建、确认、取消、选项和待发明细 API；发货创建接口不再接受独立手填客户、物料和单价。
- 新增 `salesOrder` 权限资源；录入角色可查看/创建，审核角色可确认和取消，管理员拥有完整权限。
- 历史发货单关联字段保持可空，仍可查看、签收、下载 PDF 和用于退货。
- 同步更新销售、发货、页面导航、数据模型和桌面/移动交互文档。
