# MES-lite v0.1.220

发布日期：2026-08-07

## 更新内容

- 移除物料页遗留的独立“筛选”按钮，将分类、客户和 BOM 状态收进搜索框旁的“高级搜索”。
- 精确筛选条件可以与关键词一起保存为快捷搜索，并可从快捷搜索直接恢复。
- 在物料管理和 BOM 设置各自的顶部工具栏恢复“页内选项”入口。
- 物料页的排序、字段显示、BOM 简况和列宽恢复统一归入页内选项。
- BOM 页内选项继续保留默认长度单位和默认重量单位，不再依赖应用外层的页面状态判断。

## 影响范围

- 只调整物料管理和 BOM 设置的搜索、筛选与页内选项交互，不修改数据库结构或业务数据。
- 视图模式仍保留在顶部工具栏，便于高频切换；低频显示配置进入页内选项。

## 验证结果

- TypeScript、ESLint、公共搜索与页面模块校验通过。
- Next.js 生产构建通过。
