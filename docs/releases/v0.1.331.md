# MES-lite v0.1.331

日期：2026-08-10

## 更新内容

- 将附件上传/预览、在线文档编辑、生产实绩、配置排序、数据一致性、图片优化、物料选择、工作台和显示设置组件从 `app/components` 根目录迁回所属模块。
- 为生产实绩、配置排序、数据维护、AI 识别、身份认证、AI 助手和工作区导航补齐模块 client；页面、组件和 UI Hook 不再直接调用 `fetch`。
- 将配置排序类型移入 contracts，跨领域 UI 只通过模块 `index.ts` 公开入口复用；所属模块内部使用相对路径，避免公开入口循环依赖。
- 新增 `verify:structural-goal`，固定 Route Handler、UI 请求、根组件、页面/路由体量和模块公开入口的停止线。

## 影响范围

- 不修改页面入口、视觉布局、交互结果、权限资源、API URL、Prisma Schema 或数据库迁移。
- 附件、AI 识别、生产实绩、配置排序、工作台、身份认证和导航仍使用原有接口与响应语义。
- 本机 `prisma/mes_lite.db` 和服务器正式数据均未改写。

## 结构验收

- 15 个领域/平台模块，共 386 个 TypeScript 文件，均保留唯一公开入口。
- 114 条 Route Handler 中 0 条直接访问 Prisma，0 条超过 300 行。
- 38 个页面全部使用公共顶部工具栏，归纳为 6 类公共页面骨架，0 个明确例外。
- 页面、组件和 UI Hook 直接 HTTP 请求为 0；`app/page.tsx` 为 5 行，`SystemPage.tsx` 为 31 行，超过 800 行的页面为 0。
- `app/components` 根目录只保留应用壳和跨领域公共组件；领域组件不得回流。
