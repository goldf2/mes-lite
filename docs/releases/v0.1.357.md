# MES-lite v0.1.357

日期：2026-08-13

## 更新内容

- 新增跨工单“质量任务”工作台，集中显示待检、待处置与全部记录，支持按检验单、内部批次、物料及来源单据搜索。
- 质量判定新增部分放行/冻结；库存、库位、批次余额和成本层按数量拆分，同时保持数量与成本守恒。
- 新增复检、转返工、返工完成送检、质量报废、让步放行和解冻放行；返工完成必须重新进入待检，不能直接成为可用库存。
- 新增不可覆盖的 `QualityDisposition` 处置历史、检验轮次与父子检验关系；每次动作同时写批次交易、库存流水、操作人和原因/审批依据。
- 库存增加 `REWORK` 状态及返工数量、核算量和成本；返工中、待检和冻结库存不参与普通领料、发货或调整，生产冲销阻断已拆分或已处置批次。
- 权限拆分为质量任务查看、质量判定、复检/返工/报废处置、让步/解冻放行四层服务端资源。
- 使用隔离临时演示库完成真实浏览器操作，新增 18 张质量处置截图；全流程作业指导书扩展为 106 个流程、108 页 Markdown/DOCX/PDF 交付物。

## 影响范围

- 加性迁移 `20260814100000_add_quality_dispositions` 为 `Stock`、`StockLocationBalance` 和 `QualityInspection` 增加返工及检验轮次字段，并新建 `QualityDisposition`；现有业务数量默认不变。
- `AVAILABLE / QUARANTINE / HOLD / REWORK / SCRAPPED` 成为批次状态守恒口径。质量报废是本切片唯一减少总库存与批次成本的处置，其余动作只在状态间转换。
- 现有管理员仍拥有全部权限；普通操作员默认无质量权限。审核员默认权限仅作为兼容基线，生产上线前必须按真实岗位审批拆分检验、处置与授权放行。
- 本地临时数据、截图和升级基线不等于真实 Coolify 部署完成；生产迁移、权限配置、持久卷备份和真实业务验收必须在服务器维护窗口完成。

## 回滚

新结构尚未产生业务数据时，可以回退应用代码并保留加性字段与空表。只要已经出现部分判定、复检、返工、报废、让步或解冻记录，就不能删除新增结构，也不能运行不认识 `REWORK` 状态的旧应用。需要停止质量和库存写入，保留数据库与附件一致备份，以前滚方式修复。生产迁移前必须创建可验证备份；恢复只能生成非覆盖候选，并重新核对迁移账本、`PRAGMA quick_check`、各库存状态合计、批次成本和质量处置历史。
