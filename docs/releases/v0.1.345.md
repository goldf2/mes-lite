# MES-lite v0.1.345

日期：2026-08-12

## 更新内容

- 建立附件所有者策略与服务端鉴权服务，统一映射物料、产品文档、来料、生产订单、派工、销售订单、发货、退货和流程转移。
- 附件列表、上传、文件、预览、缩略图、图片派生、更新、归档和 AI 单据识别同时校验附件动作权限、所属业务资源权限与业务对象存在性。
- 暂存附件保存当前登录账号 ID，只允许创建者读取、绑定或清理；附件客户端不再提交 `uploadedBy`。
- Middleware 阻断 `/uploads/*` 静态直读，附件原文件只能通过受保护的 `/api/attachments/*` 返回。
- 生产实绩、流程转移、旧生产日报、来料收货/红冲、发货、退货处理、成本记录和兼容领料/入库统一从服务端会话取得操作人，不再接受客户端覆盖审计身份。
- 新增《MES-lite 系统分阶段治理总目标》，明确安全、模型、MES 闭环、角色工作区和商业交付五阶段停止线。

## 影响范围

- 不修改 Prisma Schema，不改变库存、成本和业务状态计算。
- 已归档或不存在的业务对象不能继续新增或读取附件；未知 `ownerType` 被拒绝。
- 业务表单中的实际员工、收货人和发货人仍可作为业务信息保留，但库存流水和状态确认身份固定为当前登录账号。
- Git 历史中的 SQLite 清理、认证加固和备份恢复仍属于阶段 0 后续切片，本版本未执行破坏性历史改写。

## 验证结果

- 附件生命周期、对象级权限、暂存账号隔离、静态目录阻断和 AI 识别边界回归。
- 可信操作人结构守卫，以及生产实绩、流程转移、旧生产日报、来料、销售履约、旧生产执行和成本领域临时数据库回归。
- Prisma Schema、TypeScript、ESLint、模块边界、开发文档、发布记录和生产构建验证。
