# MES-lite v0.1.337

日期：2026-08-10

## 更新内容

- 新增独立 HTML 版 MES 业务泳道，使用阶段列和角色泳道展示需求、计划、备料、生产、质量、处置和交付全过程。
- HTML 页面支持宽屏完整矩阵、窄屏横向滚动、打印或导出 PDF，并区分当前能力、下一阶段和后续能力。
- 新增可直接导入 Excalidraw 的 `.excalidraw` 源文件，泳道、节点、文字和箭头均可继续编辑。
- 文档中心和 Markdown 架构文档增加 HTML 与 Excalidraw 入口。

## 影响范围

- 仅新增静态展示和可编辑图稿，不修改页面注册、API、权限、Prisma Schema、迁移或业务数据。
- HTML 由 Next.js `public` 目录直接提供，不增加运行时依赖或外部 CDN。

## 验证结果

- `node` JSON 解析校验 Excalidraw 文件
- `npm run verify:development-docs`
- `npm run verify:release-notes`
- 本机浏览器宽屏展示与响应式样式检查
- `git diff --check`
