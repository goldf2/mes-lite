# MES-lite v0.1.319

日期：2026-08-10

## 更新内容

- 在 `modules/configuration` 增加往来单位输入契约、资源差异定义、领域错误、公共资料服务和 HTTP 适配器。
- 供应商和客户共同复用多关键词搜索、输入清理、默认排序、新增、更新、归档及审计流程；保留供应商/客户各自的编码规则，以及客户有效名称唯一规则。
- `/api/suppliers` 与 `/api/customers` 从合计 331 行降为各 6 行的资源声明，不再直接访问 Prisma。
- 直接访问 Prisma 的 Route Handler 从 42 条降至 40 条；14 个领域/平台模块共有 258 个 TypeScript 文件。

## 影响范围

- 页面、API URL、请求字段和响应形状保持兼容，供应商与客户前端继续共用 `PartySettingsPage` 和公共 `ResourcePage`。
- 供应商新增和更新现在与客户一致写入操作审计；归档仍可从归档记录恢复。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
