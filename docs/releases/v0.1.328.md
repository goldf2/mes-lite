# MES-lite v0.1.328

日期：2026-08-10

## 更新内容

- 将成本能力按现有领域边界拆分：BOM 可引用成本对象归 `modules/bom`，锯切成本方案归 `modules/operations-tools`，工单成本记录与统计归 `modules/production`。
- 5 条成本 Route Handler 均移除 Prisma 查询、写入和事务，只保留权限、输入校验、领域服务、请求级审计及 HTTP 响应。
- 保持锯切方案、分项成本和 BOM 可引用成本对象在同一事务中创建；成本对象首版成本也由 BOM 命令服务一次写入。
- 新增 `verify:cost-domain-services`，使用运行后删除的临时完整 SQLite 验证三个领域的真实服务边界和数据生命周期。

## 影响范围

- 不修改页面入口、交互、权限资源、Prisma Schema 或迁移。
- 页面继续通过原有 BOM 与锯切 client 调用相同 URL；API 响应结构保持不变。
- 本机 `prisma/mes_lite.db` 和服务器正式数据均未改写。

## 结构影响

- 直接访问 Prisma 的 Route Handler 从 26 条降至 21 条。
- `modules/` 保持 15 个领域/平台目录，共 331 个 TypeScript 文件。
