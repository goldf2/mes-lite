# MES-lite v0.1.222

发布日期：2026-08-07

## 更新内容

- 将顶部工具栏统一为关键词搜索、高级搜索、视图方式、页内选项和业务操作五类公共槽位。
- 高级搜索、视图方式和页内选项统一使用图标按钮；页面专属排序、显示字段等设置继续保留在页内选项中。
- 支持按页面调整五类工具的排列顺序，并仅保存在当前浏览器。
- 不支持搜索、高级搜索或视图切换的页面默认显示禁用占位，避免切换页面时工具位置跳动。
- 在页内选项中新增“显示不可用工具占位”开关，可按页面隐藏这些禁用控件。
- 将 36 个登记页面全部纳入强制公共顶部工具栏契约，移除原有例外。

## 影响范围

- 仅调整公共前端工具栏、页面偏好和界面规范，不修改数据库结构及业务数据。

## 验证结果

- TypeScript、ESLint、页面模块契约和公共搜索回归校验通过。
- 在数据工具页验证禁用占位开关，在物料页验证搜索、高级搜索、视图、页内选项和业务操作槽位。
- Next.js 生产构建通过。
