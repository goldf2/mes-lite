# MES-lite v0.1.256

发布日期：2026-08-09

## 更新内容

- 销售订单中的“生成发货单”改为在当前页面打开弹窗，不再先跳转到发货管理。
- 弹窗自动带入当前销售订单，并预选可发货明细、推荐有可用库存的库位和剩余数量。
- 发货管理与销售订单复用同一个 `ShipmentCreateDialog`，附件、AI 识别、库存提示、提交校验和 PDF 输出保持一致。
- 开发规范新增关联单据规则：跨页面生成默认复用目标模块的公共创建弹窗，成功后刷新来源页面。

## 影响范围

- 不修改数据库结构、发货接口、库存扣减规则、权限或既有单据数据。
- 发货管理原有“新建发货单”入口保持不变，仅将内部表单收敛到公共组件。
- 其他页面后续增加“生成关联单据”入口时必须调用目标单据的公共弹窗，禁止复制表单。

## 验证结果

- 关联单据弹窗静态契约、业务单据打印、38 个页面模块契约和 TypeScript 类型检查通过。
- Next.js lint 通过，仅保留仓库已有的图片与 Hooks 警告。
- 本地浏览器验证桌面与 390px 窄屏弹窗：标题和底部操作固定，正文独立滚动，无横向溢出。
