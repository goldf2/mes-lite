# v0.1.494 宇峰平台紧凑应用与功能总览

## 问题与结果

原宇峰平台首页主要是两张大型应用卡片和收藏空白区，具体功能需要再次进入目录，首屏可访问内容不足。本版增量合入 Gemini 的三个候选组件，改为紧凑应用入口、业务领域筛选、真实功能矩阵及个人常用/高频入口，继续使用既有注册表、权限结果和偏好服务。

本版本为本地已验证、尚未发布的候选。静态与专项检查 10/10 通过，隔离真实 Next 浏览器的 26 项必需检查已有首轮 25 项与最后一项定向补验的证据；不是一次连续全通过。精确候选 CI、main 合入和生产发布仍待完成，不能将本地结果称为线上验收。

## 更新内容

- 合入并适配 `PlatformOverviewPage.tsx`、`WorkspaceFunctionCatalog.tsx`、`BusinessWorkbenchPage.tsx`。平台保留 MES Lite 与客户管理两个真实应用，小型入口可直接进入原应用；最多九个已授权业务领域提供筛选与专注视图，具体业务页通过既有 `onOpen(functionKey)` 打开。
- `>=1280px` 为左导航、中功能矩阵、右常用/高频三栏；`1024–1279px` 左导航跨行，右侧先常用/高频、后矩阵；手机单列按应用与领域、常用/高频、功能矩阵排列，避免常用区被完整目录推到页面末尾。
- 公共 `WorkspaceFunctionCardGrid` 供矩阵、搜索分组和收藏复用，支持紧凑密度、说明显示和容器列数。搜索继续使用桌面 `TopBarPortal` 与手机标题下整行检索，触控区域至少 36px，紧凑导航推荐 40px。
- 分区切换与“返回全部总览”使用 `resetSearch` 同时清除关键词与高级条件；收藏继续保存到既有当前人员偏好。高频最多五项，按使用次数降序、同频按最近使用时间降序，不另建最近访问数据或新偏好服务。
- 原 MES 首页、岗位任务、统计、完整本地侧栏与业务深链保留；平台矩阵内 55 个具体功能加独立 MES 首页入口共 56 项注册功能，仍来自同一个已授权目录。BOM 的 `section` 与数据平台地图的 `next/map/layers` 精确参数保持。

## 影响范围

本轮没有业务流程、API 入出参、权限资源、数据库模型、迁移、认证配置、人员绑定或历史单据变更。两个代码库和数据平台独立部署继续保留，不合并数据库、不代替目标应用授权，也不宣称共享联系人、MES 订单统计上图或跨域全局退出已经完成。原 MES 与平台域的 host-only 会话规则不变。

收藏、高频、领域和辅助工具均与当前已授权目录取交集；历史收藏不能恢复失权入口。加载或保存偏好期间沿用原禁用行为。业务 API 仍执行原权限校验，入口显示不构成授权。
