# MES-lite v0.1.159

发布日期：2026-08-04

## 更新内容

- BOM 多产出改为逐项确认流程：选择产出物料后，先填写基准数量，再确认加入明细。
- 当前候选产出未确认前锁定物料选择器，避免连续选择导致上一项沿用默认数量。
- 首项主产出和后续其他产出使用同一规则；数量为空、无效或不大于 0 时不能确认。
- 确认加入后自动清空候选并重新开放下一项选择，已加入产出仍可逐项修改数量或移除。

## 影响范围

- 仅影响 BOM 编辑器的产出录入交互和待保存草稿。
- 不修改 BOM 数据结构、保存接口、生产订单或库存逻辑。

## 验证结果

- TypeScript 类型检查通过。
- 浏览器验证未填写数量时确认按钮禁用，且候选未确认时不能继续选择下一项。
- 浏览器验证首项主产出数量和其他产出数量在确认后准确加入待保存明细。
- 发布说明、Docker 依赖检查及生产构建通过。
