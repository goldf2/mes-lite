# MES-lite v0.1.167

发布日期：2026-08-04

## 更新内容

- 页面选项齿轮提升为全局入口，桌面端和移动端的所有页面均可打开；通用选项包含弹窗磨砂遮罩。
- BOM 设置页的页面选项可配置新建 BOM 和新添加明细的默认长度、重量录入单位。
- 可选项直接读取系统单位目录，支持 `m/cm/mm`、`kg/g/t` 和相应的自定义单位。
- 初始偏好保持长度 `mm`、重量 `g`；设置保存在当前浏览器，不影响其他终端。
- 修改默认单位不会改写当前草稿、历史 BOM、库存单位或已经保存的标准数量。
- BOM 投入、产出行扩大数量输入区并显示物料缩略图，点击图片可居中放大查看；所有输出都可移除，移除主产出时自动提升下一项产出。

## 影响范围

- 全局顶栏、BOM 新增行默认单位、BOM 明细布局和当前浏览器页面偏好。
- 不涉及数据库迁移、库存流水、生产订单或 BOM 标准数量结构。

## 验证结果

- 单位目录脚本覆盖用户默认单位、系统回退值和无效偏好回退。
- TypeScript 类型检查与 Next.js 生产构建通过。
- 浏览器验证桌面和窄屏下全局页面选项弹窗、偏好保存、新行默认单位、输出移除和图片预览生效。
