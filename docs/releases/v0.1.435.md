# MES-lite v0.1.435

发布日期：2026-08-24

## 更新内容

- 生产日报改为先选择现场已知的投入物料，再反查包含该投入的已发布 BOM。
- BOM 候选同时显示主产出、方案名称和版本；只有一个候选时自动选中，多个候选时要求操作人员明确选择。
- 选定 BOM 后仍展开并过账该版本的全部投入，不把反查物料误当成唯一投入。

## 业务边界

- 这只是快捷日报的选择顺序调整；BOM 发布、版本不可变、日报快照、库存和成本事务规则不变。
- 服务端继续校验 BOM 属于确定的主产出、全部实际投入均来自所选 BOM，且来源库位库存充足。
- 不创建生产订单、派工或报工；需要人员、设备、作业文件和完整生产履历时仍使用生产订单实绩。

## 影响范围

- 影响生产日报选择交互、生产领域响应契约归属和投入反查纯视图规则。
- 不新增 API、权限资源、Prisma 模型或数据库迁移。
- 复用现有 `SearchableSelect`、生产领域 client 和快捷日报原子过账服务。

## 验证结果

- 投入物料去重、按投入反查 BOM 与主产出映射进入纯规则回归。
- 临时完整 SQLite 回归继续覆盖正式 BOM、直接/待检入库、质量放行、冲销、成本审计和失败整单回滚。
- TypeScript、Lint、发布说明及精确候选提交由本版发布门禁验证。

## 回滚说明

- 本版无数据库迁移，可回滚到 `v0.1.434`；已经确认的日报和库存流水不受界面选择顺序影响。
