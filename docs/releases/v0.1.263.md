# MES-lite v0.1.263

发布日期：2026-08-09

## 更新内容

- 移动端左侧功能抽屉直接挂载桌面 `DesktopNavigation` 的单列折叠模式，不再保留独立的移动菜单排版。
- 移动抽屉增加与桌面一致的功能搜索，一级菜单默认只展开当前页面所属分组，点击其他一级菜单时切换分组。
- 二级页面统一显示图标、名称、选中状态与排序提示，显示模式继续读取同一系统设置。
- 移除移动抽屉中重复的“底部常用入口”管理区；底部常用导航仍保留在应用底栏。
- 扩展响应式导航校验，禁止移动端恢复为默认全部展开的独立菜单。

## 影响范围

- 影响低于 `1024px` 的左侧功能抽屉。
- 不改变桌面导航、移动底部常用入口、页面归属、顺序、权限、路由和业务数据。

## 验证结果

- 响应式导航、工作区导航和工作区设置校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。
