# MES-lite v0.1.352

日期：2026-08-12

## 更新内容

- 为 `scripts/runtime-backup.mjs` 增加 `drill` 命令，将备份验证、非覆盖候选恢复、RPO/RTO 计算和 Markdown 证据合并为一条可重复命令。
- 演练报告与候选目录都必须是不存在的新路径；拒绝覆盖历史报告或当前运行数据。
- RPO/RTO 未达到阈值时仍保留报告，但命令返回非零状态，便于定时任务和 CI 告警。
- 报告明确区分“恢复候选技术验收”和“新实例应用验收”，不会把未执行的 readiness、登录、业务单据和附件抽查标记为完成。
- 扩展运维回归，覆盖报告内容、报告防覆盖、RPO 阈值失败和恢复候选附件一致性。

## 本机演练证据

- 对本机演示型 SQLite 创建一致快照并恢复到新候选目录，源数据库和上传目录未被覆盖。
- SQLite `quick_check=ok`，4 条附件引用与 21 个归档文件通过清单和 SHA-256 校验。
- 候选 RPO 为 255.695 秒，候选 RTO 为 0.195 秒，均达到 24 小时 / 60 分钟目标。
- 本机未安装 Docker，未执行新容器 readiness、登录和业务抽查；[演练记录](../operations/drills/2026-08-12-local-isolated-v0.1.352.md)对此保持未完成标记，因此本版本不宣称生产恢复演练完成。

## 影响范围

- 不修改 Prisma Schema，不迁移或批量改写业务数据。
- `.runtime/drills/v0.1.352` 中的归档和恢复候选受 `.gitignore` 排除，仅提交不含业务明细的演练报告。
- Coolify 的实际异地副本、部署环境恢复和真实 RPO/RTO 仍需在生产维护窗口完成。
