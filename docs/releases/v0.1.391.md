# v0.1.391 恢复左侧感应呼出

日期：2026-08-16

## 更新内容

- 自动隐藏左栏恢复鼠标感应呼出，感应范围为顶部栏以下页面最左侧 `30px`。
- 感应带停留约 160 毫秒后打开，短暂掠过不会误触；鼠标移入菜单后保持显示，移出菜单约 320 毫秒后收回。
- 悬停呼出与点击呼出使用独立状态：点击呼出的菜单不会因鼠标移出而关闭，再次点击、点击页面空白处、导航成功或按 `Esc` 后收回。
- 左上角导航按钮继续只响应点击，避免与左侧感应带产生重复触发。
- 常驻和自动隐藏状态继续使用相同的导航按钮、产品模块按钮、侧栏尺寸和菜单外观。

## 影响范围

- 影响桌面标准管理布局的自动隐藏导航和“系统设置 → 显示设置”说明。
- 更新 SOP 流程 `55-display-settings`。
- 不改变移动端导航、画布工作布局、业务页面、HTTP API、权限资源、数据库模型或迁移。

## 验证结果

- 静态回归覆盖 30px 感应带、悬停/点击三态、进入菜单保持、移出延时收回和固定入口一致性。
- 本地页面确认感应带已挂载，点击呼出、点击锁定、空白处收回及固定切换保持可用。
- 类型检查、导航专项验证、Lint 和生产构建通过。

## 回滚

本版本没有数据库迁移。代码可回退到 v0.1.390；浏览器中已保存的常驻/自动隐藏偏好仍可被旧版本读取。
