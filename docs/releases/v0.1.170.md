# MES-lite v0.1.170

发布日期：2026-08-04

## 更新内容

- 物料管理恢复 BOM 简况列和卡片摘要，有 BOM 查看权限时可按浏览器偏好显示或隐藏。
- 物料行与卡片操作区新增“创建 BOM”，进入 BOM 设置后自动将当前物料预选为主产出。
- 高级筛选新增 BOM 状态，可准确查找未建立产出 BOM、有 BOM 但无启用方案、有启用方案但无默认方案，以及已有可用默认 BOM 的物料。
- 物料导出同步应用 BOM 状态条件，保证列表筛选与导出范围一致。

## 影响范围

- 影响物料管理列表、卡片视图、高级筛选、CSV 导出和物料到 BOM 设置的页面跳转。
- BOM 简况与创建入口受现有 BOM 关系权限控制；无 BOM 权限的用户不会看到相关数据和操作。
- 不改变 BOM 数据结构、批量换算口径、生产订单快照或库存过账逻辑。

## 验证结果

- TypeScript 类型检查通过。
- BOM 状态筛选专项数据验证通过，四种状态均能返回准确物料。
- Next.js 生产构建和页面交互验证通过。
