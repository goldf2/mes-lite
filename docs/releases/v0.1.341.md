# MES-lite v0.1.341

日期：2026-08-12

## 更新内容

- 物料搜索发起新查询时主动取消上一轮请求，并只允许当前最新请求更新卡片或列表，避免快速输入时旧结果覆盖新关键词。
- 搜索请求等待期间显示“正在筛选物料”，不再继续展示上一轮结果。
- 无匹配数据时区分于“暂无物料”，显示“没有匹配的物料”并提供清除搜索条件入口。
- 非取消类请求失败时清空误导性的旧结果，并继续通过公共消息反馈错误。

## 影响范围

- 复用现有智能多关键词搜索、公共工具栏和 `AppLoadingIndicator`；搜索字段、API 参数、权限和数据库结构均未改变。
- 物料列表 client 增加可选 `AbortSignal`，现有调用保持兼容。
- 同步补充公共界面规范：所有服务端列表搜索必须遵守“最后一次查询生效”。

## 验证结果

- TypeScript 类型检查
- 物料服务和公共多关键词搜索回归
- 浏览器验证无匹配关键词先显示加载态，随后显示无结果与清除入口
- 浏览器验证有效物料编码仅返回对应记录
- 模块边界、开发文档事实基线、发布记录和生产构建
