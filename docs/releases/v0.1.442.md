# MES-lite v0.1.442

发布日期：2026-08-27

## 更新内容

- 发货详情增加明确的状态区与合法下一步：待发货可取消，已发货可确认签收或受控冲销，已签收通过客户退货处理。
- 新增独立“发货冲销”命令、原因弹窗和状态责任人展示；已取消、已冲销记录保持只读审计。
- 发货、签收、取消和冲销分别保存操作人、时间与原因；货箱、客户发货批次和库存流水同步呈现冲销结果。

## 数据与事务

- `Shipment` 增加签收、取消和冲销元数据，状态扩展为 `REVERSED`。
- `ShipmentItem` 保存确认发货时实际消耗的 FIFO 成本层快照。
- `ShipmentLotAllocation` 保存冲销操作人、时间和原因；发货货箱同步进入 `REVERSED`。
- 发货冲销在单一事务中恢复总库存、库位余额、可用量、核算量、库存金额、FIFO 成本层和内部批次余额，追加与原发货流水双向关联的 `SHIPMENT_REVERSE_IN` 反向流水；原发货事实不删除、不覆盖。

## 状态与权限边界

- `PENDING`：可有原因取消，未产生库存反向动作。
- `SHIPPED`：可确认签收；仅在尚未签收且不存在退货依赖时，可由仓库主管有原因冲销。
- `DELIVERED`：禁止直接冲销，实际回流必须建立客户退货单。
- 新增 `shipmentReverse.update` 独立权限。普通仓管、销售跟单和通用编辑账号默认无权执行；既有角色、组和个人例外不自动扩权。

## 兼容与迁移

- 新迁移仅增加可空审计字段与成本层快照，不改写既有发货记录。
- 迁移前未保存成本层快照的历史发货在冲销时建立明确的发货冲销恢复层，不伪造原来料层。
- 退货接收、质量判定和既有发货 PDF/箱码保持兼容。

## 影响范围

- 影响发货详情状态动作、发货状态服务、库存反向服务、发货批次分配、货箱状态和细粒度权限矩阵。
- 新增发货冲销 API 和一项向前兼容数据库迁移；销售订单、退货收货、来料、生产和普通库存调整保持不变。

## 验证结果

- 专用回归覆盖 FIFO 发货与精确恢复、批次/货箱同步、重复冲销、已签收阻断和存在退货时阻断。
- 细粒度权限、岗位任务 HTTP 权限、可信操作人、写接口审计覆盖、发货多明细、退货批次和货箱回归通过。
- Prisma Schema、TypeScript、ESLint、迁移、SOP 和正式候选 CI 由发布门禁验证。

## 回滚说明

- 回滚代码不会删除新增字段，也不会撤销已经确认的发货或冲销事实。
- 如需纠正业务记录，应在当前版本使用合法冲销或退货流程，不直接改数据库状态。
