# MES-lite v0.1.162

发布日期：2026-08-04

## 更新内容

- 移除 BOM 产出的候选确认卡片和“确认并配置转换”前置操作。
- 选择主产出或其他产出后，立即以默认基准数量 `1` 加入明细并定位到该产出的转换模型。
- 产出基准数量可在明细卡片中直接修改，不再需要二次确认。
- 保留逐项录入约束：当前产出至少完成一项投入转换关系后，才可继续添加下一项产出。

## 影响范围

- 物料 BOM 创建与修改工作区的产出录入交互。
- 桌面端、移动端、响应式验收、系统交互及 BOM 流程规范。
- 本次不修改数据库结构、BOM 保存格式或生产换算逻辑。

## 验证结果

- BOM 单位标准用量及长度/重量/数量批量换算专项验证通过。
- Next.js 生产构建与 TypeScript 类型检查通过；仅保留仓库已有 ESLint 警告。
- 服务健康检查返回 `200`。
