# MES-lite v0.1.191

发布日期：2026-08-05

## 更新内容

- BOM 增加“生产 BOM / 包装 BOM”用途；包装 BOM 必须只有一项产出。
- 库存管理增加包装库存穿透，将散装实际库存与整箱等包装物料库存换算为内容物等效总量。
- 库存列表直接显示库位简况，选中库存对象后右侧显示各库位数量、预留、可用量和按库位调整入口。
- 库存工具栏增加可输入筛选的库位条件，卡片视图同步显示库位数量与包装穿透摘要。

## 计算边界

- 包装穿透只读取默认启用的包装 BOM，不展开普通生产 BOM。
- 分类为“包装物”的纸箱、标签等投入不计入内容物等效库存。
- 散件、整箱和库位余额仍按原库存结构独立记账；等效总量只读展示，不写回库存或库存流水。

## 影响范围

- 新增 `BOM.purpose` 字段和数据库迁移，既有 BOM 默认归类为生产 BOM。
- BOM 设置、BOM 全览和库存查询接口返回用途及包装穿透信息。
- 库存页面调整为列表/卡片与库位详情并列的主从结构，不改变现有出入库和成本计算口径。

## 验证结果

- `npm run verify:packaging-inventory` 通过：400件/箱、39箱等效15,600件、两库位等效拆分和包装物排除正常。
- 全新 SQLite 数据库执行全部迁移成功。
- 浏览器验证包装 BOM 用途控件、BOM 列表标识、库存库位主从详情和包装穿透明细正常。
