# MES-lite v0.1.336

日期：2026-08-10

## 更新内容

- 新增《MES 业务泳道与角色参与矩阵》，统一说明销售、计划、仓库、生产、质量、管理和系统自动化之间的责任交接。
- 泳道图覆盖需求、生产订单、派工、领料、生产实绩、检验、库存放行、不合格处置、发货和追溯目标流程。
- 增加角色参与矩阵、当前覆盖范围和下一阶段最小质量闭环，明确泳道节点不等于必须新增独立页面。
- 将下一阶段停止线限制为“生产实绩 → 待检 → 判定 → 可用/冻结库存 → 库存流水”，暂不扩展抽样、SPC、复杂审批、PLC、OEE、APS 或专业 WMS。

## 影响范围

- 仅更新架构、流程和发布文档，不修改页面、API、权限、Prisma Schema、迁移或业务数据。
- 文档基线升级至 v0.1.336，现有 MES 运行行为保持不变。
