# MES-lite v0.1.246

发布日期：2026-08-08

## 更新内容

- 明确区分系统生成单据与外部上传单据：前者以结构化业务数据为正文，后者以主要上传文件为正文来源。
- 公共附件模块统一命名为“附件管理”，集中提供多文件上传、缩略图、内嵌预览、下载和归档。
- 生产订单列表不再直接上传文件，仅展示附件数量摘要；详情页标记“系统生成单据”并提供完整附件管理。
- 来料、发货、退货和派工等交易列表的文件列统一命名为“附件”，现有上传能力保持兼容。
- 多个附件可分别进入“AI 识别”回调，识别服务接入后仍须先生成字段草案并由用户确认。

## 影响范围

- 本次以生产订单作为统一详情骨架的首个垂直切片，不修改业务状态、库存逻辑或附件数据库结构。
- 来料、发货、退货等现有附件上传暂时保持兼容，后续随详情骨架迁移逐页收口。

## 验证结果

- 附件管理、单据原始凭据、文件类型、领域模块及发布文档静态契约通过。
- TypeScript、定向 ESLint 和生产构建通过。
- 浏览器验证生产订单列表只显示附件摘要，详情页显示单据来源，并提供附件上传、预览、下载、归档和 AI 识别入口。
