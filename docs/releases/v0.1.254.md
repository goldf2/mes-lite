# MES-lite v0.1.254

发布日期：2026-08-08

## 更新内容

- 将 MES、MRP、ERP 业务页面从多工作区重复挂载改为唯一工作区归属，避免切换工作区后看到大量相同菜单。
- “系统设置 → 导航与工作区”使用单一“所属工作区”选择器；移动页面时自动从原工作区移除，同时保留自定义显示名称。
- 历史配置存在重复归属时自动规范化：优先收敛到系统默认主归属；只配置在一个工作区时尊重已有归属。
- 默认分类收紧为：生产执行、工程、现场库存和生产配置归 MES；BOM 结构与用量全览暂归 MRP-lite；客户、供应商、销售及发退货归 ERP-lite。
- 系统设置、权限、AI、审计和数据维护仍是应用壳共享能力，不参与三类业务页面归属。

## 影响范围

- 复用现有 `SystemSetting` 配置记录，不新增数据库迁移，也不复制页面、路由、权限或业务数据。
- 页面显示名称现在跟随其唯一所属工作区；页面移动后名称继续保留。
- MRP-lite 不再重复展示 MES 和 ERP 页面；后续净需求、缺料、齐套和建议单应建设为独立 MRP 页面。

## 验证结果

- 工作区默认分类与每个业务页面唯一归属验证通过。
- 旧版重复配置自动收敛、单一自定义归属保留验证通过。
- 工作区配置数据库持久化、显示名称和顺序验证通过。
- TypeScript 类型检查与生产构建通过。
