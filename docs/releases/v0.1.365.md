# MES-lite v0.1.365

发布日期：2026-08-13

## 更新内容

- 增加原生“帮助中心”和顶部当前页面问号抽屉，按页面及登录账号读取权限展示 SOP。
- 将 138 个既有流程从 Python 硬编码迁移到 `sop/manifest.json` 单一内容源，新增 2 个帮助操作流程，共 140 个。
- 增加受权 SOP 截图接口、页面覆盖校验、版本影响声明和 GitHub Actions 差异门禁。
- 从同一内容源重新生成 140 流程、142 页的 Markdown、DOCX、PDF 与可搜索离线 Web。

## 影响范围

- 增加 `modules/sop`、`/api/sop*`、页面注册项和应用壳帮助按钮；不修改 Prisma Schema、迁移或生产数据。
- 生产 Coolify 继续固定在 v0.1.361，Auto Deploy 继续关闭；本次只推送代码与文档，不自动部署生产。

## 验证结果

- 使用隔离的 `prisma/mes_lite_guide.db` 完成真实 Chrome 登录、帮助中心、权限过滤和当前页面抽屉验收，并生成 2 张 v0.1.365 截图。
- `verify:sop` 校验 17 章、140 个流程、40 个关联页面、截图、权限资源和版本影响声明。
- DOCX 使用规范渲染器输出 142 张逐页 PNG；全页联系表及新增第 2、3 页、末段 Coolify 页和治理边界页均通过视觉检查。
- 类型检查、页面模块、工作区导航、模块边界、完整 CI 基线、Lint 与生产构建通过。

## 回滚说明

本版没有数据库迁移。代码可回退到 v0.1.364；移除帮助页面、问号入口和 SOP API 不影响业务数据，v0.1.362 离线指导书仍可作为历史版本使用。
