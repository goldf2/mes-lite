# MES-lite v0.1.200

发布日期：2026-08-05

## 更新内容

- 新增现代化连续工作区体验参考，明确吸收现代邮箱、Notion、Linear 连续操作方式的产品目标，而不照搬其视觉风格。
- 固化列表与详情连续浏览、同容器查看和编辑、上下文保持、统一关系编辑、全局搜索、岗位工作台、扫码连续处理和即时反馈等强感知体验原则。
- 明确有限吸附工作区只是连续任务的增强能力，不优先实现任意漂浮和多层窗口。
- 将连续工作区要求写入系统交互主规范、页面完成定义和配置化页面框架落地计划。

## 影响范围

- 影响后续资源页面、关系编辑器、对象全景、工作台和公共页面骨架的产品设计与验收方式。
- 不修改现有运行时代码、业务流程、数据模型或 API 契约。
- 本次为产品体验与前端规划文档变更，无需更新领域模型和业务流程图。
