# MES-lite v0.1.161

发布日期：2026-08-04

## 更新内容

- BOM 选择候选产出后立即显示“单位标准用量”和“投入总量 ÷ 产出总量”两种内置转换模板预告。
- 产出确认按钮明确为“确认并配置转换”，减少确认数量与配置模型之间的歧义。
- 确认主产出或其他产出后自动定位到该产品的转换模型输入区，不再要求操作员自行向下寻找。
- 保留逐项录入约束：当前候选先确认数量、完成至少一项投入转换关系后，才能继续添加下一项产出。

## 影响范围

- 物料 BOM 创建与修改工作区的产出录入和页面定位交互。
- 桌面端与移动端 BOM 界面规范。

## 验证结果

- 浏览器验证候选产出确认前即可看到两种内置模板。
- 浏览器验证确认产出后页面自动定位到实际转换模型输入区。
- TypeScript 类型检查、生产构建、BOM 比例与版本脚本通过。
- 发布说明与 Docker 依赖检查通过。
