# MES-lite v0.1.432

发布日期：2026-08-22

## 更新内容

- 增加“生产日报”快捷入口，业务实质为每日库存盘点：按一个库位加入多种物品，录入实盘数量并整单确认。
- 仪表盘默认快捷入口和“生产”功能区同时发布该页面；支持搜索逐项加入，也支持一次加入所选库位全部有账面库存的物品。
- 页面逐行显示账面数、实盘数和差异，账实一致行不产生空流水；差异行整单成功或整单回滚。
- 快捷盘点不要求生产人员、设备、工序或质量作业，也不创建生产实绩、旧生产日报或质检记录。

## 库存、成本与审计

- 不新增平行盘点表或库存账；继续以 `StockLog` 为唯一库存事务事实源，每条差异使用既有 `ADJUST` 规则过账。
- 每条差异同时写入 `RECONCILE` 操作审计，操作人只取服务器登录会话；盘点日期、库位、账面数、实盘数、差异和原因可追溯。
- FIFO 物料、低于预留量的盘亏，以及含待检、冻结或返工库存的物料继续被拒绝，生产日报不能绕过成本层或质量状态保护。
- 盘盈和盘亏按调整前移动平均单位成本同步增减库存金额，并同步内部批次余额；盘盈建立来源为每日盘点的可追溯兼容批次，但不伪造生产投入或生产成本。需要完整生产批次谱系的漏报生产仍应补录生产订单实绩。

## 页面与权限

- 页面读取沿用 `stocks.read`，确认整单要求 `stocks.update`；未新增权限资源。
- 仓库作业组和仓库管理组沿用既有库存更新授权；只读生产或质量账号可查看入口与说明，但不能过账。
- 新接口为 `POST /api/stocks/daily-count`，最多接受 200 条不重复物品，并在服务端复核库位数据范围。

## 影响范围

- 影响工作台默认快捷入口、生产功能区页面注册、库存领域 client/命令服务、库存写接口和在线 SOP。
- 不改变生产订单、生产实绩、质量任务、销售、来料或发货状态机；不新增或修改数据库表。
- 既有单条“库存调整”继续可用，生产日报是在相同库存保护上的多物品整单入口。

## 验证结果

- 临时完整 SQLite 数据库验证盘盈、盘亏、多物品盘点、账实一致跳过、库位/总库存/内部批次同步、服务器可信操作人、库存流水和事务审计。
- 验证快捷盘点不创建 `DailyProductionReport` 或 `QualityInspection`，重复物品、预留量和受控库存仍受保护。
- 页面注册、工作台默认与自定义入口、API 薄适配、模块边界、TypeScript 和 ESLint 定向回归通过；正式构建和完整领域基线由候选 GitHub Actions 执行。

## 回滚说明

- 应用可回滚到 `v0.1.431`，已生成的 `StockLog` 与 `AuditLog` 仍是合法库存历史，不应删除。
- 页面录入错误通过新的有原因盘点再次校准，不直接修改数据库或覆盖历史流水。
- 本版没有数据库迁移；回滚不需要回退 Schema。
