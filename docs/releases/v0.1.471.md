# MES-lite v0.1.471

## 更新内容

- 来料历史核查新增“导出全部明细 CSV”，Excel 可直接打开。
- 每条物料明细独立一行，保留供应商、单号、北京时间、状态、归档标记、数量及单位、核算数量、单价及计价单位、行金额、批次、库位、凭据和备注。
- 沿用已查询的日期、关键词、高级筛选及归档条件，导出全部匹配单据，不限当前页；物料搜索仍匹配整单。修改日期或归档条件后先查询再导出。

## 影响范围

GET /api/material-ins 新增 format=csv；复用原查询与数据权限，归档仍需要 archive.read。只读导出，不修改库存或历史单据，无数据库迁移。不包含附件文件，不新增 PDF 或原生 XLSX 输出。

## 验证结果

来料垂直回归、TypeScript 与 lint 已通过。新增跨页全量导出、日期端点、归档和关键词筛选、库位权限、行金额与汇总核对、中文 BOM、逗号/换行/引号及公式样式文字的回归检查。发布及线上可用性以实际验证结果为准。
