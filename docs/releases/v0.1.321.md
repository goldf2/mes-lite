# MES-lite v0.1.321

日期：2026-08-10

## 更新内容

- 将工作中心页面、读取/编辑契约、搜索模型和 HTTP client 从业务配置模块迁入 `modules/equipment`；业务配置仍保留入口，但只通过设备模块公开出口挂载。
- 新增设备与工作中心输入 Schema、领域错误、编码/写入纯规则、查询服务和事务命令服务。
- 设备只能归属启用且未归档的工作中心；工作中心归档前必须迁移全部设备，普通更新不能绕过引用检查直接停用。
- 设备归档同步进入 `STOPPED` 状态；已归档设备不能继续编辑，已归档工作中心可显式恢复。
- 设备与工作中心 Route Handler 从 139/135 行降至 84/85 行，不再直接访问 Prisma；直接访问 Prisma 的 API 从 39 条降至 37 条。

## 影响范围

- 页面入口、API URL、权限和成功响应形状保持兼容，设备台账与工作中心继续复用公共 `ResourcePage`、字段式高级搜索、列表/卡片和表单弹窗。
- 菜单归类与代码所有权正式解耦：“业务配置 / 工作中心”是用户入口，`modules/equipment` 是规则与实现的唯一所有者。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
