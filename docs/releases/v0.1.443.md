# MES-lite v0.1.443

发布日期：2026-08-28

## 更新内容

- 新增“库存 → 仓库全景”数字孪生 MVP，以二维白板展示当前账号授权的库位与物料分布。
- 库位按可用、待检、冻结、返工和空库位着色；支持物料/规格/库位搜索高亮、白板平移、缩放、复位与库位详情。
- 详情逐物料保留原计量单位，显示总量、可用、待检、冻结和返工数量，并可进入现有库存管理。

## 数据与权限边界

- 复用 `/api/stocks` 与 `/api/inventory-locations?context=stocks`，沿用 `stocks.read` 和库位数据范围。
- 不新增 Prisma 模型、数据库迁移、写接口或权限资源，不保存第二套库存余额。
- 不允许通过白板拖动执行调拨；所有库存变化继续由现有受控单据、事务账本和冲销流程完成。

## 验证结果

- 专项回归锁定停用库位过滤、混合单位逐行展示、风险状态优先级、搜索匹配、访问层复用和统一页面注册。
- 页面模块、统一导航、模块边界、开发文档、TypeScript、ESLint、生产构建和正式候选 CI 纳入发布门禁。

## 影响范围

- 影响统一页面注册表、库存菜单、库存模块的只读访问层与页面展示。
- 不影响数据库结构、库存事务、批次、成本、盘点、调拨和现有库存管理页面。

## 回滚说明

- 回滚仅移除只读页面和菜单入口，不影响库存、库位、批次、成本或流水数据。
