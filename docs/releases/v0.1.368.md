# MES-lite v0.1.368

发布日期：2026-08-14

## 更新内容

- `product-material-migration.mjs` 新增 `preflight` 只读命令，在生产维护窗口前验证映射格式、确认人/确认时间、逐行核对依据、Material 有效性、一对一关系、BOM 主产出、单据投影、空库存处置、引用计数和签字后数据漂移。
- 预检成功或失败都写入不可覆盖的 JSON 报告；报告记录映射 SHA-256、数据库前后 SHA-256 和 `readyForApply`，预检不创建备份、不回填数据库。
- 迁移专项回归增加通过、未签字、非法 JSON、缺少核对依据和签字后漂移用例，并纳入默认领域 CI 基线。
- 对 2026-08-13 生产恢复候选执行只读审计：16 个历史 Product 中 13 个有唯一候选、3 个无候选，2 张 BOM 缺少唯一主产出，Product 独占库存均为空且无流水；源数据库前后 SHA-256 一致。该候选不是当前在线生产快照，结论仍须在维护窗口前刷新。
- 增加流程 142“预检 Product 到 Material 映射”，重新生成 142 流程的 Markdown、DOCX、PDF 与离线 Web SOP。

## 影响范围

- 不修改 Prisma Schema、迁移或生产数据；数据库仍为 77 个模型和 76 个迁移。
- `audit`、`plan` 和 `preflight` 均为只读；只有人工签字、预检通过、停止写入、完成一致备份后，才允许另行执行 `apply`。
- Coolify 生产继续固定在既有批准版本，Auto Deploy 保持关闭；本版本只推送代码和交付文档，不自动部署生产。

## 验证结果

- 恢复候选 `audit`、`plan` 与未签字 `preflight` 前后数据库 SHA-256 一致；未签字映射返回失败并生成 `readyForApply=false` 报告。
- 迁移专项回归验证预检成功/失败不写数据库，既有自动备份、九类投影回填、对账和非覆盖回滚候选继续通过。
- 类型检查、Lint、生产构建、21 项领域/治理 CI、SOP 同步门禁均已通过；DOCX 与 PDF 均渲染为 144 页 A4 并完成逐页视觉检查，离线 Web 包含 142 个可搜索流程。

## 回滚说明

本版本没有数据库迁移，可回退代码到 v0.1.367；回滚只会移除维护窗口前的只读预检能力，不会逆转或修改业务数据。若此前已另行执行 `apply`，代码回滚不能代替数据回滚，必须使用该次迁移报告绑定的一致备份进行非覆盖恢复和挂载切换。
