# MES-lite v0.1.166

发布日期：2026-08-04

## 更新内容

- BOM 输入和输出的长度、重量行增加录入单位选择器，可选择单位目录中的同量纲单位。
- 切换单位时自动换算当前数量，长度新行默认 `mm`，重量新行默认 `g`，用户仍可改选 `cm/m`、`kg/t` 或已配置的自定义单位。
- 服务端校验单位所属计量方式，并将数量统一换算为物料主库存单位后保存；数量类和其他类物料保持主库存单位。
- `BOMItem`、`BOMOutput` 新增 `entryUnit`，只用于恢复用户录入显示，不参与生产、库存和成本计算。
- 新 BOM 保存后自动选中刚创建的方案并恢复完整明细，不再回到空白新建草稿。
- 单位配置将 BOM 录入单位计入使用量，已被 BOM 使用的自定义单位不能修改换算关系或删除。

## 影响范围

- BOM 设置页、BOM 保存接口、单位目录换算和 BOM 数据模型。
- 新增数据库迁移 `20260804170000_add_bom_entry_units`；现有 BOM 的录入单位初始化为原保存单位，不改写数量。
- 生产订单、库存和成本继续读取标准化后的 `quantity / unit`，计算口径不变。

## 验证结果

- Prisma schema 格式化、Client 生成和校验通过。
- `npm run verify:unit-catalog` 通过，覆盖 `31.6 mm → 0.0316 m`、`250 g → 0.25 kg`、默认单位和非法数量单位校验。
- `npm run verify:bom-versions` 通过，覆盖 `entryUnit` 迁移和整批多产出读取。
- TypeScript 类型检查与 Next.js 生产构建通过。
- 浏览器验证桌面和窄屏下默认单位、单位切换、数值同步换算和保存后恢复显示通过。
