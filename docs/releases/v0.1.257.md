# MES-lite v0.1.257

发布日期：2026-08-09

## 更新内容

- 公共页面注册统一声明主导航、页内资源和命令三类打开方式；主导航进入主显示区，页内新增、编辑和详情默认弹窗，命令在当前上下文执行。
- 所有使用 `ModalDialog` 的业务弹窗默认提供纯图标“全屏/还原”和“在主页面打开/返回弹窗”；主页面模式写入浏览器历史并复用同一业务组件。
- 产品文档详情迁移到公共弹窗骨架，不再维护独立的全屏状态。
- 发货管理支持独立创建发货单，也可选关联已确认销售订单；销售订单移除“生成发货单”，避免建立隐式 ERP/MRP/MES 自动联动。
- 物料新增默认销售价与销售币种；销售订单自动带入价格、保存默认价和来源快照，并允许在尚未产生发货记录时受控调价。
- 新增系统时序图、系统结构图和数据库结构文档，明确 MES 主体、有限 MRP/ERP 以及销售价与成本的边界。

## 影响范围

- 物料、销售订单、发货、产品文档、公共弹窗、页面模块注册、附件和 PDF 工作流。
- 数据库新增物料默认销售价、订单币种、明细价格来源与调价审计字段；不在物料主数据增加成本价字段。
- 独立发货的销售订单来源允许为空；显式关联时仍校验订单状态、未发数量与库位库存。
- 当前不实现销售转计划、计划转工单、销售订单自动派生发货等跨域编排。

## 验证结果

- Prisma schema 格式化和 Client 生成通过。
- TypeScript 类型检查、公共页面形态、单据边界、销售价与发货边界专项验证通过。
- 数据库迁移、销售订单既有流程、Lint、生产构建和发布文档校验在提交前完成。
