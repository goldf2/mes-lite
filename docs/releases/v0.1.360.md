# MES-lite v0.1.360

日期：2026-08-13

## 更新内容

- 权限资源由 30 个扩展为 48 个，并按公共入口、生产质量、工程资料、履约库存、管理运维和升级兼容六区呈现。
- 流程转移从 `stats`、BOM 结构与版本从 `bomCost`，以及供应商、客户、员工、库位、单位、文档类别、工作中心、工艺路线、业务/显示/导航/AI 设置、归档、审计和数据工具从 `system` 拆为独立资源。
- 页面注册、操作按钮、API、AI 工具、附件所属资源和业务单据定义使用同一资源边界；只读配置页禁用输入并隐藏保存、测试、新增或归档动作。
- `/api/system/settings` 强制使用 `scope=business|display|ai`，每个范围只返回和修改对应字段；AI 配置、导航配置及运维接口也使用各自资源。
- 新增仓库管理、工艺技术、设备维护、文档管理、销售发运、人员管理和权限管理员七个岗位预置组；权限管理员不自动获得业务配置或系统维护能力。
- 已有角色、既有预置组、自定义组和个人覆盖只在缺少新资源时，从对应旧资源继承五项动作；已有设置不会被新版预置覆盖，新安装直接使用细分预置。
- 使用六类真实岗位账号新增 9 张浏览器截图，全流程作业指导书扩展到 129 个流程、131 页 Markdown/DOCX/PDF。

## 影响范围

- 本版本没有 Prisma Schema 变化，仍为 74 个模型、74 个迁移；权限资源写入现有权限表，页面模块仍为 41 个，Route Handler 仍为 129 条，验证命令由 87 个增加为 89 个。
- 旧 `system` 和 `permissions` 资源继续存在但只用于升级兼容，当前页面注册和业务 API 不再依赖它们；`bomCost` 只控制成本查询，BOM 结构和版本使用 `bom`。
- 为避免升级后岗位突然失权，旧 `system` 权限会复制到 15 个细分业务/设置/运维资源，旧 `stats` 复制到 `flowTransfers`，旧 `bomCost` 复制到 `bom`，旧 `workInstructions` 复制到 `documentCategories`。这会保持原行为，但不会自动达到最小授权；部署后必须按岗位审批逐项复核并收窄。
- 预置组不会自动分配给既有账号，也不会覆盖企业已调整的组设置。权限页中“升级兼容资源”不是新功能授权入口。
- 当前没有本人、班组/工作中心和仓库/库位数据范围；列表、统计和岗位任务数量仍是单厂全局口径。个人例外也尚无原因、授权人和失效时间。
- 本地隔离数据库、HTTP 和浏览器截图不等于真实 Coolify 已部署。本版本不操作本地不存在的 Coolify 服务或服务器生产数据。

## 回滚

本版本无数据库结构变化。回滚到 `v0.1.359` 后，旧版继续读取原 `system`、`stats`、`bomCost` 和 `workInstructions` 设置；新增细分资源和岗位组设置会保留为旧版不读取的记录，不影响旧路由运行。回滚前仍需创建数据库与附件一致备份，并记录回滚会恢复宽权限边界：流程转移重新受 `stats` 控制，BOM 结构重新混入原资源，业务配置和系统工具重新受 `system` 控制。恢复旧版后必须用供应商、工艺、仓库、AI 和权限管理员账号重新验证菜单、按钮和关键 API，不能把回滚视为权限风险消失。
