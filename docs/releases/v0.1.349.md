# MES-lite v0.1.349

日期：2026-08-12

## 摘要

固定单厂轻量 MES 产品合同，停止扩大 `Product / Material` 和新旧生产过账双轨，并提供阶段 1B 数据迁移前的只读审计与结构守卫。本版本不修改 Prisma Schema、不迁移数据库、不删除历史记录。

## 更新内容

- 明确 `Material` 是唯一用户侧物品主档，`Product` 仅为待退出的旧外键兼容投影。
- 新建或补齐库存只面向有效 `Material`，不再创建或自动修复 Product 独占 `Stock`。
- 禁止新建 `DailyProductionReport`，创建接口返回 `410`；既有历史记录仍可查询、修改、确认和冲销。
- 旧工单领料、工序报工和入库接口仅允许 `materialId=null` 的历史订单；物料工单返回 `410` 并改用 `ProductionOrderActual`。
- 增加 `npm run audit:model-convergence`，只读盘点 Product 映射、旧外键、缺失物料投影、Product 独占库存和旧生产记录。
- 增加 `npm run verify:model-convergence`，阻止新增 Product 外键依赖、Product 库存写入和旧生产写路径回流。
- 增加产品边界权威文档及 ADR 0030，并把多租户 SaaS 明确降为暂停的长期候选。

## 影响范围

- 不修改 Prisma Schema、不迁移数据库、不删除历史记录，也不改变既有库存余额。
- 仍调用旧日报创建接口，或尝试给已绑定 Material 的工单调用旧领料/报工/入库接口的外部集成会收到 `410`，必须改用生产实绩。
- Product 外键仍在数据库中；生产审计、人工映射和物理迁移属于阶段 1B，不在本版本执行。

## 数据与回滚

本版本没有数据库迁移。回退至 `v0.1.348` 可恢复旧写路径，但会重新扩大兼容数据，只作为紧急技术回退。阶段 1B 必须先完成生产备份挂载、恢复演练和人工映射，才允许迁移 Product 外键。
