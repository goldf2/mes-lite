# MES-lite v0.1.348

日期：2026-08-12

## 更新内容

- 依据当前 Coolify 应用的实际域名，将生产可信来源示例统一为 `https://mes.szxiangshu.com`。
- 将微信网页登录文档中的网站域名、授权回调域和回调地址统一为 `mes.szxiangshu.com`。
- 同步文档事实基线和阶段治理记录，避免运维人员把已停用的旧域名写入新环境。

## 影响范围

- 不修改业务代码、Prisma Schema、数据库、附件或用户数据。
- `.env.coolify.example` 只是配置模板；现有 Coolify 环境变量仍需在部署平台中独立核对，仓库不会读取或覆盖生产密钥。
- 本版本不替代 `v0.1.347` 的运行时备份、readiness 和容器交付基线。

## 验证结果

- 仓库已清零旧生产域名引用。
- 版本号、发布索引、开发文档和结构文档事实基线保持一致。
- 发布记录、开发文档、TypeScript、ESLint 和受影响的运行时运维回归通过。

## 回滚

- 代码可回滚到 `v0.1.347`，无需数据库反向迁移。
- 若生产域名再次变化，应以 Coolify 当前绑定域名为唯一依据，同时更新可信来源、微信开放平台回调域和 `WECHAT_WEB_REDIRECT_URI`，不能只回滚文档中的单个地址。
