# MES-lite v0.1.280

发布日期：2026-08-09

## 更新内容

- 建立 `modules/operations-tools`，将数据工具、归档记录和操作记录从 `SystemPage.tsx` 迁入独立领域模块。
- 运维工具继续复用公共顶部工具栏、卡片/列表切换、排序表头、响应式断点、统一按钮、数据一致性检查和图片优化组件。
- `SystemPage.tsx` 从 1,949 行降至 1,474 行，只保留系统分区装配、显示/AI 设置和生产工艺配置等尚待迁移职责。
- 新增 `verify:module-boundaries`，自动禁止新增根级领域页面、跨模块内部导入、UI 依赖 Prisma/server、公共框架反向依赖业务模块，以及巨型页面/路由继续增长。
- 删除页面注册中未被运行时使用的 `allowOpenAsPage`、`allowFullscreen`、`PageOpenSource` 和 `resolvePageOpenMode`，使页面形态契约与单一可逆全屏功能保持一致。

## 影响范围

- 不改变数据工具、归档恢复/永久删除和审计日志的 API、权限、操作规则与页面入口。
- 不改变 Prisma 模型、业务流程和数据库数据。
- 页面注册仍保留“主导航进入页面、内容跳转默认弹窗、命令行内执行”的有效形态语义；只移除已失效的平行能力开关。

## 验证结果

- `verify:module-boundaries`、`verify:configuration-modules`、`verify:page-modules` 和 `verify:fullscreen-dialogs` 通过。
- TypeScript 类型检查通过。
- 生产构建、发布说明一致性和最终 Git 差异检查通过；构建仅保留项目既有的图片与 Hook 依赖警告。
