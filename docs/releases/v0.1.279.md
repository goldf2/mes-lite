# MES-lite v0.1.279

发布日期：2026-08-09

## 更新内容

- 新增 `useBomDraftController.ts`、`BomDraftEditor.tsx` 和 BOM 领域纯函数，将物料选择、草稿水合、单位换算、输入/产出编辑与保存从物料主页面拆出。
- `MaterialPage.tsx` 从 1,704 行降至 887 行，保留物料列表、详情、导入和快速 BOM 窗口编排，不再直接维护 BOM 编辑器内部状态。
- 消除 BOM contracts 对 materials 模块的反向类型依赖，统一从 `modules/bom` 导出编辑器、控制器与产品映射契约。
- 公共 `ModalDialog` 删除“在主页面打开/返回弹窗”平行形态，只保留一个图标式“进入全屏/退出全屏”按钮；普通弹窗、全屏和还原状态复用同一业务组件。
- 删除废弃的页面形态按钮、主内容挂载分支和浏览器历史状态，收紧公共浮层职责。

## 影响范围

- 不改变 BOM API、数据库模型、保存规则、权限资源和物料业务数据。
- 不改变主导航页面打开方式；页内新增、编辑和详情仍默认使用公共弹窗。
- 全屏只改变弹窗尺寸；再次点击同一按钮或按 `Esc` 可还原原弹窗并保留上下文。

## 验证结果

- TypeScript 类型检查、BOM 模块边界和公共弹窗形态验证通过。
- 本机使用迁移后的临时数据库完成浏览器验证：详情弹窗只有一个全屏动作，全屏覆盖完整视口，按钮与 `Esc` 均可还原，不存在主页面打开入口，控制台无错误。
- 开发文档、系统结构图、系统时序图和功能权限矩阵已同步到本版本。
