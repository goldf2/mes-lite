# MES-lite v0.1.182

发布日期：2026-08-05

## 更新内容

- 账号菜单打开时，仅在移动端提升主内容顶部栏层级。
- 桌面端页面工具栏保持低于全局应用页头和账号菜单，不再横向遮挡菜单内容。
- 在系统交互规范中补充全局账号菜单与页面工具栏的响应式层级规则。

## 影响范围

- 影响桌面端右上角账号菜单与页面工具栏的叠放顺序。
- 保留移动端账号菜单在页面内容之上显示的现有行为。
- 不改变业务流程、权限逻辑、API 或数据库模型。

## 验证结果

- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 桌面端账号菜单层级高于页面工具栏，移动端仍保持顶部栏提升。
