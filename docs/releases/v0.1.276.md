# MES-lite v0.1.276

发布日期：2026-08-09

## 更新内容

- 新增 `MaterialDetailDialog`，由详情切片自行重新读取最新物料资料，并在失败时安全回退到列表快照。
- 将库存摘要、计量单位、成本、默认销售价和图片附件从 `MaterialPage.tsx` 迁入详情切片。
- 编辑和全景动作改为由详情切片上报最新物料，主页面仅协调弹窗与页面状态。
- `MaterialPage.tsx` 从 2,564 行降至 2,432 行，详情数据读取不再占用主页面职责。
- 收紧 `verify:material-bom-modules`，禁止详情读取和附件视图回流主页面，并固定详情切片规模边界。

## 影响范围

- 不改变物料 API、Prisma 模型、权限资源、详情字段或附件接口。
- 详情仍使用公共 `ModalDialog`、`AppButton` 和 `AttachmentPanel`，视觉结构与交互入口保持不变。

## 验证结果

- TypeScript 类型检查通过。
- 物料/BOM 模块边界、页面模块和高级搜索契约验证通过。
- Next.js 生产构建通过。
