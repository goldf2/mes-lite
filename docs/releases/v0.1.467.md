# MES-lite v0.1.467

## 更新内容

本版本继续完善制造成本闭环：

- 生产日报快捷生产在选择已发布 BOM 后可以明确选择已保存的成本运行；成本运行同时确定本次采用的工艺路线，保存时冻结 BOM 成本和工艺路线快照。未选择时保留当前最新匹配运行回退，无 BOM 临时生产不变。
- 生产订单和生产日报的成本运行选择增加物料、产品、BOM 和工艺路线归属校验，不能把其他物料的成本运行带入当前生产事实；显式成本运行如果缺少工艺路线快照会被拒绝，避免把历史成本与当前可变路线混合，历史不完整运行需重新计算后再用于生产。
- BOM 成本对象与工序改为同字段精确匹配（编码对编码、名称对名称），取消模糊包含匹配；独立锯切成本对象不再覆盖“锯切+钻孔”等复合工序，避免漏算工序成本。
- 物料全景安全兼容旧的 `bomId = null` 成本运行：仅在产品/BOM 可以唯一确定时展示“历史成本（唯一匹配）”，歧义或物料不一致的记录不猜测归属，并显示待归属数量。
- 补充生产日报、物料全景和代码模块边界的 SOP 与回归验证；无 Prisma 迁移、库存数据改写或权限变化。

## 影响范围

- 影响生产订单创建、生产日报快捷生产和物料全景成本展示。
- 新成本运行继续保存各工序、工作中心及实际费率快照；历史已确认订单、日报和库存流水不回算、不覆盖。
- 旧成本运行若没有 BOM 编号且无法唯一匹配，会保留在数据中并提示人工补充关联，不会自动修改生产数据；缺少工艺路线快照的运行只可作为历史数据排查，不能直接成为新的生产冻结依据。

## 回滚边界

本版本无数据库迁移。若发布失败，保留上一版本健康容器并回滚代码；不删除成本运行、生产订单/日报快照或历史成本数据。若新版本已产生新的冻结快照，回滚代码前先停止新写入并保留数据库事实。
