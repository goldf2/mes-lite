# MES-lite v0.1.231

发布日期：2026-08-08

## 更新内容

- 高级搜索入口固定在关键词搜索组旁边，不再散落在顶部右侧操作区。
- 公共高级搜索面板一次列出页面声明的全部字段，每个字段可独立选择运算符和输入精确条件。
- 产品文档接入 16 个字段的精确搜索，包括文档、产品、客户、附件和日期信息。
- 移除产品文档原有以分类、状态快捷标签冒充高级搜索的独立面板，统一使用公共查询表达式。
- 窄屏高级搜索改用独立模态层，避免被页面工具抽屉裁剪。

## 影响范围

- 公共顶部工具栏、高级搜索组件和页内工具排序设置。
- 产品文档查询界面与产品文档列表 API。
- 公共前端模块、桌面端和移动端界面开发规范。

## 验证结果

- 浏览器验证高级搜索紧邻关键词搜索，并完整展示 16 个产品文档查询字段。
- 精确条件可传入产品文档 API 并参与服务端查询。
- 高级搜索字段、公共资源搜索和 37 个页面模块契约校验通过。
- TypeScript 与目标文件 ESLint 校验通过；Next.js 生产构建通过。
