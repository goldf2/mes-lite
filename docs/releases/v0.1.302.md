# MES-lite v0.1.302

日期：2026-08-09

## 更新内容

- 将发货页、发货创建弹窗和退货页从根组件目录迁入 `modules/sales`，与销售订单形成统一销售履约模块。
- 新增销售履约 client，统一发货/退货列表、候选项、创建与状态流转请求；三个迁移组件不再直接调用 `fetch`。
- 集中客户、库位、发货/退货单据和表单契约，并分开发货物料与退货物料候选类型，避免用宽泛类型掩盖接口差异。
- 根级存量领域页从 8 个降至 6 个；销售模块守卫扩展到订单、发货、退货和公开页面入口。

## 影响范围

- 保留发货与退货的列表/卡片、精确搜索、详情附件、AI 识别、PDF 打印和状态流转交互。
- 不修改 Prisma Schema、API 路径、业务状态规则或服务器正式数据。

## 验证结果

- 销售模块、模块边界、单据凭据、关联单据、附件、打印、调价边界和高级搜索专项校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
