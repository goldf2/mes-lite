## 发布要求

1. 同步递增 `package.json` 与 `package-lock.json` 版本号。
2. 新增 `docs/releases/v<版本号>.md`，不能覆盖旧版本记录。
3. 更新本索引并保持最新版本在最上方。
4. 推送前运行 `npm run verify:release-notes`。
