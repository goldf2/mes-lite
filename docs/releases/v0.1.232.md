# MES-lite v0.1.232

发布日期：2026-08-08

## 更新内容

- 右上角账号下拉菜单移除“人员管理、人员权限、组权限”三个管理入口。
- 账号下拉只保留当前登录身份、系统版本和退出登录，明确其个人账号操作边界。
- 人员与权限管理继续保留在“账号与权限”一级导航，权限和页面能力不变。
- 桌面端、移动端和功能建模规范同步采用相同入口边界。

## 影响范围

- 桌面端与窄屏顶部账号下拉菜单。
- “账号与权限”导航及相关界面开发规范；不修改任何账号、角色或权限数据。

## 验证结果

- 桌面端和 390px 窄屏账号菜单均只显示身份、版本与退出登录。
- “账号与权限”一级导航继续显示，并保留三个管理页面。
- 账号菜单边界回归脚本、TypeScript 和目标文件 ESLint 校验通过。
- 37 个页面公共模块契约与 Next.js 生产构建通过。
