# MES-lite v0.1.311

日期：2026-08-09

## 更新内容

- 将生产订单创建请求 Schema 从 Route Handler 迁入生产领域契约。
- 新增可独立测试的生产订单组号与组内行号规则。
- 将生产订单列表查询、BOM/物料校验、BOM 快照、成组创建事务和归档迁入查询/命令服务。
- 将 `/api/orders` 从 257 行降至 84 行，路由不再直接访问 Prisma。
- 扩展生产订单模块守卫，并使用临时完整 SQLite 验证关键事务规则。

## 影响范围

- 生产订单列表、旧单行创建、多行创建、归档和响应结构保持兼容。
- Prisma Schema、页面布局、权限资源和服务器正式数据不变。
- 本机测试 SQLite 和构建缓存不纳入提交；集成验证使用运行后删除的临时数据库。

## 验证结果

- 生产订单 Schema、编号纯规则、薄 API、查询/命令服务边界验证通过。
- 多行原子创建、BOM 快照、智能多关键词查询、归档与重复归档拒绝验证通过。
- 模块边界、开发文档、版本文档和 TypeScript 类型检查通过。
- Next.js 生产构建通过。
