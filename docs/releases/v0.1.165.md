# MES-lite v0.1.165

发布日期：2026-08-04

## 更新内容

- 修复 BOM 设置页输入、输出物料搜索列表被编辑区边界裁剪的问题。
- 搜索结果现在可越过输入输出区域完整显示，并保持在后续表单和操作区上方。
- Docker 构建复用 Next.js 编译缓存，并缓存 Prisma Client 生成和生产依赖裁剪结果，减少普通代码更新时的重复构建工作。
- Docker 健康检查从固定等待 60 秒改为 15 秒后开始并持续重试，缩短正常部署等待时间。
- Docker 构建支持通过 `NPM_CONFIG_REGISTRY` 参数按部署环境选择 npm 镜像，默认仍使用官方源。

## 影响范围

- 仅影响 BOM 设置页物料搜索选择器的显示层级，不改变 BOM 数据结构、保存接口或生产计算逻辑。
- 影响 Coolify/Docker 镜像构建缓存和健康检查节奏，不改变运行时持久化目录与应用启动流程。
- 现有界面规范已明确要求动态下拉不得被父容器裁切，本次无需修改建模或业务流程文档；部署说明已同步更新。

## 验证结果

- `npm run verify:release-notes` 通过。
- `npm run verify:docker-deps` 通过。
- `npm run build` 通过。
- Dockerfile 阶段依赖关系与 BuildKit 语法已完成静态检查；本机未安装 Docker CLI，镜像构建需由本次 Coolify 部署完成最终验证。
- 浏览器验证桌面端输入、输出物料搜索列表可完整越过编辑区显示，且可正常选择和关闭。
- 窄屏验证列表不产生页面横向溢出。
