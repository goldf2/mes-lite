# MES-lite v0.1.253

发布日期：2026-08-08

## 更新内容

- 在标准侧栏、画布顶部导航和移动端功能抽屉增加 MES、MRP、ERP 三工作区切换。
- 新增“系统设置 → 导航与工作区”，管理员可启停工作区、设置默认工作区，并配置页面归属与默认菜单顺序。
- 同一内部页面支持在 MES、MRP、ERP 使用不同显示名称；显示名称由企业自行定义，内部页面 ID、路由、权限资源和业务数据保持不变。
- 系统设置、权限、AI、审计和数据维护等固定共享功能在所有已启用工作区保留，避免关键管理入口被误隐藏。
- 将派工管理补入统一工作区目录，并把页面模块覆盖更新为 38 个稳定入口。
- 同步更新 MES / MRP / ERP 功能矩阵的工作区说明与 HTML 展示页。

## 影响范围

- 工作区配置复用现有 `SystemSetting` 表，不新增数据库迁移。
- 未保存过配置的系统自动使用预置的 MES、MRP、ERP 页面归属；以后新增页面也会按安全默认规则补入至少一个工作区。
- 保留已有个人导航顺序兼容读取；企业工作区配置发布后清除当前浏览器的工作区顺序覆盖，使新默认顺序立即生效。

## 验证结果

- TypeScript 类型检查通过。
- 生产构建通过，新增 `/api/system/workspace-navigation` 路由正常生成。
- 工作区菜单归属、独立显示名称、顺序恢复和安全默认值验证通过。
- 工作区配置数据库持久化验证通过。
- 38 个页面模块与公共顶部工具栏校验通过。
- 浏览器验证 MES / MRP / ERP 切换、页面独立改名即时生效，并在测试后恢复系统默认配置。
