# MES-lite v0.1.216

发布日期：2026-08-06

## 更新内容

- 在功能规划中明确长期采用 TypeScript 业务核心、PostgreSQL 生产数据库和按需 Python 计算服务的混合架构。
- 补充分阶段演进路线，优先完成数据库可靠性、业务模块边界和后台任务，再按实际需求接入 Python。
- 新增 ADR 0022，规定 Python 服务的适用范围、引入门槛、数据访问和事务边界。
- 开发文档增加算法服务技术栈说明及规划入口。

## 影响范围

- 本次仅更新架构规划、开发说明和版本元数据，不修改运行时代码、数据库结构或现有部署方式。
- TypeScript 主系统继续负责账号权限、业务规则、库存和生产事务及审计；Python 不作为第二套业务后端。

## 验证结果

- 版本号、版本文档和版本索引一致性检查通过。
- Docker 依赖清单一致性检查、文档差异检查和生产构建通过。
