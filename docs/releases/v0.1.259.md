# MES-lite v0.1.259

发布日期：2026-08-09

## 更新内容

- 将供应商、客户、库位、单位、工作中心和文档类别从大型 `SystemPage` 中拆分到独立的 `modules/configuration` 领域模块。
- 供应商、客户、库位、单位和工作中心统一接入 `ResourcePage`，复用搜索、高级搜索、卡片/列表视图、新建弹窗、归档与手动排序能力。
- 文档类别保留树形编辑交互，同时接入统一 `ResourcePageShell`、顶部搜索和高级搜索工具。
- 新增公共可排序标签与配置模块结构校验，防止配置页重新回流到单体系统页面。
- 更新页面分类、配置化框架和高级搜索校验，使文档与自动检查对应新的模块边界。

## 模块化效果

- `app/page.tsx` 保持 5 行入口，应用编排继续由 `HomeApp` 承担。
- `SystemPage.tsx` 从约 3029 行下降到约 1931 行，移除约 1098 行配置资料页实现。
- 六类配置页面拥有稳定的领域入口；后续修改公共资源骨架可同步影响这些页面。

## 影响范围

- 影响供应商、客户、库位、单位、工作中心和文档类别的前端页面组织与显示骨架。
- 沿用现有 API、权限资源和数据库结构，不执行数据库迁移，也不改变业务数据。
- 加工工艺、物料路线和系统设置仍保留在 `SystemPage`，作为后续按领域继续拆分的边界。

## 验证结果

- 配置模块、页面模块、高级搜索和配置排序专项校验通过。
- TypeScript 类型检查通过。
- 本地浏览器验证供应商、库位、单位和文档类别入口、搜索、视图切换及新建弹窗正常。
- Next.js 生产构建通过；现有图片优化与 Hook 依赖告警未在本次无关改造中扩大处理。
