# MES-lite v0.1.307

日期：2026-08-09

## 更新内容

- 为供应商/客户、库位、单位、工作中心和文档类别建立统一的业务配置参考资料契约。
- 新增业务配置参考资料 HTTP client，集中请求路径、JSON 解析和服务端错误映射。
- 供应商/客户参数化页面及 4 个独立配置页面不再直接调用 `fetch`，只负责资源页状态和用户交互。
- 扩展配置模块守卫，阻止接口路径和页面级请求重新回流配置 UI。

## 影响范围

- API 路径、请求字段、响应结构和页面布局保持不变。
- 不修改 Prisma Schema、权限资源或服务器正式数据。
- 本机 SQLite 测试数据与构建缓存不纳入版本提交。

## 验证结果

- 业务配置、模块边界和页面模块专项校验通过。
- TypeScript 类型检查和 Next.js 生产构建通过。
