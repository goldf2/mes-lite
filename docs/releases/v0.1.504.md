# v0.1.504 — 统一物料工程资料与 Excel 映射导入候选

保留现有 Material 为唯一物料主档，在原有编码、单位和库存业务上增加零件工程资料。Excel/CSV 可选择工作表、表头行并逐列对应已开发字段，预览后再确认写入。

## 更新内容

- Material 添加可空工程字段、十二项 mm 尺寸、物品性质与默认供给方式；用途和机型适用使用明确的关联记录。迁移保留主键及现有库存、订单、BOM 引用，不自动执行 MDB 导入。
- 编辑、详情、搜索、可选列表列、模板和导出接入新字段。旧客户端省略字段时保留原值；用途、机型可明确清空。适用用量不作为已发布 BOM。
- CSV/XLSX 导入使用统一字段注册表，支持手工列对应、默认件单位、逐行错误/提示和新增/更新/跳过预览。更新未对应字段保持，单机型导入保留其余机型，完整关系 JSON 支持导出后无损回读。
- 预览只读；提交重新鉴权和校验，并将物料、零余额 Stock 和审计放入同一事务。需要 materials.read/create，更新模式另需 update。历史库存、成本和所有权不在导入字段中。

## 影响范围

沿用物料资源页面及 FormField、ModalDialog、AppButton、OneToManyRelationField。MaterialEngineeringFields 和 MaterialImportReview 是领域扩展。ExcelJS 是必要的 XLSX 解析依赖，Docker 依赖清单已同步；不修改 Dockerfile 或部署配置。用户仅对本次界面明确授权 GPT，默认 Gemini 分工保持。

## 验证结果

- Prisma 校验/生成、迁移保留测试、原物料服务与模块边界回归通过。
- 新导入专项覆盖 XLSX/CSV/第6行表头、未知列、0/false、未映射保留、机型/用途无损往返、单位锁定、归档/重复编码、提交重验、审计故障整批回滚。
- 5,346 条真实准备数据在隔离数据库完整导入，5,319 条机型适用关系，字段逐一核对；重复导入全部跳过；库存数量和成本为零。此结果不代表已与生产目标库比较。
- TypeScript、Lint 和定向架构/审计检查通过。桌面真实浏览器的工程字段创建、详情与仅改名保留，以及字段映射提交/完整文件预览通过；390px 移动端创建、详情和仅改名保留通过；映射预览无页面横向溢出，浏览器错误为零。
