# MES-lite v0.1.215

发布日期：2026-08-06

## 更新内容

- 将 `qrcode` 与 `@types/qrcode` 同步到 Docker 专用依赖清单。
- 修复 Coolify 构建阶段因依赖清单一致性校验失败而中止部署的问题。

## 根因

- v0.1.214 新增二维码依赖后，根目录 `package.json` 和 `package-lock.json` 已更新，但 `docker/dependencies/` 中供 Docker 分层缓存使用的清单未同步。
- Dockerfile 在正式构建前执行 `sync-docker-dependency-manifest.mjs --check`，因此主动拒绝使用过期清单继续构建。

## 影响范围

- 仅修正 Docker 构建依赖清单和发布版本，不修改数据库结构、业务数据或二维码功能行为。
- 已部署的旧版本不受影响；重新部署 `main` 后使用同步完成的依赖清单构建新镜像。

## 验证结果

- Docker 依赖清单一致性检查通过。
- TypeScript、版本文档检查和生产构建通过。
