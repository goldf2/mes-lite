# v0.1.387 GitHub CI 历史审计基线拉取

日期：2026-08-15

## 更新内容

- 保持 actions/checkout 的最近 2 个提交浅克隆，避免无条件下载完整历史。
- 在依赖安装前按完整 SHA 精确拉取生产数据库审计基线 `be7e18f653bd684cb2367985c1f8c072801d79ec`。
- `audit-production-database.mjs` 和后续 Schema 漂移审计继续使用固定历史事实，不改成当前分支文件来绕过验证。
- 明确 Dockerfile 目录、匿名卷和 Coolify 显式持久挂载的边界，并归档生产/演示双 Webhook 构建导致主机失联的运维证据与再次上线门禁。

## 影响范围

- 只修改 GitHub Actions checkout 后的只读获取步骤、部署说明、灾备说明、事故记录和版本文档。
- 页面、API、权限、Prisma Schema、迁移、生产镜像和业务数据均无变化。
- SOP 步骤无变化，只生成当前版本 Markdown 同源文档。
