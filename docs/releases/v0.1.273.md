# MES-lite v0.1.273

发布日期：2026-08-09

## 更新内容

- 建立正式 `modules/materials` 和 `modules/bom` 领域模块，物料管理、物料全景和 BOM 全览不再混放于公共 `app/components` 根目录。
- 页面注册层统一从模块根目录 `index.ts` 加载物料/BOM 页面，不越过公开出口引用领域内部文件。
- 物料和 BOM 数据结构分别收口到 `contracts`，物料列表、客户/单位目录、导入导出、创建更新、归档与 BOM 读写收口到各自 `client`。
- 物料和 BOM UI 不再直接发起 HTTP 请求，统一处理 API 错误与返回结构。
- 新增 `verify:material-bom-modules` 契约，固化领域归属、公开出口、HTTP client 和文件规模边界。

## 影响范围

- 不改变 API URL、Prisma 模型、权限资源、页面布局或物料/BOM 业务流程。
- `MaterialPage.tsx` 由 3,186 行降至约 2,984 行，仍属于必须继续渐进拆分的大型页面。

## 验证结果

- TypeScript 类型检查通过。
- 物料/BOM 模块边界、页面注册和公共高级搜索契约验证通过。
- Next.js 生产构建通过。
