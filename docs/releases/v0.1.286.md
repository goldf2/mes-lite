# MES-lite v0.1.286

日期：2026-08-09

## 更新内容

- 将作业文档主页拆分为集合视图、创建对话框、详情/附件工作区和全屏查看器四个稳定用户任务模块。
- 新建与详情编辑共用同一份文档表单字段组件，文档状态、类型、空表单和显示格式进入领域视图模型。
- `WorkInstructionPage.tsx` 从 1,349 行降至 591 行，移出 800 行巨型页面基线；主页只保留数据读写、搜索、分页和子模块状态协调。
- 扩展文档边界校验，限制主页不超过 650 行，并检查公共弹窗、排序、一对多关联、在线正文和附件预览继续被复用。

## 影响范围

- 影响产品文档列表、卡片、新建、详情编辑、附件展示与全屏预览的前端装配方式；接口、数据库模型和服务器正式数据不变。
- 本机 SQLite 只保留一条隔离测试记录，不纳入版本提交，也不作为正式数据来源。

## 验证结果

- 文档请求契约、薄 API、查询/写入领域边界和完整临时 SQLite 集成测试通过。
- 模块边界校验通过：9 个领域模块、15 个存量根页面、5 个存量巨型页面和 6 个存量巨型路由均未增长。
- TypeScript 类型检查与 Next.js 生产构建通过；本机页面经 HTTP 返回和开发编译验证。

## 数据安全

- 集成测试只使用临时完整 SQLite 数据库并在验证后删除，未连接或修改服务器正式数据。
