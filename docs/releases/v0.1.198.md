# MES-lite v0.1.198

发布日期：2026-08-05

## 更新内容

- 在项目级协作规则中增加“公共模块优先与独立功能准入”，要求开发前检索现有组件、服务和相邻实现。
- 明确常规查询、新增、修改、归档和恢复应接入统一资源页面骨架，多对象关系应接入统一关联编辑骨架。
- 要求同一交互出现两次或已有明确第二调用方时优先评估公共化；独立实现必须记录领域理由和复用边界。
- 补充公共组件全局影响回归要求，并明确库存、成本、生产确认、冲销和 BOM 数量计算继续保留专用领域服务。
- 更新系统交互主规范、界面开发检查清单和配置化页面框架规划，使规则能够用于开发、评审和验收。

## 影响范围

- 影响后续前端页面、公共组件、CRUD、关联编辑器和代码评审方式。
- 不修改现有业务流程、数据库模型、API 契约或生产运行时代码。
- 本次为开发治理规范变更，无需更新领域模型和业务流程图。
