# MES-lite v0.1.342

日期：2026-08-12

## 更新内容

- 物料新增或编辑接口确认成功后立即关闭编辑浮窗，不再等待物料列表和 BOM 候选缓存刷新。
- 列表与关联缓存改为后台刷新；刷新失败使用“物料已保存，但列表刷新失败”的独立提示，不再让已经保存的数据继续显示“处理中…”。
- 增加物料模块边界校验，防止后续再次把保存完成状态与派生数据刷新绑定。

## 影响范围

- 复用现有 `MaterialEditDialog`、`ModalDialog`、`ModalActions`、物料 client 和页面刷新函数，没有新增平行弹窗或请求实现。
- 不改变物料字段、API 入参、权限、审计和数据库结构。
- 同步补充公共表单保存规范：业务提交完成和列表派生数据刷新必须使用两个独立状态。

## 验证结果

- 浏览器使用本机测试物料执行编辑保存，保存接口完成后约 0.5 秒内编辑浮窗关闭，页面不再残留“处理中…”按钮。
- 浏览器继续输入部分物料编码，列表只显示对应记录，确认后台刷新和搜索链路可继续工作。
- TypeScript 类型检查、物料服务回归、模块边界、开发文档事实基线、发布记录和生产构建。
- `git diff --check`。
