# MES-lite v0.1.472

## 更新内容

- 物流新增“来料历史核查”和“发货历史核查”独立只读页面。日常来料列表不再显示核查面板，保留搜索、分页和单据操作。
- 两页共用 DocumentHistoryPage、AppButton、FormField、ResourceTable；支持日期、状态、关键词、归档筛选、全部匹配状态/单位汇总及 CSV 明细导出。
- 发货按实际发货日期，保留单据单位快照；金额为当前价格，不作历史时点价格追溯，不重复扣减退货或红冲。

## 影响范围

GET /api/shipments 新增 startDate/endDate/includeArchived/includeSummary/format=csv，沿用 shipment.read 和库位数据范围，归档额外需要 archive.read。列表、汇总与导出共用查询条件。没有数据库迁移，不改库存或单据状态。

## 验证结果

定向回归覆盖跨页汇总和导出、日期端点/无效日期、整单搜索、归档/状态筛选、库位权限与金额一致性。远端发布结果须另行核验。
