## 更新内容

- 原版本仅撤销 MES 会话，Casdoor 仍可 SSO。当前 Casdoor v4.2.0 不支持 RP prompt/max_age，且跨站默认 Lax Cookie 令后台注销不可靠；采用标准首方 RP logout。
- 原会话与同浏览器挑战先撤销，UI 身份立即移除。正常验签回调将 id_token 封装 AES-256-GCM HttpOnly 分片 Cookie，密钥使用原 Runtime secret 的 HKDF 专用派生；绑定本会话/代际，限长、限期，不写数据库、URL、日志或普通 JSON。
- 固定本站两分钟加密 handoff 返回无第三方脚本隐藏表单，POST 固定 issuer；精确 state 回调清 Cookie、保持退出状态，不自动登录。原管理员密码恢复仅本站退出；缺 hint 的兼容尝试失败诚实提示。
- Casdoor 代际指纹加入 logout-protocol-v2，使旧普通 Casdoor 会话重新正常登录取得 hint；builtin、既有恢复、人员/岗位和业务权限不改。无 Prisma/依赖变更。
- 生产启用前由根任务追加 MES 专用客户端唯一退出回调 `https://mes.csyufeng.com/api/auth/casdoor/logout/callback`，其余客户端设置、密钥与身份绑定保留；本候选未执行该修改。
