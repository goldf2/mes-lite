# MES-lite v0.1.194

发布日期：2026-08-05

## 更新内容

- 图标调参实验室新增“应用到系统”，可将当前叶片、玻璃、中心和动态参数发布为系统级配置。
- AI 助手入口从系统配置动态渲染图标，发布后当前页面立即同步，刷新或重新登录后仍保留。
- 补齐自动旋转、呼吸、指针跟随和按压缩放等运行时动效参数。
- 发布接口使用系统修改权限并记录审计日志，所有参数在服务端标准化后再保存。

## 影响范围

- 影响 AI 助手图标的系统设置、实验室和全局入口展示，不改变 AI 模型配置或业务数据。
- “保存”仍仅保留当前浏览器预设；只有“应用到系统”会更新全局图标。
- 配置使用现有 `SystemSetting` 持久化，无需新增数据库迁移。

## 验证结果

- `npm run verify:ai-mark` 通过，参数边界、颜色白名单和可信 SVG 渲染符合预期。
- 定向 ESLint 检查通过，仅保留 `SystemPage` 中既有 Hook 依赖警告。
- `npm run build` 通过，包含 `/api/ai/mark-config` 动态路由。
