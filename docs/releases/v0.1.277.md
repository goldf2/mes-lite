# MES-lite v0.1.277

发布日期：2026-08-09

## 更新内容

- 新增独立的物料卡片、表格和分页组件，主页面不再展开每条物料的 JSX。
- 新增 `model/material-view.ts`，统一视图字段、排序、列宽、BOM 简况和动作契约。
- 删除物料集合中不可达的 BOM 工作区行选择判断；BOM 工作区继续使用自己的专用列表。
- `MaterialPage.tsx` 从 2,432 行降至 2,005 行，列表视觉与动作以后可独立修改。
- 收紧 `verify:material-bom-modules`，禁止集合渲染回流主页面，并固定四个视图切片规模边界。

## 影响范围

- 不改变物料查询、筛选、排序、分页、详情、归档、全景或快速创建 BOM 行为。
- 卡片和表格仍使用原有字段显示、列宽与 BOM 简况偏好。

## 验证结果

- TypeScript 类型检查通过。
- 物料/BOM 模块边界、页面模块和高级搜索契约验证通过。
- 开发文档事实基线和版本记录验证通过。
- Next.js 生产构建通过。
- 本机浏览器验证卡片、列表、分页和物料详情弹窗正常工作。
