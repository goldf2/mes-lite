# MES-lite v0.1.206

发布日期：2026-08-06

## 更新内容

- 桌面左侧导航新增“单列折叠”和“双列导航”两种用户可选布局。
- 双列模式把一级功能固定在 84px 左列，当前功能的二级入口放入独立右列；两列分别滚动，切换一级功能时页面内容保持连续。
- 1024–1279px 桌面宽度自动回退单列，1280px 及以上启用双列；移动端导航保持不变。
- 两种导航模式分别保存侧栏宽度，并继续支持拖动、键盘调整和双击恢复默认宽度。
- 导航布局设置进入公共“页面选项”，偏好只保存在当前浏览器。

## 模块化

- 新增公共 `DesktopNavigation` 组件，同一份菜单注册数据同时驱动单列与双列呈现，不在业务页面复制菜单定义、权限或路由。
- 新增 ADR 0020，固化“同一菜单模型、多种响应式呈现”的导航框架决策。

## 影响范围

- 只调整桌面应用壳的导航呈现与当前浏览器偏好，不改变页面权限、业务路由、移动端入口或业务数据。
- 用户首次升级后继续使用原有单列折叠；主动选择双列后才在宽屏启用新布局。

## 验证结果

- TypeScript、ESLint、页面模块校验、版本文档校验和生产构建通过。
- 浏览器验证单列/双列切换、一级与二级导航、偏好保存和页面内容边界。
