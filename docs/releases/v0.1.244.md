# MES-lite v0.1.244

发布日期：2026-08-08

## 更新内容

- 将已拆分的工作台、生产订单和库存页面分别迁入 `modules/workspace`、`modules/production` 和 `modules/inventory`，每个领域只通过根目录 `index.ts` 对应用壳公开。
- `app/page.tsx` 继续保持最小入口，`HomeApp` 只动态挂载领域公开入口；页面内部继续复用既有公共工具栏、搜索、视图、表格、弹窗、附件和权限能力。
- 合入业务单据打印与归档：来料、销售订单、发货、退货、流程转移、生产订单和派工单在创建后可生成 A4 PDF，历史单据可补打，生成文件按附件版本归档。
- 合入隔离的可停靠工作区实验页 `/workspace-lab`，用于验证面板停靠、呼出与布局切换，不连接真实业务 API，也不进入正式导航。
- 合入代码目录与模块边界规范；旧 `page.tsx` 注释分支仅保留合并历史，不恢复已经拆除的巨型页面实现。

## 影响范围

- 领域目录所有权、应用壳动态导入路径、单据打印入口、PDF 归档文件和独立交互实验页。
- 不修改 Prisma Schema、数据库字段、业务接口入参、库存过账、单据状态流转或现有页面布局。
- PDF 归档复用现有附件表和附件存储根目录；实验页仅使用内存模拟数据。

## 公共模块复用

- 生产与库存模块继续复用 `ResponsiveToolbarActions`、公共高级搜索、视图切换、排序、弹窗与附件组件。
- 单据打印统一复用 `BusinessDocumentPrintLink`、公共打印路由和 `business-document-pdf` 渲染器，不在各交易页面复制 PDF 模板。
- 本次没有建立第二套应用壳、顶部工具栏、搜索或页面框架。

## 验证结果

- 页面模块、单据凭据、业务单据打印和发布文档静态校验通过。
- TypeScript、定向 ESLint、生产构建以及工作台、生产订单、库存和交互实验页浏览器回归通过。
