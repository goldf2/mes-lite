# MES-lite v0.1.354

日期：2026-08-13

## 更新内容

- 新增生产产出内部批次、批次状态余额、批次交易和质量检验模型；新生产实绩的每项产出自动生成待检批次与待检任务。
- 库存汇总、库位余额和成本层增加可用、待检、冻结状态；FIFO 领料、发货和普通库存调整只使用可用库存。
- 在生产订单详情增加整批合格放行与整批不合格冻结，独立校验 `quality.update`，并同步写检验结论、批次交易、库存流水和审计操作人。
- 库存页、物料详情/全景和 AI 库存查询显示可用、待检和冻结数量；库存流水展示质量放行/冻结来源。
- 增加质量领域模块、质量权限契约、生产批次回归脚本、ADR、运维说明和阶段治理记录。
- 使用全新临时演示库完成实际浏览器操作，新增 7 张流程截图，并更新全流程 DOCX/PDF/Markdown 作业指导书。

## 影响范围

- 迁移 `20260813090000_add_production_quality_lots` 是可加性迁移，不自动回填历史批次，不改写原有库存状态。
- 本版本只完成生产产出整批质量切片。来料、投入、发货批次谱系、部分放行和完整不合格处置仍未实现。
- 已放行批次在缺少批次消费分配的当前版本不能直接冲销；待检或冻结批次可在既有安全条件下冲销。
- 本地临时数据与截图验证不等于真实 Coolify 部署完成；生产迁移、备份和验收仍需维护窗口执行。

## 回滚

新表无业务数据时可回退应用代码并保留加性结构。只要已经写入内部批次、质量任务或待检/冻结库存，就不能删除新表或直接运行不能识别状态库存的旧应用；应停止相关写入、保留证据并前滚修复。生产部署前必须创建数据库+附件一致备份，恢复时生成非覆盖候选并验证后切换。
