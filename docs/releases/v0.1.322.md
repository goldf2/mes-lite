# MES-lite v0.1.322

日期：2026-08-10

## 更新内容

- 将仅为服务器历史数据保留的旧生产日报输入契约、日期编号、状态约束、BOM 耗用快照、工作区查询、草稿命令以及确认/冲销事务集中到 `modules/production`。
- 删除 `lib/daily-production.ts` 与 `lib/daily-production-request.ts`，阻止兼容规则继续散落在扁平基础设施目录。
- 4 条 `/api/daily-production-reports*` 兼容路由合计从 714 行降至 139 行，只保留权限、Schema、操作人、审计、领域服务调用和 HTTP 错误映射。
- 直接访问 Prisma 的 Route Handler 从 37 条降至 33 条；数据库异常翻译位于服务端边界，纯领域规则不依赖 Prisma；14 个领域/平台模块共有 281 个 TypeScript 文件。
- 日报编号按业务日期现有最大序号递增，避免中间草稿被删除后生成重复编号；日期解析拒绝不存在的日历日期。

## 影响范围

- 旧日报页面不会恢复，新的生产实绩仍只从生产订单详情进入；本次只是稳定服务器历史数据兼容边界。
- 既有 API URL、权限资源、主要输入输出、审计以及 `DRAFT → CONFIRMED → REVERSED` 行为保持兼容。
- 本版本不修改 Prisma Schema、迁移或页面结构，不自动改写本机测试数据和服务器正式数据。
