# v0.1.382 统一 MES 工作台与混合系统能力边界

日期：2026-08-15

## 更新内容

- 将应用壳的 MES/MRP/ERP 工作区切换改为模块预留按钮，统一进入一个 MES 工作台；当前主按钮默认显示为 MES-lite，MRP/ERP 显示时不可点击。
- “导航设置”可修改三个模块按钮名称，并控制 MRP/ERP 预留按钮显隐；这些设置不改变菜单、权限或业务数据。
- 左上角模块按钮替代原产品名与版本副标题，系统版本号移动到桌面侧栏和移动端全部功能抽屉的左下角。
- 保留生产执行、计划、经营协同和共享平台的领域责任边界；MRP-lite 与 ERP-lite 不再作为用户必须切换的独立系统。
- 将 BOM 用量、销售订单、发货、退货、供应商、客户和企业规则等现有页面纳入统一导航，页面 ID、路由、权限资源和业务数据保持不变。
- “导航与工作区”收敛为“导航设置”，管理模块按钮名称与 MRP/ERP 显隐，以及一级功能区顺序、页面显示名称和页面顺序。
- 既有 `interface.workspaceNavigation.v1` 继续兼容：按 MES → MRP → ERP 合并页面，保留第一次出现的自定义名称和顺序，补回新增页面，并将旧 MRP/ERP 容器设为禁用且清空。
- 更新受影响架构、页面矩阵、公共前端、治理计划和 31 个导航相关 SOP 工作流，并修正 1 处库存调整文字编码；开发期只生成当前 Markdown，不重复生成 DOCX、PDF 和离线 Web。

## 产品判断

- 当前 MRP-lite 只有 BOM 结构与用量检查基础，尚未形成净需求、缺料、齐套和采购/生产建议引擎。
- 当前经营协同覆盖客户、供应商、销售订单、发货、退货和企业规则，但不包含总账、应收应付、税务、完整采购和完整成本会计。
- 因此产品对外定位为“以 MES 为核心，融合轻量计划和经营协同能力的单厂制造管理系统”；MRP/ERP 按钮明确作为预留，不制造已经存在完整独立系统的预期。

## 影响范围

- 页面：不新增或删除业务页面，只用无切换动作的模块按钮替换三工作区切换组件，并调整导航设置页和版本号位置。
- API 与权限：仍使用 `/api/system/workspace-navigation` 和 `navigationSettings` 权限；不新增接口、资源或隐式授权。
- 数据库：不新增 Prisma 模型或迁移，迁移总数保持 84；兼容逻辑只规范化系统设置 JSON，不修改业务表。
- 业务流程：生产、质量、库存、批次、设备和销售履约事务不变；用户无需先选择 MES/MRP/ERP 即可进入已授权功能。
- SOP：181 个流程总量不变，更新 31 个导航相关流程并复核 1 个文字编码修正；最终交付格式在产品冻结后一次性生成和检查。

## 验证结果

- 导航默认值、模块按钮改名与显隐、历史三工作区合并、页面别名保留、数据库持久化和应用壳结构均通过专项验证。
- 本地真实页面验证 MES-lite 主按钮完整显示，MRP/ERP 保持禁用预留；改名和隐藏保存后立即生效，系统版本显示在左侧导航底部。
- 页面注册、权限资源和业务接口无新增；TypeScript、全量 Lint、生产构建、SOP 源校验、发布树门禁和 38 项完整 CI 全部通过。
- 开发阶段只检查本次受影响的导航与帮助源，不重复检查历史 DOCX/PDF/Web 成品。

## 回滚

本版本没有数据库迁移。回滚时恢复上一应用提交即可；旧 `interface.workspaceNavigation.v1` 的三容器数据结构仍受接口接受，且规范化只发生在读取/保存配置时，不影响任何生产、库存、质量或销售记录。若已经保存统一配置，旧 MRP/ERP 菜单自定义副本不会自动重建，但全部页面及自定义名称已合并进 MES 容器，可从回滚前配置审计快照人工恢复。
