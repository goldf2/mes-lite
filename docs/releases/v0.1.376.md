# v0.1.376 生产实绩执行上下文快照

发布日期：2026-08-15

## 更新内容

- 班后实绩新增实际设备和作业文件多选：设备按订单派工/默认路线工作中心过滤，文件按订单物料或工作中心适用范围过滤。
- 保存草稿时由服务端重新解析来源并冻结设备身份、状态、工作中心及文件标题、版本、状态、正文和附件清单；来源主数据后续修改不回写历史。
- 每张实绩必须满足“设备快照或设备例外原因”和“作业文件快照或文件例外原因”，确认前再次复检；已确认/已冲销上下文由数据库触发器保护。
- 历史实绩由加性迁移填写明确的历史迁移原因，不伪造过去未保存的设备或文件。
- 页面复用公共关系编辑骨架，桌面双列、手机单列；新增 3 张真实页面截图，SOP 扩展到 181 个流程并同步站内帮助、Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 数据库：新增 `ProductionOrderActualEquipment`、`ProductionOrderActualWorkInstruction` 和两个例外原因字段；当前共 93 个 Prisma 模型、82 个迁移。
- 页面/API：仍为 44 个页面模块和 149 条 Route Handler；生产订单工作区响应增加执行上下文候选，实绩创建契约增加选择与原因字段。
- 权限：仍为 61 个资源；继续使用生产订单读取/更新与既有人员数据范围，不增加平行实绩权限。
- 不包含：附件二进制副本/哈希、自动设备采集、节拍、停机原因、OEE、部门/班组范围、真实生产岗位审批、Product→Material 生产回填或异地对象存储。

## 验证结果

- 隔离 SQLite 回归覆盖候选过滤、重复/非法 ID、例外原因、设备/文件快照、来源漂移隔离、确认必填和数据库不可变约束。
- 既有生产实绩、生产质量批次、批次谱系和批次全景回归通过；Prisma 格式化/生成、类型检查和 Lint 通过。
- 使用独立演示数据库完成桌面实绩卡片、桌面登记弹窗和 390px 手机弹窗的真实浏览器验证；页面演示未写入服务器或本机业务数据库。
- 33 项 CI 领域基线、生产构建、SOP 清单与四种产物、DOCX/PDF 逐页渲染在本次交付前执行并记录最终结果。

## 部署与回滚

1. 固定本版本精确提交，暂停生产写入并完成数据库与附件一致备份。
2. 部署时执行第 82 个迁移；它新增快照表、例外字段、索引与触发器，并只为历史实绩回填明确原因。
3. 部署后用一张已发布订单验证设备/文件候选、草稿保存、主数据修改不漂移、确认和冲销；再由生产/工艺负责人确认例外原因使用规则。
4. 回滚应用时固定到上一个已验证提交并暂停生产写入；旧应用会忽略新增结构。不得删除新表、快照、触发器或历史原因，也不得用数据库降级撤销已产生的实绩事实。
