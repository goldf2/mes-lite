# v0.1.409 货箱单据、发货单码与扫码打单闭环

日期：2026-08-19

## 更新内容

- 新增货箱单据与货箱明细，一个货箱获得唯一 `BX-` 编码，记录内容物、数量、打包人、打包时间、毛重/净重、尺寸、封箱号和现场照片。
- 发货单详情内聚合货箱列表，装箱数量与发货数量一致后才可确认发货；确认发货、签收和取消时同步货箱状态。
- 发货单与货箱单据分别支持二维码标签；物流运单号保持为独立字段，不与系统单据码混合。
- 硬件工具新增单据扫码入口，支持 USB HID 扫码枪的 Enter/Tab 结束符，可从 `BX-` 或 `SH-` 编码查询并打开对应系统单据。
- 发货单 PDF 增加发货单二维码、货箱汇总和物流运单号，货箱现场照片继续复用通用附件管理。

## 影响范围

- 新增 `PackageDocument` 和 `PackageDocumentItem` 两个数据模型，并为发货单、物料、库存批次和附件业务补充关系。
- 新货箱仅能关联统一 `Material` 主档；未完成旧 `Product` 映射的历史发货单继续使用原发货流程，不强行生成货箱。
- 为兼容旧数据，未创建货箱的发货单仍可按原规则确认发货；一旦开始装箱，则启用完整性校验。
- 货箱照片的上传、查看、下载和归档继续使用通用附件权限与审计链。
