# MES-lite v0.1.469

## 更新内容

本版本把冻结的 BOM、工艺路线、工序/工作中心成本真正带入生产过账：

- 生产订单实绩和 BOM 快捷生产日报确认时，先按实际投入库存流水得到材料成本，再按冻结 BOM 成本运行的数量基准缩放人工、机时/能源、直接耗材和固定费用等增值加工成本。
- 主产出库存成本 = 实际材料成本 + 实际增值加工成本；其他产出继续按零成本入库，避免把副产出错误地重复分摊。
- `ProductionOrderActual`、`DailyProductionReport` 及各自主产出明细新增材料/加工成本拆分字段，并保存 `appliedCostSnapshot`，记录 BOM、版本、工艺路线、工作中心成本行和实际数量缩放结果。
- 无 BOM 或历史无成本快照的生产保持材料成本兼容行为，并明确保存 `MATERIAL_ONLY` 应用快照。
- 冲销继续使用确认时保存的成本金额和原库存流水，不重新读取当前 BOM、工艺路线或成本运行，保证历史事实可逆且不受主数据后续修改影响。
- 生产实绩回归验证纳入 CI 基线；补充生产数据模型和双单位成本核算说明。
- 库存流水页新增日期范围数量变动统计，直接聚合 `StockLog`，覆盖来料及来料冲销、生产、发货、退货、移库、调整等；结果按流水类型、物料/对象和库位汇总，遵守库存数据范围，不混加不同库存单位。

## 数据库迁移

新增 `20260907150000_add_production_execution_cost_breakdown`，仅增加生产实绩、生产日报及产出明细的成本拆分字段和应用快照字段，不改写历史库存或历史单据。

库存数量变动统计不新增数据库表或统计账，复用现有 `StockLog` 查询；因此无需额外数据迁移。

## 影响范围

影响生产订单实绩确认、生产日报快捷过账和主产出库存成本展示；历史已确认记录默认保留原有材料成本，不回算。库存流水统计沿用 `stocks.read` 权限和库存数据范围，不改变发货、质检和冲销操作流程；新迁移随应用启动执行，失败时不应开始业务过账。
