# MES-lite v0.1.176

发布日期：2026-08-04

## 更新内容

- PDF 上传不再同步生成缩略图，文件写入后立即返回成功。
- PDF 缩略图改由独立子进程渲染；即使底层 PDF 渲染库崩溃，也不会导致 MES 主服务退出。
- 产品文档搜索增加附件原始文件名和附件说明，可使用图号或 PDF 文件名查找文档。
- 多文件上传改为显示实际成功数量，失败时不再被“上传完成”提示覆盖。

## 影响范围

- 影响产品文档的 PDF 上传、缩略图生成和文档搜索。
- 图片附件仍在上传时直接生成缩略图，不改变已有行为。
- 无法渲染的 PDF 会显示“预览不可用”，原文件仍可正常打开和下载。

## 验证结果

- 使用 `P12项目 21#图纸20260804.pdf` 复现底层渲染进程 `SIGSEGV/SIGABRT`，隔离后主服务保持健康。
- 同一 PDF 上传成功，文档列表和详情页可继续访问。
- 完整文件名（含中文、空格、`#` 和 `.pdf`）搜索可返回对应文档。
- TypeScript 类型检查与子进程脚本语法检查通过。
