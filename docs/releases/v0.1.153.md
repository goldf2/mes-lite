# MES-lite v0.1.153

发布日期：2026-08-03

## 更新内容

- BOM 投入从“仅原材料”调整为任意物料，支持已有产品作为投入进行二次加工。
- 生产订单创建时必须选择启用的 BOM，并冻结 BOM 版本及投入、产出快照。
- 增加班后生产实绩，支持实际投入、损耗、多项产出、人员和库位记录。
- 实绩确认、冲销和删除与库存事务联动，并更新生产订单累计完成数量。
- 仪表盘生产统计改为基于生产订单及已确认班后实绩。

## 影响范围

- BOM：投入物料、多个产出和主产出关系。
- 生产订单：BOM 快照、计划数量和班后实绩。
- 库存：投入出库、产出入库、成本承接及合法冲销。
- 仪表盘：订单与实际产量统计口径。
- 数据库：新增生产订单实绩及其投入、产出、人员明细模型。

## 验证结果

- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 生产订单 BOM 快照、任意物料投入、二次加工、多产出及库存事务脚本通过。
- BOM 版本、多产出、单位消耗与损耗计算脚本通过。
- 全新 SQLite 数据库的 55 条迁移完整执行通过。
