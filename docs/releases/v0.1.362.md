# MES-lite v0.1.362

发布日期：2026-08-13

## 更新内容

- 建立 GitHub Actions CI：Prisma、17 项领域/治理回归、TypeScript、Lint 和生产构建成为新提交门禁。
- Coolify 生产关闭 Auto Deploy 并固定精确提交；持久挂载 `/app/backups`，启用迁移前一致备份和每日北京时间 02:00 任务。
- 首份生产备份验证通过；非覆盖恢复候选达到 RPO 197.472 秒、候选 RTO 11.460 秒，证据明确区分候选技术通过与完整实例恢复。
- 记录并更正 v0.1.361 推送曾被 Auto Deploy 自动部署的事实，补齐精确版本、健康、备份和回滚控制。
- 新增单厂商业交付验收基线，明确交付范围、环境准入、业务闭环、岗位签署和发布/回滚门禁。
- 全流程作业指导书扩展到 138 个流程，新增 6 张真实 Coolify 运维截图；交付 Markdown、DOCX、PDF 和可搜索离线 Web 版。

## 影响范围

- 不修改 Prisma Schema、业务 API 或业务数据，迁移仍为 76 个。
- 新增 CI 工作流、验证编排脚本、Web SOP 构建器和商业/运维文档。
- 生产外部配置已增加 `/app/backups` 持久目录、每日定时任务和 `MES_LITE_PRE_MIGRATION_BACKUP_ENABLED=true`。
- Coolify 当前未配置 S3 Storage，异地副本仍是外部依赖；没有把主机内备份冒充异地容灾完成。

## 验证结果

- 首份生产一致备份：90 条附件记录、253 个清单文件、SQLite `quick_check=ok`、归档 SHA-256 已记录。
- 生产候选恢复：`CANDIDATE_PASS`，RPO 197.472 秒，候选 RTO 11.460 秒；候选新实例应用冒烟未执行。
- 生产 `/api/health/ready`：数据库、76 个迁移、数据目录、附件目录和备份新鲜度均为 pass。
- `npm run verify:ci`、`npx tsc --noEmit`、`npm run lint`、`npm run build`、发布文档和开发文档校验纳入本版门禁。
- DOCX 已用 LibreOffice 渲染为 140 页 PNG 并逐页联系表检查，封面、流程 133、流程 138 和治理边界关键页放大检查通过；PDF 为 140 页 A4。
- 离线 Web 共包含 138 个流程和 138 张本地图片；浏览器实测可把“迁移前备份”准确筛选为 1/138，并正常放大截图。

## 回滚说明

本版无数据库迁移。代码可回退到 v0.1.361；外部备份挂载、每日任务、已生成归档和恢复证据不得删除。若禁用迁移前备份，必须先说明替代保护措施。关闭 Auto Deploy 和固定精确提交属于安全控制，不应随代码回退而撤销。
