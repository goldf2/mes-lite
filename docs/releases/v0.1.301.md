# MES-lite v0.1.301

日期：2026-08-09

## 更新内容

- 建立 `modules/sales`，将销售订单页从根组件目录迁入销售领域并通过模块公开入口加载。
- 新增销售订单 client，统一列表、候选项、创建、状态流转和调价 HTTP 调用；页面不再直接调用 `fetch`。
- 集中客户、销售物料、订单/明细、草稿和调价契约，状态展示与日期/数量/金额格式进入领域视图模型。
- 销售订单页从 686 行降至 586 行；根级存量领域页从 9 个降至 8 个。

## 影响范围

- 保留列表/卡片、高级搜索、附件、AI 识别、PDF 打印、状态流转和受控调价交互。
- 不修改 Prisma Schema、销售业务规则、API 契约或服务器正式数据。

## 验证结果

- 销售模块、单据凭据、附件、打印、调价边界、高级搜索、模块边界和页面模块校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
