# MES-lite v0.1.202

发布日期：2026-08-06

## 更新内容

- 将全系统页面收口为工作台、资源、主从、交易、设置和工具六类公共骨架，34 个稳定页面入口全部登记模块类型并经过统一页面边界渲染。
- 设备台账和员工资料正式迁入 `ResourcePage`，统一标题、搜索、筛选、列表/卡片、排序、加载、空状态和新增入口；排序按钮同时收口为公共资源组件。
- 产品文档的适用工作中心改用一对多关联字段，员工与登录账号改用多对一关联字段；统一关联数量、搜索、对象身份和移除交互。
- 新增页面模块覆盖校验和系统级接入清单，明确复杂业务页保留库存、成本、状态流转、确认与冲销等专用领域内核。

## 影响范围

- 所有生产功能页面均由 `PageModuleBoundary` 标识稳定页面键和所属模块类型，后续可在公共边界统一调整页面语义、间距和响应式规则。
- 常规主数据页面优先使用 `ResourcePage`；复杂主从和交易页面仍保留专用业务组件，但不得复制外围页面骨架与关联选择逻辑。
- 不改变数据库结构、业务 API、库存过账、BOM 计算、生产确认和冲销规则。

## 验证结果

- `npm run verify:page-modules` 通过：34 个页面入口全部覆盖，六类模块唯一且物料三个子页面映射正确。
- 浏览器完成设备资源页桌面/窄屏、页面工具浮窗、新增弹窗、员工账号多对一和产品文档工作中心一对多回归。
- TypeScript、ESLint 和生产构建通过；ESLint 仅保留项目既有警告。
- `package.json`、`package-lock.json`、版本文档和发布索引均为 `v0.1.202`。
