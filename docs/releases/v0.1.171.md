# MES-lite v0.1.171

发布日期：2026-08-04

## 更新内容

- 物料列表和卡片中的“创建 BOM”改为在当前页面打开宽模态窗口，不再直接跳转到 BOM 设置。
- 快速创建窗口自动将当前物料作为主产出，支持多项投入、其他产出、同量纲单位换算、方案名称和默认 BOM 设置。
- 快速创建与完整 BOM 设置复用同一套草稿编辑、校验和保存逻辑，避免两种入口产生不同数据口径。
- 保存成功后自动关闭窗口并刷新物料 BOM 简况；复杂维护仍可通过“完整 BOM 设置”进入原工作台。

## 影响范围

- 影响物料管理的 BOM 创建入口和 BOM 编辑器界面复用方式。
- 不改变 BOM 数据结构、版本生成规则、默认方案规则、单位保存口径和生产订单快照。
- BOM 快速创建继续受现有 BOM 关系修改权限控制。

## 验证结果

- TypeScript 类型检查通过。
- BOM 多方案、整批共同投入、多产出和版本唯一性专项验证通过。
- Next.js 生产构建和浏览器模态交互验证通过。
