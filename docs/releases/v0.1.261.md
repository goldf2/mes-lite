# MES-lite v0.1.261

发布日期：2026-08-09

## 更新内容

- 将窄屏同级菜单从常驻展开的横向页签改为固定顶部工具条内的呼出按钮，默认收起且仅在用户点击后展开当前分组。
- 同级菜单显示当前页面名称与选中状态，选择页面、点击外部或按 Escape 后自动收起。
- 将窄屏顶部导航工具条从内容区 `sticky` 改为视口级 `fixed`，主内容统一预留顶部安全区和工具条高度。
- 扩展响应式导航校验，防止同级菜单恢复为默认全展开或顶部工具条再跟随页面滚动。

## 影响范围

- 影响小于 `1024px` 的移动端与平板竖屏布局。
- 不改变统一菜单数据源、工作区归属、权限、页面排序和业务数据。
- “显示同级菜单按钮”开关的保存方式不变，开启时显示呼出按钮，不再表示菜单常驻展开。

## 验证结果

- 响应式导航、工作区导航、页面模块和版本文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。
- 窄屏同级菜单默认收起、按钮可呼出且顶部导航工具条使用视口固定定位。
