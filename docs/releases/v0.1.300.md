# MES-lite v0.1.300

日期：2026-08-09

## 更新内容

- 将人员管理页和权限管理页从根组件目录迁入 `modules/identity-access/ui`，并通过模块公开入口装载。
- 新增身份权限 client，统一人员、权限组和授权 HTTP 调用；两个页面不再直接调用 `fetch`。
- 补齐人员角色/状态契约和人员管理服务，操作人员 API 收敛为 41 行 HTTP 适配层。
- 根级存量领域页从 11 个降至 9 个。

## 影响范围

- 保留人员审批、角色/状态维护、权限组分配和权限矩阵交互。
- 不修改 Prisma Schema、权限语义、导航结构或服务器正式数据。

## 验证结果

- 身份权限模块、高级搜索、模块边界、页面模块、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
