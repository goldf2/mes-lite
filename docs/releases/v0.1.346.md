# MES-lite v0.1.346

日期：2026-08-12

## 更新内容

- 公开密码注册默认关闭；启用后所有密码注册和首次微信登录均只创建 `OPERATOR / PENDING` 账号，不再存在“首位注册者自动管理员”路径。
- 新增一次性初始管理员安装接口。只有配置至少 32 字符的 `MES_INITIAL_ADMIN_TOKEN` 并提供匹配请求头时才能创建首个 `ADMIN / ACTIVE` 账号；已有管理员后永久拒绝重复安装。
- `Operator` 增加失败次数、最后失败时间和锁定截止时间；同一账号 15 分钟内连续 5 次密码错误后锁定 15 分钟，成功验证后清零。
- 新增 `AuthenticationThrottle` 持久限流表，对登录、公开注册和管理员安装按来源执行独立窗口及阻断策略，429 响应提供 `Retry-After`。
- Middleware 对所有非安全方法的 `/api/*` 请求执行 Origin 同源校验，支持 Coolify 反向代理转发头与显式 `MES_TRUSTED_ORIGINS` 白名单。
- 会话 Cookie 和微信 OAuth state Cookie 在生产环境显式启用 `Secure`；登录页只在服务端确认公开注册开启后显示注册入口。
- 公开注册和微信登录配置状态改为运行时无缓存读取，避免 Coolify 运行时变量被构建阶段静态结果覆盖。
- 权限角色/权限组验证改用自动迁移并销毁的临时完整 SQLite，不再连接或写入工作区数据库。

## 影响范围

- 新增一条 Prisma 迁移；现有账号、角色、密码和会话数据不改变，既有管理员不需要重新安装。
- 新账号密码至少 10 位，初始管理员密码至少 12 位；既有账号仍可使用原密码登录。
- 使用 curl、移动端或外部系统调用写 API 时必须携带与服务地址匹配的 `Origin`；允许的额外来源通过 `MES_TRUSTED_ORIGINS` 配置。
- 管理员安装完成后必须从 Coolify 删除 `MES_INITIAL_ADMIN_TOKEN` 并重新部署；公开注册只应在受控时间窗口临时开启。

## 验证结果

- 临时完整 SQLite 迁移与认证回归覆盖显式管理员安装、重复安装拒绝、公开注册待审、微信待审、失败锁定、解锁、限流隔离、同源策略和会话撤销。
- 身份权限模块、Prisma Schema、TypeScript、ESLint、模块边界、开发文档、发布记录和生产构建验证通过。

## 回滚

- 本迁移只增加可空字段、带默认值字段和独立限流表；应用可回滚到 `v0.1.345`，新增结构暂时保留，不需要回写或删除生产账号数据。
- 回滚旧应用会撤销默认关闭注册和写请求同源保护，只允许作为短时故障回退；恢复服务后应尽快重新部署本版本或更高版本。
