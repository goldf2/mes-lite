# MES-lite v0.1.351

日期：2026-08-12

## 更新内容

- 新增隔离演示库种子脚本 `scripts/seed-user-guide-demo.ts`，仅允许写入文件名含 `mes_lite_guide` 的空数据库；覆盖物料、BOM、生产、来料、库存、销售、设备、文档、配置和权限演示数据。
- 新增 65 张本地真实页面操作截图，以及 68 页《MES-lite 全流程作业指导书》的 Markdown、Word 和 PDF 交付物。
- 作业指导书按“主数据 → 业务单据 → 状态确认 → 库存/审计复核”编排，并明确质量、批次/炉批、设备事件/OEE 仍属于后续治理阶段。
- 修复生产订单发布后详情中的班后实绩面板仍保留草稿旧状态，导致“登记班后产量”按钮错误禁用的问题。
- 增加生产订单模块结构回归，要求实绩面板按订单 ID 和订单状态重新挂载。
- Word 指导书为 65 张截图补齐替代文本，表格补齐表头标记；辅助功能审计高、中、低问题均为 0。

## 影响范围

- 不修改 Prisma Schema，不执行生产数据库迁移或批量数据更新。
- `prisma/mes_lite_guide.db` 是被 `.gitignore` 排除的本机临时演示库；现有 `prisma/mes_lite.db` 未被读取、覆盖或重置。
- 截图采集自 v0.1.350 的隔离演示环境；v0.1.351 的界面差异仅为发布后实绩面板正确刷新，截图中的业务步骤仍适用。
- 指导书正文只描述当前可验证流程；质量、批次和设备事件闭环没有被误标为已交付。

## 验证结果

- 本机真实浏览器完成登录、MES/ERP 工作区、物料/BOM、生产订单发布、派工、流程转移、来料收货、库存与流水、销售订单、发货、退货返库、文档、设备、配置、系统、工具和权限操作截图。
- 生产订单发布后已在浏览器确认“登记班后产量”按钮可用。
- DOCX/PDF 共 68 页，逐页渲染检查无中文字体缺失、内容越界、截图裁断、页码或页眉异常。
- DOCX 辅助功能审计：`high=0`、`medium=0`、`low=0`。
- 全新隔离 SQLite 数据库完成 Schema 同步和演示种子写入；演示库包含 4 个物料、2 张生产订单、2 张销售订单和 2 张发货单。
- 使用业务库文件名调用演示种子时已验证安全保护会立即拒绝执行。
- `npm run verify:production-order-module`
- `npx tsc --noEmit --incremental false`
- `npm run lint`
- `npx prisma validate`
- `npm run verify:development-docs`
- `npm run verify:release-notes`
- `npm run build`

## 回滚

本版本没有 Schema 或生产数据迁移，可直接回退应用代码。回退后生产订单详情可能再次出现发布状态已更新但实绩面板仍按草稿状态禁用的界面问题；本机演示库可直接停用或删除，不影响生产数据。
