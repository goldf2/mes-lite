# MES-lite v0.1.158

发布日期：2026-08-03

## 更新内容

- 修复桌面端 BOM 工作区错误隐藏主内容纵向滚动的问题。
- BOM 右侧编辑区、转换模型、方案和投入明细恢复由页面主内容区统一滚动，不再被视口底部截断。
- 页面最右侧保留稳定且清晰的滚动轨道；顶部搜索和新建操作继续固定，不随正文滚动。
- 保留多产出达到 4 项时的局部明细滚动，并与页面主滚动正确衔接。

## 影响范围

- 影响所有桌面端业务页面的主内容滚动容器和滚动条外观。
- 不修改 BOM 数据结构、保存逻辑、生产订单或库存逻辑。

## 验证结果

- TypeScript 类型检查通过。
- 浏览器桌面视口验证 BOM 工作区最右侧显示主滚动条，并可滚动到 BOM 方案和投入明细。
- 顶部工具栏在正文滚动后保持固定。
- 发布说明、Docker 依赖检查及生产构建通过。
