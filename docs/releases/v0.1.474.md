# MES-lite v0.1.474

## 更新内容

- 重量库存、长度辅助计量的来料可选择“未测长，仅按重量入库”，无需历史样本。模式切换清空价格以避免把元/米误作元/kg，服务端禁止未知长度计价或同时提交长度。
- 延续 v0.1.473 的总长度、单根长度乘根数录入；计算值及未知值均不污染实测历史。
- 来料详情、打印、CSV、库存和物料全景区分未知/不完整长度，不展示为零实测；BOM 辅助单位核价拒绝不完整数量。
- 未测长和混存库存的移动平均出库使用主数量及金额；FIFO 保留成本层结转。支持冲销，非 FIFO 全库辅助数量核实需明确确认并保留审计。

## 影响范围

新增迁移 `20260929120000_optional_receiving_measurement`，给库存、流水、内部批次、成本层增加辅助完整性字段及流水传播触发器，历史记录默认完整，不重算历史业务。沿用来料/库存命令、SearchableSelect、ModalDialog 和现有调整权限，未新增独立操作页面或平行库存账。

辅助数值仍是内部守恒台账，完整性为 false 时不能据此推导真实总长度或单位成本。新已测长批次不会自动消除旧的未知状态。FIFO 仍不允许直接修改余额；已发布 BOM 快照不改写。数据模型、领域模型、流程总览与 SOP 同步。

## 验证结果

来料回归覆盖未知/已知混存、移动平均/FIFO 出库成本、发货冲销、来料红冲、辅助单位核价拒绝和全库补测确认。多明细发货、库存流水、成本领域及 BOM 成本回归通过。真实浏览器使用隔离接口样本验证未测长模式、重量计价、未知显示及提交字段。TypeScript、SOP、开发文档、发布说明及架构基线通过，定向 Lint 无错误、9 条存量警告。远端 CI 结果须单独核验；未直接修改生产数据库。
