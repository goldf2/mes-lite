# MES-lite v0.1.338

日期：2026-08-10

## 更新内容

- 新增“当前已实现功能流程”HTML 展示，按销售履约、来料成本、生产执行、库存转移和独立支撑五条链路呈现代码事实。
- 新增当前角色泳道，明确销售、计划、仓库、生产、质检和 MES 系统当前可以执行的操作及责任交接。
- 明确销售订单到生产订单仍为人工衔接，生产实绩确认后直接过账，基础质检记录尚未进入库存放行事务。
- 新增可编辑 Excalidraw 源文件，并保留目标业务泳道作为独立的未来蓝图。

## 影响范围

- 仅新增静态 HTML、Excalidraw 图稿和架构说明，不修改页面、API、权限、Schema、迁移或业务数据。
- 当前流程图以页面注册、Prisma 模型、生产实绩服务、库存过账与冲销服务为事实来源。
