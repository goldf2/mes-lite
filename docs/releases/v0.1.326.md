# MES-lite v0.1.326

日期：2026-08-10

## 更新内容

- 新增 `modules/business-documents`，集中来料、销售订单、发货、退货、流程转移、生产订单和派工 7 类单据的类型定义、打印投影和格式规则。
- 将打印链接、预生成 client 和“系统生成单据 + 附件管理”详情骨架迁入模块；各业务页面只通过模块公开出口调用，并继续复用公共 `ModalDialog` 和 `AttachmentPanel`。
- 将 A4 PDF 引擎、归档附件缓存、普通补打复用及强制重生成新版本迁入模块服务。
- 打印 API 从 211 行降至 42 行，只保留类型识别、资源权限、生成权限、服务调用和 PDF HTTP 响应，不再直接访问 Prisma。
- 删除两个根级业务单据组件和 `lib/business-document-pdf.ts`；直接访问 Prisma 的 API 从 30 条降至 29 条，15 个领域/平台模块共有 314 个 TypeScript 文件。

## 影响范围

- 7 类单据的打印按钮、详情附件区、`/api/business-documents/[kind]/[id]/print` URL、PDF 内容和首次创建后自动归档行为保持兼容。
- 普通补打继续读取最新有效归档；`regenerate=1` 继续按已有归档选择 `update` 或 `create` 权限并保存新版本。
- 本版本不修改 Prisma Schema、迁移、单据创建或状态流程，不改写本机测试数据和服务器正式数据。
