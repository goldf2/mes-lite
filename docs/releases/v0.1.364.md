# MES-lite v0.1.364

发布日期：2026-08-13

## 更新内容

- GitHub Actions Checkout 设置 `fetch-depth: 0`，让生产数据库审计可以读取历史迁移提交。
- `actions/checkout` 与 `actions/setup-node` 升级到 v5，使用当前 Actions 运行时，消除旧 Node 20 Action 运行时弃用告警。
- 延续 v0.1.362 的 138 流程 Markdown、DOCX、PDF 与离线 Web SOP 交付，不重新生成内容相同的制品。

## 影响范围

- 仅修改 CI 配置、版本号与事实基线文档，不修改业务代码、Schema、迁移或生产数据。
- 生产 Coolify 继续固定在 v0.1.361，Auto Deploy 继续关闭。

## 验证结果

- 本地确认审计依赖的历史提交存在，完整仓库下 `npm run verify:production-database-audit` 通过。
- 本地 17 项 CI 领域/治理基线、类型检查、Lint 和生产构建通过。
- 推送后由 GitHub Actions 完成 Ubuntu、完整 Git 历史环境的最终验收。

## 回滚说明

本版没有数据库迁移。代码可回退到 v0.1.363；生产固定提交、关闭 Auto Deploy、持久备份和定时任务不随 CI 配置回退。
