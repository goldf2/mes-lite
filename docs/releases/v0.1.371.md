# v0.1.371 设备维保工单与备件批次闭环

发布日期：2026-08-14

## 更新内容

- 新增设备维保页面、周期保养计划、到期/逾期任务、计划保养工单、故障维修工单、开始/完成/取消状态机和岗位待办。
- 新增六张维保事实表及 SQLite 不变式：计划/项目不可覆盖、工单状态不可跳转、计划保养须完整达标、结果/备件/批次分配和完成事实不可修改删除。
- 开始工单同步进入设备维修状态；完成工单在同一事务恢复设备、推进保养周期，并通过库存模块公开入口过账备件库存、成本与实际批次。
- 新增第 51 个权限资源 `equipmentMaintenance`、设备维护岗位预置、旧安装递归继承、工作中心/库位数据范围和工单附件授权。
- 岗位任务工作台新增到期保养和维保工单；SOP 增至 154 个流程，新增 6 张真实页面截图并更新站内帮助、Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 数据库：新增 `EquipmentMaintenancePlan`、`EquipmentMaintenancePlanItem`、`EquipmentMaintenanceWorkOrder`、`EquipmentMaintenanceWorkResult`、`EquipmentMaintenanceSpareUsage`、`EquipmentMaintenanceSpareLotAllocation`，迁移总数为 79。
- 页面/API：新增 `equipmentMaintenance` 页面键和 8 条 Route Handler，当前为 44 个页面模块定义、143 条 API、88 个模型、51 个权限资源。
- 库存：新增公开的业务领料过账入口，继续复用库存可用量、FIFO 批次分配、单位换算和成本口径，没有建立平行库存。
- 不包含：PLC/边缘网关自动采集、停机原因采集、节拍与 OEE；这些能力必须先确认数据源和口径。

## 验证结果

- Prisma validate/generate、全量 79 迁移从零重放通过。
- 维保领域与真实 HTTP 回归覆盖：计划不变式、状态机、幂等、工作中心/库位范围、权限 403、完整清单、库存/成本/批次原子过账、设备恢复、审计和附件授权。
- 真实本地页面完成到期计划、建计划、建报修、开始工单、备件领用与完成历史 6 个流程截图。
- SOP、开发文档、发布说明、类型检查、Lint、CI 领域基线、生产构建和应用恢复演练在提交前执行。

## 部署与回滚

1. 部署前固定精确提交，完成 SQLite 与附件一致备份并校验。
2. 应用启动执行第 79 个迁移；用设备维护岗位验证授权工作中心内的计划、工单、开始/完成和附件，用受限仓库范围复核备件候选。
3. 复核旧安装继承出的 `equipmentMaintenance`、库存读取和附件权限，不把兼容继承视为审批结论。
4. 应用回滚时固定到上一个已验证提交；保留六张新增表、设备事件与库存事实，不执行破坏性降级。
5. 只有迁移/数据库损坏且应用回滚无效时，才经业务确认恢复部署前一致备份；恢复后重新验证登录、设备状态、库存余额/流水、批次和工单连续性。
