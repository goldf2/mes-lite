# v0.1.394 系统全景与功能完备性审查

日期：2026-08-16

## 更新内容

- 新增系统全景索引，建立“架构 → 流程 → 时序 → 功能完备性 → 数据/权限明细”的统一阅读路径。
- 扩展系统结构图，覆盖外部角色与系统边界、Coolify 运行部署、17 个领域/平台模块及其依赖方向。
- 将当前来料、生产、质量、库存、销售退货和设备维保主链嵌入 Mermaid 流程图，并标明人工计划衔接和安全逆向动作。
- 补齐检验标准与任务快照、质量判定/处置、退货回流、点检维修、在线帮助和部署恢复关键时序。
- 新增 17 模块功能全景与完备性审查，按输入、处理、输出、库存/成本、追溯和逆向动作区分当前闭环、基础可用、横切支撑与兼容过渡。
- 将视频教学建议收敛为跨页面典型工作流，而不是每页或每个按钮单独制作。
- 扩展开发文档校验，防止全景文档、模块覆盖、版本基线和 Mermaid 围栏再次漂移。

## 影响范围

- 仅更新架构、流程、时序、产品审查、发布与文档治理文件。
- 不改变页面、导航交互、HTTP API、权限资源、Prisma 模型、数据库迁移或车间 SOP 步骤。
- 当前仍是单厂单实例 SQLite + 持久目录架构；MRP/ERP 仍为有限能力和预留入口，不构成完整 MRP/ERP 承诺。

## 验证结果

- 文档事实数量与代码中的页面、API、模型、权限、模块和验证命令一致。
- 所有 17 个模块均在功能审查中出现，架构/流程/时序文档使用当前版本基线。
- 相关文档链接、Mermaid 代码围栏、SOP 版本、发布记录、类型检查、Lint 和生产构建纳入发布前验证。

## 回滚

本版本没有数据迁移。可回退文档和版本文件到 v0.1.393；运行数据与业务状态不受影响。
