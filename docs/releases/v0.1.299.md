# MES-lite v0.1.299

日期：2026-08-09

## 更新内容

- 将未注册但保留的 BOM 成本页面从根级组件目录迁入 `modules/bom`，不擅自恢复导航入口。
- 新增 BOM 成本 client，统一成本工作区、成本数据、快照计算和创建成本对象 HTTP 调用。
- 补齐成本页展示契约和金额/数量/时间/千件工艺成本纯视图模型；页面从 720 行降至 490 行且不再直接调用 `fetch`。
- 根级存量领域页从 12 个降至 11 个。

## 影响范围

- 保留成本计算、成本对象、工艺成本和历史快照实现，但仍不在页面注册表或导航中启用。
- 不修改 Prisma Schema、API 契约、成本数据或服务器正式数据。

## 验证结果

- BOM 成本前后端模块、纯成本规则、模块边界、页面模块、版本文档和开发文档校验通过。
- TypeScript 类型检查与 Next.js 生产构建通过；构建仅保留项目既有警告。

## 数据安全

- 本机 SQLite 中只保留一条明确标记的测试记录；数据库文件和构建缓存不纳入提交。
- 正式数据仍以服务器数据库为准，本次没有连接、读取或写入服务器正式库。
