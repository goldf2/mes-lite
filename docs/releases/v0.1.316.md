# MES-lite v0.1.316

日期：2026-08-10

## 更新内容

- 在 `modules/receiving` 增加来料领域错误、日期编号、红冲可逆性规则、详情服务和状态事务服务。
- 将待收货编辑、确认收货、拒收和整单红冲从 Route Handler 迁入来料领域；总库存、目标库位、成本层和库存流水在同一事务内更新或恢复。
- 来料主路由与详情、收货、拒收、红冲共 5 条 Route Handler 均移除直接 Prisma 访问，只保留权限、Schema、服务调用、审计和 HTTP 错误映射。
- 来料编号改为读取当日最大历史序号后递增，多明细创建在同一事务内连续分配，避免归档或断号后复用编号。
- 直接访问 Prisma 的 Route Handler 从 56 条降至 52 条；14 个领域/平台模块共有 239 个文件。

## 影响范围

- 页面操作和 API URL 保持兼容：待收货来料仍可编辑或拒收，确认收货后增加总库存、指定库位余额并创建成本层。
- 整单红冲继续要求填写原因；对应成本层已被消费或人工改变时拒绝红冲，避免反向恢复破坏账实一致性。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
