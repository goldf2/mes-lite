# MES-lite v0.1.236

发布日期：2026-08-08

## 更新内容

- 为画布工作布局的顶部一级菜单增加 180ms 鼠标意图延迟。
- 鼠标快速横向扫过菜单时不再连续切换二级弹层；在入口上短暂停留后才切换。
- 鼠标离开入口会取消尚未发生的切换，点击打开、关闭和选择功能的行为保持不变。

## 影响范围

- 仅调整画布工作布局顶部二级菜单的指针交互。
- 标准管理侧栏、键盘与点击操作、业务页面和业务数据均不受影响。

## 验证结果

- 工作区应用壳静态契约、TypeScript 和定向 ESLint 校验通过。
- 浏览器验证快速扫过一级菜单不会切换弹层，停留超过意图延迟后正常切换。
