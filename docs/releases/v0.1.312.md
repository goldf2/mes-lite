# MES-lite v0.1.312

日期：2026-08-09

## 更新内容

- 将生产订单详情、同组订单、当前工序和 BOM 候选项装配迁入查询服务。
- 新增可独立测试的生产订单确认与取消状态规则。
- 将确认和取消事务迁入状态服务，集中退料、成本恢复、库存/库位预留释放、报工作废和取消原因。
- 将详情、候选、确认和取消四个 API 收敛为 17–24 行的薄 HTTP 适配层。
- 扩展生产订单临时数据库回归，覆盖状态流转与取消库存一致性。

## 影响范围

- 生产订单详情、候选、确认和取消的 URL、权限、请求与响应保持兼容。
- Prisma Schema、页面布局、服务器正式数据和本机测试数据不变。
- 本机测试 SQLite 和构建缓存不纳入提交；集成验证使用运行后删除的临时数据库。

## 验证结果

- 生产订单创建、详情、候选、确认、取消、归档及生产实绩专项验证通过。
- 取消后总库存预留、库位预留和领料明细状态一致性验证通过。
- 模块边界、开发文档、版本文档和 TypeScript 类型检查通过。
- Next.js 生产构建通过。
