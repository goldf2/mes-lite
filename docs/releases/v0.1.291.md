# MES-lite v0.1.291

## 更新内容

- 提取 `MaterialWorkspaceToolbar`，统一物料管理和 BOM 工作区两种页面形态的公共工具栏装配，消除门户与外部工具栏回调中的重复结构。

- 系统超过 800 行的页面从 1 个降至 0 个；前端 TSX 总量约 29,015 行。
