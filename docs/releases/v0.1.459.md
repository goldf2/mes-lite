# v0.1.459 — 统一物料编码与兼容关联

日期：2026-09-05

状态：未发布候选，已由 v0.1.460 取代。候选 CI 33943480904 在完成前主动取消：独立审查发现既有 Product.unit 不应随统一编码同步，修正和回归见下一版本；本候选未推 main、未部署、未修改生产数据。

## 更新内容

- 业务编码统一为 `Material.code`。内部兼容 Product 保留 ID，新建或无歧义复用时显式绑定 materialId，sku 与物料编码一致，不再另造 MAT- 编码。
- 物料改码和导入更新同步既有 Product；目标编码被占用时整笔回滚，不误承接其他 Product 的历史。
- BOM、成本、日报和物料全景优先按物料 ID 关联；锯切选择器仅显示主档，消除重复项。工艺路线编辑不再用前缀猜测物料。
- 扫码、工单显示和送货单保留真实 MAT- 编码；MAT-A 与 A 不等价。
- 数据工具编码规范化预览增加 Product 变更和目标物料，仅 Product 变化也可执行；歧义、重复目标、目标 SKU 占用全部阻断。执行保留 Product ID，并审计编码及绑定变化。

## 影响范围

没有新增表或自动 SQL 迁移。生产旧数据需在新鲜备份后通过现有数据工具预览并执行；本发布不会在启动时盲目批量修改。BOM 版本、投入/产出数量、库存余额、成本事实、历史单据快照均不改写。已生成的 PDF 与旧扫码会话保持历史原值，不猜测修复。

复用现有 MaterialChoiceSearch、数据工具预览/权限/事务链路和 lib/material-product 兼容入口；新增身份查询实现位于 materials/server，不新增平行目录或物料主档。
