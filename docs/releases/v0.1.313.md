# MES-lite v0.1.313

日期：2026-08-10

## 更新内容

- 将生产实绩请求 Schema、BOM/成本层快照和日期编号规则迁入 `modules/production`。
- 将共同投入、多产出、损耗、订单累计、工作区查询及草稿创建/删除迁入生产领域服务。
- 将确认投入/产出库存成本过账与冲销库存/成本层恢复迁入独立状态事务服务。
- 将四条实绩 API 收敛为 26–43 行薄 HTTP 适配层，并删除扁平 `lib/production-order-actual.ts`。
- 修正删除中间草稿后按记录数量生成实绩号可能撞号的问题，改为按当日最大历史序号继续编号。
- 扩展模块边界和临时数据库回归，覆盖实绩完整生命周期、多产出、库存成本和编号断档。

## 影响范围

- 生产订单详情中的班后实绩入口、权限、URL、请求和响应保持兼容。
- 确认和冲销继续使用同一事务原子更新投入、所有产出、库存流水、成本层和生产订单累计。
- Prisma Schema、迁移文件、页面布局、服务器正式数据和本机测试数据不变。
- 本机测试 SQLite 与构建缓存不纳入提交；验证使用运行后删除的临时完整 SQLite。
