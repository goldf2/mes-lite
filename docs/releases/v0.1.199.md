# MES-lite v0.1.199

发布日期：2026-08-05

## 更新内容

- 将前端公共框架从默认推荐收紧为强制要求：所有页面必须使用公共应用壳、资源工作区和公共语义组件。
- 明确公共框架缺少合理能力时，必须先修改公共模块或增加稳定扩展点，再由业务页面调用，禁止留下单页框架补丁。
- 常规查询、新增、修改、归档、恢复和多对象关联必须使用统一骨架。
- 将专用实现限制在全屏文件查看、图形画布、高密度矩阵等确实不适合标准结构的领域主体；外围工具栏、按钮、弹窗、反馈和响应式布局仍必须复用公共框架。
- 强化完成定义和新模块检查清单，要求公共模块变更保持兼容或同步迁移全部调用方。

## 影响范围

- 影响后续全部前端页面、公共组件、资源配置和关联编辑器的开发与评审方式。
- 不修改现有运行时代码、业务流程、数据库模型或 API 契约。
- 本次为前端架构治理规范变更，无需更新领域模型和业务流程图。
