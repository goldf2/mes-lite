# MES-lite v0.1.192

发布日期：2026-08-05

## 更新内容

- AI 助手入口图标应用参数实验室的 002 预设，使用六叶片玻璃效果和柔和中心光。
- 动效同步为 48 秒旋转、8 秒呼吸和 0.94 按压缩放，鼠标悬停仍会暂停旋转。
- 在“配置 → 系统设置 → AI 助手配置”增加“图标调参”入口，以应用内窗口打开完整参数实验室。
- 内置调参页以 002 为默认预设，继续支持叶片、材质、中心、动态和用户预设调整。

## 影响范围

- 仅调整 AI 助手图标资产、交互动效和系统设置入口，不改变 AI 模型调用、权限或业务数据。
- 调参页中的用户预设保存在当前浏览器；参数调整不会自动覆盖系统图标资产。

## 验证结果

- `npm run lint -- --file app/components/SystemPage.tsx` 通过，仅保留既有 Hook 依赖警告。
- `npm run build` 通过，类型检查和静态页面生成正常。
- 浏览器验证 `/ai/assistant-mark-lab.html` 可访问，002 默认参数和三栏布局加载正常。
