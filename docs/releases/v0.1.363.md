# MES-lite v0.1.363

发布日期：2026-08-13

## 更新内容

- 修正 GitHub Actions 在 job 级 `env` 中引用不可用 `runner.temp` 上下文导致工作流无法解析的问题。
- CI 数据库 URL 改为 SQLite 相对文件路径，使工作流可在 GitHub Ubuntu runner 创建临时数据库。
- 保留 v0.1.362 的 138 流程 Markdown、DOCX、PDF 与离线 Web SOP 作为本轮操作交付制品。

## 影响范围

- 仅修改 CI 配置、版本号与事实基线文档，不修改业务代码、Prisma Schema、迁移或生产数据。
- 生产 Coolify 继续固定在 v0.1.361；关闭 Auto Deploy 的安全控制保持不变。

## 验证结果

- 本地 `npm run verify:ci` 的 17 项领域/治理基线通过。
- `npx tsc --noEmit`、`npm run lint` 和 `npm run build` 通过。
- 推送后以 GitHub Actions 远端运行结果作为最终 CI 环境验收。

## 回滚说明

本版没有数据库迁移。代码可回退到 v0.1.362；不要撤销固定生产提交、关闭 Auto Deploy、持久备份目录、每日一致备份与失败通知。
