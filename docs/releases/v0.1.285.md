# MES-lite v0.1.285

发布日期：2026-08-09

## 更新内容

- 新建 `modules/documents`，按 `contracts/client/server/ui` 组织作业文档完整垂直切片。
- 作业文档页面通过模块公开出口加载，移除根级遗留页面，并把所有直接 HTTP 请求迁入模块 client。
- 将分类层级、智能多关键词、附件名称/类型、高级字段搜索和附件摘要迁入文档查询服务。
- 将自动标题、结构化正文、成品/类别/工作中心校验、关联替换和归档迁入文档写入服务。
- 文档 API 从 551 行降至 78 行，页面从 1497 行降至 1349 行；巨型 API 数量从 7 个降至 6 个。

## 影响范围

- 不改变文档页面布局、接口地址、查询参数、响应结构、权限、附件格式、Prisma 模型或数据库迁移。
- 保留上海时区自动标题、仅关联成品、父子类别查询、工作中心去重、在线正文搜索和附件预览摘要语义。
- 页面继续复用公共工具栏、高级搜索、卡片/列表、弹窗、在线编辑器、关系字段和文件预览组件。

## 数据隔离

- 集成验证仅在 `/tmp` 中按全部迁移创建一次性 SQLite 数据库，完成后删除。
- 未写入本机常用 SQLite，未连接或修改服务器正式数据库。

## 验证结果

- 文档 Schema、client、查询/写入服务、薄 API 和页面模块边界校验通过。
- 临时数据库验证了自动标题、正文搜索、附件组合关键词、附件摘要、工作中心替换、非法关联拒绝和归档隐藏。
- 页面模块、全屏弹窗、高级搜索、在线文档、附件管理、TypeScript、开发文档、版本说明和生产构建通过。
