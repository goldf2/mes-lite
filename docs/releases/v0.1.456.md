# v0.1.456 — 物料全景折叠仪表台

日期：2026-09-04。

## 更新内容

- 物料全景首屏改为关键指标仪表台，固定显示可用库存、待检/冻结、BOM 关系、已存单位材料成本和库存单价。
- 档案与库存、库位与文档、BOM 与工艺、加工与成本、工单与领料、库存与追溯、建模说明改为可折叠详细资料。
- 默认只展开档案与库存；支持逐组展开，也支持“全部展开”和“全部收起”。
- 布局设置继续保存显示模块、模块顺序和显示密度；移除折叠单列模式下不再生效的宽度选择。

## 影响范围

- 仅改变物料全景的页面编排和浏览器本地显示偏好界面。
- 原有物料、库存、BOM、加工成本、文档、工单和流水查询保持不变。
- 不修改接口、数据库结构、权限、库存余额或成本计算。

## 验证结果

- 物料/BOM 模块边界验证覆盖仪表台复用、默认折叠状态、全部展开/收起和无远端直连。
- 完整 50 项本地 CI 基线、TypeScript、定向 Lint、生产构建、SOP、版本说明和差异格式验证已通过；候选精确 SHA CI 和生产页面将在发布门禁中记录。

## 回滚

- 无数据库迁移；可直接重新发布 v0.1.455 对应提交。
- 浏览器已保存的模块显示、顺序和密度偏好仍可兼容读取。
