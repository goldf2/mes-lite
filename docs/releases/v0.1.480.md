# v0.1.480 MES Casdoor统一登录候选

## 更新内容

- MES独立业务系统接入统一身份：公共AuthFrame与固定web-auth0.3.5的正式OIDC/config子路径，保留Node20/React18。正常签名OIDC经精确issuer+subject关联已有ACTIVE Operator，建立原会话并使用原岗位/细粒度权限/dataScope；未绑定不建人/不授权。
- 登录设置只读Runtime状态，薄页组合既有SystemSettingsPageShell；详细连接参数只对已有ADMIN开放，不显示secret。原密码表单提取共享供builtin和人工ADMIN恢复使用，不新造Token或角色。Casdoor缺配置failclosed，不回退普通密码/微信。
- 持久化追加99号迁移：原会话来源/绑定/代际与五分钟单次挑战。随机配置代际、绑定重查/人员状态及恢复角色重查阻止撤销后旧Cookie进入；A→B→A不复活旧会话。正常退出只结束本站，不承诺身份中心退出。
- 具体接口、Runtime变量、模型、回退及生产确认范围见[Casdoor设计](../architecture/casdoor-login.md)。业务库、岗位权限、客户/库存/生产资料不变，目录API机器委托不能充当网页登录。
