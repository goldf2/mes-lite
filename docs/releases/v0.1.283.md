# MES-lite v0.1.283

发布日期：2026-08-09

## 更新内容

- 新增生产工程写入 Schema，集中工艺模板、工艺路线和工序的校验、默认值与类型。
- 新增生产工程服务层，统一拥有模板关联、手工排序、物料兼容映射、单一默认路线、工序替换软删除和事务边界。
- 将加工工艺与物料路线 API 分别从 175 行、253 行收敛至 53 行、58 行，只保留权限、请求解析、审计、错误映射和 HTTP 响应。
- 新增 `verify:production-engineering-server`，既可执行无数据库的边界与 Schema 校验，也可在临时完整数据库中验证领域事务。

## 影响范围

- 不改变页面、接口地址、权限资源、Prisma 模型、菜单或用户操作流程。
- 不改变默认路线、工序替换、模板关联物料和兼容旧 Product 表的业务语义。
- 路线创建和更新现在把物料映射、默认路线调整、工序写入放在同一个事务中，避免部分写入。

## 模块边界

- `app/api/process-templates` 与 `app/api/process-routes` 是 HTTP 适配层，不直接访问 Prisma 或实现事务。
- `modules/production/contracts/production-engineering-schema.ts` 是生产工程写入契约的单一事实源。
- `modules/production/server/production-engineering-service.ts` 是生产工程服务端规则的唯一所有者，不依赖 Next.js 请求对象。

## 验证结果

- 生产工程 Schema、服务边界、前端模块、权限、配置排序和全局模块边界专项校验通过。
- 在按全部迁移创建的临时 SQLite 数据库中，默认路线切换、模板审计前快照和旧工序软删除集成验证通过。
- TypeScript 类型检查、开发文档事实校验、版本发布说明校验和生产构建通过。
