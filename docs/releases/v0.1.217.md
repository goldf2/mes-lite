# MES-lite v0.1.217

发布日期：2026-08-06

## 更新内容

- 桌面一级导航由上下堆叠改为单行排列，默认使用“图标＋文字”。
- 页面选项新增一级菜单显示方式，可在“图标”“图标＋文字”“文字”之间切换。
- 单列折叠与双列导航复用相同显示偏好，不复制菜单数据或导航逻辑。
- 三种显示方式分别记忆双列一级菜单宽度，切换模式时自动使用适合当前内容的宽度范围。

## 影响范围

- 只调整桌面一级导航和当前浏览器的界面偏好，不影响移动导航、业务数据、账号权限或数据库结构。
- 旧版双列一级宽度偏好会在图标＋文字模式下自动限制到可读宽度，之后按显示方式独立保存。

## 验证结果

- TypeScript、目标组件 lint、页面模块校验、版本文档和 Docker 依赖一致性检查通过。
- 生产构建通过。
- 浏览器验证三种显示方式、单列与双列复用、刷新持久化和长标签单行显示。
