# MES-lite v0.1.329

日期：2026-08-10

## 更新内容

- 将扫码会话、扫码事件、撤销/完成和标签打印任务的输入、纯规则、查询与幂等事务统一收口到 `modules/operations-tools`。
- 将归档列表/永久删除/恢复、审计查询、数据一致性修复和物料编码规范化迁入运维工具领域；物料归档写入归回 `modules/materials`。
- 删除扁平 `lib` 中 5 个已迁移的运维规则/服务文件，9 条维护/扫码 API 及物料归档 API 均成为无 Prisma 的薄适配层。
- 把扫码、归档永久删除和物料编码规范化验证改为运行后删除的临时完整 SQLite，避免向本机测试库写验证记录。

## 影响范围

- 不修改页面入口、交互、权限资源、Prisma Schema 或迁移。
- API URL 和响应结构保持不变；扫码与打印重复请求继续按客户端请求标识幂等返回。
- 本机 `prisma/mes_lite.db` 和服务器正式数据均未改写。

## 结构影响

- 直接访问 Prisma 的 Route Handler 从 21 条降至 12 条。
- `modules/` 保持 15 个领域/平台目录，共 346 个 TypeScript 文件。
