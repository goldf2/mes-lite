# MES-lite v0.1.288

日期：2026-08-09

## 更新内容

- 将物料全景的数据响应结构迁入领域契约，将模块顺序、宽度、显示密度、标签和格式化规则迁入纯视图模型。
- 按稳定用户任务提取档案与库存、库位与文档、BOM 与工艺、成本快照、工单与领料、来料与库存记录六组展示模块。
- 将全景布局设置与文件查看器拆为独立弹层任务，继续保留模块显示、宽度、顺序、密度、文件缩放、旋转和下载能力。
- `MaterialPanoramaPage.tsx` 从 1,485 行降至 187 行，只保留数据加载、布局状态、文件方向更新和任务协调。
- 全景页面与子模块统一通过 `materials` 领域客户端访问 HTTP，新增边界验证防止请求、业务正文或弹层重新回流协调页。

## 影响范围

- 影响物料全景页面的代码所有权和内部组件装配；页面入口、全景 API、布局偏好键、展示内容和服务器数据模型不变。
- 不改变物料、库存、BOM、工艺、成本、工单、来料或附件业务规则。

## 验证结果

- TypeScript 类型检查、物料/BOM 专项边界、模块边界、页面骨架和 Next.js 生产构建通过。
- 模块边界校验通过：10 个领域模块、14 个存量根页面、3 个存量巨型页面和 6 个存量巨型路由均未增长。
- 本机开发服务成功编译，物料页面返回 HTTP 200；业务内页受登录保护，未使用或猜测账号绕过认证。

## 数据安全

- 本次只重组前端契约、视图和客户端请求，不执行数据库迁移，不连接或修改服务器正式数据库。
- 本机 SQLite 的隔离测试记录继续保持未提交，不纳入代码版本或部署产物。
