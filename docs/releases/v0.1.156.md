# MES-lite v0.1.156

发布日期：2026-08-03

## 更新内容

- 将 BOM 编辑器首屏明确拆分为“投入物料”和“产出明细（可多项）”两区，不再以单一输出产品输入框表达多产出。
- 产出区保留一个常驻可搜索输入框：首项作为主产出，后续可连续添加副产品、回收料、废料或其他物料。
- 每项产出独立显示物料图片、主产出/其他产出角色、主库存单位和同一基准批次的产出数量；其他产出可单独移除。
- 中等桌面宽度和移动端的产出行改为“物料信息 + 数量操作”上下布局，避免多列压缩造成文字竖排。
- 产出搜索会排除已经作为 BOM 投入或产出的物料，继续由统一的“保存 BOM”按钮一次提交全部投入和产出。
- 保存前补充至少一项投入物料的前端校验，避免把不完整 BOM 请求提交到服务端。

## 影响范围

- 影响物料与 BOM 页面中的 BOM 创建、修改和多项产出录入交互。
- 不修改 Prisma 数据模型和 BOM API；既有 `BOMOutput` 多产出关系、生产订单快照及班后实绩过账逻辑继续兼容。
- 主产出仍是生产订单计划数量和 BOM 换算的基准，其他产出按同一基准批次分别保存数量。

## 验证结果

- TypeScript 类型检查通过。
- BOM 版本验证通过，覆盖一项主产出和一项其他产出的持久化关系。
- 生产订单班后实绩验证通过，覆盖冻结全部 BOM 产出、逐项实际数量和库存过账数据。
- 浏览器实测：为既有 BOM 添加第二项产出并填写独立数量，保存后左侧计数更新为“产出 2 项”；刷新页面后两项产出及数量仍正确恢复。
- 浏览器实测中等桌面宽度：多产出行不再发生文字竖排，主产出与其他产出角色清晰可见。
- 发布说明、Docker 依赖检查及生产构建通过。
