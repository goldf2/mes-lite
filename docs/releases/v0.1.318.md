# MES-lite v0.1.318

日期：2026-08-10

## 更新内容

- 在 `modules/production` 增加流程转移输入契约、领域错误、业务日期编号、状态规则以及工作区查询、草稿命令和确认/冲销事务服务。
- 将记录/物料图片/库位/员工装配、草稿创建/编辑、来源库存校验、确认过账和冲销恢复迁入生产领域服务。
- 流程转移主路由、编辑、确认和冲销共 4 条 Route Handler 均移除直接 Prisma 访问，只保留权限、Schema、操作人、服务调用、审计和 HTTP 错误映射。
- 删除扁平 `lib/flow-transfer.ts`；流程转移编号改为读取业务日期最大历史序号后递增。
- 直接访问 Prisma 的 Route Handler 从 46 条降至 42 条；14 个领域/平台模块共有 253 个文件。

## 影响范围

- 页面操作和 API URL 保持兼容；保存草稿继续校验来源库位可用量，来源和目标库位必须不同。
- 确认与冲销只改变两个库位余额和成对库存流水，总库存、计价数量、总成本、单位成本及成本层保持不变。
- 本版本不修改 Prisma Schema 或数据库迁移，不自动改写本机测试数据和服务器正式数据。
