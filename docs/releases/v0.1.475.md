# MES-lite v0.1.475

## 更新内容

- 客户发货单 PDF 的二维码改为该归档版本的下载链接，并显示“如需电子档，请扫描二维码获取”。首次点击客户发货单时生成并保存；与最新客户归档比较实际展示内容，内容未变则复用，展示字段变化则另存新版。
- 下载接口免登录，但只允许持有随机链接的人读取对应客户版归档。后补价格、备注、物料/包裹展示信息或企业资料变化后重新输出会生成另一份 PDF 和二维码，旧码始终下载原版。内部成本、库位、操作人、单纯更新时间和签收变化不影响客户版本。
- 每次扫码都检查单据当前状态。已取消、已冲销或已归档时停止下载，显示具体中文说明；不存在、附件删除或文件缺失时显示不可用页面，匿名请求不会重新生成 PDF。

## 影响范围

复用销售领域发货 PDF 服务、DocumentAttachment 持久归档、附件路径解析及公共 PDF 响应。新增一个受限公开 GET/HEAD 下载入口；内部留档、原始附件和普通业务 API 保留认证。二维码链接以随机 UUID v4 绑定归档，客户缓存键升为 v2，采用与渲染共用的内容投影并纳入公网 Origin；旧单据下次输出会生成带下载码的新客户版，历史文件保留。无数据库迁移或库存写入。

同步数据模型、业务流程、功能模型、交互规范、部署地址说明、开发目录统计、SOP 清单及当前版本 Markdown。实物业务标签二维码继续使用原业务单号和登录校验。

## 验证结果

定向回归使用隔离 SQLite 和上传目录，覆盖匿名下载与归档字节一致、未填价格纸单后补价仍下载原版、客户/内部隔离、旧二维码升级、取消/冲销/归档说明、文件缺失禁止重生成，以及 Middleware 仅放行精确 GET/HEAD 地址；补充内部变更复用、关联展示字段变化产生新版及内容改回仍另存版本。TypeScript、模块边界、架构基线、SOP、开发文档和发布说明检查；PDF 排版渲染与二维码解码均在本地复核。远端 CI、主线和生产验收以发布记录中的真实结果为准。
