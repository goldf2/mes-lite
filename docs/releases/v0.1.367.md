# MES-lite v0.1.367

发布日期：2026-08-14

## 更新内容

- 归档列表改为同时校验 `archive.read` 与被归档对象的原业务 `read` 权限，未授权业务类型不再返回记录；响应只保留列表所需最小字段。
- 恢复归档同时要求 `archive.update` 与原业务 `update`，永久删除同时要求 `archive.delete` 与原业务 `delete`；前端只显示服务端确认可执行的动作。
- 来料、生产订单、派工、发货和退货归档继续叠加本人/工作中心或库位数据范围，跨范围读取、恢复和永久删除统一返回 403。
- 新增真实 HTTP 专项回归，覆盖无归档入口、仅归档入口、业务只读、业务可维护和受限库位账号。
- 更新流程 60“管理归档记录”并重新生成 141 流程的 Markdown、DOCX、PDF 与离线 Web SOP。

## 影响范围

- 不修改 Prisma Schema、迁移或生产数据；数据库仍为 77 个模型和 76 个迁移。
- 已自定义授予归档权限的非管理员账号，若缺少原业务资源权限或数据范围，将只能看到其被授权的归档类型和记录。
- Coolify 生产继续固定在 v0.1.361，Auto Deploy 保持关闭，本版本只推送代码与交付文档，不自动部署生产。

## 验证结果

- 专项回归证明归档入口权限不能替代原业务权限，原业务权限也不能替代归档入口权限；跨库位记录的读取、恢复和永久删除均返回 403。
- 运维模块结构守卫、类型检查、Lint、生产构建、20 项领域/治理 CI 基线、SOP 同步门禁及 DOCX/PDF/Web 生成与渲染检查通过。

## 回滚说明

本版本没有数据库迁移，可回退代码到 v0.1.366；回滚会重新暴露“归档权限可读取和操作全部归档对象”的越权路径，因此只应在隔离环境用于排障，不建议生产回退。回滚不需要数据恢复。
