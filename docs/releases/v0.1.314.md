# MES-lite v0.1.314

日期：2026-08-10

## 更新内容

- 新建 `modules/attachments`，集中附件输入契约、领域错误、存储规则、统一浏览器 client、查询服务和命令服务。
- 将上传落盘、预览派生文件生成、物料封面切换、旋转、归档后封面接替和草稿附件绑定/清理迁入附件服务。
- 将附件主 API 从 291 行降至 102 行、草稿 API 从 88 行降至 53 行；六条附件路由均不再直接访问 Prisma。
- `AttachmentPanel`、草稿附件面板、文档 client 与物料 client 改为复用同一附件公开 client，移除重复 CRUD 请求。
- 直接访问 Prisma 的 Route Handler 数量从 78 个降至 72 个，领域模块增至 14 个、模块文件增至 221 个。
- 扩展附件验证脚本，使用运行后删除的临时完整 SQLite 和临时上传目录覆盖完整附件生命周期。

## 影响范围

- 现有附件 URL、权限资源、上传限制、预览/下载、AI 识别入口和页面布局保持兼容。
- 文件正文仍保存在持久化上传目录，数据库只保存附件元数据；本版本不修改 Prisma Schema 或迁移。
- 本机测试 SQLite、服务器正式数据、上传存量和构建缓存均不纳入提交或测试写入。

## 验证结果

- `verify:attachment-management`、`verify:attachment-file-types` 和 `verify:module-boundaries` 通过。
- 临时库验证覆盖上传、空文件拒绝、列表、旋转、物料封面、归档接替、草稿绑定和取消时文件清理。
- TypeScript 类型检查、开发文档与版本文档校验、Next.js 生产构建均通过；构建仅保留 4 条既有 `<img>` 优化提示。
