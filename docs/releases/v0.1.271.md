# MES-lite v0.1.271

发布日期：2026-08-09

## 更新内容

- 公共二级菜单默认关闭功能图标，恢复清晰的纯文字层级。
- 顶部弹层、侧栏折叠菜单、双列导航右栏、功能搜索结果和移动抽屉统一使用同一规则。
- 一级菜单仍按“图标、图标加文字、文字”显示偏好渲染，不受本次调整影响。

## 影响范围

- 只调整二级菜单的默认视觉呈现，不改变菜单数据、排序、点击行为、工作区归属或权限。
- 保留公共菜单的 `showItemIcons` 显式扩展能力，确有需要的专用场景仍可单独开启。

## 验证结果

- TypeScript 类型检查通过。
- 响应式导航、工作区应用壳和页面模块契约验证通过。
- Next.js 生产构建通过。
