# v0.1.373 按标准启用的来料检验与红冲联动

发布日期：2026-08-14

## 更新内容

- 检验标准新增“来料入库待检”来源；已发布的物料来料标准成为自动送检的显式开关。
- 来料收货逐行分流：受控物料进入 `QUARANTINE` 并自动建立标准/抽样/项目快照任务，无标准物料保持原 `AVAILABLE` 行为；多物料来料单可以同时包含两种路径。
- 来料列表和详情展示质量状态与检验单号，收货提示本次生成任务数量；质量任务、判定和趋势支持来料来源。
- 待检来料红冲自动取消未执行任务并反向隔离库存；已合格且未被下游使用的批次可安全红冲，失败、已处置或已使用批次阻断直接红冲。
- 仓库收货与质量读取/判定保持权限分离，并继续叠加库位数据范围；没有新增平行权限资源或质量台账。
- SOP 增至 169 个流程，新增 8 张真实本地流程截图，并同步站内帮助、Markdown、DOCX、PDF 与离线 Web。

## 影响范围

- 数据库：第 81 个迁移允许 `MATERIAL_IN` 质量来源，调整取消保护并保持已完成/已取消任务不可覆盖；模型数仍为 91。
- 页面/API：复用来料管理和质量任务页面；收货接口增加生成任务数量，来料详情返回最小质量摘要；页面数、Route Handler 和权限资源仍分别为 44、149、52。
- 领域边界：`modules/receiving` 拥有收货与红冲事务，通过 `modules/quality` 公共入口完成标准查询、任务建立和质量回滚准备。
- 不包含：SPC 控制图、过程能力、供应商质量评分、原因分类主数据、多级审批和退供应商专用单据。

## 验证结果

- Prisma validate/generate、全量 81 个迁移从零重放通过。
- 来料质量领域回归覆盖显式标准、多物料分流、待检隔离、标准快照、合格放行、趋势、待检取消、未使用合格批次红冲及不合格红冲阻断。
- 真实 HTTP 回归覆盖仓管收货、质量任务 403、授权质检、跨库位隐藏与判定 403。
- 真实本地页面完成来料标准、收货前、隔离后、质量任务、逐项判定、放行、趋势和红冲取消 8 个流程截图。
- SOP、开发文档、类型检查、Lint、32 项 CI 领域基线、生产构建和本地合成候选应用级恢复演练通过。

## 部署与回滚

1. 部署前固定精确提交，完成 SQLite 与附件一致备份并校验。
2. 应用启动执行第 81 个迁移；先由质量负责人发布一个试点物料的来料标准，再用仓管员和质检员分别验收收货、任务可见性、判定与库位范围。
3. 未发布来料标准的物料不会改变原收货行为；扩展受控物料必须逐项经业务确认。
4. 应用回滚时固定到上一个已验证提交，暂停受控物料的新收货并保留来料标准、任务和取消记录，不执行破坏性降级。
5. 只有数据库/迁移损坏且应用回滚无效时，才经业务确认恢复部署前一致备份；恢复后重验登录、来料、质量、批次、库存、成本、趋势和附件连续性。
