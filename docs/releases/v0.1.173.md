# MES-lite v0.1.173

发布日期：2026-08-04

## 更新内容

- 修复在物料页面新增物料后，快速创建 BOM 的投入和产出搜索仍使用旧候选缓存的问题。
- 物料新增、编辑、导入和归档成功后统一刷新物料列表与 BOM 候选数据。
- 新物料无需刷新整个页面，即可被其他物料的快速 BOM 搜索并添加。

## 影响范围

- 影响物料管理和物料页面的快速创建 BOM 窗口。
- 不改变物料、BOM 或库存的数据结构。
- 没有 BOM 查看权限的用户不会额外请求 BOM 数据。

## 验证结果

- TypeScript 类型检查通过。
- 浏览器完成“新增物料 → 打开其他物料的快速创建 BOM → 搜索新增物料”回归验证，全程未刷新页面。
- Next.js 生产构建通过。
