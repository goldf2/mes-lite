# MES-lite v0.1.226

发布日期：2026-08-07

## 更新内容

- 文档上传完成后进入详情并在右侧直接预览新附件，不再自动打开全屏查看器；全屏预览改为用户主动操作。
- 文档详情改为桌面端左侧紧凑摘要与添加附件、右侧大预览与紧凑附件切换；移动端优先显示预览，再显示摘要和上传操作。
- 文档卡片使用主内容区可用宽度自动计算列数，并限制预览图高度，修复窄窗口突然变成超大单卡的问题。
- 中等宽度下缩小顶部搜索槽的基础宽度，使搜索、视图、高级搜索、页内选项和工具更稳定地排列。
- 公共深色按钮提示标签只响应鼠标悬停，修复高级搜索等弹层关闭、焦点回到按钮后提示标签持续不消失的问题。

## 影响范围

- 影响产品文档的卡片视图、详情布局、上传后预览和顶部公共工具提示标签。
- 不修改文件格式、存储、数据库结构、权限、搜索语义或归档规则。
- 同步更新桌面端、移动端和响应式验收规范。

## 验证结果

- 公共提示标签回归校验通过：悬停仍可显示，焦点恢复不会持续显示，面板打开时保持隐藏。
- TypeScript 无输出类型检查通过。
- 1440、1100、900、390 像素宽度下，本机页面根节点均无横向溢出。
- 文档上传函数不再直接打开全屏查看器，全屏预览仅保留在用户点击路径。
- Next.js 生产构建通过；现有 ESLint 警告未增加新的阻塞项。
